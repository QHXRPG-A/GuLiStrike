# 原主动绕侧与简易让路

本页是v4阶段记录。当前已完成v5受阻让路与邻居传递、全部6兵种0.5秒；请使用[当前操作说明](../YieldRelay20261111/操作说明.md)。以下保留当时的版本事实。

当前已加载 `demo-active-steering-yield-v4`。源码版Editor构建成功、编辑器重载、DataTable导入及200/600正式和验收清单更新完成。正式入口直接使用该实现；没有算法切换。[实施记录](implementation-status.json)与[编辑器回读](final-editor-readback.json)记录当前产物。

进入 `/Game/Maps/LVL_CommanderMassPrototype`，正常Play选择指挥官：

1. 一次框选多单位，右键同一位置集结：同一命令的成员不互相让路，包含已经落位的成员。仍使用原主动侧绕和圆形碰撞。
2. 另选一组向停驻队伍后方移动：只有首个阻挡单位小于或等于行进者，才会在行进者实际侧绕后向反侧横移。
3. 默认以让路者正常速度横移0.3秒，从下一逻辑步开始。横移时只移动和滑动，不请求第三个单位让路；随后继续原任务，停驻者留在让开处。
4. 重防号与同层低空单位交互，地面与低空互不让路。玩家操控单位不被自动横移。矿车和工程车沿用原任务，不插入临时让路任务或回位任务。

参数源表为[GuLiStrikeAvoidance.xlsx](../../data/Excel/GuLiStrikeAvoidance.xlsx)，`Units.YieldSeconds`控制各兵种作为让路者的横移时长，6个兵种初值均0.3秒。导出后在新构建编辑器运行 `Scripts/import_avoidance_data.py`，通过原目录缓存和Hybrid指纹生效；不逐帧查表。

同一模拟归属直接写入对方下一步的短暂横移状态。跨归属只向目标的现有模拟所有者发送一次接触请求，由其核对大小、移动层与命令归属后执行；不转交玩家控制权。位置仍使用原姿态同步。原来的一次NavMesh表面移动保持，不新增让路寻路或提交复核。

地图说明实体 `CircleAvoidanceReview_Entry` 位于 `(-35000,62000,1200)`；观察位置 `CircleAvoidanceReview_View` 已保留。入口已保存并[回读实体](player-entry.json)。也可自行运行既有 `Scripts/Performance/Open-CircleAvoidanceReview.ps1 -Scenario crossing`，或使用 `hold/gather/mixed`。

代码静态检查、源表导出与场景实体核对已完成；本轮未启动PIE、性能批次或视觉测试。此前[原主动绕侧性能报告](../CircularAvoidance20261110/原主动绕侧性能对比.md)不包含本次让路。
