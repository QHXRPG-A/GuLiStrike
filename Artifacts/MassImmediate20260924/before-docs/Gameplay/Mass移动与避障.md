# Mass移动与避障

本页补充[指挥官](指挥官.md)与[操作攻略](指挥官操作攻略.md)。2026-09-23的源码实现改为“算好一批、提交一批、先走一批”；此前整单完成后再启动的说明以本页为准。操作键、25米连续改令复用规则、兵种大小与终点容量沿用现有规则。

## 玩家可观察行为

一次大部队指令按最多25人的控制组规划。某批准备完成，在下一次10Hz权威步开始移动；其余士兵继续旧指令。目标较难到达时允许拆成更小路径组；一部分失败不会撤销已经开始的成员。改令、停止、死亡、运输或战局变化会废弃对应未提交结果。规划5秒无进展或30秒总期限仅终结剩余部分。

绿色细线连接**实际提交时的位置→该命令最终终点**，随着终点同步和客户端处理逐批出现。线已显示后持续存在，镜头移动不重新规划。仅显示当前选中、存活且具有有效移动指令的成员；取消选择、停止、到达、死亡、失去指挥权限或过期命令优先隐藏。等待与失败仍使用原有橙色、红色反馈。

编队偏移目标只有通过导航投影、局部连接及障碍占用校验才使用；尚未取得合法偏移时沿已验证路径中心线前进，并暂停横向归位。矿体、地面机甲参与预测避让；建筑继续使用NavMesh边界。贴障时保持绕行侧、削掉朝障碍内的速度，逐步减速至正常速度50%；离障0.6秒后才释放绕行方向。友方机甲让行保留，实际速度来自成功位移，移动失败停在最后合法位置。

## 数值速查

| 项目 | 本次实现默认值 | 范围 |
|---|---|---|
| 权威移动 | 10Hz，保持 | 与网络发送帧分开 |
| 规划CPU预算 | 2ms/世界帧 | 工作单元间检查，不能抢占引擎查询 |
| 位置/连接校验 | 最多64次/世界帧 | 四个移动/恢复入口共享 |
| 路径查询 | 最多4次/世界帧 | 游戏线程执行 |
| 提交 | 0.5ms、100成员/世界帧 | 下一权威步，25人原子批不可中途拆写 |
| 命令规划批 | 最多25人 | 路径降级可更小 |
| 超时 | 5秒无进展/30秒总计 | 旧请求等待35秒 |
| 状态流 | v19；1000字节/批、4批在途 | 与现有协议一致 |
| 客户端绿线更新 | 最多128条或0.5ms/帧 | 失效隐藏优先；每渲染块128线 |
| 贴障速度 | 平滑趋近50% | 恢复通行后逐步恢复 |
| 绕行侧释放 | 离障后0.6秒 | 避免左右翻转 |
| 局部流场 | 关闭 | 本轮基础修复不启用 |

以上预算不是性能实测结论；帧内单次不可抢占查询和原子提交可能越过时间界限，计数上限和诊断用于后续验收。

已知问题（2026-09-23）：玩家首条绿线近1秒才出现，服务端日志可见首批705～3992ms。HUD网络RTT只反映网络往返，不含共享预算下的规划排队及10Hz提交等待。现场采样未观察到绿线队列积压，已确认查询次数额度饱和及导航/障碍全局缓存失效机制；优化尚未实施，详细边界见[诊断记录](../Archive/20260923-Mass首条绿线延迟现场诊断.md)。
