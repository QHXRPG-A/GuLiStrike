# UI CPU优化与四档LOD — 实施与验收

当前运行定义见[需求](../RequirementDocument/20261020-UI CPU优化与四档LOD.md)。证据目录为 `D:/UE5.7/PerformanceCaptures/GuLiStrike/ui-four-lod-20261020`。

## 实现

- `gs.SceneUI.IndexedGeometry=1`启用共享顶点；`gs.SceneUI.OptimizedPaint=1`使几何缓存命中时跳过圆环、路线和血条准备，动态纹理、文字、HUD有效期继续更新。`GetFrameStatsJson`提供顶点、索引、批次、重建、命中、提交与分配容量。
- `EGuLiPresentationTier`表达四档；`EGuLiCommanderLODLevel`表达Full/Reduced/Minimal特效资源质量。两者通过显式映射关联，避免把资源索引当成运行档位。
- `UGuLiCommanderLODSubsystem`按World维护弱引用网格注册。静态网格（含ISM）和骨骼网格使用最小资源LOD限制，保留更粗的自动选择及已有强制粗档。注销、关闭或退出指挥官时恢复快照。
- 来源注册表只在World初始化、Actor生成和成员变化时通知网格策略。兵种批次、装配、施工、飞船部件和残骸入口补充注册/注销。
- `gs.Commander.MeshLOD=0`独立关闭网格限制。缺失资源LOD和Nanite通过`GetMeshLODStatsJson`逐组件解释。
- `Slate.EnableGlobalInvalidation`暂不改默认值，等待独立配对与动态验证。
- 模型描边仅在运行LOD0保留，LOD1/LOD2关闭，LOD3沿用模型隐藏规则。保留模型本体结构线、选择圆环及血条；复制表现模型时保留可恢复的原材质。重防号原模型资源已恢复，未改写已审网格几何。
