# 提速单位坡面卡住与子弹提前显示修复

## 现场与首个异常环节

用户反馈选中单位不移动，并在截图框出提前出现的子弹；随后明确要求调试已经开启的 PIE。当前地图为 `/Game/Maps/LVL_CommanderMassPrototype`，Standalone，游戏未暂停。调查中用户选择已变为24台战争机器；保存其身份、命令和路径，未另造一个替代现场。

1. 移动：命令223、订单645已经被24台单位接受，导航状态为 Normal，共享路径 Ready，单位可行动。24台速度均为0，连续无进展约62.6秒。抽样单位报告 `ExcessiveHeightDelta`，每台连续627次地面步进拒绝；导航引用有效，未因战斗停步。
2. 子弹：地面机枪碰撞每0.2秒结算一次，旧渲染每帧使用当前时间直接外推。8秒、506帧诊断采集316个样本、6次终止记录，最大领先结算位置476.79厘米，命中前最大越过命中点234.50厘米。此处是从运行状态按旧渲染公式计算的位置，未把它记作Niagara GPU粒子读回。

## 假设与验证

| 假设 | 结果与证据 |
|---|---|
| 选中/输入/命令没有送达 | 排除：成员24个，命令与订单一致，路径已就绪。 |
| StateTree或战斗逻辑覆盖移动 | 本现场不支持：人工订单仍有效、可行动、抽样无战斗目标。 |
| 提速使合法斜坡一步高差超过固定50厘米 | 确认：真实Commander导航坡度上限44度，400厘米水平采样中的19处被旧阈值拒绝；原地投影无高度跳变。 |
| 子弹时间轴领先碰撞结算 | 确认：实际SampleTime落后渲染时间，连续记录出现命中点后的外推位置。 |

临时将当前世界的基础移动速度从720设为100厘米/秒，保持现有命令，3秒后自动恢复为720。24台全部位移，范围约1470–2311厘米。该对照仅用于定位，未保存数值、修改卡牌或重置已取得的升级；共享Mass参数未作为最终修复改写。

## 源码修复

- `GuLiCommanderNavigationPolicy`：保留50厘米垂直步差保护，并按本次实际水平距离和导航允许坡度加入坡面高度变化额度。默认坡度参数为0，原四参调用语义保留。正常移动和让位移动两处调用使用真实Recast设置；旧引用的原地修复仍保留50厘米限制。
- `GuLiProjectilePoolSubsystem`：地面弹完成碰撞扫掠后发布递增序号和已确认SampleTime；发射计数只累计序号1，防止每次位置确认被重复算作发射。
- `GuLiCombatEffectTypes / ReplicationComponent`：复用5Hz地面弹快照，增加4字节确认时间，客户端由起点、速度和确认时间重建位置；不额外建立逐弹修正RPC通道。联机双方需使用同一新版原生构建。
- `GuLiCombatEffectLaserPresentation / PresentationSubsystem`：地面弹按一个碰撞周期缓冲，并限制播放时间不越过已确认扫掠。命中位置、尾迹和命中特效使用同一播放时间，避免飞过目标再回跳。僚机和玩家弹的时间轴保持原实现。
- 用户补充“移速越快越明显”后，确认第三个原因：模型显示追赶上限仍按基础速度720×3=2160厘米/秒计算，低于五张机动卡后的5467.5厘米/秒，表现位置因而持续落后。`GuLiCommanderGameState`发布按阵营、兵种生效的移动倍率；权威升级和重置同步更新，`GuLiCommanderPresentationActor`据此计算逐单位追赶速度及预测速度。
- 本次不修改Niagara、材质、美术资源、伤害规则或碰撞频率。

## 编译与原生PIE复验

- 用户明确回复“编译”“继续”，使用源码版 `D:/UnrealEngine-5.7` 构建 `GuLiStrikeEditor Win64 Development`。两轮构建均退出0，最终构建19.88秒；引擎与项目BuildId均为 `dd3ee083-a0fd-45c8-814e-67fe5ef95e31`。重启编辑器后采集以下结果，最终14个源码文件哈希与构建记录完全一致，`git diff --check`通过。
- 使用真实F4选牌入口叠加五张机动卡，基础速度保持720，升级后实测单位配置5467.5厘米/秒。
- 坡面：正常有序选兵/移动命令通道控制单位670，从 `(-17740,14340,-1598)` 到 `(-9000,14500,-429)`，约5秒观察期内到达目标，抬升约1169厘米。13个连续单模拟步的高度变化超过旧50厘米阈值，最终无进展计时为0。
- 模型：原生追踪记录443帧，显示位置与同一播放时刻的权威历史位置差为0（CSV精度0.001厘米）；实际显示速度最高约5596厘米/秒，不再被旧2160厘米/秒上限持续拖后。此结论不表示服务器当前时间与显示时间之间没有插值延迟。
- 子弹：15秒内从原生Niagara CPU上传数组匹配616个样本，头部领先已确认碰撞位置的最大数值误差约0.035厘米；其中489个样本可用真实EffectId关联命中，越过最终命中点的最大数值误差约0.0014厘米。86个未匹配样本排除，不将其推定为通过。该证据不是GPU像素读回。
- 未运行自动化测试套件、联机多端回归或性能基准；玩家画面效果尚未确认。调试脚本曾遇到受保护属性、快速移动目标点击未选中及GUID包装对象身份问题，修正采样后重新取得上述有效结果，失败的准备记录保留供追溯。
