# 开局席位选择UI — 实施与交付

## 实现

界面发生在PIE世界和网络会话创建之前，因此使用GuLiStrikeEditor内的Slate模态窗口。三个竖排按钮展示指挥官、游骑兵和巡天，底部显示当前选择以及取消、进入战场按钮。选择只修改窗口内部状态；确认返回已有EGuLiCommanderRole，由LocalPIESubsystem写入本次启动Config.Role，继续现有身份和Pawn分配。

| 文件 | 职责 |
|---|---|
| Source/GuLiStrikeEditor/Private/GuLiLocalPIERolePicker.h/.cpp | 原生Slate窗口、当前选择、键盘取消、焦点与关闭生命周期。 |
| Source/GuLiStrikeEditor/Public/GuLiLocalPIESubsystem.h | 新增默认开启的bPromptForRole配置。 |
| Source/GuLiStrikeEditor/Private/GuLiLocalPIESubsystem.cpp | 在进程和会话目录创建前取得选择；只在当前编辑器会话记忆上次确认项。 |
| Config/DefaultEditor.ini | 明确启用开局选择，MainRole=Ground保留为初始选项和非交互入口配置。 |
| Scripts/prepare_local_pie_role_picker_scene.py | 在对应原图保存入口说明Note并读取实体，不启动游戏。 |

现有模块已依赖Slate、SlateCore、InputCore和UnrealEd，无新增模块或插件。接口只在编辑器模块内部，不增加运行时RPC或兵种字段。原资源和导航检查仍先执行，清单仍为正常600兵，选择后才创建Coordinator和逻辑端。

## UI合同

- 所有权：Show函数持有窗口和内容，子控件通过弱窗口引用请求关闭；无永久Tick、计时器或全局UI委托。
- 数据：初始取上次确认项或MainRole，按钮点击更新选择，确认返回枚举；显示控件不直接修改游戏对象。
- 输入：模态窗口接管输入，初始焦点放在当前角色按钮；Tab及按钮标准键盘操作可用，Esc捕获为取消。关闭后恢复之前的编辑器焦点，真正PIE开始后的焦点由原引擎流程接管。
- 尺寸：窗口自动置于可用工作区，启用安全位置约束；角色区可滚动，标题和操作栏固定在上下两端，无悬浮提示弹层。
- 清理：确认/取消请求销毁窗口；关闭标题栏等价取消，未选择时不创建会话目录或后台进程。重复新开局创建新窗口。
- 配色：依据美术规范v1.12第11节，背景#021716、面板#032E30、悬停#274E61、按下#0A6F73、选择#6AA4BE、文字#FEE4D9；按sRGB转换到线性值，无场景灯光或后处理影响。
