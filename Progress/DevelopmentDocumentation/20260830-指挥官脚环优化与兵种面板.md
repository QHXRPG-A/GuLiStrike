# 指挥官脚环优化与兵种面板 — 技术方案

- 对应需求：[指挥官脚环优化与兵种面板](../RequirementDocument/20260830-指挥官脚环优化与兵种面板.md)

## 技术选型

复用现有 UMG 资产与 C++ HUD 适配层。兵种汇总为本地纯数据结构，通过选择、ACK、可靠状态及玩家同步事件刷新，不改变网络合同。先以 Soldier ID 去重，再一次扫描可靠状态，同时计算存活数、当前/最大生命和命令分布。

脚环继续复用同一 ISM 和 4 个实例参数。新增静态网格局部外半径 48cm、内半径 34cm，配合原 `12,12,0.02` 缩放得到约 576cm/408cm；单面 128 三角形取代圆柱。材质直接使用实例 RGB × 3 与 Alpha × 0.58，保留半透明与关闭深度测试。其代价是遮挡处仍参与绘制；本轮按明确需求保留，不使用逐兵坡地检测。

标题使用小型 UI 材质按像素宽高构造 45° 斜切边，避免外部纹理依赖。保留现有底坞、顶部和地图的容器与输入阻挡范围。脚环构建命令保存旧材质独立副本以便同一二进制、同一场景 A/B 验证。
