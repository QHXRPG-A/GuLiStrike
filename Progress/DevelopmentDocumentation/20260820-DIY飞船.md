## 技术选型

| 决策点 | 结论 | 为什么不用 X |
|---|---|---|
| 主体类型 | `AGuLiStrikeShip : ACharacter` | 用户定稿；Character 自带胶囊碰撞 + CharacterMovement(Flying) 即可做 6DOF 街机飞行。不用 Pawn+FloatingPawnMovement（用户要求 Character）；不继承现有 `AGuLiStrikeCharacter`（那套绑定俯视相机与平面约束，twin-stick 专用） |
| 部件表示 | `UGuLiStrikeShipPartComponent : UStaticMeshComponent`，具体部件 = 蓝图组件子类 | 用户定稿"部件=组件"；直接继承网格组件免去双层包装；蓝图子类填网格/材质/数值/兼容槽位，加部件零代码。不用 DataAsset+动态生成网格（用户架构为先组件类） |
| 槽位实现 | 舰体 StaticMesh 上加 socket（**用户手动加**，见下方教程） | Python 的 `StaticMesh.sockets` 属性 protected 读写被拦（已实测）、`EditorStaticMeshLibrary`/`StaticMeshEditorSubsystem` 无 socket API（已实测）；C++ 工具函数方案被用户改为手动添加，量少（7 个）可接受 |
| 兼容性 | 部件上 `TArray<FName> CompatibleSockets` | 用户定稿"接入名集合"；一个部件可接多个槽位（火箭巢示例） |
| 6DOF 移动 | CharacterMovement `MOVE_Flying` + 关平面约束；WASD 局部平移、鼠标 pitch/yaw、Q/E 滚转（`AddActorLocalRotation`） | 不用物理仿真（FloatingPawn/ChaosVehicle 引入复杂度且用户选了 Character 路线） |
| 武器实现 | 遍历已装武器部件，按各自射速从部件世界变换生成现有 `AGuLiStrikeProjectile` | 复用现有投射物；GAS 虽启用但项目零使用（Build.cs 无依赖），不为此引入 |
| 输入 | EnhancedInput：`IMC_Ship` + IA_Ship_*（Thrust/Look/Roll/Fire/Boost/CycleEngine/CycleWeapon） | 项目全EnhancedInput；Python 建映射若有 API 缺口退 C++ `BindKey`（项目有先例 GuLiStrikeCharacter.cpp:117） |

## 核心接口设计（C++）

```
UGuLiStrikeShipPartComponent : UStaticMeshComponent
  ├─ CompatibleSockets: TArray<FName>          // 可接入槽位名集合
  ├─ PartRelativeTransform: FTransform          // 相对 socket 的微调（位置/朝向/缩放）
  ├─ PartMass: float
  ├─ CanAttachToSocket(FName) → bool
UGuLiStrikeEnginePart : UGuLiStrikeShipPartComponent
  └─ Thrust: float
UGuLiStrikeWeaponPart : UGuLiStrikeShipPartComponent
  └─ Damage / FireRate / ProjectileClass / MuzzleOffset

AGuLiStrikeShip : ACharacter
  ├─ HullMesh(StaticMeshComponent, virgon) + SpringArm(追尾) + Camera
  ├─ DefaultParts: TArray<{SocketName, PartClass}>     // 出生自带配置
  ├─ PartCatalogue: TArray<PartClass>                   // 全量部件类，热切换在其中循环
  ├─ InstallPart(Class, SocketName) → bool              // 兼容校验→销毁旧→NewObject→挂 socket→注册→重算
  ├─ UninstallPart(SocketName) / GetPartAt(SocketName)
  ├─ CycleEngineParts() / CycleWeaponParts()            // 热切换按键入口
  ├─ RecomputeStats()                                   // Σ推力/Σ质量→推重比→Movement 参数
  └─ Fire()                                             // 遍历武器部件按射速出弹
```

## 手动加 Socket 教程（用户操作）

资产：`Content/Assets/Arma/CombatAvatarFly/bsg_virgon_express_carina/StaticMeshes/bsg_virgon_express_carina`

1. 内容浏览器双击该网格体 → 打开静态网格编辑器
2. 菜单 **Window → Socket Manager** 打开 socket 面板
3. 面板点 **Create Socket**（+ 号），把新建 socket 重命名为下表名字
4. 保持 socket 选中，在 **Details** 面板里直接抄下表的 **Relative Location / Relative Rotation**（单位 cm / 度）
5. 7 个加完后 **Ctrl+S** 保存资产

Socket 坐标表（✅ 已按几何质心验证的朝向定稿：+X=艏、-X=艉，直接抄数值即可）：

| Socket 名 | Relative Location | Relative Rotation | 用途 |
|---|---|---|---|
| HP_Engine_L | (-6500, -1100, 0) | (0, 180, 0) | 左引擎（喷口朝 -X 艉部） |
| HP_Engine_R | (-6500, 1100, 0) | (0, 180, 0) | 右引擎 |
| HP_Engine_T | (-6300, 0, 1800) | (0, 180, 0) | 顶部引擎 |
| HP_Weapon_Nose | (6900, 0, -300) | (0, 0, 0) | 艏部武器 |
| HP_Weapon_L | (2500, -2600, 300) | (0, 0, 0) | 左舷武器 |
| HP_Weapon_R | (2500, 2600, 300) | (0, 0, 0) | 右舷武器 |
| HP_Utility_Belly | (0, 0, -3700) | (0, 0, 180) | 腹部辅助槽 |

说明：socket 的 +X 朝向 = 部件的"前方"。引擎槽转 180° 使部件喷口朝艉部；武器槽不转（部件朝艏）。部件蓝图里还有 `PartRelativeTransform` 可再微调。
