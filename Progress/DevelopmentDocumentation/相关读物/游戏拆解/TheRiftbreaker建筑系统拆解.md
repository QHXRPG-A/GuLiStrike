# 《The Riftbreaker（银河破裂者）》拆解：以建筑系统为核心

- 调研日期：2026-09-17。资料来源为官方 Fandom Wiki、GameCore Wiki、Steam 社区指南与官方公告（见文末来源清单）；社区来源的数字均已标注。
- 拆解目的：为 GuLiStrike 建筑玩法（[基地建造玩法探索](../../../RequirementDocument/20260831-基地建造玩法探索.md)、[建筑玩法总册](../../../Gameplay/建筑.md)）提供参考。本文只描述《The Riftbreaker》的事实与设计意图，不构成对 GuLiStrike 的规则决定。
- 引擎注意：本作使用 EXOR 自研 Schmetterling 引擎、俯视角 3D、格子地面；所有"格"均为游戏内建造格。

## 一、游戏概况

- 开发商 EXOR Studios（前作《X-Morph: Defense》，塔防+弹幕射击混血），2021 年 10 月发售，持续更新至 2.x：世界扩展包与 DLC《Metal Terror》《Heart of the Swamp》《Into the Dark》（新增地下矿层与晶体建筑套件），2.0 加入合作模式。
- 类型：**基地建造 + 双摇杆机甲动作 + 生存防御**。玩家操纵机甲驾驶员 Ashley 与机甲 Mr. Riggs，单人即可完成全部建造与战斗；**没有独立的建造单位**，"建造者"就是玩家自己。
- 模式：战役（多生物群系地图，主线是建双向裂隙传送门回地球）、生存（定时波次）、沙盒（自由建造与蓝图保存/加载）。

## 二、核心循环

```
空降选址 → 建总部(HQ)+矿场+电力 → 采碳/铁扩军备
→ 攒资源/升HQ 触发敌潮 → 城墙+炮塔+机甲协防
→ 实验室研究解锁更高梯级 → 地热/核能/合成器摆脱矿脉依赖
→ 前哨(Outpost)扩张到外区地图 → 稀有资源/巨构 → 终局
```

设计要点：**进攻压力与经济发展同源**。敌潮强度不是纯时间驱动，而是由玩家自己的发展行为（囤积稀有资源、升级 HQ、建裂隙站/巨构）触发——玩家越贪，打得越狠，节奏掌握在玩家手里。

## 三、建造交互与 UX

| 机制 | 说明 |
|---|---|
| 建造菜单 | CTRL 打开两行径向/条形菜单：第一行是分类（热键 Z–N），第二行是该分类下的具体建筑；选中后在地面蓝格上点击放置 |
| 直接放高级梯 | 按住 ALT 放置的是已研究的高等级版本 |
| 拖拽批建 | 围墙、地板、电线支持拖线/拖块批量放置 |
| 无建造单位 | 支付资源后蓝图自建，按建造时间完成；机甲模块可减建造时间/费用（建造速度 −4/8/12/16%，维护工具 −16% 费用） |
| 无建造半径 | 建筑可放在任意有效蓝格（ explored 且地形允许），**实际扩张骨架是电网**（见第五节）；地形障碍（悬崖、深渊、液体）敌人不可通行，是天然城址 |
| 穿行规则 | **非军事建筑对单位无碰撞**（发电机、矿场等可穿过），可密集排布；城墙/塔等军事建筑阻挡双方 |
| 批量工具 | 后期版本补齐：批量升级（工具页点选多座）、批量维修（原地重建被毁建筑）、拆除工具（清废墟并返还部分资源）；被毁建筑留下程序化生成的废墟 |
| 信息呈现 | 建造模式下矿脉显示剩余量（悬停单格有精确值）；小地图边缘显示当前太阳能/风电出力百分比 |

UX 设计意图：把 RTS 的"选农民→走到→修"整段砍掉，建造决策=选址+资源，不产生操作负荷；风险全部转移到"建好后怎么守"。

## 四、建筑分类（六大类）

来源：Fandom Wiki Building 页。战役限定建筑标注（战役）。

### 1. 主建筑

- **Headquarters 总部**：7×8 格；1–7 级（费用 200/200 → 25000/25000 碳+铁；血量 5000→11000；产能 +20→+1280 能量/秒；2 级起建造 120 秒）；提供复活点、任意距离传送回 HQ 的裂隙跳转、半径 8 内每秒治疗机甲（20→50）；自带基础仓储（1000 能量、每种稀有资源 50、各类塔弹药 1）。**升级 HQ 会激怒敌潮**。
- **Armory 军械库**：研究机甲武器/模块、制造机甲弹药。
- **Laboratory 实验室**：研究建筑科技树。
- **Communication Hub 通讯枢纽**：解锁后续研究与雷达能力（地热等可再生资源研究需要它）。
- **Outpost 前哨**（战役）：2×2 格迷你 HQ，费用 1000+1000、300 秒建造、2000 血、+20 能量/秒、同样给复活点/传送/半径 8 治疗；**上限 8 座**，不能建在裂隙传送门附近；核心作用是把外区地图的资源经裂隙传回主基地。
- 其余（战役）：Orbital Scanner、Rift Station（回地球的主线传送门）、各类稳定器、Weather Control Station 等，多为任务巨构的前置。

### 2. 能源建筑（详见第五节）

Solar Panel、Wind Turbine、Geothermal / Gas / Nuclear / Fusion / Magma Powerplant、Carbonium Powerplant（烧碳发电）、Plant/Animal Biomass Powerplant、Energy Storage（储能）、Energy Connector / Energy Pylon（电网连接器/电线杆）。

### 3. 防御建筑（详见第七节）

墙与门（多材质多梯级+DLC 变体）、Heightened Wall Floor（抬高地台）、各类炮塔（按弹药/伤害类型分组）、AI Hub（AI 核心）、Repair Facility（维修厂）、Shield Generator（护盾塔）、Short Range Radar（雷达）、Mine Layer Tower（布雷塔）、Rift Portal（玩家传送点）、六系陷阱（上限 25，研究升至 50/75）。

### 4. 资源建筑（详见第六节）

矿场（Carbonium/Ironium Factory、Rare Element Mine、Drone Mine）、仓储（固体/液体/弹药库）、转换器（碳/铁合成器、气体过滤、生物堆肥、生物质冷凝、电离器、超冷精炼、等离子转换、铀离心机、水过滤、**塔弹药工厂**）、生物质开发（Harvesting Station、Flora Cultivator）、液体开发（液体泵、管道、压缩机/解压器、气体提取器）、Crystal/Loot Collector。

### 5. 装饰建筑

灯、地板、旗杆、花盆、雕像——纯表现，无功能（沙盒/美化用）。

### 6. 巨构（战役终局， DLC 扩展）

Quantum Cortex Laboratory、Arcology Workshop、Nanobot Center、Hydroponic Laboratory、Gravitational Hyper Lens、Mega Rift Station 等；每种限建一座，**建造或升级触发比裂隙站更强的敌潮**。选择不回地球才解锁该科技树。

## 五、电力系统：用电网代替建造半径

- **能量是全局池**（每张地图独立）：发电建筑每秒产出、耗电建筑每秒扣除，Energy Storage 平滑昼夜与峰值（推荐太阳能:储能 ≈ 3:1）。
- **电网是物理网络**：发电与用电建筑要通过 Energy Connector / Energy Pylon 连成网络；扩张远处矿区=拉电线过去。社区共识：用便宜的风电/太阳能"电力走廊"连接分基地。
- **昼夜循环**：太阳能仅白天发电（80/格），夜里靠储能或风电（T3 48）顶——发电结构本身有布局博弈。
- 发电梯级（社区指南数字，每级可研究翻倍）：

| 电源 | 出力（1/2/3 级） | 条件/消耗 |
|---|---|---|
| 太阳能 | 80（仅白天） | 无消耗 |
| 风电 | →48（T3） | 无消耗、无需储能 |
| 碳电厂 | 50/150 | 烧碳 |
| 生物质电厂 | 100/200 | 1 物质/秒（配合种植链可再生） |
| 地热 | 200/400/800 | 必须建在地热口上；火山生物群系 ×2 |
| 气电厂 | 500/750/1000 | 50 气/秒 |
| 核电/聚变 | 更高梯级 | HQ 3/4 解锁研究 |
| 岩浆 | 500+ | 需冷却塔（DLC 深层） |

- **缺电行为优雅降级**：优先保炮塔，矿场在炮塔开火时自动停产、打完恢复——停电不会瞬间崩盘，而是产出降级。
- 设计意图：电网把"扩张范围"变成需要经营与防御的实体资产（电线是可被切断的软肋），比抽象的建造半径多了攻防目标。

## 六、资源与生产链

### 矿业：脚印式开采

- 矿场建在矿脉上，**3×3 脚印覆盖多少矿石格决定矿脉寿命，不决定速度**：1 级矿恒 +1/秒。同一 16 格矿脉：盖 1 座（9 格）= 1/秒慢慢采；盖 4 座 = 4/秒快速抽干。矿场每座 −20 电力。
- 稀有元素矿同理，且**囤积稀有资源超过阈值（社区实测约 5000）会触发专门的大规模敌潮**——采集本身就是挑衅。
- 矿脉有限会耗尽，逼迫转型：地热/生物质/合成器（500–800 能量/秒换 2–4 碳或铁/秒）实现"电力→物质"，后期摆脱矿脉选址约束。

### 仓储

- HQ 自带少量仓储；Solid/Liquid/Ammo Storage 扩容（社区建议 ~1 万起步，研究后 3–4 万）。仓储不足时溢出浪费。

### 液体与气体链

液体泵（建在液池上）→ 管道运输 → 过滤/转换（泥浆 200→水 100；气体过滤厂 100 泥浆→25/50/75 气）→ 供气电厂/精炼。是第二层"选址+管路"玩法。

### 生物质链（可再生电力）

Flora Cultivator（种植无人机）+ Harvesting Station（收割）→ Plant Biomass Powerplant。社区配比：1 种植器 + 3–4 收割器净赚约 150 能量/秒。种植器需要开阔空地——又是一个选址约束。

### 塔弹药链

- 炮塔分**能量塔**（直接耗电）与**实弹塔**（低口径/高口径/爆炸/液体四类弹药池，全图同类共享）。
- Tower Ammo Factory 用基础资源生产塔弹药，Ammo Storage 扩容。弹药链让"防御强度"成为持续运转的后勤系统，而非一次性投资。

## 七、防御体系

### 墙与门户

多材质/梯级墙与门（含 DLC 能量墙、晶体墙、藤蔓墙），可拖拽批建；社区标准是**双层墙 + 炮塔嵌墙**（塔替代某段墙）。建议堡垒占地约 18×18。抬高地台（Heightened Wall Floor）让后排塔越过前排射击。

### 炮塔分组（按弹药类型）

| 组 | 代表 | 射程（格） | 定位 |
|---|---|---|---|
| 低口径 | Minigun | ~14 | 便宜持续输出 |
| 高口径 | Shotgun | ~14–15 | 近距爆发 |
| 能量 | Laser/Gatling Laser/Plasma/Railgun/Sentinel/Lightning | 14–15（Sentinel 等） | 耗电、精确、反装甲 |
| 爆炸 | Artillery / Heavy Artillery (Bertha) | ~30 / 90（10 格溅射） | 远程压制、反成群 |
| 液体 | Flamer / Acid Spitter / Shockwave | 10–11 / 7 | 反小快怪（火/酸）、近距击退（震波） |
| 特殊 | Attack Drone Tower、Mine Layer (~20)、Power Rod、HCM | — | 无人机/布雷/超远程 |

### AI Hub：炮塔的软人口上限

- 每座智能炮塔需要 **AI 核心**才能运转；AI Hub 生产核心，核心池**全图共享**。社区经验控制在 ~30 核以内（耗电大）。
- 效果等同 RTS 人口上限，但它是"可被摧毁的建筑+可扩展的产能"，防御纵深里多了一层高价值目标。

### 维修与护盾

- **Repair Facility**：半径 11 内自动派无人机维修建筑，耗电+钴（Cobalt）；规划城墙时要让维修圈覆盖所有受击面。
- **Shield Generator**：半径 8 区域护盾。
- 机甲在 HQ 半径内免费回血；维修包按梯级回复 25–100%。

### 玩家与基地的协防

官方指南明确"不要只靠炮塔"：敌人沿路径攻击**第一座遇到的建筑**（吐酸怪优先打塔），轰炸甲虫能越过悬崖轰击——墙的走向（迷宫化）、塔的射程覆盖与机甲的走位补伤共同构成防御。自然屏障（悬崖/深渊/液体）不可被地面敌通过，选址时是免费城墙。

## 八、威胁与波次：发展即挑衅

| 触发源 | 效果 |
|---|---|
| 囤积稀有资源过阈值（社区实测约 5000） | 该资源专属大规模敌潮 |
| 升级 HQ | 激怒敌潮 |
| 建造/升级裂隙站、巨构 | 比普通波更强的特攻 |
| 袭扰本地巢穴、在其附近建造 | 局部小规模报复 |
| 种田/收割生物质 | **不**激怒（官方刻意放过农业链） |
| 难度与时间 | 波次强度随难度设定和游戏进程内的怪物强度等级缩放；自定义难度可调波次强度/每波攻击组数/频率 |

设计意图：把"塔防波次定时器"换成"玩家行为的反馈"——想安稳发育就压着阈值走，想搏一把就故意攒资源引怪。威胁是可计算的经营决策。

## 九、科技与升级

- 实验室（建筑科技）与军械库（机甲）双树，通讯枢纽解锁深层；HQ 等级是梯级门槛（太阳能/风电→地热/生物质/核电→气电→聚变对应 HQ1→4）。
- 大多数建筑 3 级；可再生能源研究让太阳能/风/地热/生物质**每级产量翻倍**；单建筑升级（建造模式点选）或批量升级（工具页）皆可。
- 陷阱上限 25→50→75 也走研究。

## 十、战役多地图与前哨物流

- 主 HQ 固定在主地图；通过裂隙传送到各生物群系地图采集稀有资源（每张图特产金属）。
- **Outpost 是跨地图经济的钥匙**：在目标图建前哨（上限 8）后，该图资源即并入全局池（社区与官方讨论证实）；AI 核心**不跨图**，每图需重建（社区来源）。
- 离玩家所在图以外的基地继续运转（时间不暂停，社区问答证实），因此外区前哨必须自持：社区方案"1 矿场 + 2 风机"即电力自洽，或加维修塔与少量防御。
- 2.0 合作更新进一步强化"在富矿图设资源前哨"的玩法。

## 十一、对 GuLiStrike 的启示（对照，不构成决定）

对照对象：[基地建造玩法探索](../../../RequirementDocument/20260831-基地建造玩法探索.md)（工程单位护送、容量限制、丢点停机）与[建筑玩法总册](../../../Gameplay/建筑.md)（B 键建造、六种建筑、蓝红矿事务、建造车施工、占领与维护）。

1. **建造摩擦的两个极端**：Riftbreaker 零摩擦（自建、无半径）因为它是单人 PvE，乐趣全在"建成后的攻防"；GuLiStrike 用工程车施工制造护送协作，是 PvP 团队化的另一极。草案担心的"护送是否只是操作负担"恰好是两者的分界线——Riftbreaker 的经验说明：如果协作价值立不住，砍掉摩擦并不损失深度。
2. **电网 vs 抽象容量**：Riftbreaker 用实体电网承担"扩张范围+可打击软肋"两个职能。GuLiStrike 现在用"当地容量"约束，更适合短局 PvP；实体电网可作为以后 PvE/持久战模式的候选，把"占点"变成"占并护线"。
3. **弹药/维修后勤制造防御衰减**：炮塔吃弹药池+维修厂耗钴，让纯龟缩有持续成本。对 GuLiStrike 的护盾维护、维修站候选是直接佐证：防守建筑应有"运转成本"而不只是建造成本。
4. **AI 核心式软上限**：用"共享核心池+可摧毁的生产建筑"替代硬性炮塔数量上限，比全局数值上限更有攻防目标感。可作为指挥官建筑上限的替代方案评估。
5. **发展即挑衅**：囤资源/升级触发敌潮的思路，可映射为"蓝矿库存/建造进度提升敌方战略点压力或暴露度"，给经济决策加风险维度；但 PvP 双方对称时需要不同的平衡锚点。
6. **脚印采矿**：矿场覆盖矿格数决定寿命而非速度——简单规则同时产生"密集抽干 vs 均匀细水长流"的抉择。GuLiStrike 已有密度涂绘的矿点数据，可对照评估。
7. **非军事建筑无碰撞**：一条低成本规则同时解决基地内部通行与"巨型战争机器过基地"问题（草案明确要求保留大单位通行空间），值得直接借鉴。
8. **批量工具的时机**：Riftbreaker 发售后才补批量升级/维修/拆除，说明建筑数量上去后逐个点选是真实痛点；GuLiStrike 指挥官建造 UI 应预留框选批量操作。
9. **废墟与重建**：被毁建筑留废墟、维修工具原地付费重建，比"从零重摆"保留玩家的布局心血，也符合"丢点先失去功能、可恢复"的草案方向。
10. **前哨=迷你 HQ+资源回传**：与 GuLiStrike 前哨/据点思路同构；差异在 Riftbreaker 的前哨本身是跨图物流节点。若未来引入多战区，可参考"前哨打通资源池、但特殊物资不跨区"的取舍。
