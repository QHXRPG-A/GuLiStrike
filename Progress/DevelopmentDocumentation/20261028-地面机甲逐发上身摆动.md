# 地面机甲逐发上身摆动

## 实现

- `GuLiStrikeMech.xlsx / Gait / Shoot` 新增 `UpperBodyRecoilLeftAsset`、`UpperBodyRecoilRightAsset`、`UpperBodyRecoilScale=0.35`、`UpperBodyRecoilMaxDegrees=8`。引用 A4B2 当前 Rocket_L/R，其他 Gait 行默认空引用/零参数；C++ 行结构由标准导出器生成。
- AnimInstance 在允许表现的客户端准备阶段解析两段同骨架、非加法参考，缓存每帧 `MiddleJoint` 的组件空间旋转相对首帧增量，强引用持有资源。丢弃位移，首尾旋转归零；专服不加载新增参考。缓存按配置指纹与骨架复用，缺少任一兼容参考时关闭新增效果。
- 复用 `TriggerIntegratedRecoil` 的实际射击年龄、左右索引及原有迟到事件保护。把每侧参考完整周期映射到 0.24 秒，从当前旋转衔接重触发；用旋转向量合成、限幅，再按 `1-BlinkPose.X` 衰减。重置、解除占有或外部位移清除残留。
- `UpperBodyRecoilRotation` 作为一个新增只读输入传到原瞄准节点；先绕胸舱枢轴旋转 `cockpit` 及双臂，再按既有流程计算瞄准、肩部制退、枪管后坐及闪现姿态。`MiddleJoint`、腿部与足部 IK 不被武器层覆盖。
- `BindUpperBodyRecoil` 只重建现有瞄准节点的引脚并增加一个变量连接；对比所有原连接签名，拒绝丢线结果。不调用全图重建。
