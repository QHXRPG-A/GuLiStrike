# 三张视差3D卡牌交互演示 — 技术方案

## 技术选型与边界

动画与流程行为采用蓝图与材质；用户追加授权一个只读 C++ 焦点接口和 `GuLiStrikeEditor` 编译。Python 脚本仅用于编辑器制作与验证，不是运行依赖。复用原有五层网格组合和视差牌面；RewardCards 提供卡背贴图。商城源资产未修改。

镜头朝向 -Y，卡牌宽度沿 X、高度沿 Z，垂直翻转轴为 Z。位置根与悬停、翻面节点分离。流程管理器保存阶段和阶段时间，左键采用 Enhanced Input Started；阶段入口与完成清理均有防重入约束。

2026-09-22 根据用户追加“力度再大50%”，最大偏转由每轴 ±8° 调为 **±12°**，插值速度保持 12。牌面材质赋值后预取纹理 5 秒，减少首次入场的低清贴图等待。

## 参数与接口

管理器 `Presentation Tuning` 分类中可调：`EntryDuration=0.5`（每张）、`FlipDuration=0.45`、`FlashDuration=0.25`、`ExitDuration=0.5`、`MaximumTilt=12`、`HoverInterpSpeed=12`、`FlashIntensity=8`、`CameraDistance=140`、`HorizontalFOV=50`、`FarDistance=1100`。闪光材质另有 `FlashColor`，动态材质用 `Progress` 推动包络。

`UGuLiCardRevealViewportLibrary::IsCardRevealViewportFocused(PlayerController)` 是唯一新增原生 API，`BlueprintPure`，只读本地玩家对应游戏窗口的激活状态。无有效本地玩家、无游戏视口、Slate 未初始化或窗口/应用失活均返回 false。允许同一游戏窗口内的 UI 获得键盘焦点；不保存对象、不订阅生命周期、不增加 Tick、无 RPC。复用项目现有 Engine / Slate / SlateCore 依赖，未改 Build.cs。管理器每帧的 `UpdatePointer` 与点击时的重新命中共用此接口；失活时目标偏转变零，由原有插值回正。控制器初始化时设置游戏视口焦点。

`StartPresentation()` 仅完成阶段可进入；`OnPresentationFinished(SelectedIndex)` 在清理之后广播，索引 0 / 1 / 2 对应左 / 中 / 右。演示地图的 PlayerController 负责初始化相机、HUD 与输入上下文；重播按钮委托回到管理器。

卡牌层级为 `PositionRoot → HoverPivot → FlipPivot → ArtworkCenter → 牌面/文字/框/装饰/卡背`；局部闪光独立附着在位置根。命中使用未倾斜的屏幕矩形，视觉角度不会改变命中区域。地图只放置管理器、主光、环境光、玩家起点；三张牌由管理器在运行时创建。

- 运行验证：真实 PIE 中完成 69 项检查记录（包括截图写入检查），见 `runtime-live.json`。验证了 0.5 / 1.0 / 1.5 秒落位，中心/四边/四角压动，离开牌面回正，分别选择 0/1/2，翻面时忽略点击，空白/他牌不可确认，持有第一次 Enhanced Input 输入跨越翻面后不自动确认，新一次按下才确认，清理和 HUD 重播委托。

## 闪光视觉记录

同一相机和参数下记录 `t=0`、`t=0.055`、`t=0.22` 秒。助手已查看：起始无白块；峰值是所选卡中心的白金亮点与局部辉光；后段扩散变淡，周围卡牌与背景保持可读。三张牌在 0.25 秒后共同退场，完成阶段只剩提示与重播按钮。此项是助手预览记录，**用户尚未验收**。

## 已知限制与恢复记录

- Windows 窗口失焦的初版限制已通过追加授权处理：蓝图生命周期回调不足以覆盖桌面窗口，现在直接读取 Slate 应用与该玩家游戏窗口的激活状态。最终 Alt+Tab 手感仍保留为玩家验收项。
- 最早在 PIE 中产生的空卡牌包滞留于编辑器内存，导致一次预览编译失败。用户关闭弹窗后，重建组件又触发了生成模板重名断言；磁盘完整蓝图未被该次失败覆盖。已将生成脚本改为复用现有组件，重启后重新加载并编译、保存、运行验证成功。最新检查以 `final-validation.json` 与 `runtime-live.json` 为准，早期探测/失败日志不作为成功证据。
- 可视化工具的离屏 `Shot showui` 曾截到编辑器视口；最终图片已由正常 PIE 窗口重新采集。未使用该错误截图作为 HUD 或效果验收。

## 玩家操作与预期

打开专用 Map，Play。等待三张依次落位，将鼠标移到卡牌边角观察压动。点击任意一张，等待其翻到卡背，再单击该牌确认：局部闪光后三张一起离开。点击“重新播放”重新开始。
