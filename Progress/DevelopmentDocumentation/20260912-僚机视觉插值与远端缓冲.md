# 僚机视觉插值与远端缓冲 — 技术方案

## 技术选型与边界

在 `CollisionRoot` 与 `VisualMesh` 之间加入无碰撞的 `PresentationRoot`。MovementComponent仍是Pawn根Transform唯一写者，并保存最近两个完整固定步Transform；每次客户端帧推进结束后，以 `FixedStepAccumulator / FixedStepSeconds` 计算显示Alpha，将插值结果只写入 `PresentationRoot`。

Remote Pawn仍由PresentationActor每帧求值并写根Transform；把固定回看时间从0.1秒改为0.2秒，不修改Accepted Pose协议或上传频率。正常运行的远端轨道明确使用 `RetainLastPose`：快照超过0.5秒后停止外推、保持最后姿态可见且不可交互。

## 涉及模块

| 变更点 | 路径/类 | 类型 |

| 可视模型Pivot | `AGuLiWingmanPawn` | 纯客户端表现组件 |

| 远端插值回看 | `AGuLiWingmanPresentationActor` / `DefaultGame.ini` | 客户端表现配置 |

## 风险与备忘

- 视觉模型将相对逻辑根延迟一个固定步以内；这是固定步插值的显式表现延迟，不进入命中、碰撞或Candidate。
- 远端回看增加到0.2秒会增加对应视觉延迟，但不改变服务器状态或交互判定。真实断流后的远端模型会停在最后已接受姿态，不会用淡出/重现伪装成连续更新。
