# 指挥官双机甲骨骼与武器挂点 — 技术方案

- 对应需求：[指挥官双机甲骨骼与武器挂点](../RequirementDocument/20260906-指挥官双机甲骨骼与武器挂点.md)

## 技术选型

复用原变形骨及蒙皮，复制到 `/Game/GuLiStrike/Robots/<Unit>/Rig`。每种机甲使用独立 `SKM_`、`SK_`、`CR_` 资产；统一语义控制器，不重命名源骨、不共用 Skeleton。UE5.7 内置 Control Rig 已默认启用；使用当前源码版 Python/RigVM API 建图，不引入新原生插件。

FourFRobot 四条双骨链用双骨 IK，WM01 六条多关节链用 CCDIK；保留 FK 精调与原辅助骨。脚部控制位于 Global 空间，经接地点偏移驱动末端骨，不伸缩骨段。WM01 主体/骨盆继承补偿用于隔离武器和腿。
