# 玩法地图对齐Demo光照

## 请求与边界

用户反馈局内仍黑，包括 `LVL_ShipWingmanAirCombatPrototype`，并要求“根据demo_map来调整”。以 `/Game/StylizedPineEnvironment/Maps/Demo_Map` 当前实际呈现为参考，定向调整指挥官和空战两张玩法地图。沿用[美术规范v1.2](../RequirementDocument/GuLiStrike美术规范.md)，不改变资产外观规则、地图布局或游戏模式。

## 诊断与修改

Demo编辑器视口固定EV100=0；它的地图曝光0.5–0.6未参与该参考画面。玩法地图原固定EV100=2、补偿1.25，与参考显示方式不同。空战另有Gamma W=0.54、Contrast W=1.39及灰色色调0.614583，叠加压暗Ship。

| 修改 | 结果 |
|---|---|
| 两图曝光 | 固定EV100=0、补偿0，明确启用对应覆盖 |
| 色彩/Film | 中性色彩及Film覆盖状态对齐Demo，去掉空战旧压暗配置 |
| 太阳 | 白色、强度45、间接强度1；保持原方向及阴影设置 |
| 天空光 | 强度2、白色、间接强度1、下半球颜色对齐Demo；保留捕获方式 |
| 保留范围 | Bloom、GI/反射方法、材质、模型、布局、相机配置、游戏规则及全局控制台设置 |

Demo太阳强度3直接复制的PIE候选让棋盘地面过暗，未采用。最终45为两张测试关卡的局部校准，不升级为全项目灯光默认值。
