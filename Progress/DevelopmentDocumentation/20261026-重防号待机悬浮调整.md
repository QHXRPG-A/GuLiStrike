# 重防号待机悬浮调整 — 实施与交付

## 实现

当前参数修订只修改 `GuLiMechanicalAnimation.h` 和 `Config/DefaultGame.ini`，默认值与配置一致：HoverBobAmplitude=80、三个Period=5，Pitch/Roll各3.2度。`.cpp`沿用首版已交付的俯仰相位 `Phase + 1.3`、侧倾相位 `Phase + 1.3 + PI/2`，保持90度相差和四角依次起伏；稳定单位ID散列和模拟/渲染服务器时间不变。

CPU距离始终为最终世界厘米，`BuildFrame` 写入位移前除以ModelScale，材质LocalToWorld只缩放一次。因此正式WM01当前0.192缩放、旧预览0.2缩放都产生±80厘米浮动。现有120厘米表现基准、30米低空逻辑高度、5/15厘米每秒迟滞、0.2秒停驻确认和0.35秒平滑混合保持。

`HoverBodyTransform` 继续供本体、枪口、导弹口及四盘喷口使用。GPU保持先侧倾、后俯仰的相同顺序；当前/前帧数据、离屏时钟、插值、转向及批量Niagara管线不变。无新增API、网络字段、组件Tick、表字段或模型资产改动，飞船、僚机与玩家Ground不在本次修改范围。
