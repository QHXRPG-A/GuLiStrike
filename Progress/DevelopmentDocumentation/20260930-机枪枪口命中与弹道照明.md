# 机枪枪口命中与弹道照明

## 已写入的实现

- Excel `GuLiStrikeVfx.xlsx / Effects`：ID5 `MachineGunImpact` 三轴1→2；新增ID52 `GroundMachineGunMuzzle`，复用原NS_Flash_1路径、三轴1。经既有导出器生成JSON与VfxId头文件，未手改生成物。
- `GuLiMechanicalMuzzlePresentation.cpp` 改用ID52，仅指挥官WM01施加动态2倍；现有枪口姿态、出膛时间及对象池保持。
- `GuLiCombatEffectLaserPresentation.cpp` 为地面指挥官弹道提供4组灯光数组，跨所有1024槽批次按距离保留最多6项，相同距离按槽位排序，选择过程只保留6个候选。位置采用已补偿的显示弹头；颜色使用未乘自发光的友敌颜色，Alpha携带25倍亮度和已有淡出系数。
- 复用Catalog照明字段，默认半径800cm、亮度25、上限6；每帧和回收时禁用空槽，边界包含灯光球。诊断计数 `GroundMachineGunLights` 统计本帧上传灯数。
- `WireLaserPoolReader` 仅在准确的NS_WingmanLaserPool路径且非枪口读取时增加灯光数组/绑定。悬浮及导弹复用者不增加这些数据。渲染器使用独立位置/颜色，关闭逆平方、半透明受光、MegaLights及其阴影，指数2、高光0.2。
- 新增 `Scripts/Vfx/ground_machine_gun_lighting.py`、`Scripts/apply_machine_gun_effects.py`，并更新完整重建脚本，使定向升级与后续重建保持同一契约。新模块未加载时定向升级拒绝导入命中缩放，防止旧枪口代码误用ID5。
