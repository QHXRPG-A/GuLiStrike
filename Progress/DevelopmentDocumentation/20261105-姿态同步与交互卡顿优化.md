# 姿态同步与交互卡顿优化 — 实施记录

## 实施结果

| 用户要求 | 正式实现 | 边界 |
|---|---|---|
| 姿态批量发送 | `GuLiNetProtocol` 编解码共享信封；`PeerChannel::Pump` 按原队列公平顺序将同接收端姿态、组件和回执合成至多64记录、总长不超过1000字节的数据包 | 当次 Pump 直接发送，不新增等待窗口；单个大消息仍用必要分片路径；实际字节扣原预算 |
| 合并回执 | 回执随姿态通道批量传输；`EncodeAcknowledgment` 在游程和去掉尾零的位图中选择较短编码 | 完整保留512位确认范围与版本/代次/序号；`Confirm` 仍先验证全部位图再更新基线；不额外给回执加10Hz等待 |
| 抑制无变化状态 | Mass 同步/worker 两条正式调用路径共用 `ShouldPublish`；组件正文和权限标识完全相同时抑制重复发送 | 姿态必须零速度、全部量化字段相同、上个样本已确认；5个模拟步内刷新。组件0.5秒补发，变化回原10Hz路径 |
| 矿石全量重建 | `OnResourceOwnersChanged` 与目录种子/节点变化分离；归属更新不重置矿石删除队列、不调用 `InitializeNodeObstacles` | 已绑定据点继续由原 `ApplyHybridControlPoint` 更新归属/供电/进度/奖励；避免数值读回先于回调时吞掉占领奖励 |
| 选择重复全拷贝 | 新 `GetBoundObjectViews` 只遍历有效Actor绑定，生成无能力正文的轻量记录，按原ObjectKey顺序排序 | 单选、框选/同类选择、选择变化通知三处替换；纯兵种选择没有ActorIds时跳过工程车枚举；控制权限检查保留 |

字段审查：共享 Match/Sender、Epoch、OwnerEpoch、ControlEpoch、At、ResourceGroup、ResourceEpoch；不同时逐记录显式覆盖。每条消息保留 Kind、完整 ObjectKey 和 Sequence。未降低坐标量化、炮管角度、悬浮或 VAT 精度；VAT相位等真实变化仍发送，不能当成静止重复值丢弃。

接收端完整验证整个批次后才提交记录，逐记录做序号窗口去重；旧包、乱序包和无效尾部不能绕过原权限/基线校验。发送失败保留队列；首次传输编码统计按真实记录字节计，公共字节独立记账。

## 姿态通道 100 KB/s 验收

- 基线使用协议 35 的 18:38 采集。原地图、单对端、300 名本地士兵，逻辑 tick 211–512，姿态通道实际 160.43 KB/s，控制通道约 1,948.61 KB/s。姿态替换 1,306 条，期末待发 41 条。目标按十进制 KB 和传输层成功发送的字节计算，包含批次和传输包头。[基线](D:/UE5.7/PerformanceCaptures/GuLiStrike/20261105-183827-557D4994/report.md)
- 协议 36 以同一份经哈希握手的开局清单建立短编号，恢复完整对象类型、稳定 ID 和生命代次。动态对象或新生命使用完整键。单兵姿态从已验证的外层恢复对象身份、权属代次和捕获时刻，保留游戏战局代次、编码序号、模拟步与逐对象确认基线。
- 工程车和采矿车的位置、朝向、速度、通行与作业按各接收端确认的快照分别编码。初次发送或基线失效时发送完整状态；相同、已确认状态约 0.5 秒校正，施工占位和未确认状态约 0.2 秒续发。位置、角度和路线精度沿用原模型。
- Alt+/ 窗口新增实发 KB/s 和两类车辆的姿态、正文及确认字节。按逻辑 tick 211 附近启动同一采样，可通过[复采入口](../../Scripts/Performance/capture_motion_budget.py)复现。构建与运行证据集中在 `TestResults/Performance/20261105-motion-100`。
- 三次主验收的实发量为 54.70、56.19、53.92 KB/s，按总字节和总时间加权为 **54.94 KB/s**，较基线降低 **65.76%**。每次都是独立房间、前台渲染客户端、六个采样点、300 名本地模拟士兵。十五个约一秒区间最高 60.64 KB/s。记录字节已与 UDP 套接字实发计数核对。[验收数据](../Evidence/20261105-PoseNetwork/20261105-motion-100/acceptance.json)
- 姿态记录从 117.91 降至 31.62–32.15 KB/s，仍发出 7,121–7,169 条。两类车辆的姿态记录合计 5.63–5.88 KB/s。三类队列在主窗口的六个点均待发为零，窗口替换为零。其他通道独立核对，控制通道基线为 1,948.61 KB/s，本轮为 1,953.46–1,964.37 KB/s。[增量归档](../Archive/20261105-姿态通道100KB每秒验收.md)
