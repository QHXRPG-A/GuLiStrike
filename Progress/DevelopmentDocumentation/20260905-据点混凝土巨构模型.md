# 据点混凝土巨构模型 — 技术方案

- 对应需求：[据点混凝土巨构模型](../RequirementDocument/20260905-据点混凝土巨构模型.md)

## 技术选型

使用当前连接的 Blender 5.2.1 LTS，通过 Blender MCP 执行 Python 建模。参考以规则板墙、弧段和柱体为主，采用截面拉伸、非破坏倒角和独立构件更容易控制轮廓与尺寸；直接生成随机 AI 网格难以精确保持这种厚度、弧线和模块边界，因此未采用。未引入任何 UE 插件或原生代码。

- 以 80 单位归一化塔高描述几何，再按 `HEIGHT_M / 80` 将顶点烘焙到 300m。
- 所有源对象原点位于地面；导出通过求值副本合并、三角化，不破坏源构件修改器。
- 4m 平铺 PBR 混凝土：2048×2048 底色、粗糙度、OpenGL 法线、DirectX 法线。
- 竖向面 UV 沿截面周长展开；导出网格生成第二套打包 UV。
- Cycles 64 samples、降噪、RTX 4090 OptiX 渲染四个视角；展示地面、人物与灯光不进入导出。

## 风险与备忘

- 当前实测外包尺寸 `71.03086853 × 66.19805145 × 300m`。用户确认的是巨物方向，尚未确认这个精确尺寸。
- 27,020 三角面、1 个材质槽；闭合构件允许彼此穿插，并非单一布尔实体。
- 浮动弧壳和深缝是外观结构，未定义可通行、可进入或可破坏功能。
- 首版建模交付时游戏仍使用 20m 占位方块；同日后续用户要求导入 UE，现已在[接入文档](20260905-据点巨构导入与占位替换.md)中完成资源替换及目录范围更新。可见缝隙仍不自动可通行。
- 源脚本适配中文 Blender 默认节点名称，以及 Blender 5.2 的天空节点枚举；GLB 导出显式限定 `use_active_scene=True`，避免带入其他场景中的选中对象。
- 直接模型检查不新增自动化测试；C++、Build.cs、Target.cs 和原生插件均未修改，不触发源码版编译门禁。
