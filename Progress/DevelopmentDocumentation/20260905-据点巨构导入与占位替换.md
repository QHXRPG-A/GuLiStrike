# 据点巨构导入与占位替换 — 技术方案

- 对应需求：[据点巨构导入与占位替换](../RequirementDocument/20260905-据点巨构导入与占位替换.md)

## 技术选型

使用源码版 UE5.7 的 Python AssetImportTask、传统 FBX 工厂与项目现有 `GuLiBuildingAssetBakingLibrary.bake_render_geometry_scale`。先导入独立源网格，再把渲染几何以 Scale 1 写入旧据点资源，保留硬引用与软路径。直接向旧方块导入会进入旧资产重导入处理器；在 MCP 任务图回调中调用默认 Interchange 同步导入还会造成任务图重入，因此正式导入通过普通 Editor 启动脚本执行。
