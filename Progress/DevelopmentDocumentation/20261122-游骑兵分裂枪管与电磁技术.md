# 游骑兵分裂枪管与电磁技术

## 数据与实现

`GuLiStrikeRogueCards.xlsx` 中 Cards、Effects、GroundWeaponEffects 三张工作表分别定义前置、处理器和等级参数。卡牌 14.01、15.01、16.01 的效果 ID 为 9、10、11，对应配置 ID 为 6、7、8。公共文本的占位参数和 F4 升级预览使用同一等级数据。VFX 表第 72 项指向项目内适配的 `NS_GroundElectromagneticArc`。它复用指定商城系统的 Lightning、spark、glow、smoke 发射器，以 `User.ArcStart` 和 `User.ArcEnd` 控制端点。主弧的项目材质 `M_GroundElectromagneticArc` 使用 4×4 的 16 帧图集，包含原来的八个关键帧和八个过渡帧。

控制端提交候选目标及视图投影参数。权威游骑兵按稳定目标身份累计锁定时间，每次枪管动画通知重新检查距离、遮挡和目标资格。一轮共用枪管动作与冷却，各枚弹独立取得射击身份、完整伤害与折射链。目标退出时仅释放自己的锁定位。电磁扫掠冻结首个敌方受击体或世界阻挡点，结算沿用 Hybrid 伤害事务。护盾以实际吸收量折回基础伤害，减速使用目标的逻辑时钟。各段闪电通过现有表现通道发布。

工程资源入口为 `Scripts/GroundMech/Rogue/install_targeting_cards.py`。导入器回读该组数据行、公共文本与靶场部署，验证三份暂存清单的前置及效果参数后写回正式清单。[需求](../RequirementDocument/20261122-游骑兵分裂枪管与电磁技术.md) · [玩家数值](../Gameplay/游骑兵.md)

2026-11-23 根据实战采样调整电磁弧。每段闪电产生 4～8 个短时火花，火花受重力和阻力影响。烟雾在 0.35 秒消散。四个发射器都在首帧发射，发射窗口结束后等存活粒子自然消散。修改已写入正式资源和重建脚本。[性能记录](../Archive/20261123-游骑兵电磁弧性能优化.md)

同日按玩家反馈将主弧宽度增加 40%，蓝色自发光提高约 35%。直击和折射段均在命中时亮起。每段主弧在 0.16～0.32 秒内播完 16 帧闪电，然后定格在第 16 帧，用剩余 0.18～0.34 秒平滑渐隐，从亮起到消失共 0.5 秒。[宽度与亮度](../Archive/20261123-游骑兵电磁弧节奏与亮度.md) · [16 帧图集与采样](../Archive/20261123-游骑兵电磁弧十六帧播放.md)

每道主弧在生成时独立选取三处弯折的方向和幅度，并选择一档拐点间距。直击与每段折射各自保持这组形状直至消失。三处各有 16 档偏移，再乘以 8 档间距，共 32,768 组。[轮廓变化与齐射采样](../Archive/20261123-游骑兵多电弧形状变化.md)

主弧图集每帧的亮芯都接到枪口与命中端中心，折射段沿用同一做法。正式纹理重载后已核对全部 32 个端点，并用左右枪口至靶位的两段直击和一段折射核对粒子几何、帧序与消失时间。[枪口衔接修复与复测](../Archive/20261123-游骑兵电磁弧枪口端点.md)

## 玩家验收

1. 打开 `/Game/Maps/LVL_CommanderMassPrototype`，选红队 Ground 游骑兵，到 `GroundRogue_Entry`。F4 升强化子弹至三级，取得人工智能引擎。按住开火分别对准空地、友军和未锁满的蓝靶。应当只在蓝靶锁满后自动开火。
2. 取得分裂枪管。站在 `GroundRogue_SplitObserve`（X −2100、Y 48700）朝向 `GroundRogue_Enemy_01` 至 `05`。每级让一个、两个和更多敌人进入大圆，等各自锁满。每次左右交替的枪管动作按已锁数量发射，上限依次为 2、3、5。移走准星使一个目标完全离圆，观察其他目标继续受击。
3. 取得电磁技术。对 `Enemy_05` 观察带盾时与破盾后的生命扣除，对 `Enemy_06` 观察移速变化。第五靶起始护盾 55，第六靶开启兵种初始移动行为。可在蓝队指挥官席对第六靶下达移动命令，建立同一路段的速度对照。各等级的减速、时长、护盾加伤见玩法表。
4. 同时拥有折射时，观察每枚分裂弹的首段从当次枪口到首个命中点，此后每一段连接相邻命中点。把目标移到 `GroundRogue_Wall` 后核对遮挡。请反馈卡牌等级、同时锁满数、异常目标或端点。

靶场六个蓝队部署在三份正式清单中均已核对。画面、手感和实战组合效果待玩家验收。
