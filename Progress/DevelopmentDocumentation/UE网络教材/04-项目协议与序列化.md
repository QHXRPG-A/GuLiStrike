## 学习目标

读懂 FGuLiCommandAck，并区分身份、业务版本与运动时间戳。

## UE 概念

NetSerialize 与 TStructOpsTypeTraits 定义结构体的网络写法；读写顺序、位宽必须一致。Sanitize 只整理格式，不授予权限；返回值和 bOutSuccess 也不能混为一谈。CharacterMovement 的 packed move 则通过专用 MoveData 容器扩展，仍使用引擎移动 RPC。

## 项目调用链与源码

从 [CommanderTypes.h](D:/UE5.7/test1/Source/GuLiStrike/Commander/Network/GuLiCommanderTypes.h) 的 FGuLiSelectionRequest、FGuLiMoveRequest、FGuLiCommandAck 阅读：选择提交圆心、半径预设、Modifier、请求号与已知选择版本，由服务器确定 SoldierId 成员；移动提交目标与选择版本，同样不上传成员数组。

| 标识 | 当前用途 |
|---|---|
| SoldierId / CohortId | 战局内稳定士兵身份 / 临时选择分组 |
| ProtocolVersion / MatchEpoch | 协议格式 / 战局隔离 |
| ConnectionGeneration / SyncGeneration | 公共身份绑定代次 / 士兵初始化代次 |
| SnapshotRevision / StateRevision | 名册快照 / 士兵离散状态版本 |
| SelectionRevision / ClientCommandId | 选择成员版本 / 原样重试编号 |
| BatchOrderId / FrameSequence / ServerSimTick | 权威移动批次 / 姿态帧 / 模拟步 |

ACK 的 CommandKind 区分选择、移动，Result 表示整体结果，CohortResults 保存分组结果，ServerSelectionRevision 用于校验。选择请求的 ClientRequestId 填入 ACK.ClientCommandId，必须同时按种类和编号路由。

实际源码：[FGuLiCommandAck::IsAccepted](D:/UE5.7/test1/Source/GuLiStrike/Commander/Network/GuLiCommanderTypes.cpp)。

```cpp
return Result == EGuLiCommandAckResult::Accepted
    || Result == EGuLiCommandAckResult::PartiallyAccepted;
```

例如移动 42 形成批次 105，甲组 Accepted、乙组 PathFailed，整体为 PartiallyAccepted。客户端只对甲组等待权威批次 105，不能将乙组算作成功；迟到 ACK 携带的选择版本也可能已旧。

[FGuLiSoldierPoseChunk::NetSerialize](D:/UE5.7/test1/Source/GuLiStrike/Commander/Network/GuLiCommanderTypes.cpp) 将位置、速度分别按 10 cm、10 cm/s 量化，朝向为 uint16，状态 2 bit、标志 1 bit；先保留原始头部合法性，避免 Sanitize 掩盖错误。

飞船的 [FGuLiShipNetworkMoveData::Serialize](D:/UE5.7/test1/Source/GuLiStrike/Gameplay/Ship/GuLiShipMovementComponent.cpp) 追加本地推力、转向、侧移、Boost、ConfigRevision 和 BarrierGeneration。输入必须有限且各轴在 [-1,1]。客户端旋转和角速度仅供误差比较；服务端按自身朝向、已提交配置重建加速度。LoadoutState.Revision 表示装配，RequiredLoadoutRevision 绑定所需装配，BarrierGeneration 隔离暂停及重绑定，均不是 CMC.TimeStamp。

## 易错点

SoldierId 不是跨端共享的 MassEntityHandle；v3 不是帧号。Epoch 判断相等即可，不比较大小。飞船复用 UE 默认时间戳检查和单步时长限制，尚不等于完整防时间加速作弊。

## 练习与答案

1. **理解题：ACK Accepted 表示运动完成吗？** 只表示意图进入执行；姿态收敛、抵达另行观察。
2. **理解题：Sanitize 能防越权选兵吗？** 不能，仍需服务器验证身份、角色和成员。
3. **源码题：Selection 7、Move 7 与飞船时间戳 7 如何区分？** 前两者由 ReceiveCommandAck 按种类和编号路由；飞船走 CMC 响应，并校验配置、屏障及 SavedMove 时间戳，不进入指挥官 ACK 队列。
