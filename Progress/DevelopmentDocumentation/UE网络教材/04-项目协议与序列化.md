## 学习目标

读懂请求与 FGuLiCommandAck，知道每个版本号解决什么问题，而不把所有 uint32 当成同一序号。

## UE 概念

NetSerialize 定义结构的网络读写布局，TStructOpsTypeTraits 将它接入 UE；读写双方必须使用相同字段顺序和位宽。Sanitize 是格式整理，不等于授权校验。函数返回值与 bOutSuccess 各有职责，不能只看 return true 判断数据合法。

## 项目调用链与源码

入口集中在 [FGuLiSelectionRequest](D:/UE5.7/test1/Source/GuLiStrike/Commander/Network/GuLiCommanderTypes.h:190)、[FGuLiMoveRequest](D:/UE5.7/test1/Source/GuLiStrike/Commander/Network/GuLiCommanderTypes.h:215) 与 [struct GULISTRIKE_API FGuLiCommandAck](D:/UE5.7/test1/Source/GuLiStrike/Commander/Network/GuLiCommanderTypes.h:305)。选兵请求描述区域，移动请求描述目标和选择版本，客户端不直接提交控制组成员。

| 标识 | 当前项目中的含义 |
|---|---|
| SoldierId / CohortId | 战局内稳定单兵身份 / 临时冻结选择组 |
| ProtocolVersion / MatchEpoch | 线协议兼容 / 战局隔离 |
| SyncGeneration / SnapshotRevision | 连接初始化代次 / 整份名册更新 |
| SelectionRevision / StateRevision | 选择成员版本 / 单兵离散状态版本 |
| ClientCommandId / BatchOrderId | 原请求关联号 / 服务器接受的移动批次 |
| FrameSequence / ServerSimTick | 姿态捕获帧号 / 服务器模拟步 |

ACK 的 CommandKind 区分选兵与移动，Result 表示总体结果，CohortResults 保存逐组结果；ServerSelectionRevision 供后续意图使用。选兵请求的 ClientRequestId 回填到 ACK 的 ClientCommandId，数字相同不代表命令相同。


项目源码节选（[bool FGuLiCommandAck::IsAccepted() const](D:/UE5.7/test1/Source/GuLiStrike/Commander/Network/GuLiCommanderTypes.cpp:317)）：

```cpp
bool FGuLiCommandAck::IsAccepted() const
{
	return Result == EGuLiCommandAckResult::Accepted
		|| Result == EGuLiCommandAckResult::PartiallyAccepted;
}
```


例如移动 42 接受为批次 105，甲组 Accepted、乙组 PathFailed，总体是 PartiallyAccepted。客户端只对甲组等待权威命令 105，不能把乙组也画成执行成功。缓存 ACK 的选择版本可能已旧。

姿态位置、速度分别按 10 cm、10 cm/s 量化，朝向用 uint16；状态用 2 bit，标志用 1 bit。[FGuLiSoldierPoseChunk::NetSerialize](D:/UE5.7/test1/Source/GuLiStrike/Commander/Network/GuLiCommanderTypes.cpp:544) 在 Sanitize 前保存头部是否合法，防止整理过程重置协议字段后掩盖错误。

## 易错点

SoldierId 不是两端共用的 MassEntityHandle。协议 v3 不是第三帧。序号回绕比较以半个 uint32 空间为界；Epoch 则是身份标记，不应用数值大小判断新旧。

## 练习与答案

1. **理解题：ACK Accepted 是否意味着运动完成？** 只说明接受意图；后续执行、姿态到达和抵达是另一阶段。
2. **理解题：Sanitize 能阻止越权选兵吗？** 不能，权限与成员归属要由服务器业务路径验证。
3. **源码题：Selection 7 与 Move 7 的 ACK 如何区分？** ReceiveCommandAck 同时比较 CommandKind 和 ClientCommandId，不能仅按数字匹配。
