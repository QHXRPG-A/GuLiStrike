# Ship第二批三组件贴图与框线制作 — 实施与审核

## 范围与方法

本批为`Autocannon`、`Triple_Barrel_Turret`、`Single_Barrel_Turret`，按现有组件编号补齐。沿用原模型，只更新材质与线稿；用户明确要求“效果图+三视图审核 → 依据图纸和原模型调整贴图框线 → 成品审核”，本批A和B均需独立记录。

通过源码版UE5.7命令行只读提取现有蓝图、原型几何、原骨骼和挂点，保留静态参考FBX与已有骨骼Blender/FBX源。根据首批经验，不再尝试NullRHI不支持的骨骼FBX导出；原资产没有保存或重导入。

原型视图直接来自保留的骨骼源，在隔离检查副本中使用中性显示材质；不会修改用户当前打开的Blender或首批交付。设计图由内置图像生成工具按实际原型视图制作，仅用于审核A。首批已审双联炮和CIWS作为色块、线稿、明暗的风格参考。

## 任务与审核

- [x] 冻结三件当前原型、骨骼、挂点、安装变换和源文件哈希，UE包提取前后不变。

- [x] 生成三件效果图与正/侧/背三视图，修订跨视角主要分色差异，并记录来源、提示词及文件哈希。

- [x] 按后续直接发布授权导出并运行现有回读，完成正式UE接入；不倒填B视觉通过。

2026-09-17用户在针对上述三个版本的审核A提问后回复“开始制作”，记录为三件A通过。[审核A记录](../../ArtSource/Ships/ShipComponentStyle_20260917/Batch02/approval_A_20260917.json)冻结已审参考与原型源哈希；制作脚本先核对这些输入，再执行材质处理。B仍需实际成品审核。

A阶段以每件四视角设计板提交。自动炮v2统一侧甲及正面套环的分色，单管炮v2统一侧盖、连接处机械层及背部色块；首版全部保留。三联炮保留v1。图纸只约束表面效果，若二维表现与原型结构存在差异，形体和接口以冻结原模型为准。

参考整理时检查三/三/一炮口特征、主要护罩及散热结构、四视角覆盖和主要色块对应。原型源哈希与十五张中性视图哈希全部相符；用户随后明确放行A。

## 实际Blender材质候选v2

复用首批材质与机械检查流程，在冻结的骨骼原模型上完成分区色块、独立内线遮罩及三档光影。原主体顶点、拓扑、角点法线哈希一致，保留原UV并新增色块与线稿UV。每件一个主体材质槽，内嵌及外置BaseColor、ORM、LineMask三张2K贴图；可编辑面分色属性、角点颜色和分区记录保留。

外轮廓为`OUTLINE_TOGGLE`集合中的独立辅助对象，可关闭且不进入后续FBX。三档明暗由实际EEVEE场景灯光和自阴影驱动；换光和关闭框线的渲染均已生成。v1为内部检查版本，v2统一单管炮连接凹槽与护罩下方的深色机械层，防止浅色三角碎片破坏接缝读形。本次仅提交v2进行B审核。

沿用`Root → BarrelPitch`及单骨骼权重1，现有逐度检查覆盖−15°至75°共91个姿态，未发现活动件与固定件表面相交。最大刚性误差约0.000014米、炮口跟随误差约0.000013米，处于浮点精度范围。分别输出−15°、0°、30°、75°彩色与灰模，并生成97帧、24fps连续俯仰视频。三段视频完整解码成功。视觉检查覆盖效果、背面、俯仰极值、缩小和换光视图；实际审核页切换视角与大图正常。

三件单独`.blend`和含三个场景的总览已保存；实际成品、贴图、参数和来源SHA-256见B清单。用户当前交互Blender文件和首批交付未被替换。技术检查不代替用户B；本批最终FBX导出、FBX回读及UE正式验证尚未运行。
