# 一键截帧与CPU分析插件 — 技术方案

## 实现与依赖

| 模块 | 职责与依赖 |
|---|---|
| GuLiFrameProfiler（Editor） | Alt+/、Tools 菜单、任务生命周期、TraceAuxiliary、RenderCaptureProvider、TraceServices、标准 Slate 报告；只依赖引擎模块 |
| GuLiStrikeEditor | 私有依赖插件接口，注册原生性能及 Slate 归属采样适配器；插件不反向依赖项目 |
| GuLiStrike | 只新增原生采样占用查询，不改变运行玩法 |

状态：Idle → Armed → Recording → ClosingTrace → WaitingGpu → Analyzing → Idle。只允许一个任务，5 秒窗口以书签标记，分析取完整 Tick 帧。异步分析释放会话后交付；输出不经过海量事件 CSV。

Hybrid 统计匹配现有分析 v5 的范围并集，细分范围允许互相包含，不相加。分析 v2 区分已测量、无活动、不适用、未就绪和缺少埋点；只在原生覆盖及运行就绪均确认时，无调用才登记为零。编辑器采样没有玩法世界，相关项目标为不适用。

Slate 归属 v3 在采样前缓存视口、游戏 UI 层及编辑器子树的弱身份，覆盖嵌入式和独立窗口 PIE。归属变化覆盖父级所有者，避免混合祖先把游戏子树误扣为编辑器。客户端上界只减去确认独占的编辑器区间，未知及共享工作仍保留；逐帧检查视口和 UI 层身份，退出时卸载所有调试回调。后台任务工作量与主线程范围分报。快照包含主线程采集屏障和已有后台快照范围；资源副本周期仍为五秒。
