# 地面机甲火箭跳 — 实施与验证

## 技术选型

只在地面机甲Pawn引入ASC、GAS能力和Fuel/MaxFuel属性；不恢复Ship/Commander的旧GAS架构。GameplayAbilities/GameplayTasks为本需求依赖，价值是统一激活、中断和资源权威。配置失败时禁用本能力并报告明确错误，其他机甲功能继续工作；验证成本包括GAS资源同步与移动回放衔接。

Excel技能表按ExecutionType区分Weapon/GAS，火箭跳行2/RocketJump。服务器通过GameplayEffect结算容量；CMC保存预测容量、恢复计时和输入，校正与外部位移版本一致。持续推力复用PhysFalling，保持Mass和世界碰撞。

喷火复用指定商城原件；HUD使用项目自有弧形网格材质。本地实例拥有表现组件，专服不创建。当前参考来自用户指定资源与截图，技术验证不代表用户最终视觉审核。

## 配置与实现入口

唯一数值源：[GuLiStrikeMech.xlsx](../../Data/Excel/GuLiStrikeMech.xlsx)“技能表”，行名RocketJump，ID 2，ExecutionType=GAS。升级表保持原3行，机枪技能与资产身份保留。

| 配置 | 初值 |
|---|---|
| MaxFuel / InitialFuel | 100 / 100 |
| FuelDrainPerSecond / FuelRecoveryPerSecond | 20 / 20 |
| FuelRecoveryDelay / FuelBarFadeSeconds | 1 / 1.5秒 |
| ThrustAcceleration / MaxRiseSpeed | 2180 cm/s² / 1200 cm/s |
| JetSocketLeft / JetSocketRight | Jet_Outlet_L / Jet_Outlet_R |
| JetScale / JetPitchDegrees | 1 / -90° |
| FuelBarHeight / FuelBarRightOffset | 400 / 450 cm |
| AirSpeedMultiplier / JetMaxTiltDegrees | 1.5 / 15° |
| FallGravityMultiplier | 2；仅停止有效推进后的下降阶段 |

`UGuLiGA_RocketJump`负责本地预测激活与停止，`UGuLiGroundMechAttributeSet`包含Fuel/MaxFuel，服务器通过两种即时GameplayEffect初始化和结算。ASC由Pawn持有，属性集通过默认子对象注册，不随重新占有补满。表现由`UGuLiGroundMechRocketComponent`维护。

CMC在PhysFalling中按实际子步扣容量，最后不足一个子步的容量只提供对应时长的推力。SavedMove记录按住/能力状态、容量和恢复计时；修改资源的移动不合并。校正消息携带与同一时间戳位置校正匹配的资源基准，回放仅还原输入，并从该基准顺序计算，不再次应用GameplayEffect。服务器只比较客户端容量以发现差异，不接受它作为权威。外部位移版本与Mass支撑快照保持原合同；客户端、服务端须同时使用本次构建，沿用工作区已升级的公共协议17，不与此前协议15产物混用。

制作入口：[configure_rocket_jump_data.py](../../Scripts/GroundMech/configure_rocket_jump_data.py)添加初始配置；[author_rocket_jump_assets.py](../../Scripts/GroundMech/author_rocket_jump_assets.py)在编辑器中导入技能表，创建弧条材质和Space输入，再更新项目Blueprint默认值。商城火焰资源保持只读。

## 实机反馈调整（2026-09-21）

初版源码Editor/Game构建已通过；现有13项GroundMech自动化回归全部通过。已导入技能DataTable、GAS输入及弧条材质，并从实机采样确认100容量持续5秒耗尽、最高上升速度1200、容量与GAS属性一致。发现旧Blueprint移动子对象缓存重力0.2，已在项目资产制作脚本中恢复原生默认重力1及地面移动参数。

用户实际体验后要求：推力调为原来的0.25、容量未满常显、UI放大两倍、空中W/A/D以走速1.5倍转向、火焰偏转最多15°。已把高度改为400、增加Excel空中倍率与喷口偏转配置，并导入和验证。空容量的细边仍显示红色，保持耗尽状态可读。

当时因2180×0.25=545小于重力980，曾询问净加速度和重力的调整含义。用户后续明确要求推力先保持2180，已由[动画与空中战斗方案](20260921-地面机甲动画蓝图与空中战斗.md)覆盖旧待确认项。空中输入扩展WASD，喷气改为有效空格按下即点火；旧连续画面不代表新版视觉验收。

最新追加下落反馈：新增Excel字段FallGravityMultiplier，默认2。CMC在无有效推力且垂直速度非正的子步应用该倍率，上升和推进不改变。该条件由回放已有速度和能力状态推导，不添加另一份网络资源或移动状态；仍使用现有世界/Mass连续碰撞和终端速度限制。
