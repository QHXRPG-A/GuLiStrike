# 飞船骨骼部件与 Socket 保留 — 技术方案

对应[已确认需求](../RequirementDocument/20260911-飞船骨骼部件与Socket保留.md)。具体编辑器配置步骤见[配置说明](../../outputs/ship-part-visual-migration/README.md)。

## 实现

`UGuLiStrikeShipPartComponent` 从 `UStaticMeshComponent` 改为 `USceneComponent`。部件保存安装变换、兼容槽位和行为；Actor 拥有临时静态／骨骼视觉子组件，视觉网格以单位变换附着到部件。注册时创建，注销、销毁和切换时清理；视觉碰撞关闭。

保留 `StaticMesh`、`OverrideMaterials` 等同名迁移字段，新增 `VisualType`、`SkeletalMesh`、`GetVisualMeshComponent`、`GetSkeletalVisualComponent` 和 Socket 查询接口。旧4个部件蓝图按修改前快照恢复并保存，2个飞船蓝图重新编译保存。舰体、武器网格和Skeleton没有写入。

武器可配置 `MuzzleSocketName`。指定时取视觉网格炮口相对于部件的变换，并乘服务器权威安装变换；未指定时沿用 `MuzzleOffset`。缺失显式炮口时拒绝发射，服务器射击资格和伤害账本链保持原用法。骨骼视觉启用不可见时更新姿态和骨骼，以支持服务器查询；持续附着的特效应直接挂到视觉网格。

`InstallPartLocally` 在卸旧件前增加视觉组件就绪检查，避免无网格的新配置清空原槽位。静态和骨骼部件均沿用现有服务器装配发布和客户端重建路径。
