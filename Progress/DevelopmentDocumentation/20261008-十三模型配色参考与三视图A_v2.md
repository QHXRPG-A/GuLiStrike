## 制作与来源

本轮使用内置 `image_gen.imagegen`，先按实际模型视图生成蓝方设计，再从完成的蓝方图板派生对应红方，保持构图、姿态和固定区。最终选择二十六张 1536×1024 PNG，另保留八张未选首稿、全部三十四次成功生成的精确提示词和输出来源。

先驱号和彼之矛使用 CommanderLOD 实际原模型四视图；六座 SSF 使用已入库 B_v2 的实际 Blender 四视图。护盾、前哨、防空炮、哨戒炮、矿厂从现有 UE 网格或完整 Blueprint 提取原生视图，三份捕获报告均为 `success=true`、`source_assets_saved=false`、`gameplay_started=false`。捕获只建立临时预览，没有修改或保存正式网格、材质、地图及游戏引用。

两座炮塔沿 +Y 炮口方向核对正视；原捕获 Right→Front、Back→Left、Left→Back。矿厂使用完整 Blueprint 的主体、门和坡道装配。前哨沿用现有堆叠长柱式占位建筑，未替换成其他建筑。现有部件、尺寸、装配、活动件、动画和 LOD 是后续施工依据；二维图板不作尺寸测量图或 Blender 成品。

## 配色及读图修订

统一选取用户色卡中的奶油白／深灰固定色和蓝灰／莓红队色，队色局限于每模型配置列出的连续面板、窄环带和标识。功能灯保持原位置和固定颜色，不扩大光晕。护盾顶部三处灯心两队均为青色，装甲不自发光。

| 模型 | 最终参考核对要点 |
|---|---|
| 先驱号 | 六足、双炮、天线及后环识别结构；浅色主体与腿甲，肩部及后环为队色 |
| 彼之矛 | 四足、长炮体及开放支架；保留深灰枪口和机构，施工体共用设计 |
| 护盾发生器 | 三柱与 Y 形底座；顶部功能青灯固定，柱身浅色、上部盖板为队色 |
| 前哨建筑 | 保留堆叠长柱结构，正视按原模型校正；腰部笼架为队色 |
| 防空炮 | 双发射仓，正面每侧五个原弹头；后盖闭合深灰，长护板及转台窄带为队色 |
| 哨戒炮 | 单根阶梯炮管、四向底座与后软管；六孔通风盖框为队色，孔内和炮管为深灰 |
| 矿厂 | 主体、门、坡道与侧柜齐全；门和坡道恢复浅色，队色只在前侧翼及柜面窄带 |
| SSF 空军基地 | 浅色主体裙边占主导，队色收束为窄腰带和外侧盖板 |
| SSF 克隆中心 | 四侧舱与高背架保留；顶框为队色、工作区深灰，取消额外橙色块 |
| SSF 指挥中心 | 环状层叠塔与天线；浅色主装甲，单条上环及部分支架面板为队色 |
| SSF 军工厂 | 宽主体墙面及门甲为浅色；取消整片队色墙，收束为前盖板和窄腰带 |
| SSF 反应堆 | 保留原容器、四腿、背盒和管线；窄顶环及视窗框为队色 |
| SSF 战略中心 | 保留倾斜阵列与四天线；雷达工作栅面固定深灰，边框及腰带为队色 |

以上为助手对最终参考图的逐项视觉检查，不填写用户 A“通过”。图板采用统一四视图布局和正交设计表达；生成绘画仍可能在细节投影和画面比例上近似，实际几何与尺寸必须继续按原模型核对，不能直接推导已完成一比一建模。
