# 指挥官 UI 与小兵血条视觉设计：开发文档

> 日期：2026-08-29  
> 状态：第三版视觉整改已完成，等待复审  
> 对应需求：[20260829-指挥官UI与小兵血条视觉设计](../RequirementDocument/20260829-指挥官UI与小兵血条视觉设计.md)

## 实现结果

本轮使用 UMG 与 WidgetService 构建静态视觉资产，没有接入游戏、没有创建运行时入口，也没有修改玩法代码。最终 HUD 为三个互相独立的响应式岛：顶中战况条保持固定设计尺寸；战术地图和底部指挥坞分别通过独立 `ScaleBox` 只向下缩放，超宽屏不放大。

| 资产 | 结果 |
|---|---|
| `/Game/Commander/UI/Widgets/WBP_CommanderHUD` | 顶中 420×64、左下 276×276、底部 1120×204；6 编队卡；5×3 命令矩阵；7 个命令与 1 个静态上下文键提示 |
| `/Game/Commander/UI/Widgets/WBP_SoldierHealthBar` | 84×12；默认 75%；2px 外框；3 条四分位分隔线；未填充轨道为纯黑 |
| `/Game/Commander/UI/Review/WBP_CommanderUI_ReviewBoard` | 嵌入实际 HUD；四种血条状态；同一移动图标的默认/悬停/禁用三态；不再设置重复的左上审核横幅 |
| `/Game/Commander/UI/Textures/Icons/T_UI_Cmd_*` | Move、Attack、Stop、Hold、Patrol、Rally 六张 UI 纹理 |

## 视觉实现

### HUD 层级与响应式规则

- `RootCanvas/SB_TopStatus`：顶部居中，设计尺寸 420×64。
- `RootCanvas/C_MapRegion/SC_MapScale/SB_MapDesign`：左下区域横向锚点 `0..0.15625`，距左/底 24px，`ScaleToFit + DownOnly`，设计尺寸 276×276。
- `RootCanvas/C_DockRegion/SC_DockScale/SB_DockDesign`：底部区域横向锚点 `0.208333..0.791667`，距底 24px，`ScaleToFit + DownOnly`，设计尺寸 1120×204。
- 1920×1080 采用 1:1 设计尺寸；1280×720 捕获中地图约 0.638、指挥坞约 0.667；2560×1080 保持 1:1 并居中，不横向拉伸。

### 色彩与排版

- 深黑蓝背景与面板：`#050A12`、`#0B1622`。
- 青色信息轨与默认移动图标：`#18D7FF`；暖金属外框：`#D1AF86`。
- 六类命令使用语义分色：移动青、攻击橙红、停止琥珀、坚守绿、巡逻紫、集结金；透明源图仍保持统一等线宽，最终颜色由 UMG Brush Tint 提供。
- “选取”使用薄荷青 UMG 四角选框符号与金色激活框；不新增位图纹理，旁侧低强调槽展示 `+ / 框大小` 的静态上下文提示。
- 主文字：`#EDF8FF`；生命色：`#E44758`。
- 中文主文案使用 UE 默认复合字体；审核截图已确认中文回退字形可读。
- 占位数据统一为“轨道控制”、`02:02`、`08:42`、`1280`、`75/100`。

### 图标生成与导入

最终生成约束提示词为：`single isolated sci-fi RTS command glyph, light-cyan geometric monoline, centered on a true transparent RGBA canvas, generous padding, no text, no border, no frame, no shadow, no baked glow, no checkerboard or background`；分别替换主体为 Move、Attack、Stop、Hold、Patrol、Rally。Attack、Hold、Rally 额外重新生成一次以消除伪透明棋盘背景。审核整改后保留这些透明单色源图，在 HUD 内由 UMG 着色为六种功能色，避免把多套状态颜色烘焙进纹理。

源图保存在 `outputs/imagegen/commander-ui/icons`，均为 RGBA 透明图。导入纹理回读结果：`TEXTUREGROUP_UI`、`TMGS_NO_MIPMAPS`、`TC_EDITOR_ICON`、`MaxTextureSize=256`、`NeverStream=True`。

### 小兵血条与审核板

- 血条外框为 84×12，内部轨道为 80×8，默认填充 60×8，即 75%。
- 内部未填充轨道为纯黑 `#000000`；红色只表示当前生命值。
- 分隔线位于 x=21/42/63，对应 25%/50%/75%。
- Review Board 展示满血 100%、受伤 75%、选中 55%、危急 15%，以及同一 Move 图标的默认、悬停、禁用三态。
- 所有状态均为静态审核占位；没有生命数据读取、状态事件或动画。

## 工具与过程说明

- 本轮没有启动 PIE；写入前仅结束了另一任务遗留的 PIE 会话，随后全部采用离屏 Widget 捕获。
- 编辑器内递归导入纹理会触发渲染命令刷新断言，因此改为单独的完整编辑器 Python 导入会话，确认六个包逐个保存后再回到干净编辑器完成 WBP 制作与验证。
- Widget 离屏捕获器不会执行正常视口的 `ScaleBox` 预布局；窄屏和超宽审核图仅在捕获时使用等价的显式缩放值，捕获完成后已经恢复并保存最终 `ScaleToFit + DownOnly` 配置。
- 既存性能优化工作区改动没有被保存、覆盖或回退；未修改 `Content/Commander/Units/**`、Mass/Navigation、Resolver/DataTable、`M_CommanderUnitRing`、C++、Config 或地图。
