# 巡天飞船 HUD 与 3C 正式接入

## 试玩

打开 `/Game/Maps/LVL_CommanderMassPrototype`，点击播放，选择 **无双·巡天 → 巡天 HUD**。试飞从红方巡天开始，默认离地 180 米。普通对局驾驶巡天也会加载同一套操控和仪表。

| 输入 | 作用 |
|---|---|
| 鼠标、滚轮 | 绕舰观察、调整观察距离，向下转至极限为垂直俯视 |
| 左键、右键 | 左键按住使用当前炮组，右键沿用僚机导弹操作 |
| W / S、A / D | 前进与后退、左右平移 |
| Q / E、空格 / C、左 Shift | 左右转向、升降、推进加速 |

地图的 `Gameplay/Tests/XuntianHUD` 文件夹内有六个编辑器站位。高位舰比出生舰高 60 米，同高舰与出生舰等高，低位舰低 105 米。地面蓝方步兵分别位于距出生舰约 70° 和 27° 俯角处，方便直观对比默认射界。上述角度从出生舰位置估算，射击时各座炮使用自身挂点与炮口判定。

## 调整舰腹射界

在 `BP_CombatAvatarFly01` 的 `XuntianGunnery` 组件中展开 **巡天 → 舰腹射界**，修改 `GroundMinDepression` 和 `GroundMaxDepression`。0° 表示沿舰体水平面瞄准，90° 表示垂直向下。提高最小俯角会缩小远端射区，降低最大俯角会在舰底正下方形成内圈盲区。

默认区间是 **45° 至 90°**，包含两端。运行时由持有飞船模拟权的一端调用蓝图函数 `SetGroundGunLimits(MinDeg, MaxDeg)`。函数返回设置是否成功，要求两个有限角度满足 `0 ≤ MinDeg ≤ MaxDeg ≤ 90`。`GetGroundGunLimits` 可读回当前值。地面斜纹、准星红叉、逐炮可射状态和主炮开火均引用这组角度。

## 正式数据与界面

| 部分 | 数据及表现 |
|---|---|
| 观瞄 | 相机射线产生世界瞄点。瞄中飞行单位时按该单位与本舰舰体中心的相对高度选组。无目标时由视线与场景交点决定 |
| 炮口 | 正式装配目录提供 40 座防空炮、2 座舰腹炮。每座炮从自身挂点转向共用瞄点。多管模型轮换实际炮口，每座炮只画一个圆圈，圆圈进入 1080 高参考画布的 20 像素半径后隐藏 |
| 弹丸与反馈 | 从当前炮口的实际朝向发射。与本舰碰撞时穿过，其他对象按正式池化弹丸和命中流程处理。击毁播报来自已确认的致死事件 |
| 场景标记 | 两种视角都能看到地表射界。淡橙色面表示有炮可射，斜纹覆盖盲区。空中每艘敌舰旁的虚线落到本舰高度，炮组图标随相对高度和可射炮数更新。盲区准星叠加带深色描边的大红叉 |
| 肉鸽牌 | `SetOwnedCardSnapshot` 接收巡天真实持牌的完整版本快照。防空／僚机仓、舰腹／导弹／燃烧弹、护盾和电子干扰各占一栏，同分支只展示当前进阶。无持牌时四栏留空 |
| 计分 | 右下预留红蓝双方比分和对局时间，当前显示短横线。击毁播报独立更新，最多三条，七秒淡出 |

## 与 ground-reticle 试玩版对照

中央双弧、矩形雷达底图、两种准星和炮组图标共用一张 2048 × 2048 的原生透明图集。图集按离线 Demo 的 Canvas 绘制指令生成，数字沿用项目的 Rajdhani SemiBold。实时航速保留一位小数，每座炮的圆圈以 50% 不透明度绘制，进入中央 20 个参考像素后隐藏。

自由相机开场相对舰首偏转约 23.5°，镜头略微上仰。下看 35° 至 72° 时，原本在准星左侧的高度读数移向左侧高度带，舰体完整度移入底部中央的六段状态条。航速和当前武器始终在准星右侧。向高位、同高及低位敌舰转动时，目标旁的虚线以本舰高度为落点。180 米和 420 米处各有一圈本舰等高标记，随舰移动。

地表覆盖使用真实地形高度，在舰腹炮可射区域绘制连续色面，在盲区绘制世界坐标斜纹。最近可射点在地面显示四个角标，准星旁的箭头指向该点。本地仪表生成脚本为 `Scripts/Art/HUDuiPRO/build_xuntian_instruments.py`，地表和天空材质源文件位于试玩目录的 `Native/` 下。

## 敌机旁的炮形与叉号

巡天按每帧的敌机模型位置绘制图标和高度虚线。对于仅有位置快照的目标，图标在相邻采样间插值。目标首次出现时立即显示当前状态。之后，目标中心超过舰体等高线上方或下方 1.5 米才改变上下区判定，新的可射状态持续 0.15 秒后才更换图标。该缓冲只用于图标显示。

在 `/Game/Maps/LVL_CommanderMassPrototype` 选择 **无双·巡天 → 僚机对空**，固定视角可检查掠过舰身的敌机，再绕舰转动镜头检查图标与模型的相对位置。**巡天 HUD** 试飞提供高位、同高和低位三艘靶舰，可用升降操作检查持续越过等高线后的切换。

独立对局跟踪了 25 架敌方僚机。579 帧中图标锚点与同帧模型中心全部对齐，等高线附近 14 次穿线期间图标保持稳定。[复测记录](../Archive/20261128-巡天敌机图标频闪修复.md)

炮形和小叉的填色与描边由同一张朝向镜头的四边形绘制。材质按像素覆盖率平滑边缘，高度虚线从敌机一端起算间距。可在 **无双·巡天 → 僚机综合** 观察掠过舰体的两个标记。按 **F4 → 升级** 可依次装上双联和三联腹炮。开局机库正在装配时，一次点击即可排在机库之后完成。2832 版已在对局中核对渲染线程选择的材质、按钮点击和联机装配结果。[材质与升级实测](../Archive/20261128-巡天标记材质回退与升级点击复核.md)
