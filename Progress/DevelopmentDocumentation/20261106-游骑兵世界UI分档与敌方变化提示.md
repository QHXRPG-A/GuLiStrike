# 游骑兵世界UI分档与敌方变化提示 — 实施与验收

## 当前实现

- `UGuLiGroundSceneUISettings`独立配置35000/50000厘米；常态透明度公式在350、425、500米分别为1、0.5、0。Ground屏幕占比阈值为零，模型、弹丸及其他席位LOD参数未修改。
- `UGuLiGroundSceneUIState`按完整Hybrid Key和LifeGeneration保存本地生命基线；首次绑定只建立基线，后续订阅`OnObjectChanged`并用`GetObjectView`读取变化对象。生命、最大生命、护盾、最大护盾比较不包含位置；重复通知不续期。
- 只保留符合显示资格的活敌方；死亡、变友方、移除及旧生命被替换时清除。视野外计时继续但不提交提示，回屏不重新计时；切席位在身份通知中解除绑定，即使Widget被模态隐藏也清理。
- 描边透明度为距离和事件透明度的最大值；事件复用3秒保持、0.5秒淡出。状态条仅事件期间显示，恢复到满生命仍完成提示。
- Ground在单位圈与Actor圈采集之前跳过；据点光环继续常态距离渐隐。健康条84×12，护盾条84×3、间隔2，#6AA4BE；快照传递时间透明度，Slate不再丢弃该值。
- 每本地视图一个捕获。ISM代理按源模型/材质批次维护独立对象槽，复制原0–62号自定义数据，63号保存该对象透明度；远端变化只加入该对象。Actor子组件纳入，骨骼代理使用LeaderPose且不运行动画Tick。
- 100组源材质/实例对应独立掩码派生资源；保留WPO、裁剪、静态参数分支和源参数。R记录透明度、G记录覆盖，UI材质沿用原描边颜色和2像素采样宽度。精确比较源参数数组，仅修订变化时复制Uniform；位置和自定义数据也按差异上传。
- 提示结束回收稳定槽位，池保留容量复用，空批次隐藏；源组件失效或换席位/地图时销毁代理。本体LOD和受击Overlay不被修改。
