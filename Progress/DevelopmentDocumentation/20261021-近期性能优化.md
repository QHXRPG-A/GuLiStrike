# 近期性能优化 — 开发汇总

本页是2026-10-18至21日这一轮优化的开发入口。当前合同见[需求汇总](../RequirementDocument/20261021-近期性能优化.md)，阶段经过见[整合归档](../Archive/20261021-近期性能优化整合归档.md)；18份开发原文、分册及元数据完整保存在[原文ZIP](../Archive/20261021-近期优化原文.zip)。

## 当前结论与推进顺序

**正式优化已接入，但全部本机受令成员的20–30ms响应尚未稳定达到。** build-54名单处理修复没有新增响应计时；build-57解决扫荡者姿态及斜坡导航功能问题，不能据此宣布响应或整帧达标。

先消除原顺序中的重复复制、回执匹配、快照及交付等待，再测全部成员的累计响应；稳定≤30ms后才复核最终配对性能。最高优先级插队尚待用户判断，未实施。UI四档专项的停止检查要求继续有效，助手不读图。

## 正式实现与回退

| 范围 | 当前实现/约束 |
|---|---|
| Hybrid同步 | 唯一实现`hybrid-sync-unique-v2`，默认mask31；64/128退役并兼容忽略，旧同步分支已删除。修复快照屏障占住Mass逻辑时钟、累计时间丢失；保持60Hz及可靠顺序 |
| 资源恢复 | 常规备用副本改为5秒，首次副本、退出最终快照即时采集；离线周期与核心契约有证据，不能将旧10Hz性能当作新构建数据 |
| 网络CPU | 保留正文容器转换消除、定义索引、压缩上下文复用；可靠正文≤64KiB默认无损低级别压缩，更大正文走标准级别；`gs.Hybrid.FastSmallPayloadCompression=0`独立回退，客户端创建时锁定并传给逻辑端 |
| 弹丸服务 | 同客户端、同完整对象身份复用目录节点，逐次读取当前生命与所有权；保持发布编码、身份/生命周期和可靠包完整排序 |
| 本机输入/呈现 | 即时意图绿线、纯兵种完整选区索引及混合/不完整回退；60Hz本机手动移动、直接使用已提交姿态、移动后采样同步、活动端点软避让、就绪路线索引 |
| UI | `gs.SceneUI.IndexedGeometry=1`、`gs.SceneUI.OptimizedPaint=1`；缓存命中复用容量并跳过圆环/路线/血条重复准备，动态纹理/文字/HUD有效期仍更新；完整圆环64段、128三角形、128共享顶点 |
| 网格/描边 | `EGuLiPresentationTier`四档与特效资源质量显式映射；World内弱引用注册，动态生成/装配/池复用/注销维护；`gs.Commander.MeshLOD=0`独立回退。模型描边仅LOD0保留，结构线/选择圈/血条保持 |
| 工具/特效 | 保留GuLiFrameProfiler、原生指标、默认关闭的响应诊断、地面Mass死亡爆炸1/3尺寸；全局`Slate.EnableGlobalInvalidation=0` |

此前提前结果应用、帧尾结果应用、弹丸发布预检查、可靠包部分排序、VAT合并提交五类实验已移出生产；保留常规应用、完整发布/排序和逐字段VAT提交。GameplayWorker原有专属帧尾入口保留。历史采集的候选含义以其`capture.json`为准。

`t.IdleWhenNotForeground=0`和`Slate.bAllowThrottling=0`只属于配对测量条件，脚本结束恢复，不能写作全局生产默认。较早5ms实验中的“Slate共享顶点关闭”是当时状态，当前UI共享顶点已正式启用。

`GuLiNetCommandSubset.h`只构造命令元数据及指定成员；按所有者首次建立空分组再依序追加。`ToUECommandMember`只转换当前对象，协议批次/冻结选区仍完整且Slot不重排。保留Event、逻辑时间、参数、完整身份、OwnerEpoch/ControlEpoch、坐标与可靠回执，不新增异步借用或持久缓存。
