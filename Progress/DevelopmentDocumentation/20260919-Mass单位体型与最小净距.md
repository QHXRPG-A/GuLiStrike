# Mass单位体型与最小净距 — 运行时开发

> 已撤回：以下保留历史事实，当前实现以[战争机器模型大小适配](20260919-战争机器模型大小适配.md)为准。

## 技术选型

共享策略使用二维圆形占地和实际垂直范围；成对距离为半径和加较大净距。World登记表在实际移动后立即更新，支持生成、扫掠、批量相对运动及注销。Mass预测保留现有阶段和有限邻居预算，最终约束检查全部可能接触对。

候选先经导航验证，再在最多四轮内处理相对运动接触。优先保留增加间距的移动，仍冲突时缩短双方；未解冲突及受影响运动取消本步移动，再验证导航和邻居。预算不足不能接受非法位置。

混编按小组最大体型保守排布，候选仍逐对验证；保持目的地分帧预算和部分分配。服务器继续已有10Hz模拟；工程车每个CharacterMovement子步检查，占位登记不依赖过期Mass快照。Crowd保守预判半径为本体半径＋净距，MaxAgentRadius改为1000厘米。

## 性能与计算复杂度

同一既有脚本、500单位、无客户端、40秒、shuttle模式和原地形；不修改压力场景或测试矩阵。表中为单次运行实测，不承诺固定百分比：

| 指标 | 修改前 | 首次修改后 | 最终修改后 |
|---|---:|---:|---:|
| 固定模拟步P95 ms | 1.6572 | 2.2492 | 6.4435 |
| 帧P95 ms | 18.4566 | 18.5264 | 20.7103 |
| 约束每帧P95 ms | 无此计数 | 0.6695 | 1.3859 |
| 候选对累计 | 无此计数 | 4010734 | 4007606 |
| 阻挡累计 | 无此计数 | 31462 | 31373 |
| 约束违规累计 | 无此计数 | 0 | 0 |

最终固定步P95比基线增加4.7863ms，首次复跑增加0.592ms；两次复跑有明显耗时波动，不能把其中一次当作稳定成本。完整数据见上方三次运行对比及[最终压力报告](../../TestResults/CommanderMove10Hz/clearance-final-20260919-n500-c0/analysis.json)。CSV按渲染帧累计，候选和阻挡包含预探测及两次批量验证；不是唯一单位对数，不是每模拟步平均耗时。解析已排除CSV尾部元数据。修改前没有违规计数，不能据此宣称修改前为零违规。

开销来自占位登记、空间桶候选枚举、最多四轮接触约束及导航复核。常规分布与附近候选数相关；极端密集情况下候选仍可能退化为二次量级。最终约束不以六邻居截断换取速度；未解冲突冻结关联运动。客户端只限制额外预测偏移，不运行全体严格求解，没有新增逐帧RPC或刚体模拟。
