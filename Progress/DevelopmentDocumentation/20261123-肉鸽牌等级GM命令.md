# 肉鸽牌等级 GM 命令

在开发版对局中进入游骑兵或指挥官席位。打开游戏控制台，输入 `gs.GM.Card.Set <卡牌ID或当前语言的完整牌名> <等级或max>`。游骑兵修改当前玩家的构筑，指挥官修改本队构筑。输入 `0` 移除该牌。获取次数未设上限的牌使用具体数字。结果可在 Output Log 搜索 `gs.GM.Card.Set`。

## 游骑兵多目标靶场

打开 `/Game/Maps/LVL_CommanderMassPrototype`，选择游骑兵席位。自空构筑逐行输入以下命令。

```text
gs.GM.Card.Set 10.01 3
gs.GM.Card.Set 14.01 max
gs.GM.Card.Set 15.01 max
gs.GM.Card.Set 16.01 max
```

四行依次取得强化子弹三级、人工智能引擎三级、分裂枪管三级、电磁技术三级。到 `GroundRogue_SplitObserve` 对准多个蓝靶，三级分裂枪管最多同时攻击五个锁满目标。单独输入 `gs.GM.Card.Set 分裂枪管 1`，每次上限变为两个目标。

持有分裂枪管或电磁技术时，`gs.GM.Card.Set 14.01 0` 会被拒绝。先将这两张牌分别设为 0，即可移除引擎。持有强化子弹时，设置互斥的爆破套餐会被拒绝。[现行数值](../Gameplay/游骑兵.md)

## 权威处理

入口沿用 F4 所用的个人或团队 Hybrid 卡牌事务。升级逐级执行正常获取限制。降级校验剩余构筑和依赖，指挥官同时撤回对应等级的效果来源。合法变更使旧候选失效，并按新版本同步 HUD 和武器。游骑兵移除再取得爆破套餐时重新计算爆破进度。相同等级的重复请求保留当前版本和候选。

正式牌表提供 ID、牌名、归属和等级上限。非 Shipping 的规则解码器才接受 GM 操作，普通选牌和已有快照继续使用原有格式。[控制台入口](../../Source/GuLiStrike/Gameplay/Cards/GuLiRogueCardSubsystem.cpp) · [游骑兵结算](../../Source/GuLiNetCore/Private/Capabilities/GuLiNetGroundRogue.cpp) · [指挥官结算](../../Source/GuLiNetCore/Private/Capabilities/GuLiNetArmyContract.cpp)

## 游骑兵 PIE 实测

2026-11-23 在上述地图的游骑兵席位逐条输入命令，读取个人卡牌等级和权威构筑版本。三张目标牌均为 3 级时构筑版本为 13。重复设置分裂枪管三级、请求四级、移除引擎、将强化子弹降至二级，这四次操作后版本仍为 13。分裂枪管可以单独降到一级并移除。依次移除电磁技术、引擎和强化子弹后，可以取得原先互斥的爆破套餐。17 次检查全部通过，测试结束时五张牌的等级均为零。[逐条命令与回读](../Evidence/20261123-RogueCardGM.json)
