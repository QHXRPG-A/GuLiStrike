# 游骑兵按键定向闪现与惯性拖拽动画 — 实施记录

## 实现边界

Character 在 Shift Started 回调中直接读取 EnhancedPlayerInput 的当前 MoveAction，避免依赖 Move 回调先后顺序。IA_Ground_Move 使用 Cumulative，反向输入抵消。以 Atan2(右轴,前轴) 加摄像机水平角写入既有 BlinkYaw；距离沿用归一化 Direction 的原算法。

BlinkComponent 权威接受请求时记录 FacingYaw，移除按 Direction 强制转身。状态恢复同步 Direction 与 FacingYaw，动画每步由两者差值重建固定混合角度。Ground 私有状态版本 13→14、移动呈现 8→9，输入和共享控制版本 7 不变。

AnimInstance 提供 BlinkBlend、BlinkDirectionDegrees、BlinkNormalizedTime，保留 BlinkSequenceWeight。Editor Library 局部替换最终 Sequence Evaluator 并清理旧变量节点，保留 TwoWayBlend 的 A 分支、IK、炮台及混入权重。Evaluator 禁止推进通知与根运动，BlendSpace 不使用输入平滑、权重平滑或标记同步。

动画由 `Scripts/GroundMech/Blink/author_blink_animation.py` 的显式一次性制作入口生成。日常导表只配置 BlendSpace/数据/节点，不调用重制函数。原始腿部轨道与前闪手调数据以 Source 姿态和附加曲线哈希核对。UE 5.7 Sequencer 数据模型不支持旧 raw-track Getter，改用 AnimPose 的 Source 数据求值，不把压缩或已叠加姿态写回原始轨道。
