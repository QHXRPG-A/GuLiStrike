# 双矿单位矿模型与 Blender 审核

## 制作方法

用可重复执行的 Python 脚本建立八个确定性母版。晶体采用带窄倒角的多边截面、错落肩部与尖冠；岩基采用嵌入地面的不规则切面岩块。蓝矿偏粗厚放射，红矿偏细长柱体与刀片；逐面颜色控制明暗与边缘亮度，晶体和岩基各一个材质槽。

残缺和残矿采用原母版零件的子集与封口截断，不重随机位置、不整体缩放。每件模型保留零件顶点组与矿种/家族/状态属性；审核与拼装使用链接网格副本。制作内容带专属所有权标记，重跑仅替换本脚本生成的数据，不删除其他场景内容。
