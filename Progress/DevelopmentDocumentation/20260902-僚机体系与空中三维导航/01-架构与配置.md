### 0.2 权威分类

`EGuLiMovementAuthorityMode`固定为：

- `ServerSimulated`：Commander Soldier。
- `OwnerPredictedServerReplay`：玩家Ship CharacterMovement。
- `ClientValidatedRelay`：Wingman与玩家Ground战争机器。

`ClientValidatedRelay`的含义不是“服务器低频模拟”：

1. Lease Owner客户端产生全部运行时Position、Rotation、Velocity、Bank、FlightMode和Path结果。
2. 服务器只在Candidate到达时校验。
3. 合法Candidate经确定性量化/归一化后保存为Accepted Snapshot并转发。
4. 缺包、Rejected、Stale、换主空窗期间，服务器不生成任何替代运动值。
5. Health、Damage、Death、Replenish、Reward和比赛结果仍只由服务器写。

必须持续满足：

- `server_wingman_motion_step_count=0`
- `server_ground_machine_motion_step_count=0`
- `server_generated_runtime_transform_count=0`
- `server_wingman_state_tree_tick_count=0`
- `server_wingman_path_request_count=0`
- `server_wingman_steering_step_count=0`
- `server_wingman_flight_integration_step_count=0`
- `server_ground_machine_state_tree_tick_count=0`
- `server_ground_machine_path_request_count=0`
- `server_ground_machine_steering_step_count=0`
- `server_ground_machine_movement_integration_step_count=0`

初始出生Transform和“复制合法Candidate的已接纳值”不属于服务器生成运动；任何从上一快照积分、外推、插值后写回共享逻辑状态的行为都属于违规。

### 0.3 服务端仍然承担的工作

- 创建稳定身份、Roster、生命和SimulationLease。
- 以1Hz检查Lease、连接、Heartbeat和LastValidCandidateTime。
- 收包触发Candidate身份/时序/运动/导航/碰撞验证。
- 保存有限Accepted Snapshot历史并转发给相关客户端。
- FireIntent收包触发敌我、生命、距离、LOS、冷却和幂等验证。
- Damage Ledger、死亡、补充、奖励与可靠表现事件。
- Bootstrap、LateJoin、观战和断线清理。

服务器没有Wingman/Ground固定运动Tick；网络队列为空时，不应产生它们的Validator工作。

## 1. 模块与依赖边界

### 1.1 逻辑目录

| 模块/目录 | 职责 | 禁止事项 |
|---|---|---|
| `Plugins/GuLiFlightNavigation/GuLiFlightNavigation` | Runtime数据资产、只读八叉树、异步A*、路径结果 | 不引用GuLiStrike玩法类型 |
| `Plugins/GuLiFlightNavigation/GuLiFlightNavigationEditor` | Bake/Validate/Clear、签名、Cook校验 | 不进入Runtime包 |
| `Source/GuLiStrike/Battle/Contracts` | 稳定ID、状态Ref、Candidate/Acceptance/Combat DTO和窄接口 | 不依赖具体Wingman/Commander类 |
| `Source/GuLiStrike/Battle/Relay` | Lease、Accepted Snapshot Store、事件驱动Validator、Rebase | 不运行运动、StateTree或A* |
| `Source/GuLiStrike/Gameplay/Wingman` | 客户端Mass模拟、服务器生命周期适配、远端表现 | 服务器侧不得实例化运动Processor |
| `Source/GuLiStrike/Battle/Combat` | 通用TargetHandle、Fire验证、Damage Ledger、表现事件 | 不信任客户端Damage/Health |
| `Source/GuLiStrike/Battle/Network/Relay` | Roster/Lease、Candidate、Acceptance、Accepted Pose、Bootstrap | 不承载Commander旧复制链 |
| `Source/GuLiStrike/Gameplay/Ship` | 保留CMC重演、生命和弹丸桥 | 不承载25架Wingman状态 |
| `Source/GuLiStrike/Gameplay/Ship/Abilities` | Pawn自有ASC、AbilitySet/Loadout、三项僚机GA和GroupAbilityConfig投影 | 不替代PlayerState Army ASC，不引入AttributeSet数值链 |
| `Source/GuLiStrike/Gameplay/GroundMachine` | 正式Ground类接入ClientValidatedRelay | 不与Commander Soldier混用Authority |

除FlightNavigation Runtime/Editor外，上述目录仍属于单一`GuLiStrike` C++模块。依赖边界依靠Public DTO、接口、前置声明和`.cpp`注册适配器维持，不因为逻辑目录增加虚假Build.cs模块。

依赖方向：

`FlightNavigationEditor -> FlightNavigation Runtime <- Wingman -> Battle/Relay -> Battle/Contracts <- Battle/Combat <- Ship/Ground/Commander Adapters`

- Runtime导航不认识Team、PlayerGuid、Lease、Ship或Commander。
- Relay不依赖Combat实现；Combat通过`IGuLiAcceptedStateProvider`读取状态。
- Header优先前置声明，具体include放在`.cpp`。
- UCLASS/USTRUCT/UENUM只在反射、复制或资产序列化需要时使用。
- 不移动现有公开类、不更改蓝图类路径，避免资产Redirector风险。

### 1.2 计划类

- `UGuLiSimulationLeaseSubsystem : UWorldSubsystem`
  - 只在Server/Standalone拥有写入实例。
  - 使用1秒Timer运行`RunLeaseMaintenance()`，不是每帧Tickable运动系统。
- `UGuLiAcceptedRelayStateSubsystem : UWorldSubsystem`
  - 服务器保存最后Accepted Snapshot和有界历史。
  - 唯一运动写入口为`AcceptValidatedCandidate()`。
- `UGuLiWingmanClientSimulationSubsystem : UWorldSubsystem`
  - 只在持有Lease的游戏客户端激活30Hz客户端模拟。
- `UGuLiWingmanValidationService`
  - 由Candidate接收事件调用；无独立Tick。
- `UGuLiSimulationNetSyncComponent`
  - Battle PlayerController的独立默认组件，处理Lease/Candidate/Acceptance/Rebase。
- `UGuLiSimulationWorldReplicationComponent`
  - 发布可靠Roster/Life/Lease和不可靠Accepted Pose。
- `FGuLiCommanderBattleAdapter`、`FGuLiShipBattleAdapter`、`FGuLiWingmanBattleAdapter`
  - 通过公共接口向Combat注册目标和生命入口。

| FlightNav Bake数据 | Cook资产，不是SaveGame | Editor Bake工具 |
| Tuning/EntityConfig/StateTree | Cook资产 | 内容开发者 |
| Group/Member身份、Roster、Team | Replicated-only | 服务器生命周期 |

| Client Simulation Transform/Velocity/Bank/Mode | Client-local transient | Lease Owner客户端 |
| Candidate | 不可靠上行 | Lease Owner客户端 |
| Accepted Relay Snapshot | 服务器短历史+不可靠下行 | 服务器只复制合法Candidate |
| Health/Dead/Reward/Replenish | Replicated-only | 服务器Damage/Lifecycle |
| Remote插值/外推、Niagara、音频 | Client-local transient | 表现层 |
