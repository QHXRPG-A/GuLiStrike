# 重防号战斗射程优化

## 实施

使用 WM01 / UnitTypeId=2 的正式表驱动路径，不涉及玩家地面机甲。Q当前通过`GuLiUnitSkillExecution`使用最终`BasicAttack`射程乘技能倍率；单独把普攻乘4会同时把Q放大4倍，因此将Q倍率3.2→2，得到`12000×2=24000cm`，准确等于旧`9600×2.5`。固定射程字段同步为24000cm。

| 入口 | 行/字段 | 旧值→新值 |
|---|---|---|
| `data/Excel/GuLiStrikeSecondaryWeapons.xlsx / UnitSkills` | WM01_Strafe.RangeCentimeters，J5 | 3000→12000cm |
| `data/Excel/GuLiStrikeSecondaryUnitSkills.xlsx / Skills` | WM01_HomingMissile.RangeCentimeters，F4 | 9600→24000cm |
| 同上 | RangeMultiplier，H4 | 3.2→2 |
| `GuLiStrikeSecondaryWeapons.xlsx / Projectiles` | WM01_Missile.MaximumLifetimeSeconds，M4 | 8→20秒 |
| `/Game/GuLiStrike/Commander/Skills/DA_CommanderSkills_V1` | WM01_HomingMissile主动定义 | 射程24000cm、倍率2 |

导弹原8秒寿命按24米/秒只能提供192米直线飞行预算；本次按2.5倍增加至20秒，覆盖240米圆心、8米随机落点区和起飞曲线。机枪现有24米/秒×5秒已覆盖120米，无需改变其寿命。MissileLauncher武器行中的3000cm不作为主动Q射程来源，实际范围来自上述主动定义。伤害、攻速、弹速、散布、冷却及解锁等字段经实施前后逐字段比对保持原值。
