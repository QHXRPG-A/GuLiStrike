# Hybrid单架构与旧CS运行路径退役

2026-10-12用户确认“不再管旧CS架构，已迁移的部分可以直接删了，性能测试也只测新架构”。此决定覆盖此前LegacyCS默认、最终对照后退役和12/48轮计划；沿用构建、重启及多进程授权。历史证据保留，之后不维护或执行CS回归。

## 已修改的边界

- 运行选项只保留Hybrid，默认配置同样为Hybrid；承载仍为LocalUdp/EOS，客户端仍为Rendered/LogicOnly。旧CS命令行显式报已退役，不静默启用旧分支。
- 启动器移除UE专用服务器、CS地址/端口与两模式展开，保留一个协调后端、一个渲染客户端、五个NullRHI客户端及原物理核分组。
- 公共GameMode从757行缩为81行，只保留角色Pawn配置、云端确认后的Commander镜头Pawn和引擎出生防重复入口；移除本地选席、换职提交、复活定时器、掉线载具托管和僚机重分配。Ground/Air出生、空席及接管由对象登记和提交结果驱动。
- 公共PlayerNetSync移除连接复制字段、确认RPC和重试/就绪写入；只读GameInstance/World的连接与当前PlayerState就绪。保留既有反射类路径和Blueprint就绪Getter。
- PlayerState删除身份、阵营、职责、席位、席位版本和两种就绪字段的CS复制登记及三个RepNotify；保留原属性名、反射类和Blueprint只读Getter。协调成员提交结果直接更新本地镜像。未迁通的资源和装备接口不在此次删除范围内。[删除前文本及哈希](../../TestResults/HybridFullAcceptance/Implementation/cs-player-role-replication-source59/files.json)保留。
- PlayerController换职直接提交协调服务，删除旧Server/Client换职RPC对及本地死亡排队回调。被移除方法没有BlueprintCallable/Pure暴露；原生调用已同步替换。
- 飞船运动组件移除项目的CMC输入打包、SavedMove、服务器重演/纠正、配置确认RPC、复制屏障和连接身份；1141行缩至441行。World逻辑时钟调用本机积分，查询端不推进。原转向积分和碰撞移动函数逐字复用，并保存[算法哈希](../../TestResults/HybridFullAcceptance/Implementation/cs-ship-movement-retirement-source56/reused-algorithms.json)；Hybrid显式私有快照字段未变，Ship版本保持5。
- Ground运动删除专用SavedMove、移动/回执容器、燃料和平台纠正、支撑ID复制与旧网络Tick；物理删除两个MovementNetwork文件，删除只验证旧CMC报文的测试及旧重复序列化。保留Mass连续碰撞、平台支撑、火箭燃料、障碍登记和碰撞片段回放；12项物理函数逐字复用，[哈希及文本快照](../../TestResults/HybridFullAcceptance/Implementation/cs-ground-movement-retirement-source61/files.json)留档。Ground显式快照字段未变，适配器保持4，与WM01独立；source62构建及600档移动/火箭恢复专项通过，战斗回归单独记录。
- 在600档正式战斗恢复V3通过后，删除Ground两个开火/瞄准RPC、旧输入/Tick分支、姿态与休眠复制、开火计数/来源/瞄准复制、燃料/上限RepNotify、火箭状态复制及旧CMC燃料基线入口；GAS火箭仅本机执行，输入与推进仍由操控者/模拟者和World逻辑时钟驱动。稳定反射类、属性名及Blueprint输入/Getter保留。11份删除前文本及[六项未改合同/算法哈希](../../TestResults/HybridFullAcceptance/Implementation/cs-ground-input-fuel-retirement-source62/reused-contracts.json)留档，Ground快照版本保持4。未完成的Ground升级入口及其复制登记仍待迁移，不把静态清理当成升级通过。
- 将原僚机选敌算法抽为共享玩法函数，旧实现中的重复算法已移除；保留Hungarian分配、切换惩罚、距离回差、地形和廊道检查。该抽取为复用准备，Hybrid攻击尚未接通，不作为全玩法完成。
