# 游骑兵无人生还大招试玩

在正式地图驾驶游骑兵起飞、悬停并扫向多个地面目标。按 Q 的条件是机甲脚底到下方支撑面至少 30 米。释放期间可以转动准星，每一发按当时的方向取终点，从背部左右上方交替出弹。

| 试玩项目 | 预期 |
| --- | --- |
| 发射节奏 | 一级每轮 10 发，每 0.5 秒一发。二至四级每 0.3 秒一发，第五级每 0.2 秒一发。 |
| 施放动作 | 双炮臂完全交叉后蓄力整 1.0 秒，胸舱带着双臂由轻到重地抖动。0.1 秒展开后闪光，连射中保留机体轻颤，每发对应一侧肩甲后坐。准星稳定，双腿回到悬停姿势。 |
| 施放镜头与闪电 | 本机驾驶游骑兵成功按 Q 后，镜头从肩后绕到正面仰拍。展开后用 0.20 秒沿左肩回到玩家机位。一级至五级及靶场试用都能触发。机身闪电放大到前版的两倍，镜头轨迹、回镜用时与闪电倍率均走肉鸽源表。 |
| 散布与轨迹 | 一至四级的发射散布半角为 2.5°（总张角 5°），五级半角为 4°（总张角 8°）。每发独立起弧，可以飞出锥体再收束。已经发出的导弹继续飞向原定点。 |
| 距离与速度 | 每发从自己的肩部发射点量水平距离。实际弧线首次到达 200 米时锁住水平坐标，以 45.5 米/秒向下起步，再以 95 米/秒² 加速，触地爆炸。巡航中先落地可提前引爆。 |
| 表现与命中 | 弹头三个方向保持两倍尺寸，自带尾迹延长到 27.3 米。导弹可穿过单位与墙侧，从上方触及地形、屋顶或高架台面时爆炸，从下方通过平台时继续飞行。 |
| 调参 | 水平转俯冲距离、弹速、巡航时限和下砸加速度走游骑兵技能表。弹头倍率、尾迹长度和淡出时间走特效表。 |
| 性能 | 巡航按 30 Hz 推进，权威端每 0.1 秒检查走过的轨迹与地面高度。只有落地爆炸才按范围查找受击体。 |
| 伤害 | 每枚基础伤害为 30。三级和四级为 32.4，五级为 34.8。 |
| 选牌升级特效 | 选牌界面收起后，游骑兵的普通升级光以 2 倍速播放。无人生还四升五时直接播放 1.5 秒脚下龙卷风，前 0.2 秒由目标尺寸的 10% 放大到 100%。两种特效均在上版半径的基础上将高度拉长到两倍。 |
| 连续试玩 | 发完最后一枚恢复移动。仍满足高度条件时可再按 Q。 |

试玩入口为 `/Game/Maps/LVL_CommanderMassPrototype` 的 **Play → 无双·游骑兵 → 无人生还靶场**。驾驶角色使用 Ground 席位的正式 ModelId 4001。普通对局在爆破套餐路线取得三级强化爆炸弹后，无人生还进入 F4 候选池。选到一级后解锁 Q，之后可再选四次。见[开发记录](../DevelopmentDocumentation/20261118-游骑兵无人生还大招试玩.md)。
