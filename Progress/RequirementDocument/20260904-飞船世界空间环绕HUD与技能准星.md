# 飞船世界空间环绕 HUD 与技能准星

## 背景

当前 Ship UI v1 使用整屏 UMG，中央“航向”标记不符合第三人称巨型飞船的观察与瞄准语义。目标是保留参考图的轻量科幻信息层级，但把信息拆成真实世界空间节点环绕本地玩家飞船，并为后续需要瞄准阶段的 GAS 技能提供可复用准星。

## 需求描述

- 顶部状态、左侧飞行、右侧武器信息使用世界空间 Widget 节点；节点每帧按相机 Forward/Up 重建朝向，使平面始终平行玩家屏幕，并保持稳定屏幕尺寸。
- 只要本地飞船仍有效，三个常驻面板就必须钳制在 24px 视口安全区内；镜头穿近舰体、部分包围盒角点位于相机后方或一次投影失败都不得把整套 HUD 隐藏。
- UI 使用无深度测试且在 Motion Blur 之后绘制，镜头运动模糊不得降低文字与线框可读性。
- HUD 只显示已有权威或本地真实数据：就绪、舰体生命、速度/最大速度、Boost、基础武器和僚机导弹可用状态。
- 准星采用非圆形断开切角样式，默认隐藏，由 Gameplay Ability AssetTags 决定是否启用。
- `Ship.Ability.Reticle.Omni` 允许虚拟准星在安全视口内自由移动。
- `Ship.Ability.Reticle.Bounded` 使用技能自带的归一化矩形，显示半透明切角范围框并把准星限制在框内。
- 进入瞄准态立即把相机前向对齐飞船前向；瞄准期间相机跟随船体，鼠标 Look 输入改为移动准星。退出只隐藏准星并恢复自由环绕，不恢复进入前视角。
- 当前编队、基础武器和右键瞬发导弹不接入新准星。

## 边界

- 不做 UI 淡入、闪烁、缩放、补间或镜头过渡动画。
- 不新增目标选择、确认发射、命中判定、RPC、服务器瞄准校验或 Gameplay Targeting System 依赖。
- 不显示假目标、假弹药、护盾、热量、导弹警告或停靠信息。
- 不替换或删除 Gate 2 历史资产 `/Game/Ship/UI/Widgets/WBP_ShipHUD`。

## 验收标准

- [x] 三个常驻 HUD 节点只为本地拥有飞船创建，在缩放、FOV 和分辨率变化时保持稳定屏幕大小与环绕位置；近距穿模/部分角点过近时仍常驻屏幕安全区。
- [x] 所有节点逐帧旋转为屏幕平行平面、不被舰体深度或 Motion Blur 影响、不接受焦点或硬件输入。
- [x] 准星默认隐藏；两个 GAS Tag 分别进入全向和受限模式，互斥配置可被拒绝。
- [x] 瞄准态相机与飞船前向一致，鼠标移动虚拟准星；退出后相机从当前方向恢复自由环绕。
- [x] 受限模式显示半透明范围框并正确钳制准星；全向模式不显示范围框。
- [x] 当前三个正式技能行为不变，新增测试仅覆盖本需求。
- [x] 五个 Widget 无动画、Tick、Binding、MVVM 和 EventGraph 节点。
