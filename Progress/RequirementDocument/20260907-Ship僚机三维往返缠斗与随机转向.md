# Ship 僚机三维往返缠斗与随机转向

- 上游：在“Ship 僚机对地轰炸与对空盘旋攻击”首版上，替换会产生原地绕圈观感的对空 `AirOrbit`

## 背景

首版对空攻击在目标附近持续生成切向盘旋速度，固定翼僚机容易围绕很小的局部圆心连续修正，画面接近原地转圈，也没有形成“接敌、脱离、拉开、折返”的空战节奏。本次把对空机动改成每架僚机独立的三维往返状态机；对地 45° 俯冲、10 枚/1.5 秒和纯 AOE 保持原语义。

## 已确认行为

1. 每架僚机独立循环 `AirApproachFire → AirBreakawayTurn → AirRetreat → AirReturnTurn → AirApproachFire`。编队级 UE StateTree 继续以 10Hz 管理护航、归队、紧急避障、失联与死亡；个体攻击状态机只生成 30Hz 引导速度。Mass Integration 仍是 Transform/Velocity 唯一写入者。
2. `AirApproachFire` 以 45m/s 朝实时目标接近并允许机枪开火。进入“目标半径 + 僚机半径 + 300m”边界后停止开火，进入脱离转向。
3. 每次进入 `AirBreakawayTurn` 或 `AirReturnTurn` 都重新进行确定性随机：左右偏航绝对值 40°–90°、俯仰 −30° 至 +30°。种子组合僚机稳定种子、目标 Revision、状态入口序号、ClientTick、状态盐和候选序号。
4. 转向控制点位于当前位置沿随机方向的 `2 × 物理转弯半径`；45m/s、20°/s 时约 257.8m。进入控制点 75m 范围或越过到达平面后改指向最终目的地；转向 10 秒仍未完成时直接引导，避免持续绕圈。
5. 脱离转向入口为本轮冻结一个远离点。其纵向位于目标朝 Ship 方向的 35%–60%，且至少 `max(450m, 避让边界 + 75m)`；横向/垂直位于 150m×100m 椭圆截面。走廊过短时允许延伸到 Ship 后方。
6. 最多测试 8 组确定性远离点/控制点候选，每段都必须通过 FlightNav 和 WorldStatic 球扫掠。本轮不随 Ship 或目标移动重采样；没有安全候选时取消该机攻击引导，等待 1 秒后重试，让编队 StateTree 接管归队或恢复。
7. 到达远离点 75m 内或越过到达平面后进入随机折返；折返控制点完成后重新朝实时目标闭合，循环往复。固定翼速度、有限转弯率、僚机分离和逐步避障全程保留。
8. 自动目标只在 1500m 内获取；自动和指定目标均保持到 1800m。目标超过 1800m时清空目标并锁住自动索敌，直到按服务器最新 Accepted Pose 判定归队完成：至少向上取整 80%的存活僚机在 Formation 的 600m CatchUp 范围内，且没有存活僚机超过 900m Recovery 范围。缺少或超过 1 秒的姿态样本不能算归队完成。
9. 已开始的地面俯冲继续完成冻结的一轮，结束后再响应超距归队。死亡、紧急避障、租约/配置失效仍可按既有高优先级规则中断。
10. 编队、僚机机枪、僚机对地导弹继续是三个独立 Ship 技能。以后激光等表现和执行语义不同的武器采用同槽换技能、Definition 与执行器；同类武器的伤害、冷却等升级使用新的冻结 Profile。

## 验收标准

- [x] 旧 `AirOrbit` 攻击模式和切向盘旋引导从本功能源码、数据与资产配置中移除，替换为 `AirDogfight`。
- [x] 四状态循环、只在接近阶段开火、转向到达/越面、10 秒超时和 2×转弯半径由定向自动化覆盖。
- [x] 同一入口随机结果可复现，不同僚机/轮次发生变化，左右和上下转向均能出现。
- [x] 远离点满足纵向下限和椭圆区域，本轮冻结，并通过 FlightNav/WorldStatic 候选验证。
- [x] 1500m 获取、1800m释放、自动索敌锁和 80%/600m/900m 归队门生效。
- [x] Dedicated Server + 两客户端各 25 架完成多轮接近、脱离、远离和折返；服务器运动写入保持 0。
- [x] 对地俯冲、固定条带、10枚/1.5秒和纯AOE定向测试无回归。
- [x] 源码 Editor/Game Development 构建及 7 项专项自动化通过，数据资产回读成功。
