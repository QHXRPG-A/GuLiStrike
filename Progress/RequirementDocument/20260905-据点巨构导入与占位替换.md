# 据点巨构导入与占位替换

## 背景

用户已提供混凝土纪念塔参考并要求按巨物规格制作。Blender 首版为约 71.03 × 66.20 × 300m 的建筑。本次用户明确要求“将该建筑导入至 UE，替换之前的占位资源”。

## 需求描述

1. 导入本次已交付的 FBX 和混凝土 PBR 贴图，用于游戏中的据点。
2. 替换当前 20m 方块外观，更新建造目录中的包围盒与接地偏移。
3. 保留现有据点输入、类型与资产引用，保存可继续使用的 UE 资源。
4. 核对导入尺寸、材质和编辑器中的显示结果。

## 边界

- 延续首版的 300m 高度；这是制作初值，用户确认的是巨物方向。
- 沿用现有整块 Box 放置与实体阻挡方式。构件间缝隙不新增穿行、室内、破坏或占领功能。
- 不改原生建造逻辑、其他建筑资源、地形或战争机器资产。
- 不新增或扩充自动化测试。既有 20m 占位断言不代表本次新资源需求。

## 验收标准

- [ ] 原据点资源显示为巨构，资产引用可正常解析。
- [ ] UE 尺寸约为 7103.087 × 6619.805 × 30000cm，运行时 Scale 为 1。
- [ ] 目录据点行匹配新网格包围盒和地面原点。
- [ ] 底色、粗糙度、DirectX 法线正确连接，并有 UE 视觉检查证据。
- [ ] 保留原方块备份，保存正式资产并归档。
