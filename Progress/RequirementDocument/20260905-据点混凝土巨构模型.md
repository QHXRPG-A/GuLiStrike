# 据点混凝土巨构模型

## 背景

当前据点为 20×20×20m 灰色占位方块。用户提供 8 张参考图，并打开 Blender，希望为游戏据点发展实际模型；后续明确“是一个巨物，按照巨物的规格开发”。

参考呈现清水混凝土纪念塔：高低错落的竖向板墙、半圆柱及弧形壳体、中段宽腰带、顶端开口管柱、深而窄的竖向缝隙。图片中的微小人形用于强调尺度。

## 需求描述

1. 依据用户参考制作可编辑的 Blender 第一版模型，保留非对称竖向轮廓和中段弧形腰带。
2. 按巨构比例制作。**假设**：本版高 300m、最大宽约 70m；300m 是助手制作初值，用户未指定精确高度。
3. 使用灰白清水混凝土，增加基础分缝、细颗粒与模板拉杆孔的平铺材质；不把本版包装为近距最终美术成品。
4. 输出整体、反面、地面仰视和局部预览，展示场景包含 1.8m 人形比例尺。
5. 交付 `.blend`、FBX、GLB、可独立使用的贴图和规格记录。

## 边界

- 本阶段为模型与外观评审；不改 UE 建造目录、占位资产、玩法功能、碰撞、占领、经济或出兵规则。
- 不制作内部楼层、可进入空间、破坏骨架、战斗特效或阵营换色逻辑。
- 保留 Blender 打开前已有场景，不覆盖用户其他对象。
- 本次未请求添加自动化测试，直接进行模型、文件与渲染检查。

## 验收标准

- [x] 产生可编辑的第一版工程，21 个构件可分别调整。
- [x] 实际高度 300m，外包宽度约 71m，包含 1.8m 人形比例尺。
- [x] 四个指定视角已渲染并人工查看。
- [x] 导出网格有 UV、材质和米制尺寸；FBX 回读尺寸一致，GLB 只含目标建筑。
- [x] 工程、贴图、参考、导出和项目文档均落盘。

艺术定稿和 UE 实机验收尚未进行，以上勾选只表示第一版交付条件有证据。
