# Ship导入与扫荡者战争机器风格重制

- 当前 Blender Ship 船体及独立描边导入 UE，保留第四套 UV 的内部线稿遮罩和现有碰撞、挂点。
- Id 1 / DefaultSoldier：Wheeled Bug 改为扫荡者；机枪代替驾驶舱，只俯仰 −15°～60°，轮子实战随移动旋转。
- Id 2 / WM01：Quad Lvl3 改为战争机器；保留侧炮，背部左右两个独立导弹舱，固定向前上仰45°，每舱一个现有发射出口。
- 两台保留已验收图的机械细节与橙红白涂装，不能以低模为由改成玩具式方块；按原单位占地长边校准到约5%误差。
- 地面摧毁使用 NS_Explosion_03，僚机摧毁使用 NS_Explosion_05，均补冲击波；轰炸使用 NS_Explosion_01，原扩散环缩到主火球约1.5倍。
- 保留源特效完整烟火节奏、旧资源回退、兵种Id及战斗数值，统一缩放并同步部署脚本。
- 继续批量静态网格渲染，机械姿态及枪口跟随仅由客户端现有数据驱动，不增加RPC。
- 验收包括编译、资产读回、近远景及阶段画面、PIE入口/回池/服务器隔离、约定的爆炸和单位规模性能采样。
- 本轮不新增或修改自动化测试文件；仅保存明确修改资产。

## 最新建模约束

- 2026-09-17 最新修改覆盖此前双单位统一加线稿要求：扫荡者删除内部线稿与外轮廓，战争机器保留；重导入 UE。地面摧毁爆炸缩至当前的 0.6，僚机摧毁配置不变；修正当前指挥官关卡环境、单位和爆炸被后处理压黑的问题。
- 用户明确停止 Tripo；后续使用 Blender 规则几何手工建模，不复用其生成网格和贴图。
- `ArtSource/TacticalStyle_20260916/Concepts` 下的 Sweeper / WarMachine 各一张 Concept_v1 与 Front / Left / Back 共八张图，是用户已验收方案。按这些图还原，不另做风格迁移、重新设计或要求重复确认方案。
- 还原内容包括整体比例、主体轮廓、装甲厚度及分件、色块分布、轮毂/悬浮盘、武器和导弹舱；表面应平整清楚，保留中等尺度的机械细节。减面需保留这些特征。
- 扫荡者两侧装甲有向外凸起的弧度，应按图制作规则、左右对称的成形曲面，不能将“表面光顺”误解为侧甲必须是平板。
- 与 Ship 一致指造型语言、干净线稿和适度分档光影；不是复制 Ship 的蓝白配色，也不是极简低龄卡通。
