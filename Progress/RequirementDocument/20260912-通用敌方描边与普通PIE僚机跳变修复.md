# 通用敌方描边与普通PIE僚机跳变修复

- 敌方Ship和僚机显示清晰红色外轮廓；己方和友方不显示敌方描边。
- 阵营网格组件和相机后处理可复用于后续兵种，沿用现有阵营数据，不增加网络消息。
- 默认描边约2像素，受场景遮挡影响，保留原机体材质。
- 保持Owner逻辑、碰撞、攻击30Hz；定位网络样本、表现时钟、逻辑/模型Transform之间的首次跳变。
- 按普通播放入口、原GameMode和真实目标战斗验证；不以固定百万血靶和改出生点的QA结果替代。
- 避免防御性编程，保留合法身份与真实死亡语义，工作区既有改动全部合并保留。

- [x] 普通PIE同条件前后采样可解释并验证卡顿/瞬移的修复。
