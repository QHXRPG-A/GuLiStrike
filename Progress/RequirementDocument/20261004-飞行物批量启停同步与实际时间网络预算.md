# 飞行物批量启停同步与实际时间网络预算

## 需求与边界

覆盖指挥官、玩家 Ground 席位与僚机的机枪、激光、曲线弹和追踪弹。创建与结束走同一个可靠通道，每批至多 16 条，实际编码载荷至多 1000 字节；冻结运动参数、服务器散布方向、FlightId、Epoch 和必要的表现参数。取消飞行物的周期快照、导弹纠偏及 Actor 移动复制。加入或重连只补建一次当前活跃飞行物；去重和结束墓碑阻止复活。

客户端池初始 512 槽，按 256 扩容，各 World 独立管理；表现 Actor 不复制、不回调伤害，专服不建表现池。服务器保留数据轨迹、空间查询、扫掠和伤害账本。500 是验收负载，没有新增玩法硬上限。客户端不上传权威伤害。

连接使用项目内 `UGuLiIpConnection`。原 Tick 完成后，从原债务、实际发送增量与实际网络时间重新结算；单次恢复及空闲信用均最多 100ms，处理提前返回、初始化、关闭和计数器回绕，Replay、InternalAck、拥塞控制沿原行为。连接速率保留 250000B/s，单位模拟及姿态采集保留 10Hz。战局协议 23 → 24。

## 验收

- [x] 隔离验证预算开关；1608 条原生样本最大恢复偏差 0.002507%，长卡顿只恢复 100ms。
- [x] 离线公式覆盖 20/35/60/120Hz；原生实测约 20Hz 与 32–36Hz。
- [ ] 原生实际 60/120Hz 间隔：当前 PIE 在对应上限下仍只到约 36Hz，未算通过。
- [x] 三来源创建/结束、服务器账本回归、真实 Ground 开火、曲线负载、静态障碍反弹及来源死亡检查。
- [ ] 双枪散布、完整移动目标视觉矩阵、丢包下断线重连及独立客户端 Actor/碰撞成本。
- [x] 去重、一次性中途加入补建、过期创建抑制、World/Epoch 清理与池复用；17 项唯一回归最终通过。
- [x] 30 秒三来源峰值 508，持续飞行状态流量为零；该负载的最老待发姿态年龄 P95 为 0ms。
- [ ] 相同人口、开火、镜头与客户端数的旧版/新版 30 秒差值，确认飞行总流量下降至少 50%。
- [x] 在 `/Game/Maps/LVL_CommanderMassPrototype` 保存三来源和约 500 枚飞行物入口、四个出生点和反弹挡板；编译、重载、回读及运行结果留档。

性能目标须用实际采集确认；预算公式核对、静态源码和资产回读不替代运行验收，也不预先承诺 FPS 提升。
