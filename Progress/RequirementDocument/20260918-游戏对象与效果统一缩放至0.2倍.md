# 游戏对象与效果统一缩放至0.2倍

## 确认范围

用户要求模型变为原尺寸20%，当前已开发游戏特性和效果同比适配。地图不缩、速度同比缩、时间不变；原地图同距离赶路约需原来的5倍时间，不另调经济补偿。

`/Game/StylizedPineEnvironment/Maps/Demo_Map` 的地形、树木、草坪、岩石和布局保持。该图仅增加可单独移除的验收陈列，不迁入完整对局、不改默认地图，不设计新出生点、领地或矿区。

## 数值合同

- 长度、速度、加速度×0.2；平方距离×0.04。UE继续使用厘米。
- 时间、冷却、射速、动画周期、角度/角速度、FOV不变；伤害、血量、成本、库存、产量、数量、人口不变。
- 屏幕像素UI不同比缩小；世界空间锚点、范围提示与真实玩法尺寸一致。
- 不缩绝对世界坐标、领地边界、出生锚点或矿簇中心；对象内部布局缩小后重新贴原地形。
- 不改原网格、骨骼、Blender/FBX或商城原件，保留造型、配色、既有线稿例外和动态效果时序。
- 不使用全局时间倍率、WorldToMeters、全世界重力修改或运行中战局热切换。

## 必须覆盖

单位/载具/建筑/矿物/残骸；模型与碰撞/选中/挂点；地面和空中导航；全部已接入武器/技能/护盾/占领/传送；建造生产、采矿运输、门与坡道；弹丸、激光、导弹、枪口、尾焰拖尾、爆炸和材质反馈；三种角色镜头及世界UI；网络精度和相关烘焙数据。

Q专项：射程240→48米，落点区域直径40→8米，爆炸/预警半径8→1.6米；6秒冷却与0.8秒预警波纹保持。预警从服务器冻结的实际伤害范围读取，不维护独立半径。

- [ ] 清单包含旧值、目标值、坐标空间、应用入口及迁移版本；重复执行不二次缩放。
- [ ] 有效包围盒、碰撞、选中、挂点、残骸和爆炸一致，父子继承不重复应用。
- [ ] 移动、建造出兵、采矿进出厂、舰载机、护盾、占领、传送和镜头回归。
- [ ] 服务器/客户端尺寸与导弹预警一致；XY/Z/速度量化为20厘米/2厘米/20厘米每秒；旧协议拒接。
