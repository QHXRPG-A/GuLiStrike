# 地面机甲辅助瞄准

## 背景与目标

降低地面机甲机枪的精确指向负担，同时保留玩家对鼠标、镜头和开火时机的控制。适用于地面和火箭跳过程中的同一机枪。

## 已确认规则

- 以鼠标为屏幕圆心，敌人瞄准点沿相机右向偏移100cm所得的投影距离作为该目标的判定半径；使用同一视口像素坐标，随目标深度、镜头缩放变化。
- 圈内持续辅助，始终选择屏幕距离最近的有效敌人，不保持旧目标。屏幕位置完全重合时先取相机深度较近者，再按稳定目标标识排序。
- 只修正机枪瞄准点和出膛方向；鼠标、镜头和上身原有朝向逻辑保持。左键按下/松开仍负责开火/停火，已发射子弹直线飞行。
- 候选覆盖现有战斗系统的Mass部队、僚机，以及带战斗血量组件的飞船、建筑和其他Actor。排除自己、友军、未分配阵营、死亡、相位化、屏外、超射程和场景遮挡的目标。
- Mass优先使用AimOffset，缺失时取模型包围盒中心；Actor使用碰撞包围盒中心，僚机使用已接受姿态中心。检查相机和枪口到目标点的场景遮挡。
- 无候选或目标失效时恢复原始鼠标射线，包括空处开火；界面、建造、失焦、行动锁和解除占有沿用原有输入约束。

## 配置与边界

配置唯一入口：[GuLiStrikeMech.xlsx](../../Data/Excel/GuLiStrikeMech.xlsx) → `技能表` → `id=1 / BasicMachinegun`（第4行）。`AimAssistEnabled=true`，`AimAssistRadiusCentimeters=100`。不建立蓝图默认值副本；各级机枪升级共同引用该技能行。火箭跳与既有升级数值不改。

本轮不增加锁定UI、自动开火、提前量预测、弹丸追踪、新网络协议或新的可伤害对象。不新增或扩充测试文件、用例、测试脚本、框架或地图；不自动运行已有测试、PIE、Standalone或性能验收。初始默认不编译，用户随后明确要求编译，已完成GuLiStrikeEditor原生构建及新字段导入。

## 验收标准

实际交付证据见[开发文档](../DevelopmentDocumentation/20260921-地面机甲辅助瞄准.md)。玩家效果在 `/Game/Maps/LVL_GroundMech_FireReview` 既有靶场确认：靠近敌方瞄准点时枪口修正，鼠标位置保持；多目标选最近者；移出范围或目标失效恢复自由射向。静态与场景数据核对不代表运行效果通过。
