# Ship僚机对地轰炸与对空盘旋攻击

> 后续变更：本文件记录首版攻击落地。对空“目标点盘旋”已由[三维往返缠斗与随机转向](20260907-Ship僚机三维往返缠斗与随机转向.md)替换；对地俯冲需求继续有效。

## 背景

现有 Ship 僚机具有护航编队、各自选敌的基础伤害和手动五机导弹齐射，尚无统一 Ship 攻击目标、俯冲轰炸或对空盘旋。本次将僚机机动、武器表现和独立技能接成可调的完整攻击循环。

## 需求描述

1. 以 Ship 为中心的三维球形范围自动捕捉目标；有效的玩家指定目标优先。本轮只交付指定/清除目标接口与只读当前目标，不增加选敌按键或 UI。地面目标为现有 Commander Soldier，空中目标为 Ship/Wingman。
2. 25 架存活僚机各自就位后陆续出击。高度过高时先自行下降进场，再执行固定 45°、1.5 秒俯冲。每架每轮发射 10 枚；数量和时长由表控制。
3. 拉起起始高度限定在离地 50–100 米，初值 100 米；平滑拉起过程中最低高度不得低于 50 米。进场、转弯和爬升不计入 1.5 秒投弹段。俯冲位移为速度×时长/√2；45m/s 时最大投弹起始高度约147.7m。
4. 每架沿自己的进攻方向生成条带，首枚落点是目标地面位置。俯冲开始冻结整条落点，本轮不随目标移动或死亡重算。每枚从实际发射僚机的枪口朝其落点发射；飞行段继续复用 WM01，命中爆炸改用指定 `NS_Explosion_Big_17` 的项目内副本。按2026-09-13最新要求，主体特效使用5倍组件Scale，冲击波保留此前3.1倍Scale；视觉大小不再作为40米伤害半径的精确边界。每次爆炸按复制效果种子生成随机 Yaw，Pitch/Roll 保持 0，两层同向同时播放，并在 3 秒上限到达时强制退出活动状态；Commander 的 WM01 爆炸保持不变。
5. 对地仅 AOE 结算，不叠加碰撞单体伤害；一枚对同一目标最多结算一次，不同导弹可以分别伤害目标。
6. 对空以配置速度接近目标，进入安全距离后维持距离绕目标盘旋。机枪仅在机头前向射界、射程和 LOS 同时满足时开火；盘旋未对准时停火。复用指挥官机枪表现。
7. 紧急避障、死亡、对应武器更换或模拟租约失效时，取消未发弹药并安全退出，不补喷；已接纳弹体继续按发射快照结算。
8. 编队技能不变，新增独立的常驻僚机机枪、僚机对地导弹两个 Ship 技能。未来激光等表现不同的武器采用同槽替换技能/执行器，数值升级沿用配置修饰。

## 边界

- 不制作激光、升级选卡、换装 UI、手动选敌操作或新的目标类型。
- 不为每架僚机增加 ASC/Actor，不为每发子弹激活 GA；服务器不运行僚机导航或飞行积分。
- 本任务开始时工作区已有大量未提交修改，在既有工作上增量实施，不回滚其他任务改动。
- 用户已明确授权新增 GuLiWingmanAttackRunTests.cpp、GuLiWingmanAttackCombatTests.cpp，及仅覆盖本功能的 Dedicated Server+双客户端 PIE。其他测试扩展不在授权内。

## 验收标准

- [ ] 指定目标优先，自动目标失效后重选；两种攻击消费同一目标命令。
- [ ] 每架正常完成的俯冲恰好在1.5秒内发射10枚，改表后数量和时长生效。
- [ ] 45°俯冲、合法高度拉起、平滑转弯及独立进场均可观察；没有瞬移或绕过安全积分。
- [ ] 首枚从目标开始、后续按各架来向展开条带；本轮落点不跟随移动目标。
- [ ] 纯AOE、重复消息去重、来源追踪、换装和中断行为正确。
- [ ] 对空接近后盘旋，机头未对准时无权威开火，也无残留的持续枪口火焰。
- [ ] 25架/双客户端表现与权威伤害一致，视觉裁剪不减少实际发射/伤害数量。
- [ ] 定向测试、源码版Editor/Game构建及BuildId核对通过，证据归档。
- [x] 2026-09-13表现增量：指定Big_17项目副本接入随机Yaw和3秒清理；最新调整为主体5倍、冲击波3.1倍，Commander引用未改。
