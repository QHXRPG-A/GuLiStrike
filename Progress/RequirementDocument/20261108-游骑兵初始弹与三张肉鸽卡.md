# 游骑兵初始弹与三张肉鸽卡

## 已确认规则

武器档位保留基础伤害 D=10／15／20、基础攻速 R=4／8／12。游骑兵通过 Ground 席位使用个人构筑，与重防号 WM01 的指挥官构筑分开。

| 项目 | 规则 |
|---|---|
| 初始子弹 | 0.6D，即6／9／12；长度由6000改为3000厘米，当前宽度不变，表现弯曲为0，直飞 |
| 先驱者、扫荡者 | 当前弹道长度再减半，当前宽度不变、零弯曲；伤害、弹速、散布保留 |
| 重防号 | 原有完整子弹效果和数值保留 |
| 09.01 增加攻速 | 无前置，重复获取升级；实际攻速 R×1.08^等级 |
| 10.01 强化子弹 | 无前置，单级；恢复D伤害与原完整弹道 |
| 11.01 爆破套餐 | 无前置，最多三级；每5／4／2发普攻附一枚爆炸弹 |
| 前置关系 | 06.01折射、07.01灼烧均依赖10.01；08.01灼烧爆裂依赖07.01 |

实际攻速上限30发/秒。超过上限的下一等级不进入候选，选牌确认时再次校验；武器换档同样拒绝超限组合，不截断增益。构筑变更刷新武器缓存、伤害和HUD，并按剩余冷却比例调整计时。

## 动画触发与直接命中

基于正式 `Anim_Mecha_Shoot` 制作一秒 `Anim_GroundFire_AlternatingLoop`，由单一循环Montage播放，右Fire在0秒、左Fire在0.5秒，通知携带枪口侧；两枪动作错开半周期，首尾连续。实际攻速R对应播放倍率R/2，总间隔1/R、同侧周期2/R。按住持续播放，松开停止新增发射；重按保留下一侧并遵守剩余冷却，升级保留相位与剩余冷却比例。移动、瞄准和骨骼分层保留。

开火输入先更新Loop状态，再由逻辑端正常推进动画；真实Fire通知产生事件，骨骼更新后同一步读取枪口，进入Mass共用的 `Launch → 碰撞 → 伤害结算`。删除游骑兵申请接纳、等待回执、启动单次动画及再次等待释放的链路与第二次射速等待。不以定时器伪造Fire；离屏仍推进逻辑动画，显示端姿态更新不得再次触发玩法。

通知确定发射顺序，回执和容器遍历不得改写左右顺序；通知、ShotId、恢复及重复回执不得重复发射。枪口反馈与公共发射一致，单发失败记录原因，不因开火动画异常暂停整场战斗。初始/强化弹仅由冻结快照区分数值和表现，共用直接命中链路，无强化前置。使用真实敌方Mass单位，沿ShotId核对通知、枪口、入池、碰撞、提交、有效回执及生命/护盾数值，并回归Mass原有射击。

PIE启动就绪后退出启动超时判定，后续错误保留真实原因。恢复保存循环相位、下一枪侧别及发射序号；协议、恢复版本和正式Manifest同步。

## 爆炸弹和恢复

爆炸弹与触发普攻同时发射，从当前枪口沿不随炮管自转的上身横轴向外偏移50厘米，右枪向右、左枪向左，方向与普攻平行。独立位置、碰撞、寿命和结束状态；主弹结束不回收附弹。弹速为普攻70%（当前16800厘米/秒），射程120000厘米、寿命约7.14秒、碰撞半径15厘米；外移路径先扫掠阻挡，避免穿墙出生。无追踪、抬升或曲线。命中敌人或阻挡地形爆炸，超时/射程耗尽直接回收。

弹体与拖尾视觉尺寸2倍，命中爆炸大小不变。项目内副本组合 `Missile_Cluster/飞弹` 导弹载体与尾迹连接、`VFX_Missile` 飞行主体/烟火/Ribbon、`NS_Explosion_19` 命中爆炸；移除普通弹拖尾替代路径。Niagara记录世界空间历史位置，停留0.12秒、淡出0.38秒，弹体结束后尾迹继续消散。源资源的追踪、曲线和自带爆炸不参与玩法，公共弹丸池统一位置、碰撞、结束与结算。

爆炸伤害固定为当发基础档位的2D，即20／30／40，不要求强化子弹；半径1500厘米，范围内无衰减。只结算一次范围伤害，普通子弹仍照常结算。爆炸不附加直接命中伤害、不触发折射、灼烧、灼烧爆裂或自身；受击体、敌我、护盾及遮挡遵循现有范围伤害规则。

计数仅由权威接纳成功的原始普攻发射推进，打空计数；失败、重复回执、折射和爆炸弹不计数。达到阈值附弹并归零；首次取得或升级11.01归零。进度归属PlayerGuid，停火、死亡复活、换席和同局恢复保留，新局清空。

每发冻结伤害、实际攻速、表现弹种、构筑版本和附加弹授权，保存Fire时刻和枪口。一次原始接纳记录保存两条独立轨迹，附加弹身份从原始ShotId稳定派生；两条轨迹及待结算回执完成后才退休，恢复、重试和重复回执不得再次生成或扣血。
