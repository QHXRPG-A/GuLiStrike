# 统一特效目录与ID引用

资源路径与基础缩放共同决定唯一特效定义。相同组合共用稳定正整数 ID；颜色、旋转、时长、组合规则保留在原配置。动态体型与范围系数仅在表现调用处应用一次。

新增 `Data/Excel/GuLiStrikeVfx.xlsx` 的 `Effects` 工作表，字段为 `id/name/Note/ResourcePath/ScaleX/ScaleY/ScaleZ`，沿用三行元数据及 Excel → JSON → DataTable 管线。其他表、配置、代码和蓝图通过整数 `…VfxId` 引用。保留玩法定义资产、网络实例 GUID 与法术场 ID 的原义。

覆盖现有粒子、特效材质、专用网格与蓝图入口；资源内部依赖仍由资源维护。迁移机枪三类来源、导弹、尾迹、喷气、传送和运输、闪现、受击、销毁、预警及描边。解析失败报告并跳过表现，不中断伤害。

验收包含目录和引用完整性、资源存在与类型、Cook 依赖、迁移前后逐项比对、蓝图编译及读回、定向导入幂等性、Editor/Game Development 源码版 UE5.7 构建和 BuildId。用户授权增加仅覆盖目录规则的 `GuLiVfxRegistryTests.cpp` 并适配受影响测试。

2026-09-21 已按用户指定的静态验收标准交付。实现及证据见 [技术方案](../DevelopmentDocumentation/20260921-统一特效目录与ID引用.md)，数据维护见 [特效目录说明](../../Scripts/Vfx/README.md)。
