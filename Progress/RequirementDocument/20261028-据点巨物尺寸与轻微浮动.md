# 据点巨物尺寸与轻微浮动

## 目标与决定

用户反馈现有据点太小，希望有巨物感，长宽高大约是护盾发生器的3倍。已明确选择三轴分别匹配目标，允许现有细长塔身变宽。2026-10-29用户要求取消贴地，确认中立、己方和敌方全部始终浮空。

- 尺寸基准为正式建筑定义5（护盾发生器），消费模型包围盒与建筑目录最终 MeshScale，包含已有网格量化缩放；三轴分别乘3。
- 当前护盾约5.9592×6.7445×9.7664米，据点目标约17.8777×20.2334×29.2993米。尺寸随基准建筑正式配置变化，不固化为近似米数。
- 全部据点从显示第一帧起平均离地5米，上下各0.5米，8秒一周期，底部保持4.5～5.5米净空。中立、己方、敌方共用同一浮动规则；占领、换主和恢复中立不落地、不重置相位。
- 保留旧 ModelHeightCm 作为基准缺失时的兼容回退，并记录诊断；运行时和编辑器使用共享尺寸计算。
- 地面碰撞、导航、占领、经济和运输锚点继续使用既有规则。悬浮同步时钟与阵营分区合同保留；旧占位模型已由下述B_v1替换并退役。

## 模型重制方向（2026-10-29）

用户在确认原网格是平底后要求“好丑，需要重新制作，希望上下对称，且更科幻感一点，可以先出参考图”。据此新增造型重制，尺寸与全状态悬浮目标保留。

- 上下关于水平中面镜像，具备等量、完整的装甲和机械结构；底部以与顶部对应的造型收口，呈现完整悬浮巨构。
- 强化中央能量核心、环形装甲腰带与规则支架，保持项目动漫机械、线稿、三档明暗和统一色库方向。
- 先交[参考A_v1](../../ArtSource/Buildings/OutpostSymmetry_20261029/References_A_v1/README.md)，含主效果和三视图，待用户审核设计；本阶段未制作Blender模型、未替换UE资产。
- 后续用户明确“面数太多了，再来一版，这个形状是不错的，可以保留”。A_v1外形与比例认可保留，结构简化为[参考A_v2](../../ArtSource/Buildings/OutpostSymmetry_20261029/References_A_v2/README.md)：合并连续装甲，简化腰环、核心套环和内部机构，减少小分件；实际网格面数在建模后统计，不通过参考图虚报减面结果。
- 用户后续明确“blender已开，一比一制作”，据此将A_v2作为建模依据；已制作[Blender成品B_v1](../../ArtSource/Buildings/OutpostSymmetry_20261029/Production_B_v1/README.md)，含修改器4824三角面；后续用户明确“导入至UE并实装，删掉之前的据点模型”，作为对应源版本的B放行。
- 用户新增“中间的光柱需要白和阵营色之间能够切换”。中央光柱使用独立材质参数，支持中立白与实际阵营色；Blender先提供白／己方蓝／敌方红预设和独立亮度控制，外壳颜色单独维护。UE现已按实际归属和本地阵营视角绑定，外壳固定色保持。
- 后续按[模型制作技能](../../.agents/skills/guli-model-production/SKILL.md)及[美术规范](GuLiStrike美术规范.md)执行参考审核、Blender还原、成品审核与导入，已有悬浮逻辑直接复用。

## 正式接入（2026-10-29）

ModelId 2003正式指向`/Game/GuLiStrike/Buildings/OutpostSymmetric/Meshes/SM_OutpostSymmetric`，49个据点预览与实际运行网格均已替换。旧占位塔、早期立方体与原始塔共3个UE网格已迁移引用后删除。源码Editor编译、保存后的实体核对及已授权局内白/蓝/红画面核对完成，见[正式交付与证据](../../ArtSource/Buildings/OutpostSymmetry_20261029/UE_Delivery_v1/README.md)。

## HDR发光与自转增量（2026-10-29）

用户明确要求增强光柱、亮线与灯槽的HDR自发光，保留白／阵营色切换，避免全部曝白，并使用现有Bloom形成柔和光晕；随后追加缓慢自转并指定“60秒一圈”。

- HDR集中在原发光区域，较宽的柱面保留色彩，最高亮度用于细亮线；外壳维持原线稿、轮廓及三档明暗。通过材质即可实现，本轮无需改网格或新增粒子、灯光组件。
- 中立、己方、敌方全部绕竖直轴每60秒转一圈；与8秒浮动共用现有同步时钟及生命周期相位，归属变化不重置。模型围绕包围盒中心旋转，地面玩法锚点固定。
- 现有Bloom配置保留。实现、编译与实际49据点6°/秒读回完成，见[本轮交付与局内图](../../ArtSource/Buildings/OutpostSymmetry_20261029/GlowSpin_v1/README.md)；这些技术核对不替代玩家验收。
- 用户随后在局内图上圈出腰部横向灯带，要求改白，并将所有光亮度设为当时的2倍。已仅将腰带两层发光区域改白，支架/尖端灯槽保留原色；四类HDR峰值固定为首版各自2倍，重复应用不叠乘。[白腰带与2倍亮度交付](../../ArtSource/Buildings/OutpostSymmetry_20261029/WhiteBelt_x2_v1/README.md)保存原图与局内核对。
- 用户再要求“光柱自发光强度再增大2倍”。已将中央柱面4.4→8.8、光柱亮条12→24，腰带和其他灯槽维持上一版；[本次参数与保存证据](../../ArtSource/Buildings/OutpostSymmetry_20261029/CoreBoost_x2_v1/README.md)。

## 验收

- [ ] 玩家确认近远景体量、宽厚感及与护盾建筑的比例符合预期。
- [ ] 玩家确认中立与已占领据点都有明显离地间隙，轻微浮动且节奏缓慢，归属变化不落地、不重置相位。
- [ ] 玩家确认点选浮动模型后的运输终点仍为原地面位置。
- [x] 用户确认新模型参考设计及Blender还原版本的上下对称、完整下半部和科幻造型，并授权正式导入。
- [ ] 用户确认中央光柱中立为白、己方/敌方切换阵营色，外壳不被光柱改色覆盖。
- [ ] 用户确认HDR柔和光晕、阵营色辨识和60秒自转节奏符合预期。
- [ ] 用户确认白色腰部横灯带与2倍发光强度符合图示要求。

对应场景 `/Game/Maps/LVL_CommanderMassPrototype`：R1C4为初始占领对照，R4C4为中立对照，两者均须保持悬浮；R1C4右侧40米有仅编辑器显示的护盾尺寸参照。初始交付只做静态检查和实体数据核对；后续用户明确要求进入局内截图，并授权“这个会话允许读图”，本会话按该授权进行PIE截图及画面核对，不改变全项目默认规则。本项编译沿用用户已明确给出的同范围许可。
