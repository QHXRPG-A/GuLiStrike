# 地面机甲动画蓝图与空中战斗

## 行为

- 源动画目录 `/Game/Assets/MechaController/Mech_Constructor_Lt_Med/Animations` 的22段动画复制到项目目录，原件保留；行走BlendSpace使用项目副本。
- `ABP_GroundMech` 的AnimGraph实际求值：地面移动、起飞、空中循环、落地，融合0.1秒；C++只提供运动状态。
- 空中双腿相对待机姿态，反向倾斜15°：进入1秒、循环保持、退出1秒，中途转换连续；水平速度进入阈值10cm/s、退出5cm/s。
- WASD沿现有世界方向控制空中移动，最大1080cm/s，斜向不加速。角色Yaw按实际水平速度以540°/秒转向；上身及机枪独立瞄准鼠标。
- 有容量且可使用技能时，空格按下即本地预测播放双喷，不等离地或动画。松开、耗尽、被拒绝或中断时结束发射并自然消散；其他客户端可见，专用服务器无表现组件。
- 正式机甲绑定现有武器配置，默认升级1.1；地面、推进、滑行、转向、下落和落地均可开火。瞄准空处使用射线远端，不因未命中而停枪。
- 推力2180cm/s²、上升上限1200cm/s、容量与恢复、容量UI、喷口最大15°偏转沿用现值。普通地面和有效Mass顶部均视为落地。
- 实施中用户追加加快下落：新增Excel下落重力倍率，首轮默认2，仅在无有效推力且开始下降后生效；上升参数不变。
