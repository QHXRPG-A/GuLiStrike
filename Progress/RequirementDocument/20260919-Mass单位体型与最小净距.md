# Mass单位体型与最小净距

> 已撤回：以下保留历史事实，当前实现以[战争机器模型大小适配](../DevelopmentDocumentation/20260919-战争机器模型大小适配.md)为准。

## 规则与范围

最小中心距为半径A＋半径B＋max(净距A,净距B)。源表使用最终游戏尺度，不再乘模型比例。扫荡者宽度/净距3.1/0.5米，战争机器12.5/2.5米，两类工程车3.6/1米。无效数值阻止兵种目录投入使用并报告行名及字段。

敌我双方参与，死亡及相位沿用既有豁免。仅闲置友军可临时让位；作业、锁定单位不主动移动，不推开敌军。让位不覆盖命令，范围为自身宽度，速度上限25%，连续1秒无通行冲突后尝试回位，新命令取消。

服务器严格执行，内部1厘米余量；允许客户端既有量化/插值的轻微显示误差。本期不改模型比例、墙体净距、NavMesh烘焙和同步协议，不引入全军刚体模拟。

## 验收标准

- [x] 两列完成生成、正常编译及定向导入，原资产/行名/兵种ID不变，四类数据回读正确。
- [x] 初始部署整批合法；生产受阻保留余量并按0.25秒重试，所有权变化清理余量；编队和目的地随体型调整。
- [x] Mass预测与最终移动约束读取同一体型；完整相对运动检查无六邻居截断，最多四轮后冻结剩余冲突关联运动。
- [x] Mass及工程车双向占位、同步提交，闲置友军让位和回位符合规则。
- [x] 工程车子步、工厂移动、导航恢复、吸附、传送及退出相位通过同一占位检查。
- [x] 客户端额外预测受拥挤约束，协议不变。
- [ ] 既有回归通过；当前场景验收及500单位前后同配置性能记录完成。
- [x] 源码版Editor/Game Win64 Development构建及BuildId核对完成。

已勾选的接入项表示实现完成，不代表所有分支都做过专项人工组合。当前相关回归89通过、2项既有失败；当前场景主要行为和500单位性能已记录，详细边界见配对开发文档。

战争机器同类中心距至少15米，与扫荡者至少10.3米，与工程车至少10.55米。
