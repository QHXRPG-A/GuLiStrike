# GPU渲染降耗

## 范围与取舍

- TSR改FXAA；关闭全局体积雾，保留普通高度雾。
- 保留虚拟阴影，降低方向光和局部光精度；保留Lumen GI及异步调度，降低探针与场景更新成本。
- 士兵、矿车、工程车、僚机常态身体材质Roughness下限0.8；关闭目标网格的光追、距离场、间接光照贡献和反射/天空捕获可见性。
- 包含僚机本地及远端表现；玩家直接驾驶主飞船保持原材质策略。接受金属光泽减弱。
- 不修改引擎渲染器；屏幕空间倒影及GI粗糙反射近似仍可能存在，不能宣称完全关闭所有反射。

## 验收

- [x] 初始化、池复用、车辆表现重建和特效恢复均接入目标材质策略。
- [x] 画质预设后配置实际生效，TSR和体积雾GPU事件消失。
- [x] A修改前、B修改后软件VRS开启、C修改后软件VRS关闭各完成单客/双客三轮。
- [x] 1200存活、移动人数P05≥1140、服务端零丢步；优化后全部样本单客P95≤16.67ms，双客≤33.33ms。A基线有1份客户端样本超预算，照实保留。
- [x] 按约定规则作出选择：C单客GPU恶化16.25%，故最终保留VRS。
- [x] 源码UE5.7 Editor/Game Development构建、BuildId、已有回归与同镜头画面检查有证据；3项原有失败与动态画质覆盖限制单列。
