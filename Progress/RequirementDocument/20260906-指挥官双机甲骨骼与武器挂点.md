# 指挥官双机甲骨骼与武器挂点

## 背景

FourFRobot 与 WM01 当前通过静态 Crowd 网格显示，原模型分别保有 21 根和 99 根变形骨骼。先准备可摆姿的项目骨骼资产，让后续武器挂点校准和多足动画有可靠基础。

## 需求描述

- 分别复制原 Skeletal Mesh 和 Skeleton，保留参考姿势、骨名、蒙皮及有效材质引用，不改商城模板。
- 为四足 FourFRobot、六足 WM01 制作独立 Control Rig，统一全局、主体、武器、脚部 IK 和腿部 FK 控制规范。
- 主体升降/倾斜时脚部目标保持全局控制空间位置；武器控制不带动腿。WM01 保留液压辅助结构。
- 创建并校准机枪、瞄准和 WM01 双导弹出口 Socket，记录所属骨骼和坐标空间。

## 边界

- 仅交付骨骼与编辑器摆姿资产；不替换 Crowd、不接入动画或战斗、不回填开火配置。
- 不修改原生代码、原有弹道、伤害或 Marketplace 源资产。
- 不新增自动化测试文件；仅执行本方案已确认的资产回读、编译和人工摆姿验收。

## 验收标准

- [ ] 原参考姿势、尺寸、朝向、材质和蒙皮保持一致。
- [ ] 主体、各武器独立控制；全部十条腿可抬脚、前伸、侧移，无非预期翻折或伸缩。
- [ ] Socket 贴合出口并随实际武器骨运动，局部 +X 指向发射方向。
- [ ] 控件复位正常；Control Rig 编译零错误，明确保存后重新加载通过。
- [ ] 留存默认站姿、主体倾斜、单脚抬起和武器转向截图；未验证项如实记录。
