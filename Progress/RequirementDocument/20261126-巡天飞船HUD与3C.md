# 巡天飞船 HUD 与 3C

## 操控

鼠标转动同一台观察相机。中央准星跟随视线，当前炮组的每座炮独立追向同一世界瞄点。急转时，每座炮用一个半透明圆圈显示实际炮口指向，圆圈进入中央准星范围后逐个隐藏。左键使用当前炮组，炮弹可以穿过本舰。

准星指向与本舰同高或更高的飞行单位时，使用防空炮组。指向低位单位或低处地表时，启用舰腹炮并检查俯角。视线离开空中目标并转向下方时，防空炮回正。向正下方转动相机可连续进入垂直俯视。Tab 继续用于无双席位的角色切换。

## 界面

- 对空时，舰体读数在准星左侧。切到舰腹炮时，舰体图标、百分比和分格血条同帧出现在底部中央，底框同时显示。切回防空炮时，整组立即回到准星左侧。俯视时高度读数移至左侧刻度，当前武器与可射炮数留在准星右侧。
- 地面常驻淡橙色可射区和带斜纹的盲区。空中敌舰旁的虚线和炮组图标提示相对舰高，本舰周围保留等高弧。盲区使用覆盖准星的大红叉，战斗画面省去盲区和回正中的文字。
- 顶部最多四个巡天专属持牌栏，分支升级共用槽位。当前没有正式持牌时显示空槽。右侧展示真实击毁，右下预留对局时间及红蓝双方比分。
- 舰腹射界由舰体水平面向下量角，默认 45° 至 90°。设计师可修改上下限，场景斜纹、中央准星和开火共同使用调整结果。

## 玩家验收

| 操作 | 预期反馈 |
|---|---|
| 用略俯的相机对准高位或同高敌舰 | 右弧显示防空炮图标及数量，炮口汇聚于敌舰 |
| 从高位目标快速转向低位，再转回高位 | 舰体读数随炮组直接切换固定位置，镜头和高度刻度随俯角连续变化 |
| 分别瞄准射界内外的地面单位，按住左键 | 可射区发射，盲区出现大红叉并停止发射，斜纹持续可见 |
| 转动视角后停住，再观察准星 | 每座炮的圆圈以 50% 不透明度显示，接近准星中心后逐个消失 |
