# Ship 动漫低模风格 Blender 样板

## 背景与目标

用户在参考《吞吞堡垒》的方向讨论后，要求将目前的 Ship 改为“动漫化、低模、简约的贴图纹理、大色块、清晰轮廓，加适度的三渲二光影”，明确“模型大致形状不要变”，并在已打开的 Blender 中展示。

首版交付后，用户追加：“加点线稿让动漫感更强一点”。沿用保留舰体形状的约束，增加适度外轮廓和主要装甲结构线，避免把所有三角面显示为线框。

用户随后确认：“把装甲内部线条烘焙成贴图遮罩，外轮廓保留独立描边”。内部线条从实体曲线改为纹理，保持舰体形状、原有配色和外轮廓描边；保留实体线稿版备份。

## 需求与边界

- 依据当前玩法类 `BP_CombatAvatarFly01` 实际引用的 Dreadnought 舰体制作，保留长舰艏、宽舰尾、两侧翼板和主要机械轮廓。
- 简化内部小装饰及细密纹理，使用少量明确的主色、辅色和功能色，制作可编辑的三渲二材质。
- 在当前 Blender 中展示新版并提供原版对照，保存独立工程与多角度预览。
- 范围为风格试作和美术评审，不要求导入 UE、替换玩法模型、制作可导出的 UE 材质或修改飞船装配系统。

## 交付检查

- [x] UE 资产接口确认源网格与材质，并保存导出来源记录。
- [x] 新旧整体尺寸一致；保留顶点与源顶点重合；只减少内部微小装饰与共面边。
- [x] 六色可编辑材质、三档明暗和规则条带已在 EEVEE 显示。
- [x] Blender 当前显示新版；文件内包含原版与并排对照场景。
- [x] 斜视、俯视、侧视、尾部及新旧对照已渲染并查看。
- [x] 装甲内部线条已改为打包的4K灰度遮罩，外轮廓壳独立保留；当前Blender及并排对照同步更新。
- [x] 舰体及外轮廓几何一致，总三角面从37,362降到16,402；实体线稿版已备份。

以上是样板交付检查，不代表用户已确认最终美术风格。
