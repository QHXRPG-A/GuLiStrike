# GuLi 独立地图设计器

## 背景与目标

项目单位化后，需要在 UE 编辑器外、UE 关闭时也能使用的本地软件。以二维网格编辑，三维同步预览，将现有据点和红蓝矿资源分布编辑能力移植到同一工程。软件位于 `Tools/MapDesigner`，提供双击启动。

## 需求描述

- TypeScript、Canvas 二维网格、Three.js 三维预览、Python 本地文件服务；前端资源全部打包到本机。支持当前地图快照、新建、保存、自动恢复、撤销重做。
- 固定 3 米一格，整数宽长；原点不动，在 +X/+Y 裁剪或延边扩展；宽×长格对应 (宽+1)×(长+1) 共享顶点，按 UE Landscape 三角划分采样。
- 方形升降、整平/拾取、平滑、起终点线性坡道；1/2/4/8/16 格预设及自定义，默认硬边，拖动补点、共享顶点每笔一次、整笔撤销、Esc 取消。
- 格坐标、世界坐标、高程色阶、矩形选区、平移缩放，以及可旋转缩放和开关网格的三维预览。
- 完整标记创建/移动/复制/删除/启用/搜索、标签/备注/参数/多区域；四种形状及多边形顶点编辑。
- 自定义类型、默认区域、九种字段及校验规则；字段按 GUID 迁移，同 GUID 改名保值，不兼容修改必须显式处理。旧 Marker/Region/Field/Layer 身份保持，新建和复制使用新身份。
- 据点默认保持离地偏移跟随地形，可逐个关闭；与地形笔画共同撤销。越界业务数据保留并提示。
- 红蓝独立层、叠加、加深/擦除、强度/软边/清层、辖区归属及异常统计；方形和圆形笔刷；旧资源格 25 米，新图默认 3 米；世界向下取整，负坐标正确。
- 7×7/49 据点规则和固定资源预算不变；地面/坡度/辖区/布局提示，真实矿簇继续通过现有 UE 生成流程产生。
- 版本化 `.gmap`：双精度厘米高度、尺寸/原点/设计边界、材质权重、完整类型/区域/密度和导入基线。旧图载入不整体量化高度。
- 导出原六/九 JSON、CSV，另附 16 位高度图、换算、修改摘要。物理地形按 63 格组件延边补齐，逻辑边界独立记录。
- 插件负责通用地图标注数据，项目 Editor 模块负责地形、占地、逻辑/资源范围、NavMesh；保持依赖方向。应用前校验基线/差异，存在 UE 改动报告冲突，完整校验后事务提交，保存前备份并读回。

## 边界

默认目标 `/Game/Maps/LVL_CommanderMassPrototype`；首次数据重新从编辑器读取。交付独立软件和适配能力；用户编辑、导出后，助手再按数据调整 UE，本轮不应用地图设计。单轴 8160、总格数 4,194,304 为现有占地数据和内存上限，不要求宽长是 63 的倍数。拓扑替换中的非空植被基底迁移需要独立处理，不静默删除植被。

用户明确授权源码版 `GuLiStrikeEditor Win64 Development` 编译、保存、停止当前 PIE 并重开 UE。该授权不扩展到启动游戏验收。视觉由用户核验，助手不截图、读图或视口目检。

## 验收标准

- [x] 提供本机双击入口、打包前端、操作说明和当前地图工程；UE 关闭也可编辑保存。
- [x] 从重开后的编辑器读取完整快照：567×567 格、322624 顶点、50 标记、283 区域、5 类型、10 字段，旧资源格 25 米。
- [x] 构建/类型/Python 语法、模型数值、身份迁移、负坐标密度、保存重开、导出读回和补边数值核对。
- [x] 原生适配构建及依赖核对；正常预检查通过，冲突预检查拒绝，源数据未改写。
- [ ] 用户核验二维/三维视觉、笔刷手感和全部 UI 操作；入口及步骤见使用说明。
- [ ] 用户完成设计并交付导出后，再执行真实 UE 应用及玩家效果验收。
