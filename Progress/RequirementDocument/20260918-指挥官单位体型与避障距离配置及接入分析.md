# 指挥官单位体型与避障距离配置及接入分析

## 背景与目标

当前战争机器最终模型约12.41×12.50米，Mass统一半径1.5米，生成/移动槽位3.2/3.6米，导致外观已经相交而逻辑仍认为未接触。
用户要求在指挥官Excel增加模型宽度、最小避障距离；战争机器填写12.5米、2.5米，其他单位由本轮给出初值，并分析复杂度与计算量。

## 字段与语义

源表为 `data/Excel/GuLiStrikeCommander.xlsx / Soldiers`，L、M列分别是：

- `ModelWidthMeters`：最终游戏尺度下的模型占地宽度，按圆形占地直径消费；不用于再次缩放模型。
- `MinAvoidanceDistanceMeters`：两个单位圆形占地外缘间的最小净距，A/B双方取较大值。

两字段均为 `float / Necessary`，数字使用米，表内显示单位并在表头批注说明定义。

| 单位 | 模型宽度（米） | 最小净距（米） | 初值依据 |
|---|---:|---:|---|
| 扫荡者 | 3.1 | 0.5 | 实测平面约3.021×2.611米，宽度向上取整；同类中心距3.6米 |
| 战争机器 | 12.5 | 2.5 | 用户指定，与当前模型尺寸相符 |
| 电磁矿车 | 3.6 | 1.0 | 当前3.6米车长作为圆形占地初值 |
| 建造车 | 3.6 | 1.0 | 沿用当前同尺度工程车基线 |

`Dmin = (WidthA + WidthB) / 2 + max(GapA, GapB)`。
同类战争机器15米，战争机器与扫荡者10.3米，战争机器与工程车10.55米，工程车之间4.6米。

## 本轮边界

完成Excel与字段说明、代码接入分析。运行时代码、生产JSON/CSV、生成头文件、UE DataTable、导航烘焙均留在后续实施阶段。
“所有单位”接入应覆盖友军/敌军、Mass单位和两种工程车；既有相位等明确不参与碰撞的状态仍沿用现有规则。
字段表达圆形占地规则，不等于任意朝向下逐三角模型外轮廓的精确距离；必要时根据转向可见轮廓调整占地宽度。
