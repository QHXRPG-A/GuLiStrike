# 游骑兵肉鸽卡牌与武器解耦

1. 缺少「无人生还」或其前摇无效时，其他有效游骑兵卡牌仍可构建联机规则。Q 的授予、表现与图标通过效果绑定查找对应卡牌。
2. 人工智能引擎决定自动扳机与锁定时间。分裂枪管按等级容量和有效目标数增发。电磁技术能够沿手瞄射线或指定目标结算瞬时命中。当前正式牌树继续要求先取得引擎。
3. 本地开火和权威冻结共用普攻射速、子弹伤害和弹效计算。已获准的弹丸和折射以当时的属性结算。
4. 已登记的武器效果负责 Excel 数值读取及牌面参数。通用伤害系统向源能力查询护盾倍率。
