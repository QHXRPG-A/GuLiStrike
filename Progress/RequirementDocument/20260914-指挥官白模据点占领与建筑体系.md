# 指挥官白模据点占领与建筑体系

## 目标与交付边界

在现有5×5红蓝矿棋盘、Territory归属接口和建筑放置支付基础上，建立“地面占领 → 首占赠送设施 → 维护与出兵 → 部队继续夺点 → 工程车跨区施工和采矿”的指挥官白模。

本次交付包括代码、Excel、项目自有白模特效及联机验证。下文为批准的玩法合同，是否通过验收以实际证据为准。指挥官与WM共用建筑定义；工程车包括建造车与采矿车，两者均可使用快速通道。

建筑生命周期、据点占据、维护供给和工程车通行分别表达：建造完成不代表已被占领，欠维护费不代表通道断气，通道被切断也不改变地面部队的进攻权限。职责与开源参考见[技术方案](../DevelopmentDocumentation/20260914-指挥官白模据点占领与建筑体系.md)。

## 玩法需求

### 1. 地面占领与首次赠送

- 以Territory领域统计双方存活地面单位，每单位一票；包含地面玩家载具和工程车，排除建筑、飞船及其他空中单位、死亡单位和正在通道内运输的单位。同一单位不重复计票。
- 节流采样，占优方推动连续进度；人数相等或双方无人时进度保持。人数差决定方向，首版不额外按人数差放大占领速度。
- 进度范围为红方端点-1至蓝方端点+1。中立由0推至任一端点才完成占领；已占据点须推至另一端点才易手，途中包括经过0均保留原归属。白模中立占满20秒，因此从一个端点完整推至另一个端点为40秒。
- 占领组件通过服务器权威入口修改Territory归属。经验只广播占领事实，不接入成长、奖励分配或选牌。
- 每个据点本局首次被任一方占领时，按建筑表赠送列表，在固定插槽直接生成已完成的基础兵营、护盾发生器和矿厂各一座。
- 发放记录按据点和插槽保存。生成失败仅重试尚未成功的插槽；成功生成后被摧毁的赠品不补发。重试不回滚已经完成的占领。
- 存活赠品随据点易手转交新阵营。玩家自建建筑、已经出厂的单位不自动转交。已发放记录不因易手、客户端重建或Actor重新发现而重置。
- 首版25个地图据点本体常驻、已完成且不可摧毁，只争夺归属；对应常驻传送区也不可摧毁。

### 2. 基础兵营与持续推进

基础兵营的生产单位、周期与数量读建筑表，白模默认每10秒24名Mass基础战斗单位。

1. 出厂先检查所属据点实际存在的八方向空间邻接，从其中选择最近的敌方或中立据点。边界外不存在的邻居不计入。
2. 八邻接全属己方时，沿空间邻接继续向外搜索，以累计据点中心距离选择最近的非己方目标；等距按稳定Territory ID决定。
3. 选择结果是目标据点，士兵通过普通地面AttackMove接近其中心，沿途作战。兵营选点不依赖工程车运输树，也不受通道断气影响。
4. 自动进攻目标仍未完成占领时，士兵留在当地作战、占点；目标变为己方后重新选点继续推进。玩家手动指令优先，不被自动选点覆盖。
5. 全图均为己方时原地待命；重新出现非己方据点时恢复自动选点。地面目标不可达时尝试下一个候选，无可达目标则待命。
6. 据点维护失败时，其赠送兵营停止出兵；恢复供给后继续生产，不补发停产期间积攒的批次。

每队Mass战斗单位默认上限300，GM可调。统计包含初始部署、所有生产来源的存活Mass战斗单位及生成预留名额；工程车、玩家WM和Ship不计。多个兵营共享同一上限，不能各自计算300。剩余名额不足一批时允许少量出兵，失败释放预留，不积攒无限补发队列。回收残骸期结束的仿真实体和复制记录，不以历史总生成数代替当前人口。

### 3. 建造车与空中快速通道

开局每队一辆独立建造车，Soldiers行配置，首版复用工程车模型的独立表现资产，保留GM生成入口。建造车接入既有选兵、移动和共用建筑菜单；放置生成工地，右键己方工地派车施工，多车按有效工作量线性累计。采矿车只负责采矿；运输组件通过暂停／恢复边界协作，不修改货物队列和施工进度。

| 出行入口条件，按顺序判断 | 行为 |
|---|---|
| 最终目标在当前Territory | 普通地面移动 |
| 最终目标在八方向邻接Territory | 普通地面移动，与目标阵营无关 |
| 最终目标在敌方或中立Territory | 普通地面移动，不借道传送 |
| 最终目标在其他己方Territory | 默认去当前据点法阵并查询通道 |
| 入站前不存在合法通道 | 使用普通地面寻路 |

- 按据点中心距离生成确定性的静态最小生成树，25点24条无向边，同长边以稳定Territory ID排序；初始化后固定连线。空间八邻接、运输树、包围几何分别查询，不能混用。
- 节点位于据点地面上方10,000cm。地面NavMesh只负责进站前及出站后，空中行程由服务器沿折线计算。
- 每Territory一个`StrongholdGate`常驻法阵，表行通过数字ID引用，常驻且不可摧毁；与既有指挥官双点传送技能独立。
- 路线节点须归己方且未被包围。欠维护费不影响通道；被围节点关联边隐藏，其他不可通行连接淡显，法阵继续存在。运输树没有备用环路，不因断路自动增加连线。
- 入站保留原车辆身份、血量与货物，暂停采矿、施工、战斗和占点；进入不可攻击的相位状态，隐藏车辆，显示亮蓝能量球。
- 表现为“法阵内化球 → 0.5秒上浮 → 起点1秒内加速到基础车速50倍 → 沿蓝线多跳巡航 → 终点0.5秒减速 → 地面0.2秒蓝光出车”。整趟只在起点加速、终点减速，中继不停站、不重新加速。
- 服务器根据整条空中折线长度积分计算速度与时间，替换旧的距离除50倍速度。短行程等比压缩加减速时间，峰值仍为50倍。
- 目标据点动态环形出口基准半径4,000cm，根据车辆完整占地和周围障碍选择离原始最终目标最近的合法落点。落位后恢复车辆与任务，完成剩余地面移动；出口拥堵则等候，禁止重叠强行落位或丢车。
- 途中逐段复验。断路先重算；不可达时退至最近经过的己方节点出站，全部失效时退至己方初始基地出口。紧急改道可以从当前速度重新计算剩余行程，身份、血量、货物必须保留。
- 复制路线、阶段、服务器时间和出口位置；客户端据此重建，不复制粒子，也不由特效回调决定到站。晚加入恢复当前阶段，不重播已结束的入站、出站效果；专用服务器不创建表现组件。

### 4. 包围断气与维护断供

| 状态 | 判定来源 | 首版后果 | 恢复 |
|---|---|---|---|
| 包围断气 | 敌方控制区形成空间封锁 | 该据点进出工程车通道失效；不停兵营、不撤供盾、不毁建筑或车辆 | 空间封锁解除后恢复通行 |
| 维护断供 | 周期蓝红双资源原子支付失败 | 该据点赠送兵营停产，护盾发生器停止供盾；不切断通道、不停矿厂 | 下一维护周期足额支付后恢复 |

白模包围采用明确的几何近似：按每队分别把敌占Territory作为阻挡，从地图外缘对非敌占区域做四邻接连通检查；己方据点无法连至外缘即视为被围。中立区域可连通，边界默认不充当封锁墙。不能以运输树上的连通与否或闭环作为包围判据；空中单位与普通敌兵经过也不直接改变控制区封锁。

据点产出分配、维护周期和供给状态接入`UGuLiResourceWorldSubsystem`；实际库存继续由现有`UGuLiTeamEconomySubsystem`唯一持有，通过现有经济接口支付，不迁移或复制库存。

维护按稳定Territory顺序逐点结算。每点蓝红一起扣或都不扣，失败仅影响该点，下周期重试，不累计欠款；易手不重置维护时钟。维护周期和费率由GM可调。恢复供给不复活已毁设施，也不补发停产部队；据点塔和buff的断供后果留待相应功能实现。

矿厂易手时，已接收货物保留接收时的结算阵营，后续接收采用新的合法归属；未卸载货物仍随原矿车。矿车重新选择己方矿厂，多矿厂身份不得因相同阵营发生冲突。既有矿藏、采集权限、加工速率及运输容量规则保持原合同，补充本次必要的换主和重新选厂处理。

### 5. 建筑生命周期与共用数据

- `AGuLiPlacedBuilding`增加建造中、完成、摧毁三态，通过共用生命周期组件接入据点与矿厂，保持现有Actor类型与资产身份。
- 有效参建建造车的施工工作量线性相加；离开、死亡或进入通道即停止贡献。完成和摧毁只提交一次，摧毁关闭功能和碰撞，首版回收建筑实例；正式建筑爆炸演出另行制作。
- 全局仅增加薄建筑注册表，提供登记/注销、Territory／团队／类别查询及生成／完成／摧毁三个事件。地图据点登记为已完成；退出世界的注销不等同于战斗摧毁。
- 红、蓝、中立占据态留在Territory归属和占领组件，注册表不增加第二套权威状态。
- 地图据点及首占赠品不占既有每建造者6座／全局手动建造24座额度，注册总量不能沿用该手动额度截断。

新增`GuLiStrikeBuildings.xlsx`供指挥官与WM共用，沿用数字ID、JSON、TableRows和UE导入管线：

| 字段组 | 内容 |
|---|---|
| 公共列 | 数字ID、稳定行名、显示与功能介绍、类别枚举、静态网格、血量、护盾、可建造等级、蓝矿费、红矿费、占地、施工工作量 |
| 兵营特有列 | 生产单位ID、生产周期、批次数量 |
| 据点特有列 | 首次赠送建筑ID列表、入口法术场ID |
| 法术场表入口行 | `StrongholdGate`类型、常驻、不可摧毁、入口范围与表现配置 |

选填空值使用类型默认值；类别必需参数仍必须填写，例如兵营有效的生产单位、正周期与数量，以及据点有效的赠送和入口引用。枚举、ID唯一性和跨表引用全量校验成功后才更新生成物；失败不产出新生成物并保留上一版有效输出，不能留下半新半旧数据。只给入口填写新类型字符串而不扩展法术场解析器，不算完成。

## 白模默认值与调参

| 参数 | 首版默认 | 说明 |
|---|---|---|
| 占优采样间隔 | 0.25秒 | 一次采样形成按Territory分桶的快照 |
| 中立占满时间 | 20秒 | 单方持续占优；另一端完整易手40秒 |
| 单车施工基准 | 10秒 | 标准工作量由1辆有效参建车完成；多车线性加速 |
| 维护周期与单价 | 30秒；蓝矿1、红矿1 | 每已占据点每周期，逐点原子支付 |
| 基础兵营生产 | 10秒／24名 | 读表 |
| 每队Mass战斗单位上限 | 300 | 包含生成预留，GM可调 |
| 空中高度／法阵与出口环半径 | 10,000cm／4,000cm | 出口按完整车辆占地扩大 |
| 通道速度倍率 | 50倍 | 按整条折线积分，起终点加减速 |
| 上浮／加速／减速／出站闪光 | 0.5／1／0.5／0.2秒 | 短程压缩加减速；可调表参数 |

以上均为可调原型值，不是平衡结论。每队300意味着双方合计最多600；既有500单位验证不能当成600单位或长期滚动出兵已通过的性能证据。

## 验收标准

以下为交付验收矩阵，本次不新增自动化测试代码。已有测试、人工PIE观察与构建分别记录，不把文档检查等同于玩法通过。

- [ ] 建筑表与StrongholdGate行导出、生成、UE原生回读一致；空值默认正确；必填、枚举或引用失败时旧有效生成物保持不变。
- [ ] 仅存活地面单位参与占优；平局保持、端点才易手、首占赠品仅一次、失败插槽重试和已毁不补均可观察。
- [ ] 存活赠品换主，自建建筑和已出厂部队不换主；据点及常驻入口不可摧毁；矿厂队列结算归属与重新选厂正确。
- [ ] 兵营按10秒／24名出兵，多兵营共享全队300上限；初始兵和预留占名额，失败释放，残骸结束后记录可回收。
- [ ] 邻接有非己方目标时选择最近目标；八邻接全己方时向外找到最近敌方或中立据点，不在后方停止推进。
- [ ] 当前目标未占领时留守作战占点；变己方后重选；全图己方待命，敌方或中立重现后恢复；手动接管不被覆盖；不可达尝试其他候选。
- [ ] 最小生成树25点／24边、全连通、无环且同布局生成一致；兵营空间邻接和包围几何不受树形连接限制。
- [ ] 工程车同域、八邻接、非己方目标直接地面移动；远处己方进站，多跳不停站、整趟加减速、动态出口、免伤与任务恢复正确。
- [ ] 包围或易手引起途中断路时，重算与安全退出不丢车；全部历史节点失效、出口拥堵和晚加入行程重建可处理。
- [ ] 维护双资源全成或全败，下周期恢复、易手不重置；维护与断气两类状态互不混淆，通道线和入口表现与状态相符。
- [ ] 开局每队一辆建造车，选兵与共用菜单、右键工地、建造中／完成／摧毁、多车线性施工、注册事件去重以及地图赠品额度豁免可验证。
- [ ] 双客户端PIE可重建归属、进度、建筑与通道；经济与维护账目仍仅己方可见；晚加入不重复发奖、扣费或生产。
- [ ] GM可调本期维护、占领、施工和单位上限参数；实际生效时机及观察结果有记录。
