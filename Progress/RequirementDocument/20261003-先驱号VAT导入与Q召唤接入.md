# 先驱号 VAT 导入与 Q 召唤接入

用户于 2026-10-03 明确要求实施本方案。美术前序沿用 [RSG 六足机器人工作项](20261003-RSG六足机器人美术统一.md)，B-v1 是本次唯一获准生产基线；配色及结构选择本身不代替审批。

## 已确认配置

| 项目 | 配置 |
|---|---|
| 身份 | `DefaultSoldier`、UnitTypeId 1、显示名先驱号 |
| 体型 | 体宽 625 cm，保持已审比例；避障半径 312.5 cm；包围盒、命中、圈选和生成间距同步 |
| 基础属性 | 移速 1440 cm/s、100 生命、0 防御 |
| 基础主枪 | 两把主机枪同时射击，每枪每秒一发、每发 10 伤害、6000 cm 获取目标射程 |
| 机枪散布 | 原 10° 总锥角统一为 2°，最大偏离轴线 1° |
| Q | 默认解锁，自身目标，立即召唤 5 个扫荡者，每台独立 30 秒冷却，无资源消耗 |
| 扫荡者 | `SweeperSummon`、UnitTypeId 5，旧模型、720 cm/s、2000 cm、单枪 1/s × 10；无召唤技能 |
| 存续与容量 | 永久可控、允许累积、先驱号死亡后保留；不计生产人口或预占，保留全局实体容量 |

体型取表配置口径：重防号体宽 12.5 m，现网格实测约 13.98 m，此差异须留档。重防号仍为 `WM01` / UnitTypeId 2，与 Ground 玩家机甲独立。

## 正式资源与动画

- 在 `/Game/GuLiStrike/Robots/RSGMech` 新建副本，保留商城原包和冻结 B-v1。
- FBX 回读核对 44 骨骼、参考姿态、单骨刚性权重、七动作时长、单位、朝向及法线；再正式导入。
- 采用 30 fps 骨骼纹理 VAT，静态顶点保存骨骼索引，顶点着色器处理位置与法线；四档 LOD 共用动画数据并接入现有 ISM。
- 本体每档一个材质区段，LOD0–2 增加一个外轮廓区段；保留 2K 色彩图集、独立结构线遮罩、三档明暗。
- 四档总面数 `37338 / 15905 / 5642 / 1944`，屏幕阈值 `1 / .40 / .16 / .06`。
- 待机、四向移动、死亡接入运行时；落地完整保留展示。移动相位由真实速度和步幅驱动。CPU 枪口与 GPU 共用骨骼采样和瞄准变换。
- 渲染范围覆盖变形，玩法范围采用校准体型；原动作接地偏差保留并记录。

## 数据与权威召唤

通过 excelize-cli 编辑 Excel，再使用既有导出器生成结构与 JSON，最后使用现有 UE DataTable 导入器。Soldiers 增加可选 VAT 引用和仅召唤标记，UnitSkills 增加每轮弹丸数且默认 1。双枪各产生独立弹丸、伤害事件和 ShotId。头像 1 改先驱号，旧扫荡者头像迁至 5，Q 提示同步。

网络协议 22 升为 23；保留既有机械动画自定义槽，紧凑同步 VAT 状态。沿用服务器请求去重与混选分发；多台先驱号分别执行各自的五台召唤与冷却。

以施法者水平包围盒外扩扫荡者半径与 50 cm 间距，优先五个外围均布点，受阻再查最多三层外圈、每层 36 点。检查导航、障碍及实体间距。实行整批 5 或 0，失败不扣冷却，提交失败回滚新实体。执行前复制上下文和状态，执行后按 SoldierId 重新查找施法者，避免容器扩容悬空引用。
