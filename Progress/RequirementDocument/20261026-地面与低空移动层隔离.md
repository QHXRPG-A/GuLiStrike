# 地面与低空移动层隔离

## 背景与目标

垂直空间概念包含地面、30–99米低空、100米起的高空。高空沿用当前玩家飞船的空域与移动方式，允许侵入低空；本轮只实施地面和低空。

重防号指兵种 `WM01 / UnitTypeId=2`，与玩家 Ground 席位的游骑兵分开。重防号进入低空，目标高度通过兵种表设为当地地面上方30米。

## 需求与边界

- 地面、低空共用原地面导航、地形与静态障碍约束；导航在地面计算，低空实际根位置加配置高度。
- 跨层单位不发生移动碰撞、推挤、避障与让路，实际占地、出生落点及指挥官目标站位按层隔离，允许同一XY由两层各自使用。
- 同层沿用既有交互。低空是一个平面移动层，30米和80米的低空单位也在同层求解；工程车彼此互通的原有例外继续保留。
- `Soldiers.MovementLayer`：0为地面，1为低空；`AltitudeMeters`：地面填0，低空允许30–99米。禁止非法层级、非有限数值和越界高度。
- 当前只把WM01填为1、30，其余兵种保持0、0。保留既有模型缩放和悬浮盘局部动画，禁止重复叠加高度。
- 不新增高空导航，不改飞船、僚机的移动、碰撞、最低高度、升降或编队规则，不按低空移动层改战斗目标类别。

## 验收标准

- [x] 源表、生成结构、JSON和引擎兵种表具备分层与高度字段。
- [x] 重防号配置为低空30米，其余当前兵种为地面0米。
- [ ] 在原型图中观察重防号根位置保持当地地面+30米，坡地、移动、停止和恢复不累积高度。
- [ ] 地面兵与重防号交叉移动时互不让路和推挤；两组重防号仍执行同层避障与让路。
- [ ] 混合选择下目标站位按层独立分配，同层占地保持既有约束。
- [ ] 出生、传送及状态恢复保持所属层与高度；飞船和僚机现有行为保持。

静态和编译证据不代替玩家效果验收。玩家入口为 `/Game/Maps/LVL_CommanderMassPrototype`，布置与操作见[开发记录](../DevelopmentDocumentation/20261026-地面与低空移动层隔离.md)。
