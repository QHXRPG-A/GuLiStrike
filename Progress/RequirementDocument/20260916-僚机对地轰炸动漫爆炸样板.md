# 僚机对地轰炸动漫爆炸样板

以用户第二张参考为主，保留原火球峰值规模（同机位外径差约 10% 内），缩短尾烟。仅改视觉；伤害、命中点、导弹数量和攻击节奏保持当前值。

## 制作与接入

- 一个 CPU Niagara，四发射器：1 闪光（0–0.1s）、8 低模团块（1.8s 内）、1 扩散环（0.05–0.55s）、12 火星（0.65s 内）。共享约 320 三角面的团块网格。
- 奶黄色、橙红外缘、浅灰粉烟团；Masked 分区材质，末段缩小溶解。扩散环最大外径不超过主火球 2.5 倍。不使用折射、粒子碰撞、动态灯、物理碎片或独立描边壳。
- 资产位于 `/Game/GuLiStrike/FX/WingmanWeapons/StylizedExplosion`，系统名 `NS_WingmanGroundExplosion_Toon`。
- 修改现有 `DA_WingmanGroundExplosion`：Scale=5、RandomYaw=true、MaximumLifetime=2、AdditionalLayers 为空。组件缩放只应用一次。
- 保留 Big_17 两层作为回退；沿用客户端表现、手动回池、距离裁剪，池容量 32。部署脚本识别并保留新变体。
- 不添加公共 C++ 接口、RPC 或伤害配置；仅保存明确修改资产。

## 验收

- 原版两层共同播放与新版同机位、分辨率、画质、位置、种子；单次、10 发、三组交叠各预热并采样三轮。比较总 GPU 增量、Niagara CPU、透明覆盖、回收，收益须超过波动。
- 检查起爆、峰值、消散及近景、指挥官远景、明暗背景、斜坡。
- 真实僚机攻击入口验证客户端连续触发、回池和专用服务器抑制；编译零错误、保存读回。
- 交付游戏内效果、回退入口、前后时序画面和性能证据。其他特效、场景光照、全局渲染保持现状。
