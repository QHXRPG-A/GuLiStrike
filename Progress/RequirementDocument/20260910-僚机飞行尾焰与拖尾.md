# 僚机飞行尾焰与拖尾

## 背景与目标

给当前 `SM_Wingman_Mass` 飞行僚机补充持续推进的视觉反馈。

## 需求描述

- 两个发动机喷口各显示一束蓝白色尾焰。
- 喷焰长度随飞行速度变化；拖尾保留空间轨迹并逐渐淡出。
- 客户端僚机显示层统一接入，资源保存在项目自有目录。

## 边界

本次为视觉表现接入；联机完整矩阵、最大数量性能实测与打包运行不作为本次用户视觉确认的完成依据。

- [x] 双喷口位置与朝向正确。
- [x] 可观察飞行、转弯与停止发射后的拖尾消散。
- [x] 当前空战关卡25架僚机均挂接并激活尾焰组件。
- [x] Niagara与材质编译通过，资源和代码保存。
