# Ship第三批支援组件贴图与框线制作

用户要求“继续挑选一批组件进行制作”。根据现有组件目录，本批选择`Drone_LaunchBay`无人机发射舱、`Electronic_JammingDevice`电子干扰装置、`Shield_Generator`护盾发生器，将已建立的Ship风格扩展到机库和支援设备。

用户此前明确原组件模型保留，只修改渲染、贴图、框线与三渲二光影；仍按“实际原模型与项目风格 → 效果图和三视图 → 用户A → 原模型表面制作 → 用户B”推进。选批授权不代替具体参考或成品的视觉审核。

## 范围与验收

- [x] 从当前UE资产只读提取三件网格、尺寸、原点、材质及挂点，冻结原型版本。
- [x] 每件效果图、正/侧/背三视图、原模型对照和共用风格说明完整。
- [x] 用户审核具体版本A，记录决定后进入实际表面制作。
- [x] A通过后完成2K贴图、独立内线和可关闭外轮廓、三档光影，主体几何和接口保持一致。
- [x] 提交实际Blender渲染、灰模与所需活动检查，取得B决定后导出最终FBX及回读。

保留发射口、面板、天线或发生单元等实际原型特征；数量和功能由源资产决定，不根据名称想象新结构。不扩展组件玩法，不擅改舰体挂点、碰撞或全局灯光，UE正式接入另行安排。

2026-09-17用户补充：无人机发射舱“需要有僚机飞出标识”，并用箭头指定沿导轨从效果图近端指向右上方远端出口。参考图与后续贴图加入僚机剪影和定向箭头，置于现有装甲表面；各视角保持同一物理方向，不新增三维飞机或改变舱体结构。用户原始标注保留于本批`References/Drone_LaunchBay_User_ExitDirection_20260917.png`。

同日用户要求干扰装置、发生器与CIWS的色系区分，明确“CIWS 不改”。电子干扰装置曾提出紫晶紫候选、护盾发生器提出叶绿候选，CIWS继续使用已审青蓝。紫色随后被用户指定的深蓝白黄替代。这是资产修订，不改变规范版本。

用户随后明确“干扰装置 改成深蓝、白、黄”，替代紫色候选。当前干扰装置v3按指定三色安排深蓝阵面、白色外框及支座、黄色前盖板和连接护罩；护盾绿色候选与CIWS青蓝保持。具体图纸仍按A审核记录。

规范为[GuLiStrike美术规范v1.0](GuLiStrike美术规范.md)，制作记录见[开发文档](../DevelopmentDocumentation/20260917-Ship第三批支援组件贴图与框线制作.md)。源文件集中于`ArtSource/Ships/ShipComponentStyle_20260917/Batch03/`。

用户在[参考审核A页面v3](../../ArtSource/Ships/ShipComponentStyle_20260917/Batch03/Review_A_v3.html)展示后回复“开始实施”，通过无人机v2、干扰装置v3、护盾v3，决定与源哈希见[审核A记录](../../ArtSource/Ships/ShipComponentStyle_20260917/Batch03/approval_A_20260917.json)。

实际表面制作期间，用户标注“这里是朝外的，图标放这里”：僚机剪影与箭头移到薄长侧壁朝外面，移除原顶面及厚侧壁标识，飞出方向保持。已保存[用户位置标注](../../ArtSource/Ships/ShipComponentStyle_20260917/Batch03/References/Drone_LaunchBay_User_ExteriorMarking_20260917.png)和[位置修订记录](../../ArtSource/Ships/ShipComponentStyle_20260917/Batch03/surface_revision_20260917_exterior_marking.json)。

用户在[实际成品审核B v3](../../ArtSource/Ships/ShipComponentStyle_20260917/Batch03/Review_B_v3.html)展示后明确“三件均通过 B，导出 FBX”，见[决定记录](../../ArtSource/Ships/ShipComponentStyle_20260917/Batch03/approval_B_20260917.json)。[最终交付总览](../../ArtSource/Ships/ShipComponentStyle_20260917/Batch03/Delivery/v3/Review.html)及[完整ZIP](../../ArtSource/Ships/ShipComponentStyle_20260917/Batch03/ShipComponentStyle_Batch03_20260917_v3_Delivery.zip)包含三套静态FBX、四份可编辑Blender、九张2K贴图、材质参数和全部实际预览。FBX尺寸、原点、几何、UV、材质槽与静态接口回读通过；获批源保留，UE正式验证未运行。

## 2026-09-17 全组件正式替换

用户后续明确“开始实施，然后把这些组件导入至ue替换正式资源”。本批纳入全13件正式替换，保留原网格路径、蓝图引用、源几何、原骨骼/挂点和碰撞。新增三档材质、2K纹理及独立轮廓，保存后独立回读通过。下文之前的“UE未运行/另行安排”是原交付阶段状态；当前实施以本节及[总开发记录](../DevelopmentDocumentation/20260917-Ship剩余四组件贴图与框线制作.md)为准。

首批v4、第三批v3沿用已有B通过；第二批v2和第四批v1按[直接发布授权](../../ArtSource/Ships/ShipComponentStyle_20260917/UE_Integration/release_authorization_20260917.json)导出，不补写额外B视觉通过。7门炮637姿态核对通过；原舰体bottom_mid_0缺失与六个组件无兼容槽位仍按旧配置保留，完整实战/性能未覆盖。
