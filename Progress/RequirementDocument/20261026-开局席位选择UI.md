# 开局席位选择UI

## 需求

当前 `/Game/Maps/LVL_CommanderMassPrototype` 的普通本地PIE从配置直接读取MainRole，默认Ground。点击播放后增加简易选择窗口：指挥官、游骑兵、巡天，显示当前选项和“进入战场”“取消”。确认后交给既有角色和网络启动流程。

每次新开局都显示选择；同一编辑器会话保留上次确认的选项，取消、Esc和窗口关闭不开始对局。不将游骑兵与指挥官兵种重防号WM01混用。

## 边界

- 只接交互式本地PIE入口，不新增打包游戏大厅、阵营选择或地图出生点选择。
- 不修改地面、低空、飞船或僚机的运动、碰撞、导航及既有出生坐标。
- 正常模式沿用600兵清单及原有启动检查。关闭选择开关或无人值守模式仍使用显式配置的MainRole；模拟模式不新增弹窗。
- 按项目统一色库制作，助手不截图或目检；运行和视觉效果留给玩家确认。

## 玩家验收

- [ ] 原图点击播放出现选择窗口，三个席位可以切换并显示当前选择。
- [ ] 分别确认三个席位，进入现有对应视角和操控方式。
- [ ] 取消、Esc和关闭窗口均返回编辑器，不创建后台对局进程。
- [ ] 结束后重新播放可再次选择；Tab/Enter/空格及窗口缩小后的滚动可用。
