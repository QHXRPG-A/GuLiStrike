# 僚机视觉插值与远端缓冲

## 背景与目标

僚机逻辑运动固定以30Hz推进，Owner客户端当前直接显示每个固定步后的Pawn根Transform；高于30FPS渲染时会重复显示同一逻辑姿态后跳到下一姿态。远端虽有快照插值，但巡航5Hz快照间隔约0.2秒，现有0.1秒回看不足以持续处于已知样本区间。

目标是在不改变权威逻辑、碰撞、攻击位置或网络协议的前提下消除可见模型的固定步跳动。

## 需求描述

- Owner僚机保留Pawn根节点作为30Hz确定性逻辑、碰撞、导航、Candidate和攻击坐标。
- 可见模型使用相邻两个已完成逻辑步的 `PreviousTransform → CurrentTransform`，按当前固定步余量逐渲染帧插值。
- Remote僚机继续消费既有Accepted Pose，不增加网络包；插值回看时间改为0.2秒，以覆盖巡航5Hz的标准样本间隔。
- Remote快照超过0.5秒时停止外推并保持最后姿态可见，不再淡出、隐藏或回收后重现。
- 初始化、权威Rebase和远端池复用必须形成明确的不连续边界，不跨边界混合旧视觉姿态。
- 新代码不增加静默修正、兜底路径或替代旧值的防御性行为。

## 边界

- 不改变30Hz固定步、最多每帧4步、运动算法、FlightNav、碰撞或攻击判定。
- 不改变Candidate/Accepted协议、上传频率、服务器权威边界或伤害位置。
- 不新增或扩写自动化测试用例；使用当前已有测试、源码构建和双客户端PIE采样验证。

## 验收标准

- [x] Owner Pawn根Transform仍只由既有30Hz MovementComponent写入。
- [x] Owner可见模型在相邻逻辑姿态之间逐渲染帧平移和旋转。
- [x] 攻击、碰撞、导航及Candidate继续读取Pawn根Transform，不读取视觉插值Transform。
- [x] Remote标准插值回看覆盖0.2秒的5Hz快照间隔。
- [x] Remote断流时固定保留最后姿态，不再淡出或隐藏。
- [x] 初始化、Rebase和对象池复用不残留上一段插值。
- [x] 源码版 `GuLiStrikeEditor Win64 Development` 构建、Presentation 7/7、Attack 12/12和双客户端PIE通过。
- [ ] 完整Pawn套件全绿：当前5/6成功，`PerMemberAirGroundAttackExecution` 仍使用旧攻击状态预期而失败。
