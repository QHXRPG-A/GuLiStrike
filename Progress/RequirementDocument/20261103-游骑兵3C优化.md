# 游骑兵3C优化

## 目标与确认依据

仅作用于Ground玩家游骑兵，ModelId=4001，正式角色`BP_GroundMech_Light`及A4B2整机骨骼。用户确认：默认自由瞄准、右键只保留近距离构图、地面和空中均按0.8比例横移、机体采用小容差持续跟随。相机基准是用户提供截图对应的**蓝图编辑器预览观察视角**。

2026-11-04用户要求“用当前视口设置摄像机相关参数”，相机基准更新为00:05:50（+08:00）读取并冻结的当前蓝图视口；[本次冻结记录](../../Artifacts/GroundCamera_20261104/blueprint-preview-camera.json)替代11月3日数值作为当前默认值。其他3C目标沿用原确认。

幅度方案经只读源动画试算：五个移动动作增加25%；后退跑步受机械腿约束只能增加约8%，用户确认分别调幅度，保留骨长、膝角和脚间距。

## 行为与数值

- 鼠标中心准星持续驱动炮台和机体水平朝向；地面、站立与空中共用转向时钟。右键只控制镜头及对应HUD状态，取消W优先跟随镜头。
- 转身倍率2→4，上限1080→2160°/s，启动/停止角度15°/5°→1°/0.5°；小角度转身按实际单步角度降低姿态权重。
- 地面前进216、横移172.8cm/s；普通空中前进324、横移259.2cm/s；喷气前冲保持864cm/s。组合键先归一化，再应用各方向速度。
- 五个动作：前进/左右水平幅度0.8→1.0，后退步行1.0→1.25，抬脚0.65→0.8125，骨盆起伏0.55→0.6875。后退跑步三项改为1.08、0.702、0.594。
- 从指定蓝图预览视口精确读取并冻结位置、旋转、FOV，换算为Camera.Free；缩放范围为初始臂长0.65～2倍。保留近距离构图、0.2秒切换、避障和闪现恢复。
- 继续阻止菜单、建造、失焦、死亡及解除控制期间的战斗输入；网络恢复不得从持续跟随标志推断右键按下。

## 完成与验收记录

2026-11-04 按用户指示完成本工作项。下列条目是玩家核验项目，保留实际反馈状态。

### 2026-11-04 上下身独立转向确认

用户以坦克炮塔/底盘分离为操控参考，确认下身保持当前逻辑，上身即时响应、水平完整旋转。仅水平轴采用快速跟上、平稳停住的阻尼，不回弹；隔离下身传来的旋转、倾斜和摇摆，保留腰部位置和升降。默认T90=0.10秒、收敛容差0.05°；双臂限位改为相对上身，仍沿实际炮口射击。相机、右键拉近、移速和步态沿用当前配置。

- [ ] 下身分步转身不再带偏上身，持续追踪不等待脚步。
- [ ] 小角度、90°/180°、连续反向和跨±180°转向均连续、无回弹；俯仰保持原响应。
- [ ] 双臂限位跟随上身坐标，转向后方不会被底盘限位拉回；弹道与实际炮口一致。
- [ ] 菜单、控制恢复、闪现及新局/网络恢复无旧目标追转或跳角。

### 原3C验收

对应地图`/Game/Maps/LVL_CommanderMassPrototype`，沿用`GroundMobility_Entry=(-2800,50000,1149.04)`。

- [ ] 不按右键即可站立、移动、空中瞄准，并驱动机体追向；右键只改变镜头。
- [ ] 转身速度与动画同步；小角度修正无整步突然甩腿，左右与斜向移速符合比例。
- [ ] 加大步态后脚步频率匹配位移，膝部、脚间距、支撑与上下坡保持稳定。
- [ ] 默认相机符合指定预览视角；缩放、右键、闪现结束及控制恢复行为正确。
- [ ] 联机恢复保留独立镜头状态，失焦/菜单/解除控制不残留开火、喷气或转向输入。
