# 单位受击白光与摧毁爆炸

## 需求

- 所有已有受伤入口的单位受击时，叠加白色发光，强度在0.5秒内衰减到0；再次受击重新开始0.5秒渐变。按用户追加要求，单位本体透明度保持不变，不做透明度渐变。
- 僚机、指挥官作战单位、矿车等非玩家直接操控单位，摧毁时播放一次爆炸和向外扩散的冲击波。
- 其他非玩家单位爆炸来源为 `/Game/RealisticExplosionPackD`，运行时从A～T共20个System中随机选取，均自带0.75秒Shockwave层。僚机按下方最新追加改为独立空爆池。
- 玩家飞船保留受击白光，不套用非玩家单位摧毁爆炸。
- 2026-09-13追加：所有单位的血条与受击白光使用同一触发链，受击后完整显示3秒，再用0.5秒渐隐；再次受击重新计时，选中单位保留现有常驻血条。
- 摧毁爆炸以最小兵种当前效果为视觉基准；代码读取兵种目录和实际模型包围盒，根据相对尺寸缩放，不按兵种ID写死尺寸或倍率，不让尾焰等特效撑大尺寸。
- 后续追加：所有已有单位销毁爆炸在上述模型相对缩放基础上统一再放大5倍；保留兵种间相对比例，不修改对地轰炸特效或伤害范围。
- 僚机销毁追加：改用 `/Game/AllExplosions/Niagara/Aerial/NS_Explosion_Aerial_3` 与 `NS_Explosion_Aerial_4` 等概率随机二选一，完整保留烟雾冲击波和折射层；其他单位仍使用A～T且保留各自Shockwave，不更改对地轰炸。
- 2026-09-13深夜追加、09-14实施：单位销毁冲击波最大外径不超过爆炸主体峰值外径的2.5倍；根据资产实际尺寸校准，不把Niagara缩放参数直接写成2.5。随后反馈“所有的爆炸，冲击波都冲屏幕脸上了”，将对地Big_17一并纳入重复缩放排查；保留主体5倍、冲击波层、随机朝向与原伤害规则。
- 2026-09-14追加：单位被摧毁后显示铁锈报废态模型；僚机继承被摧毁前的完整运动速度，以重力做自由落体，落地后销毁残骸实体。地面单位沿用现有5秒残留时长。

## 边界

- 表现不产生额外伤害、击退或资源奖励，不修改战斗结算和死亡规则；新增僚机残骸仅与静态场景碰撞，不与存活单位、其他残骸或导航交互。
- 矿车当前没有统一血量组件；本次接入其标准受伤事件和真实销毁事件，不新增矿车血量数值。
- 没有权威生命值的占位单位显示灰色受击状态条，不伪造剩余血量；已有Health组件或僚机权威血量的单位显示实际比例。
- 采用项目副本保存池化、裁剪和动态灯光调整；指定素材原件保持现有内容。
- 迟加入、切图、归还对象池不重播历史死亡。
