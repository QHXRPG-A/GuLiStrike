# Ship 空中部队原型关卡与三倍航速

## 背景与目标

现有 `/Game/Maps/LVL_CommanderMassPrototype` 以指挥官与地面部队验证为主。本需求复用其地形与战局框架，建立独立的 Ship 空战入口：玩家作为 Air 角色驾驶 `BP_CombatAvatarFly01`，并沿用当前 V3 僚机能力组。与此同时，当前玩家 Dreadnought 空装配的最大航速提高到原值的三倍，便于在大尺度空战区域内接敌和脱离。

## 需求描述

1. 新建独立地图 `/Game/Maps/LVL_ShipWingmanAirCombatPrototype`，以 `/Game/Maps/LVL_CommanderMassPrototype` 为模板，不覆盖原图。
2. 地图使用 `AGuLiShipTestGameMode`，首个玩家优先取得 Air 席位并生成 `BP_CombatAvatarFly01`；该 Pawn 沿用 `/Game/GuLiStrike/Ship/Abilities/DA_ShipAbilitySet_WingmanV3`，默认拥有 25 架僚机。
3. 在空中布置四个玩家出生点，形成三维交战区域；最远出生点间距保持在僚机 1500m 自动索敌半径内。
4. 为新地图烘焙独立 FlightNav DataAsset，引用必须指向新地图的 World 与 FlightNavigationVolume。
5. 将新地图加入 Cook 与必需 World Package 清单。
6. `GuLiStrikeShip.xlsx` 继续作为航速唯一编辑入口。仅把 `Dreadnought.BaseMaxSpeed` 从 `1800` 改为 `5400cm/s`；保持 `SpeedMultiplierMin=0.5`，所以当前空装配有效最大航速从 `900` 变为 `2700cm/s`。`BaseAcceleration=600cm/s²` 保持不变。

## 边界

- 不修改 Commander Mass 原型图的玩法语义。
- 不改变 `Default` 调参行，不扩大到所有舰型。
- 不把加速度同步放大三倍。
- 不新增或扩充自动化测试文件；使用现有数据部署、资产报告和源码引擎独立运行验证本次资产与数据改动。

## 验收标准

- [x] 新地图可独立加载，WorldSettings 指向 `GuLiShipTestGameMode`。
- [x] 四个 Air 出生点与战斗中心存在，最远出生点间距不超过 1500m。
- [x] 新地图拥有独立且有效的 FlightNav DataAsset，Formation 导航净空合同通过。
- [x] Dreadnought 表值为 `BaseMaxSpeed=5400`，生成 JSON 与 UE DataTable 部署成功。
- [x] 当前空装配有效最大航速由 `900` 提高到 `2700cm/s`，倍率精确为 3。
- [x] 源码版 UE5.7 独立运行能加载地图、使用 Ship Test GameMode、建立僚机组并进入已编写 StateTree。
- [x] 地图被加入 Cook 与 RequiredWorldPackages 配置。
