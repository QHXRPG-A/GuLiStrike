# 2v2指挥官与无双席位

## 已确认的范围

- 每队最多两名在线参战玩家，分别占指挥官与无双席位。
- 无双同时拥有并模拟游骑兵（Ground）、巡天（Air）及其召唤物。开局选项决定起始操控单位，局内按 Tab 切换，未操控单位继续模拟。
- 房间开始处理离队后，原玩家身份本局失去加入资格。正在离队和已经离线的身份再次加入时立即被拒绝。队友按现有规则接管模拟。
- 每名无双同一时刻只输入操控一个载具；切换不改变房间身份、席位版本或两台载具的模拟权。双方无双席仍各只允许一名玩家。
- 继续使用现有 Hybrid 模拟分摊。指挥官活动兵种保持选择/操作时收回、闲置时向同队分摊；建筑、经济、矿与控制点继续共用全局 `match/resources` 资源组。
- 保留 Commander/Ground/Air 枚举和协议字段。网络层 Ground/Air 都匹配本队唯一无双；本地单独保存当前操控目标，UI与输入按目标更新。
- 正常房间默认等待红蓝各两人就绪。普通 Local PIE 继续使用编辑器中的红方所选角色与蓝方指挥官逻辑客户端，显式等待各一人。

## 验收约束

| 场景 | 预期 |
|---|---|
| 红蓝各指挥官 + Ground 或 Air | 共四席，可组成完整 2v2 |
| 同队 Ground 与 Air 同时加入 | 第二名无双被拒绝，包括指挥官尚未入局时 |
| 同队第二名指挥官或第三名参战玩家 | 拒绝加入 |
| 正在离队或已离线的原身份再次加入 | 直接拒绝，席位版本与房间阶段不受此次请求影响 |
| 同队旧三人在线名册恢复 | 拒绝冲突名册，不截断或强行改角色 |
| 空出的席位 | 可由符合条件的新身份填补，使用原有入局流程 |
| 本地四席目录 | 红指挥官、红无双、蓝指挥官、蓝无双 |
| 选择 Ground 或 Air | 房间保留初始身份；两台载具及其召唤物均由本队无双模拟 |
| 无双局内按 Tab | 切换到己方另一台已就绪且存活的载具；HUD、相机和输入随操控目标切换 |
| 切走与切回 | 旧单位停止持续移动/射击输入，继续物理与玩法模拟；召唤物不因切换转移或销毁 |
| 目标死亡、休眠、未就绪或失去权限 | 保持原操控目标；界面模态期间不切换 |
