# Ship第二批三组件贴图与框线制作

用户要求“再做接下来的三个组件”，本批按现有组件编号补齐自动炮`Autocannon`、三联炮`Triple_Barrel_Turret`、单管炮`Single_Barrel_Turret`。三者均使用现有骨骼原模型，保留原几何、尺寸、机械绑定、原点与炮口接口。

用户随后明确：“还是那一套工作流：根据模型和项目美术风格产出效果图+三视图给我审核，再根据效果图+三视图+原模型调整贴图和框线，给我审核”。该指示是本批流程依据，不能用首批过审代替本批审核A或B。

## 风格与范围

共用首批v4的浅色装甲、深蓝灰结构、清楚的大色块、内线与三档光影。自动炮和三联炮参考首批双联炮赭黄配色，单管炮参考CIWS青蓝配色；具体分色必须随本批图纸审核。以实际原模型为形体依据，不新增装甲、炮管、护罩或倒角。

1. 只读核对并保存三件源网格、骨骼、挂点、尺寸和哈希；原型渲染仅作参考，不是新成品。
2. 每件提供效果图、正视、侧视、背视和原模型对照，提交具体版本审核A。
3. A通过后，依据已审图与原模型调整可编辑贴图、独立内线和外轮廓、三渲二光影；默认每件2K纹理。
4. 提供实际Blender视图、灰模及俯仰演示，提交审核B；放行后才完成最终FBX导出和回读。UE正式接入另行安排。

## 验收

- [x] 三件效果图与三视图完成并修正主要分色差异，原型关键特征保留，用户审核A决定及版本有记录。
- [x] A通过后按图完成原模型贴图、框线与三渲二渲染，主体几何和接口未变。
- [x] 实际成品已展示，按后续直接发布授权完成导出和回读；B未额外视觉通过，分别记录。
