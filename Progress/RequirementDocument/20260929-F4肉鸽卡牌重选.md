# F4肉鸽卡牌重选

在现有F4选牌界面底部右侧增加“重选”，由服务器重新抽取最多三张不重复的合格卡。优先替换成未显示的卡；不足三张时从仍合格的原候选补足，无其他牌时保留原候选并提示。依赖、互斥和获取次数规则继续生效。

选择前和翻面完成后可重选；入场、翻面、等待重选结果、提交或成功退场期间不可用。重选不发奖励，旧会话不能在替换后继续确认。Esc关闭后重开保留最新候选。

本次不改卡图、卡牌数值或战斗特效；不引入费用、次数或新的资源系统。

## 玩家验收

- [ ] `/Game/Maps/LVL_CommanderMassPrototype` 就绪指挥官按F4，可见“重选”。
- [ ] 有其他合格牌时替换，无其他牌时提示且原牌仍能选择。
- [ ] 依赖牌不会提前出现，重选不会发奖励或清除队伍获取记录。
- [ ] 连点和旧会话确认不会重复结算；Esc重开保留最新候选。
