# 蓝矿、红矿、据点维护与三线 Roguelike 成长

## 背景与目标

2026-09-08，用户在双棋盘与工程车玩法讨论中补充资源设定，并明确将资源暂称为 **蓝矿、红矿和经验**。本稿集中记录已确认规则；此前讨论中的物资、能晶等具体命名不再作为当前资源名称。

沿用用户已提出的双棋盘前提：据点范围彼此无空隙，共同组成据点棋盘；资源随机分散在资源棋盘，与据点区域叠加。地图上的矿藏不可再生。工程车施工、50 倍快速通道和包围断气的既有讨论保留在[来源记录](../Backlog/2026-09.md#idea-202609-001-围棋融入大战场据点作为棋子的玩法模型)，本稿不补定其未决规则。

## 需求描述

### 一、资源职责

| 要素 | 获取与分布 | 已确认用途 |
|---|---|---|
| 蓝矿 | 地图分布较多；有限矿藏，不可再生；经采矿车与资源加工厂转为真实库存 | 建筑建造；工程车建造；所有通过兵工厂生产的兵种，包括四足机器人、WM01、工程车等；据点维护 |
| 红矿 | 地图分布较少；有限矿藏，不可再生；经采矿车与资源加工厂转为真实库存 | 据点维护；外层战略支援，包括导弹齐射、打击光线、护盾，以及供 Ship 快速跨区的传送门、加速带等；选取部分强力 Roguelike 牌所需的额外费用 |
| 经验 | 主要通过击杀敌对单位和占领据点获得 | 唯一触发 Roguelike 选牌时机的手段；WM、Ship 与指挥官三线独立 |

工程车既属于明确指定的蓝矿建造对象，也包含在兵工厂生产范围中，同一次生产按对应费用记录，不因出现在两处用途描述中重复计费。本轮没有为兵工厂强力兵种另行追加红矿生产费。

### 二、采集、加工与入库

玩家只能采集据点内部的矿。采矿车和资源加工厂共同负责把采出的矿转化为玩家可实际消费的库存，职责流程为：

`据点内地图矿藏 → 采矿车采集 → 资源加工厂加工 → 可消费的蓝矿／红矿库存`

地图上尚未开采的矿，以及尚未完成入库流程的矿，不直接当作玩家可消费库存。地图矿藏、采集过程和真实库存需要在规则上区分。

此处固定的是据点内部采集限制与采矿车、加工厂的职责；己方、敌方和中立据点的采集权限、运输方式、加工时间及换算比例仍待细化。资源加工厂的确认取代此前“采集后直接入库、不增加加工环节”的建议。

### 三、据点维护与断供

**据点维护同时消耗蓝矿和红矿。任一种资源不足以满足维护要求，都触发相同的四项后果：**

1. 据点不再产出基础单位。
2. 据点塔的防御武器失去能力。
3. 据点护盾消失。
4. 据点内由据点提供的兵种增强 buff 消失。

用户最初在蓝矿段写了维护与缺矿后果，在红矿段写了“只消耗红矿”；随后明确澄清为双资源维护。以上双资源规则为最终记录，原“只消耗红矿”表述不再生效。

维护资源恢复后的重新启用时机、护盾如何恢复，以及多个据点的扣费顺序尚未指定。快速通道的断气仍按既有敌方据点范围包围规则记录；本轮确认的维护后果为上述四项。

### 四、红矿与外层战略支援

外层战略支援消耗红矿，已明确的例子是导弹齐射、打击光线和护盾。2026-09-09 用户进一步明确传送门、加速带等红矿支援用于让 Ship 从战场一处瞬时或近即时转移到另一处，以改善跨区赶路时间。具体支援费用、效果参数、库存归属及调用权限尚未定稿，布设与通行如何计费也待细化，见[首版 Demo 与 Ship 节奏需求](./20260909-Demo3v3与Ship战略机动及高频选牌.md)。

用于战略支援的护盾和据点自身的维护护盾分别按其所属功能记录；本轮不将二者合并成同一个技能或同一笔费用。

### 五、经验与三线 Roguelike 成长

- 经验主要通过击杀敌对单位与占领据点获得。
- 经验是唯一触发选牌时机的手段；蓝矿和红矿余额本身不产生额外选牌时机。
- WM、Ship、指挥官三线独立，分别维护各自经验成长与选牌触发进度。
- 2026-09-09 已确认 Ship 的选牌频率显著高于 WM 和指挥官，并优先投入 Ship 卡牌设计制作；具体相对倍率、经验曲线、阈值和单张强化幅度待定。高频选牌仍由经验触发，不由红矿余额或支援消费直接触发。
- 部分强力牌需要消耗相当数量的红矿才能选取；具体牌目和费用尚未确定。

选牌触发与选牌支付是两个环节：**先由对应成长线的经验触发选牌机会，再在选取需要红矿的强力牌时满足并支付该牌费用。** 红矿承担这类牌的选取费用，不能替代经验直接开启一次选牌。

本轮不把经验改成消费型矿产，也不因占点或击杀已经授予经验而额外直接发放选牌次数。具体经验奖励、触发阈值、同一职业多名玩家的经验分配，以及强力牌所扣库存的归属与支付权限仍待细化。

## 与此前讨论的衔接

本稿是上述资源与成长规则的当前依据。此前[双棋盘资源讨论](../Backlog/2026-09.md#2026-09-08-双棋盘有限矿藏与-roguelike-资源收敛)保留为过程记录，其中以下候选建议由本稿替代：

- 当前命名统一为蓝矿、红矿和经验。
- 采矿车与资源加工厂共同完成入库，取代采集后直接计入库存的建议。
- 据点明确需要蓝矿、红矿共同维护，取代维护主要集中于可选高阶设施的建议。
- 任一种维护资源不足会停止据点基础出兵等四项功能，取代资源耗尽后据点仍保留基础出兵的建议。
- 部分强力牌收取红矿费用，取代所有选牌一律免费的建议。
- 三线分别依靠经验触发选牌，取代本次讨论中以团队统一阶段安排三线选牌时机的建议；既有团队贡献如何分配经验仍需另行细化。

其余未冲突的历史建议也不因此自动变成已确认规则。[基地建造探索](./20260831-基地建造玩法探索.md)和[大战场草案](./20260826-5v5大战场玩法草案.md)中与本稿直接冲突的资源、维护或成长候选描述，以本稿为准。
