# Hybrid 世界更新平均不超过 5 ms

## 目标与边界

渲染客户端完整Hybrid主线程工作平均≤5ms，包含世界逻辑推进、状态应用、回执、外层网络收发，以及移到其他主线程位置的相关工作。嵌套计时取并集，不重复相加。分析scope_version=2为完整口径，旧世界推进范围仅作诊断。Hybrid和整帧P95不恶化，队列不持续积压。

同机两个客户端和一个 Coordinator 保持相同配置；本地模拟归属、玩法、模拟频率、画质不变。命令至实际权威位移、最终回执的额外均值、P95 和峰值均不得超过对应 A 场景平均帧长。旧 mask=511 不视为已验证方案。

## 实际负载

以运行时 SimulationOwner、HasSimulation、存活状态统计，分别记录本地权威、对端权威和休眠对象；阵营、全场总数和显示实例不能替代。

| 类型 | 最低本地实际模拟数 |
| --- | ---: |
| unit/1 | 165 |
| unit/2（重防号） | 135 |
| unit/5（扫荡者） | 365 |
| unit/3（矿车） | 16 |
| unit/4（工程车） | 16 |
| territory/7 | 49 |
| building/4、building/5 | 各 34 |
| building/6 | 36 |

匹配生产、采矿、移动、交火和历史目录规模。原房间无法恢复，因此建立新同条件基线，保留历史 15.08 ms 作为参考。600 单位原场景仅作为回归项。
