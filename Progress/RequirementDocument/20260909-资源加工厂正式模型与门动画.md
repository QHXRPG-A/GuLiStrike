# 资源加工厂正式模型与门动画

采用参考图科幻装甲厂房造型，宽 60m、深 48m、高 22m，门洞约宽 36m、高 14m。包含灰色数字迷彩、黄黑警示条、蓝光内舱、单扇顶部铰链上翻门。开关门各 3 秒。

交付范围为正式模型、材质、动画及可放置蓝图；本次不扩展建造菜单、加工经济和多人逻辑。门默认关闭，由外部蓝图调用，提供完成事件与车辆入口／卸货位置。
