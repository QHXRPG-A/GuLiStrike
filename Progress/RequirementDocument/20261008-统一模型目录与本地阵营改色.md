# 统一模型目录与本地阵营改色

当前补项为扫荡者 `ModelId=1005`；用户明确不做克隆兵营占位 `2004` 和领地据点占位 `2007`。扫荡者取消新增参考图，全部原橙色为 TeamPrimary 可变区，其他原配色、结构及动画保持。用户最新“导入 UE、接入自动改色。”明确放行已展示的[Blender B_v1](../../ArtSource/SweeperTeamColor_v1_20261008/REVIEW.md)，[授权绑定](../../ArtSource/SweeperTeamColor_v1_20261008/formal-import-authorization.json)记录具体版本哈希。正式原材质已接入UV精确遮罩，Excel及对应DataTable已更新；双方真实Q召唤各5个扫荡者，各端己蓝敌红，实际参数、登记归属刷新、未知阵营和外部清零恢复已核对。两类占位模型ID和资源保留、改色开关关闭；[本次增量](../Archive/20261009-扫荡者橙区正式导入与自动改色.md)不替代最终玩家观感确认。

用户后续授权覆盖本阶段最初的“不编译、不运行、不正式导入”默认边界。已按具体消息完成本次源表、原生模块、DataTable及14模型/共用施工体正式入库；来源B文件SHA256和用户原话见[存储授权](../../ArtSource/ModelInterface_B_20261008/formal-import-authorization.json)。用户“这些黑块太深了，再浅一些”授权提亮当前模型暗面及已通过可见性隔离确认的矿石黑块；固定色卡和原网格保持。最终用户验收与技术执行分别记录。

新增 [GuLiStrikeModels.xlsx](../../Data/Excel/GuLiStrikeModels.xlsx)，四张三行元数据表登记模型资源、Parts、Vector／Scalar 参数和 ColorRegions。资源路径、纯视觉类及 VAT 由模型表维护；兵种、建筑、舰体、飞船部件、Ground、僚机及其他玩法模型以 ModelId 引用，保留网络身份、玩法类、数值、行为、缩放、socket、骨骼与动画。

ModelId 是独立稳定正整数。程序按资源类型解析并查询目标组件参数实际值，区分默认值、MID 和 CPD；写入遵循登记权限，阵营参数归本地配色系统管理，不复制 N 套模型。SSF 已有 Team Color 使用统一 TeamPrimary 键，其他候选接入相同 CPD 契约。

己方浅／深队色 #6AA4BE／#274E61，敌方默认 #A34053／#662249，固定乳白 #FEE4D9、米砂 #D5C09C、机构 #2C3735。一般不透明区域 Alpha=role/255；CPD 8–11、12–15、16、17，保留受击 7 及每实例动画槽；扫荡者保留原Alpha，原UV精确遮罩只驱动TeamPrimary和启用。自动改色以已确认兵种／建筑范围及当前排除项为准；工程车、Ground、DIY、僚机和矿石只迁目录与参数，保持当前配色。

沿用 B_v1：护盾三点队色灯、前哨整件矩形及半圆环、空军基地顶甲分区，彼之矛施工体共享设计。所有场景 UI 继续后处理之后批量绘制；未知身份脚环隐藏，脚环径向 20 cm，选中只添四个同色标记。

新配色必须先交独立候选并经过具体 B 审核；现有已审正式资源先做 ID 迁移。环境地编及特效目录不扩大。本阶段默认只静态检查、预览和对应地图保存回读，不编译、不游戏、不新增或运行自动化测试。

验收对应 `/Game/Maps/LVL_CommanderMassPrototype`、`/Game/Maps/LVL_GroundMech_Demo`、`/Game/Maps/LVL_ShipTest`。源表、源代码及实体数据检查不能替代双客户端晚加入／归属变化或实际三视图验收。细节及剩余项见 [开发交付](../DevelopmentDocumentation/20261008-统一模型目录与本地阵营改色.md)和 [接口说明](../../Data/Models/README.md)。
