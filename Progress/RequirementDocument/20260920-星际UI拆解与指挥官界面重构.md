# 星际UI拆解与指挥官界面重构

## 范围

完整局内指挥官HUD：资源、小地图、选择与详情、肖像、5×3命令卡、0–9编队、任务队列、B建造、T战术运输、提示与F10菜单。使用指定Dark GUI素材和现有单位立绘，工程车补静态肖像；不修改地面／空中角色UI。

## 行为

- 24头像组／页，8×3；同兵种按稳定单位顺序每25个合并为一组。单击选择该组，Shift移除该组，Ctrl保留当前选择内同类，CtrlShift移除同类。
- 类型页签及Tab只切查看，Q仍面向完整选择。数字键编队保持现有规则。
- 小地图左键／拖动定位；右键与M模式左键提交移动，Shift追加。
- 任务展示当前来源、完整单选队列、多选共同前缀／差异、持续停止、安全退出与错误；点击目标定位。
- B目录使用真实费用和放置规则；T展示真实阶段与参与数。菜单只接管本地输入，Esc优先关闭顶层界面。
- 头像操作服务端校验，共用可靠顺序；协议15→17，不增加任意成员列表授权。客户端只提交组内锚点，服务器按同样的兵种、身份类别和稳定ID排序重建最多25名成员。

## 2026-09-20 画面反馈补充

- 命令卡与建造目录只显示图标，名称、快捷键和简介移入悬停提示；提示第一行为加粗名称，下方为简短介绍。禁用图标仍能查看原因。
- 去掉小地图下方操作说明、选择区底部说明、底部任务摘要条、命令卡标题。相关操作说明保留在帮助与悬停提示中，任务状态通过任务图标展开查看；收紧腾出的留白。
- 编队条采用紧凑槽位，数字键与成员数分开显示；空组不显示第二个 0。
- 肖像按原图宽高比适配，禁止拉伸。生命、护盾、移动速度、防御、蓝矿载货、红矿载货采用“图标＋数值”，属性名称与解释移入提示。
- 新增 `Data/Excel/GuLiStrikeGameTexts.xlsx / Texts`，仅“文本id、介绍、内容”三列；界面文案和相关玩法反馈从该表读取，动态值使用占位符。已有兵种／建筑／任务名称仍引用对应玩法源表，避免重复维护。
- 头像格不显示 `#实例ID`，改为头像加本组人数；头像悬停不再显示实例名称、生命值和选兵操作说明。组血条显示该组汇总生命比例，详情区的生命、护盾等属性继续使用图标加数值。
