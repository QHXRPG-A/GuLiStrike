# 十三模型配色参考与三视图 A_v2

## 2026-10-09 后续执行状态

A_v2已被用户提出的修改及十四模型A_v3取代。 当前成品及运行见[统一目录交付](../DevelopmentDocumentation/20261008-统一模型目录与本地阵营改色.md)。

## 背景与目标

用户认为旧版 SSF 六座、彼之矛、护盾发生器、前哨建筑和先驱号颜色杂乱、不协调，要求先出参考图和三视图，审核通过后再施工。用户批准十模型重做计划，随后提供四张色卡并明确“颜色不要乱配，在这几个色系当中去选配”，最后追加“包括防空炮、哨戒炮、矿厂也用上述配色重新制作”。本任务据此扩展为十三个独立模型、二十六张蓝红参考图板。

## 需求描述

- 保留现有轮廓、比例、装配、活动件、动画和 LOD，依据实际模型视图制作二维配色参考。
- 主装甲使用浅色，机构使用深灰，蓝红队色集中在少量连续面板或阵营标识；清理碎纹、无意义划线和零散小色块，保留主要结构线及三档明暗。
- 配色只从用户四张色卡中选择。本次候选为奶油白 `#FEE4D9`、深灰 `#2C3735`、蓝灰 `#6AA4BE`、莓红 `#A34053`；已有功能位置允许少量琥珀 `#EE9D58` 或青色 `#0D9099`。基础涂装值由配置记录，参考图的光影色阶不作为新涂装色。
- 每模型分别交付蓝、红两张独立图板，每张含三分之四效果、正视、左侧视、后视及色卡；蓝红仅改变指定队色区。另附固定区／队色区／功能区说明、总览和放大画廊。
- 使用内置图像生成工具，留存实际输入视图、提示词、来源和输出哈希。三视图采用正交设计表达，原模型仍是实际尺寸和几何的权威依据。

## 边界

覆盖先驱号、彼之矛、护盾发生器、前哨建筑、防空炮、哨戒炮、矿厂，以及 SSF 空军基地、克隆中心、指挥中心、军工厂、反应堆、战略中心。彼之矛施工体共用彼之矛设计，不额外计数；SSF 本轮不新增玩法类型。重防号、扫荡者、采矿车、建造车、玩家地面机甲和 DIY 飞船模型不在本任务重做范围。

新增目录固定为 `ArtSource/LocalTeamColorReference_A_v2_20261008`。保留旧版红蓝对照及 SSF 既有审核历史。本阶段仅交付参考图、配色说明和审核记录；用户明确通过某个模型的具体 A 版本后才制作该模型，实际 Blender 成品另走 B 审核，再更新正式 UE 资源。

## 验收标准

- [x] 十三个模型各有蓝、红独立图板，共二十六张，均含四个指定视角及色卡。
- [x] 每模型附固定区、可变队色区、功能区配置；蓝红配对保留固定色，浅色装甲占主导。
- [x] 保留原模型视图与提示词，提供总览、可放大画廊和来源清单；文件保存后回读核对。
- [ ] 用户确认指定模型的具体 A_v2 配色、分区及参考表达；尚无该版本通过决定。
- [ ] 通过 A 后按实际原模型施工，提交 Blender 成品 B；本阶段不适用。
