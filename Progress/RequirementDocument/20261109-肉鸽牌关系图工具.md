# 肉鸽牌关系图工具

为指挥官、地面和空中提供三个页签。每个节点显示卡名和总等级，点开可查看、编辑通用说明和各级效果。已有卡和新增卡均可设置总等级，0 表示不限。使用拖拽移动节点和建立关系，支持新增、编辑、删除卡牌及删除连线。

各席位的节点显示已有的独立图标，右侧详情显示对应牌面。图标和牌面分别按节点 ID 绑定，卡名可以继续编辑。已有参考稿的草稿可在详情中显示最新参考图和选稿状态。

前置线由前置卡指向后继卡，门槛取源卡草稿等级范围，多个前置均须满足。互斥用无向虚线表达。单向禁用由触发方指向目标方，可停用已有效果并移出候选，也可只停止后续获取、保留已获等级。关系限同席位，循环前置及前置链内部互斥须在编辑和保存时拦截。

保存三页的节点、坐标、关系及相对正式卡表的变更。现有卡使用正式 ID，新卡先作为草稿设计，后续根据保存内容接入 Excel、公共文本、游戏卡池与效果。

## 工具交付验收

- [x] 三个席位读取当前正式卡表，空中页可从空白开始设计。
- [x] 点击看说明，支持移动、增删、编辑、拖线与撤销。
- [x] 草稿写入文件，重新打开恢复内容及布局。
- [x] 保存包含新增、删除和修改清单，校验拒绝无效关系。
- [x] 第三轮的 15 张分级牌、59 条效果和两条引擎三级门槛已回填至原节点，27 个节点的身份、顺序和坐标逐项核对一致。

用户保存实际卡牌设计并确认接入范围后，可按草稿安排正式接入。
