# 肉鸽牌关系图工具

为指挥官、地面和空中提供三个页签。每个节点显示卡名，点开查看描述。使用拖拽移动节点和建立关系，支持新增、编辑、删除卡牌及删除连线。

前置线由前置卡指向需要它的卡，多个前置均须满足。互斥用单条无向虚线表达。关系限同席位，循环前置及前置链内部互斥须在编辑和保存时拦截。

保存三页的节点、坐标、关系及相对正式卡表的变更。现有卡使用正式 ID，新卡先作为草稿设计，后续根据保存内容接入 Excel、公共文本、游戏卡池与效果。

## 验收

- [x] 三个席位读取当前正式卡表，空中页可从空白开始设计。
- [x] 点击看说明，支持移动、增删、编辑、拖线与撤销。
- [x] 草稿写入文件，重新打开恢复内容及布局。
- [x] 保存包含新增、删除和修改清单，校验拒绝无效关系。
- [ ] 用户调整实际卡牌设计并确认接入范围。
