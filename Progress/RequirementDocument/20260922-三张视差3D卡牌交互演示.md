# 三张视差3D卡牌交互演示

## 背景与目标

以真实三维卡牌承载现有视差材质，HUD 仅负责提示和重播。动画、交互流程使用蓝图与材质，不接入奖励、战斗和联网。用户后续明确允许增加一个最小 C++ 窗口焦点接口，并授权编译 `GuLiStrikeEditor`，用于补齐 Windows 失焦检测。

资源来源为 `/Game/Assets/card/ParallaxCardMaterial` 和 `/Game/Assets/card/RewardCards`，商城资源只作为引用来源。功能资产集中于 `/Game/GuLiStrike/Cards/RevealDemo`。

## 确定行为

| 阶段 | 行为 |
|---|---|
| 入场 | Moon、Star、Tower 正面依次从屏幕中央远处飞来，各耗时 0.5 秒，总计 1.5 秒，缓出落位。 |
| 布局 | 中心横坐标约 20%、50%、80%，纵坐标 50%；同高竖直、平行，保留比例，高度约屏高 50%，宽度不超过屏宽 24%。 |
| 悬停 | 全部入场后开放；中心固定，鼠标所在侧向屏内压，各轴最大 ±12°，中心偏转趋零，离开或失焦平滑回正。无前移和漂浮。 |
| 首次点击 | 立即锁定，其他牌回正且不能改选；原地绕竖直轴 0.45 秒翻转 180°，显示统一 RewardCards 卡背。翻转中忽略点击。 |
| 等待确认 | 仅选中牌可悬停和接受翻转结束后的新一次按下；空白和其他牌无动作。 |
| 再次点击 | 关闭交互；所选牌中心局部白金闪光 0.25 秒，快速亮起、轻微扩散、平滑消退。 |
| 退场 | 闪光结束后三张同时用 0.5 秒回到中央远处并缩小消失；保持当前正背面。 |
| 完成 | 清理卡牌与闪光；发出一次完成事件；显示“重新播放”，重播恢复三张正面。 |

## 实现约束

2026-09-22 用户追加“鼠标给卡牌的力度再大50%”：最大偏转从每轴 ±8° 调为 ±12°，回正速度保持不变。

- 独立地图 `/Game/GuLiStrike/Cards/RevealDemo/Maps/LVL_CardRevealDemo`，深灰背景，专用透视相机，固定曝光。
- 位置根 → 悬停节点 → 翻面节点 → 牌面、文字、框和装饰组件，中心枢轴。
- 稳定命中坐标不随悬停倾斜变化，避免边缘抖动。
- 独立 GameMode、PlayerController、Enhanced Input 左键动作，不加载指挥官 HUD 和战斗输入。
- 管理器提供 `StartPresentation()` 与 `OnPresentationFinished(SelectedIndex)`；左、中、右对应 0、1、2。
- 时长、悬停角度和闪光参数在编辑器中可调，提示不截获卡牌点击。

## 验收标准

- [ ] 三张正面牌按 0.5 / 1.0 / 1.5 秒顺序落位，16:9、16:10、21:9 比例与间距合理。
- [ ] 悬停中心、四边、四角方向正确，牌心不移动，离开和窗口失焦回正。
- [ ] 分别选择 0、1、2，检查翻面、锁定、防连点、新按下确认。
- [ ] 局部闪光的起始、峰值、消散可见且无全屏闪白。
- [ ] 三张同时退场，无残留与重复完成事件；重播完整复位。
- [x] 蓝图编译、连接、材质参数、引用和保存地图实体配置检查完成。
- [x] 运行验证、闪光视觉预览、用户最终视觉验收分别记录，静态通过不等于效果已验收。

运行检查和截图已交付，以上交互条目保留为玩家验收清单；Windows 失焦检测已按追加授权接入原生接口，详见开发文档。
