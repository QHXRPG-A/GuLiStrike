# 游戏内 GM 分页浮层面板

## 背景与目标

项目已有全局运行时调参、军队技能、单兵工具、指挥官导航与相机诊断等 `gs.GM.*` 命令，但操作仍依赖控制台和 Output Log。本需求将它们收敛为游戏视口内的可视化工具，便于 PIE 与 Development 运行中调参、查询和诊断。

## 需求描述

- 仅在非 Shipping 构建中注册，`F10` 呼出/关闭，打开时 `Esc` 关闭。
- 面板固定在视口右侧，默认约占宽 42%、高 84%，不显示全屏遮罩；列表过滤后每页 10 条。
- 打开后世界继续运行，但本地玩法输入被阻断；关闭后按指挥官/地面/空中角色恢复原输入和光标状态。
- 覆盖 `gs.GM.List/Get/Set/Reset`、`gs.GM.Skill.*` 的交互式功能，以及 `gs.GM.Commander.Nav.*` 和 `gs.GM.Commander.Camera.Debug`；排除 `gs.GM.Skill.QA` 等自动化 Gate。
- 保留现有权限：Standalone/Listen Host 可修改，普通客户端不发送新 GM RPC，仅展示已有复制事实或明确的不可用原因。
- 结果区显示成功、失败、Pending、影响数量和详情，同时保留 UE 日志。
- `Reset All` 与 10000 人 Bench 需 5 秒内二次确认；其他诊断仅手动刷新。

## 边界

- 不增加 RPC、复制字段、存档、配置持久化、Blueprint API 或自由命令终端。
- 不更改现有控制台命令名、参数、数值限制、World 生命期或技能 GAS 提交路径。
- 面板不可拖拽或缩放，不暂停 Standalone 世界。

## 验收标准

- [ ] PIE 和 Development Game 中可用 F10/Esc 重复呼出关闭，无重复实例、残留委托或输入卡死（纯策略自动化已通过，人工 PIE 待补）。
- [ ] 1280×720、1920×1080 和超宽屏下面板保持右侧安全布局，不占满视口，所有列表每页最多 10 条。
- [x] 运行时调参、技能覆盖/来源/替换/移除、单兵查询/生成/Bench、导航与相机诊断均有类型化表单入口。
- [ ] Listen Host 可执行权威操作；客户端修改按钮禁用并说明未复制数据，无新增 GM 网络请求。
- [x] 原有命令和 RuntimeTuning/Skills/Commander UI/Input 回归通过。
- [x] 源码版 UE5.7 的 `GuLiStrikeEditor Win64 Development` 和 `GuLiStrike Win64 Development` 构建通过，BuildId 一致。

## 当前验证边界
