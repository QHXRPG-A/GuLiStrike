# Hybrid状态应用耗时优化

## 背景与目标

用户要求“优化Hybrid 状态应用，目标减少30%耗时”。基线为 2026-11-06 已编译交付的弹丸优化版本，三轮交火采样合计 1147 帧，状态应用平均约 2.918 ms/帧，P95 约 10.678 ms。需在同场景补采当前机器基线并保留旧数据。

## 需求描述与边界

优化主线程有序交付、对象模拟、单位共享系统及相应重复查询和拷贝。保持逻辑步频、碰撞与伤害判定、任务顺序、对象完整身份、权限交接和现有表现合同。不得通过更改计时分类、降低单位或弹丸数量、跳过模拟、修改画质或延迟业务生效达标。

## 验收标准

- [x] 固定源码版 UE5.7、GuLiStrikeEditor Win64 Development、地图 `/Game/Maps/LVL_CommanderMassPrototype`、指挥官相机及配置，前后各三轮 5 秒交火采样。
- [x] 保持现有 `state_apply` 三类 Scope 的包含子调用并集口径，合并完整帧平均耗时下降至少 30%。同时报告 P95、P99、峰值、总帧时、每秒及每逻辑批次成本。
- [x] 核对逻辑时钟、活跃单位、弹丸碰撞与命中量、网络错误，确认负载可比且未以减慢或遗漏业务换取结果。
- [x] 正式代码通过静态检查和获准构建，新二进制已加载，相关场景已保存并读回配置。
- [x] 记录技术验证与用户视觉验收的边界，视觉核验由用户进行。

技术验收结果：蓝方视角基线2.979091 ms/帧，新版2.055180 ms/帧，下降31.013%；每逻辑步下降23.949%，整帧间隔下降9.487%。以上复选项表示对应技术证据及视觉验收边界已记录，不表示玩家已确认效果。
