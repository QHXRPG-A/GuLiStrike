# 指挥官脚环优化与兵种面板

- 类型：UI、表现层性能
- 日期：2026-08-30
- 状态：已确认；2026-08-31 实施与验收记录已归档。

## 背景

用户指出性能优化后，复杂度视图中的士兵脚下仍有红色圆盘，并要求按截图调整底部指挥 UI。此前优化了兵模，按旧需求保留脚环常显；现有脚环使用压扁圆柱和半透明双面、关闭深度测试的圆形遮罩材质，仍提交被透明遮罩隐藏的圆盘与重复表面。

本需求以用户最终确认的实施方案为准。截图用于布局与形状参考；2026-08-30 补充明确：血量仅统计存活士兵，阵亡必须减人数，不降低其他满血存活者的血条。

## 需求描述

- 脚环改为 64 段、128 三角形的真正中空单面平面环，按旧遮罩内外半径保留尺寸。简化材质，保留实例颜色、透明度、发光和穿透遮挡行为。
- 脚环继续常显，未选为阵营色、选中为金色、阵亡为暗红并保留 5 秒。不增加逐兵地面检测。
- “编队”“指令矩阵”只用中文，置于左侧垂直、右侧 45° 斜切、上长下短的标题底板；保留底坞尺寸、配色和响应式缩放，移除双斜线与静态审核水印。
- 左区合为一张横向“士兵”卡，不显示控制组编号、不按 25 人拆卡；显示选中存活数、真实血量、命令状态，混合执行结果汇总呈现。
- Soldier ID 去重后，以存活者当前生命之和 / 存活者最大生命之和绘制血条。阵亡同时退出人数、分子和分母；无存活选择时收起，可靠状态未就绪时显示“同步中”。
- 移除“框 80m”按钮、图标、文字和点击绑定，该格恢复普通空槽。保留小键盘 `+`、主键区 `Shift+=` 在选取模式循环 `80→200→450→80m`；移动模式无响应，UI 点击后仍可用。

## 边界

不新增真实兵种，不改变底层 25 人控制组、选择/移动协议、网络协议、顶部战况条或小地图，不扩展未实现命令。不新增逐帧状态扫描或逐兵 Widget。复用事件通知和现有防点击穿透、输入焦点、析构解绑机制。

## 验收标准

- [x] 多个控制组只显示一张“士兵”卡。
- [x] 25 名满血兵阵亡 5 名后显示 20 人，血条 100%；受伤和不同最大生命按总量计算。
- [x] 全灭、清空、重新选择、换局无残留；缺状态显示同步中。
- [x] 两种加号和移动模式门控保留，移除按钮后 UI 输入阻挡不变。
- [x] 检查 1280×720、1920×1080、2560×1080 的标题、排版和输入阻挡。
- [x] 固定 500 兵、画质与机位，对比近景和远景正常画面、复杂度视图与 GPU 耗时，证明脚环成本下降且整体不回退；不要求热图全绿。
- [x] 保存对比证据、构建与测试结果，更新开发文档、归档、玩法记录和索引。

性能结论限定于本次固定场景：典型成本下降，未观察到稳定整体回退；不宣称所有尾部尖峰消除。18 份 CSV、补充 Busy 采样及首轮远景 p95 异常均保留在[验收归档](D:/UE5.7/test1/Progress/Archive/20260831-指挥官脚环优化与兵种面板.md)。
