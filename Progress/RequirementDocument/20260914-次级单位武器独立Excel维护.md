# 次级单位武器独立Excel维护

## 背景与目标

配置原先分散于 Commander、Ship、SpellFields 三个工作簿，以及 WM01 和旧版僚机武器 DataAsset。武器参数统一维护于 `Data/Excel/GuLiStrikeSecondaryWeapons.xlsx`；按2026-09-14用户补充要求，所有法术场/AOE统一维护于 `Data/Excel/GuLiStrikeSpellFields.xlsx / Fields`。

## 需求描述

- 指挥官地面兵种武器技能、槽位、伤害、频率、射程与枪口配置集中维护。
- 僚机对空、对地及仍被授予的基础枪、齐射导弹全部纳入；索敌参数一并迁移。
- 武器爆炸伤害、范围、时序与其他法术场集中到SpellFields；移除次级武器表的WeaponFields工作表。
- 地面武器Skills和僚机WingmanWeapons使用“产生的法术场”列引用Fields.id，避免在武器表重复填写AOE数值。
- WM01 实体导弹速度、抬升、追踪和寿命参数从 Excel 读取，并自动绑定资源。
- 旧工作簿移除相应武器源数据；生成物记录真实源文件，防止双份维护。

## 边界

玩家主单位、兵种生命/移动属性、编队飞行导航、传送及纯美术表现仍归各自系统。原有即时命中/实体弹道语义和数值保持；原生临时测试对象可保留明确的内联后备值。

## 验收标准

- [x] 新 Excel 覆盖全部已挂载的次级单位武器，无遗留资产独占武器数值。
- [x] 导出和导入后，UE 原生解析值与表格一致。
- [x] 已有资产、技能槽和全局法术场引用可继续解析。
- [x] 全局法术场只有SpellFields一个Excel维护入口，已有2条爆炸与4条传送配置的ID和数值保持。
- [x] 武器填写数字法术场ID，导出自动解析；无效引用不产生更新后的生成物。
- [ ] Editor/Game 源码版构建和相关既有回归测试通过。

构建通过；24项既有回归20项通过、4项失败。详见开发记录与增量归档，不将部分回归结果标记为全量通过。

本次法术场归并补充验证：源码Editor/Game构建通过，7表26行导入及原生回读通过，3项直接相关的既有自动化通过。未修改或新增测试，未重跑前次4项失败用例。
