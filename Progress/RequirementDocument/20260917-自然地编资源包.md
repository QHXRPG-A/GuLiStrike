# GuLiStrike 自然地编资源包

## 目标与已确认决定

用户提供一张草地组合图和一张自然资产陈列图，要求先制作资源并保持项目风格。规划中明确选择“图二整套基础包”“植被无线稿”“整体放大十倍”“包含轻微风摆”“源文件加UE资源样板”；随后明确要求实施整份计划。

实施中用户追加“草的面数普遍偏高”“花朵的面数看着也挺高”，随后明确“这些都是植被，用UE5植被常用的制作方法制作”。当前改为v3：图集＋紧裁/弯折卡片＋Masked双面＋实例化，不逐根草叶、逐片花瓣/蕨小叶堆几何。LOD0预算：草簇6–24、单花8、紫花穗12–20、蕨20–36、花毯16三角面。见[v3制作规范](../../ArtSource/Environment/NaturePack_20260917/Review/FoliageCards_v3.md)；预算不是实测或性能结论。旧v2图保留外形和色彩作用，图内旧面数与逐瓣几何方法已失效。

采用Ship的干净色块和三档明暗，植被保持自然绿系，花色局部点缀，岩石灰紫色。此包植被不制作内部线稿及外轮廓，岩石保留细轮廓与少量主要折线，作为专属例外记录于[美术规范](GuLiStrike美术规范.md)。

## 资源范围

| 分类 | 数量 | 内容 |
|---|---:|---|
| 草丛 | 13 | 高草3、4种短草剪影各2疏密、干草2 |
| 阔叶与蕨类 | 7 | 单枝、分枝、三叶丛、小蕨、大蕨、大阔叶丛、小莲座 |
| 穗类 | 2 | 金黄麦穗、绿色穗草 |
| 花卉 | 6 | 白、黄、红、两种紫花穗、粉花 |
| 地被 | 4 | 阔叶、三叶草、白花毯、蓝花毯 |
| 岩石 | 2 | 高立岩、低矮宽岩 |

34款摆放资源对应33个独立网格，蓝花毯复用白花毯网格、UV和花朵位置，仅改变花瓣材质。完整编号、设计尺寸及形态约束见[资源规格](../../ArtSource/Environment/NaturePack_20260917/asset_manifest.json)和[制作入口](../../ArtSource/Environment/NaturePack_20260917/README.md)。

十倍尺寸烘入模型，UE导入和默认实例Scale1。独立草花约高2–10米，阔叶约高4–15米；地被为更低矮组块；岩石主尺寸5–30米。

## 材质、动态及交付

- 植被采用透明遮罩图集、紧裁卡片和必要弯折；Masked＋双面、共享图集和母材质，每网格1材质槽；LOD0/1/2与Static Mesh Foliage实例化摆放。大阔叶仍保留必要的体积与剪影。
- 风摆由UE材质WPO实现，顶点Alpha根0尖1；默认最大位移高度的2.5%，周期3–5秒，各实例错相，WindStrength=0完全关闭。
- 公开颜色、风向、风速、风强度、美术光方向参数；岩石另有线强度/轮廓宽度参数。
- 使用Ship既有三档ArtLightDirection美术光路线，表面明暗不自动采样场景灯光/阴影；在独立样板中对齐太阳。
- 植被无碰撞、无导航影响；岩石简单凸碰撞，轮廓不碰撞、不投影。
- 交付可编辑Blender、FBX、纹理、UE静态网格/材质/FoliageType、编号陈列和草地组合样板。
- 正式地图铺设、玩法逻辑、PCG生产系统不在本批范围。

## 审核与验收

- [ ] A：全套编号设计板与分组正/侧/背参考，明确十倍尺度、三档色阶、植物无线稿。
- [ ] B：先制作六件代表模型，再扩全套；提交真实Blender渲染、三视角及同角度参考对照，经用户明确通过。
- [ ] 读回34款摆放资源、33网格、尺寸、原点、法线、材质槽和LOD；FBX与UE一致。
- [ ] 草簇、整朵花冠、蕨羽叶按v3图集/面片方法制作；逐LOD读回三角数、UV与根权重，检查透明重叠、边缘扩色和mip闪烁，不用面数代替GPU验证。
- [ ] UE提供近景、俯视、200/800/1800米镜头臂长、俯角55°、FOV45°的截图。
- [ ] 风摆视频显示固定根部、实例相位差、关闭风摆及LOD切换。
- [ ] 固定密度样板记录实例、三角面、绘制调用及GPU耗时；性能结论仅限该样板。

审核A、B、UE技术和性能分别记录，参考图不可冒充三维或引擎截图。依据[美术规范](GuLiStrike美术规范.md)保留双审；已通过的版本不重复要求批准。
