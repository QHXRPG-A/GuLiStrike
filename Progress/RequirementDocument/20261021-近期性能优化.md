# 近期性能优化 — 需求汇总

范围为用户确认的 **2026-10-18 至 2026-10-21**：Hybrid、Slate/UI、四档LOD、帧采集工具、交火CPU和本机指令响应，以及本轮暴露的扫荡者姿态与导航恢复问题。

本页维护当前需求；[开发汇总](../DevelopmentDocumentation/20261021-近期性能优化.md)维护实现和下一步；[整合归档](../Archive/20261021-近期性能优化整合归档.md)保留历史结论及原文索引。7份需求原文及原始元数据完整保存于[原文ZIP](../Archive/20261021-近期优化原文.zip)，稳定ID保留在文末。

## 当前目标与验收口径

**优先推进本机Mass指令响应：30ms为上限，向20ms优化，且最终性能不退化。** 从同一指令入口到全部受令成员真正起步、模型实例提交计时，绿线在输入当前帧提交，不等待规划或回执。响应达标后再做固定负载配对性能复核，迭代中只进行必要的分段诊断。

- 总响应取全部成员最晚的模型提交，不能只报最快成员或首个成员；绿线、权威位移、模型提交均为同一起点的累计值，不能相加。
- 保留1cm与原2cm实际位移观察值，门槛调整不是运行收益。语义输入探针不等于操作系统鼠标到显示器扫描输出；程序提交、最终呈现和玩家感受分别记录。
- 稳定持有本机模拟权的单位不增加网络往返容差。本机CPU队列等待与远端RTT分别归因；所有权交接另列证据。
- 保留完整身份/代次、FIFO、可靠回执、取消/失败清理、合法位置与伤害结算。最高优先级插队仍待用户判断，当前继续消除原顺序中的重复工作。

## 各项需求及剩余边界

| 范围 | 当前合同 | 尚待完成 |
|---|---|---|
| Hybrid世界更新 | 渲染客户端完整主线程工作平均≤5ms；包含世界推进、状态应用、回执及外层收发，嵌套区间去重；P95和队列不恶化 | 5ms目标未达成。旧100ms备用快照构建的8.12ms不能作为当前5秒构建的成绩 |
| Slate布局与绘制 | 游戏客户端完整UI平均<2.5ms，覆盖Prepass、Paint、失效及相关公共工作；完整PIE另报 | 历史静止单对客户端上限1.5843ms不能代替动态UI、移动、交火和俯瞰覆盖；未单独验收的项目保持未验证 |
| UI与四档LOD | 保持外观、绘制顺序、交互及动态内容；共享顶点/缓存与网格策略可独立回退；全局失效保持0 | 用户已要求停止该专项检查，不自动恢复三轮UI/LOD/GPU验收；视觉由玩家核验 |
| 常规帧时间 | 历史同负载600单位、32建筑下，25.929ms降至13.567/13.586ms，P95约19.3ms | 该场景平均15ms目标已有证据，玩家效果待确认；不能移作当前交火响应或其他负载的达标证据 |
| 一键采集工具 | 编辑器自动加载GuLiFrameProfiler；Alt+/或Tools菜单先采CPU 5秒，再单次截当前视口并后台分析 | 玩家确认PIE焦点、文本框和弹窗行为；有Trace占用不接管、无RenderDoc仍生成CPU报告、中断保留不完整证据 |
| 扫荡者与导航恢复 | 新生远端扫荡者收到并应用实际姿态；同址有效导航面可恢复引用，实际搬移仍遵守碰撞及动态障碍 | 编译和结构化功能结果已有证据，玩家核验被攻击、受击及斜坡移动观感；不计为性能验收 |

**范围演进：** 15ms是早期整帧预算，严格20ms是此前响应口径；当前以本页20–30ms要求为准。已取消18窗口、45分钟长测及新增PIE故障矩阵；已完成的历史长测保留为事实。资源异常边界沿用生产核心离线证据，不补称断网PIE通过。

## 四档运行定义

按相机**目标高度**划分，覆盖兵种、建筑、玩家地面机甲与飞船及装配、受击、施工、残骸副本；三种相机模式和MeshLOD资源索引单独表达。

| 运行档位 | 条件 | 网格/表现 |
|---|---|---|
| LOD0 | 35≤高度<100m | 自动网格选档、全量表现、保留模型描边 |
| LOD1 | 100≤高度<300m | 最高精度限制为MeshLOD1，允许更粗自动档；全量表现、去掉模型描边 |
| LOD2 | 300–700m | MeshLOD1精度上限、战术表现、去掉模型描边 |
| LOD3 | 总览模式 | 图标、模型隐藏与总览特效策略 |

特效资源质量依次映射Full / Full / Reduced / Minimal。缺少MeshLOD1保留原网格，Nanite维持现有机制；不生成新减面资源。模型结构线、选择圈、血条和操作指示保持。退出指挥官、关闭策略或注销时恢复组件设置；同World多视图满足最高精度需求，不同World隔离。

## 负载、行为与测量约束

- 保持同机两个客户端和一个Coordinator、本地模拟归属、60Hz逻辑步及顺序、伤害、人口/弹丸、画质与相机。常规资源备用快照周期为5秒，首次副本与退出最终采集即时；5秒不是最大回退保证。
- 地面Mass摧毁爆炸线性尺寸缩为此前1/3属于用户明确要求的表现变更；后续配对两边均使用该尺寸，不能计作纯CPU收益。其他爆炸时长和伤害保持。
- 使用`/Game/Maps/LVL_CommanderMassPrototype`。交火正式配对为2359×1748预览前台、编辑器主窗口最小化，原生逐帧确认窗口条件；同构建、相同镜头/质量/准备，三轮交替A/B，各热身10秒、采样30秒，报告均值和合并原始帧重算的P95。
- 负载按SimulationOwner、HasSimulation、存活状态区分本机/对端/休眠对象；全场总数、阵营或显示实例不能替代本地模拟数量。高负载Hybrid合同至少为unit/1=165、unit/2=135、unit/5=365、unit/3与unit/4各16、territory/7=49、building/4与5各34、building/6=36，并匹配采矿、生产、交火与历史目录规模。
- Trace诊断与正常性能测量分开，嵌套计时取并集，跨线程与GPU重叠区间不相加；计时窗口不做截图或对象枚举。助手不读图，技术检查不能替代玩家验收。
- 扫荡者UnitTypeId=5、先驱号=1、重防号WM01=2；玩家Ground地面机甲使用独立路径。
