# 指挥官与地面战争机器最小建造系统

- 验收结论：实现、三组定向自动化与最小双客户端复制验证完成；现场问题修复已通过 Live Coding 与原三组测试，修复后的可见交互仍待人工复验

## 背景

基地建造探索已确定“轻量主基地＋前哨、控制区内自由摆放、工程单位施工、团队资源和当地容量”等长期方向，但尚无可操作的建造闭环。首个可玩切片先让指挥官和地面战争机器直接放置三种无功能建筑，以验证选址、体量、实体阻挡与多人权威链路；士兵运行时阻挡/绕行、经济、施工和作战能力留到后续版本。

## 需求描述

- Commander 与 Ground 玩家按 `B` 进入或退出建造模式；首次进入默认选择建筑 1，之后记住上次选择。
- 建造模式内按 `1/2/3` 选择防空炮、哨戒炮、据点方块；LMB 放置并保持连续建造，RMB、Esc 或 B 退出。
- 建造模式外保留 Commander 既有 `1=移动工具` 与 RMB 移动行为。
- Commander 使用鼠标指向的合法地面；Ground 使用屏幕中心射线，必须在 Pawn 100 米内且有视线。
- 本地显示合法绿色、非法红色的半透明预览；服务器重新验证并权威生成，所有客户端看到同一结果。
- 建筑保持直立，自动取当前视角水平朝向，立即完成、无资源消耗。
- 坡度上限 15°；建筑不得与世界物体、Pawn、其他建筑或存活的 Commander Mass 士兵重叠，并在放置检测中保留 100cm 水平间距。
- 三种建筑合计每位建造者最多 6 个、每局最多 24 个。建筑实体 Box 阻挡具有物理碰撞的角色；本阶段不把建筑注册为 Commander Soldier 动态导航禁行区。
- 原生 HUD 显示约 2 秒的选择、成功与拒绝原因提示，不修改冻结中的 `WBP_CommanderHUD`。
- 建筑只存在于当前 Match/World；建造者离线后保留，并继续按稳定 `PlayerGuid` 计数。

### 建筑资产

- 建筑 1：以 `/Game/Fab/Missile_Turret` 的 `missile_turret` 为源，在规范副本上烘焙 12 倍 BuildScale，资产启用 Nanite 并保留 32 个材质槽；因其中玻璃槽为半透明，预览和已放置组件使用 fallback 表示，避免 Nanite 持续刷警告。
- 建筑 2：以 `/Game/Fab/Stylized_Turrets_-_Tower_Defense` 的绿色/金色 `Stylized_Turrets_A_a` 为源，在规范副本上烘焙 12 倍；保持非 Nanite，并把复制材质实例的 `DiffuseColorMap` 绑定到复制后的 `Stylized_Turrets_A` 纹理。
- 建筑 3：新建 20m × 20m × 20m 灰色据点占位方块。
- `/Game/Fab` 原件保持不变；外部资产规范副本位于 `/Game/Assets/Props/Buildings`，玩法目录和预览材质位于 `/Game/GuLiStrike/Buildings`。

## 边界

- 不实现经济、资源、工程兵、施工时间、攻击、防空逻辑、占领、血量、伤害、拆除、撤销、存档、领土限制或手动旋转。
- 不修改关卡、不修改 Commander WBP、不新增 UE 模块或第三方依赖。
- 不把 Commander 可放置范围解释为长期“己方控制区”；MVP 尚无领土系统，只验证合法地面。
- 本阶段不实现 Mass Soldier 与建筑/Ground Pawn 的硬碰撞，也不实现建筑触发的士兵局部绕路。建筑仍保留对普通物理 Pawn 的 Box 阻挡，建造校验仍禁止直接压住存活士兵。
- 测试仅限用户批准的 `BuildingPlacementPolicyTests`、`BuildingWorldTests`、`BuildingAssetTests` 三组。任何第四组、相邻系统全量回归、更多客户端、性能耐久、Cook 或打包测试均须先说明原因并再次确认。

## 验收标准

- [ ] Commander 与 Ground 的 B → 1/2/3 → 预览 → LMB 连续放置 → 退出键盘闭环已实现，但尚未在可见交互 PIE 中人工验收；Air/Observer 的客户端与服务器拒绝规则已自动化验证。
- [x] 模式外 Commander 的 `1=移动工具` 路由保留，`2/3` 不触发建造；RMB 原移动分支未被建造模式外逻辑替换。策略测试和源码检查通过。
- [x] 服务器规则覆盖未就绪、角色、资源、有限数值、地面、坡度、Ground 距离/视线、重叠、请求去重、频率及 6/24 上限；自动化确认拒绝不增加建筑数量。
- [ ] 本地合法绿色/非法红色预览及约 2 秒 Canvas 提示已实现，尚未在非 NullRHI 的可见画面中人工验收。
- [x] 成功请求只生成一个复制建筑；最小 Dedicated Server + 2 Client PIE 中三端均出现同一座 Outpost，类型、阵营、建造者 GUID、Scale 1 与 Box 碰撞合同一致。
- [x] 现场确认旧实现会在建造后让所有活动士兵短暂停顿，原因是 Commander 导航重建回调无差别冻结并修复全部活动编队；按本阶段边界关闭建筑的导航相关性，原三组测试确认组件合同，修复后“建造不再触发全局停顿”仍待可见 PIE 复验。
- [x] 防空炮与哨戒炮规范副本的全部 Source LOD 为 BuildScale 12 且运行时合同为 Scale 1；资产 Nanite、32 个有效材质槽、A_a 纹理修复和 20m 方块合同均由资产测试确认。防空炮运行时组件因半透明玻璃槽明确禁用 Nanite 路径。
- [x] 退出、角色变化、失去就绪、Pawn 替换与 EndPlay 的预览清理路径以及 HUD 委托解绑已实现；本轮未修改 Commander WBP 或关卡。
- [x] 仅运行获准的 `BuildingPlacementPolicyTests`、`BuildingWorldTests`、`BuildingAssetTests`；现场修复后 3/3 成功，未新增测试组或扩大矩阵，双端最小 PIE 结果已如实归档。
