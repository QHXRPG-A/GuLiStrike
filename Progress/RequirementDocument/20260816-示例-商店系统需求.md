# 示例-商店系统需求

- 类型：gameplay（含 UI）
- 日期：2026-08-16
- 状态：草案（**示例文档**，用于演示格式，非真实需求）

## 背景

玩家在关卡中获得的货币缺少消耗出口，核心循环缺少"资源投入 → 变强"的环节。需要一个商店提供局内成长感。

## 需求描述

1. 击败敌人掉落货币，自动拾取并累计到 HUD
2. 关卡固定位置有商店交互点（靠近提示，按键打开）
3. 商店 UI 提供 ≥6 个可购买项（含：回复、永久属性提升、技能强化）
4. 购买后立即生效并有反馈（音效+数值变化）

## 边界

- 不做局外永久解锁（meta 进度）——留待后续版本
- 不做多货币；不做打折/刷新机制

## 验收标准

- [ ] PIE 中击杀 3 个敌人后货币数正确显示于 HUD
- [ ] 购买"永久属性提升"后，重新进入关卡仍生效（单局内持久）
- [ ] 货币不足时购买按钮置灰且点击无效果
