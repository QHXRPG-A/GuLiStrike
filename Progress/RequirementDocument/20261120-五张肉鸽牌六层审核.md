# 五张肉鸽牌六层审核

本批 HTML 制作已完成。五张用户原图分别对应一张牌，图层从外到里按下表排列。每个物件连同遮挡区和运动所需外沿一起制作，页面支持逐层独看、原图对照和极限位移。

| 牌面 | 从最前层到背景 |
| --- | --- |
| 电磁技术 | 平台、主体球、左浮石、右浮石、两侧机械臂、实验室背景 |
| 分裂枪管 | 左上发光片、枪体、右下发光片、环境发光体 A、环境发光体 B、背景 |
| 人工智能引擎 | 左下近景触手、右上伸入球心的触手、球、顶部拱形触手、后方回弯触手、背景 |
| 增强AOE | 前景地面、底部冲击波、爆心与动态模糊线、蓝焰、紫焰、背景 |
| 恶魔引擎 | 前景雾、右侧小魔、左侧大魔、左侧远景灵魂群、右侧远景灵魂群、背景 |

最后一轮反馈要求去除《增强AOE》白色爆心的细横线，并参照《恶魔引擎》原图增加雾里的灵魂。交付版保留底部冲击波，左右两组灵魂各有四只。[制作与核验记录](../DevelopmentDocumentation/20261120-五张肉鸽牌六层审核.md)
