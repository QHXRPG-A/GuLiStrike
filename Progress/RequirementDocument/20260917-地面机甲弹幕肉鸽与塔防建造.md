# 地面机甲弹幕肉鸽与塔防建造

## 背景与目标

用户定稿原意：“玩家单独控制一个高成长高机动性机甲，经验升级+弹幕肉鸽+塔防建造，因此地面部队的子弹速度减慢”，并要求查明当前子弹速度。

地面玩家的主要操作对象为一台机甲，核心体验是机动战斗、经验成长、局内构筑和防御建设。“单独控制一个”定义直接操控对象数量，不据此改写既有多人战局与角色席位。

## 已确认需求

- 玩家直接控制一台高成长、高机动性的机甲。
- 地面玩法包含经验获取与升级、弹幕肉鸽和塔防建造，作为同一角色体验的组成部分。
- 地面部队降低子弹速度，为玩家观察弹幕、移动和躲避提供空间；本期限定扫荡者（FourFRobot / SoldierA）和WM01两种地面部队的正式机枪 `Strafe`。

## 初始基线（实施前）

以下为2026-09-17首次核对的历史基线；正式Strafe后续以本页“本期定稿参数”为准。

| 武器 | 当前行为 / 数值 | 证据 |
|---|---|---|
| 扫荡者（FourFRobot / SoldierA）与WM01机枪 | `DirectSingleTarget`直接结算伤害，没有子弹飞行速度 | `GuLiStrikeSecondaryWeapons.xlsx / Skills`的Strafe行；[导出技能表](../../Data/Json/DT_GuLiStrikeCommander_Skills.json)；[ExecuteDirect实现](../../Source/GuLiStrike/Gameplay/CombatEffects/GuLiCombatEffectRuntimeSubsystem.cpp) |
| 地面机枪弹道表现 | C++默认显示0.075秒，整段枪口至目标的瞬时光迹；该时长不是飞行时间 | [表现默认配置](../../Source/GuLiStrike/Gameplay/CombatEffects/GuLiCombatEffectDefinition.h)与[端点表现实现](../../Source/GuLiStrike/Gameplay/CombatEffects/GuLiCombatEffectPresentationSubsystem.cpp) |
| WM01追踪导弹 | `6000 cm/s = 60 m/s`；配置最长寿命8秒 | `GuLiStrikeSecondaryWeapons.xlsx / Projectiles`的WM01_Missile行，速度位于E4；[导出弹体表](../../Data/Json/DT_GuLiStrikeSecondaryWeapons_Projectiles.json) |

WM01导弹的[原生解析器](../../Source/GuLiStrike/Gameplay/CombatEffects/GuLiCombatEffectDefinition.cpp)从绑定的MotionProfileRow读取速度；未绑定表行时才使用资产内联值。本次编辑器Python桥连接被拒绝，未回读当前编辑器资产的绑定和临时覆盖，故以上是源配置与代码基线，不宣称是当前PIE实例的实测速度。

**初始实现推论：** 若机枪需要成为可躲避弹幕，必须让伤害随弹丸飞行并在真实命中后结算。只延长0.075秒光迹或让视觉子弹变慢，仍会在开火时直接扣血，不能满足走位躲弹目标。本期已据此接入公共弹丸池，实施和验证结果见关联开发文档。

## 本期定稿参数

| 项目 | 确定值 |
|---|---|
| 弹速 / 最长寿命 | 120m/s / 5s，无碰撞最多600m |
| 开火射程 | 保留100m / 150m，已发射子弹不按开火射程截短 |
| 射速 / 伤害 | 保留2发/s、10伤害 / 4发/s、7.5伤害及现有修饰规则 |
| 服务端模拟 | **5Hz**，200ms完整线段连续扫掠；僚机继续30Hz |
| 存活状态同步 | 独立5Hz、自包含批量快照；从原公共1Hz快照排除 |
| 发射 / 命中 / 结束 | 及时可靠批量事件；客户端连续推算，服务器独占碰撞和伤害 |
| 碰撞半径 | 初值15cm，与18m视觉长度独立 |

- 朝发射时目标位置直线飞行，无重力、追踪、提前量和散射；穿过友军且无友伤，遇第一个敌方受伤目标或场景障碍回收。
- 池化逻辑弹丸复用 `UGuLiProjectilePoolSubsystem`、空间筛选、回收与Damage Ledger；不迁移Mass、不生成逐弹Actor，不新增前排开火限制。
- 发射时冻结伤害、来源、速度与寿命；发射者死亡、目标死亡或出射程不删除已发射弹丸；换局清理。
- 弹速、寿命、碰撞半径由现有武器Excel的UnitSkills维护，进入最终技能配置与变更识别，依序导出、编译、导入和回读。`StrafeTest`保留原即时测试变体。
- 复用僚机对空Niagara、材质、光晕和批量呈现。地面长度独立倍率0.6（30m→18m），内芯宽保持0.5m、外围光晕比例与亮度不变；本地我方黄色 `(1,1,0)`、敌方原红色 `(1,0.025,0.015)`。僚机自身尺寸及绿/红配色不变。
- 弹迹头部对应弹丸位置，出生阶段长度不超过已飞行距离，命中沿用0.04秒消退；保留地面原枪口，移除正式Strafe旧瞬时全长光迹。
- 5Hz的代价：常规200ms步内120m/s子弹走24m，碰撞结算可能延后约0.2秒；扫掠覆盖整段路径，移动目标使用独立200ms历史近似。网络和卡顿延迟另计，客户端命中前可能短暂越过权威命中点。

## 边界与待细化

- 本期实施仅涉及上述两种地面机枪；WM01导弹与僚机武器参数、同步节奏沿用现有配置。
- 高机动的具体移速、加速度及机动能力，高成长的经验曲线、升级选择和构筑内容，仍需细化。高成长不自动表示选牌频率超过Ship。
- 塔防建筑种类、建造方式、资源成本与指挥官建造权限的分工尚未确定。
- 本期不将调整扩展到其他地面武器或玩家武器；完整机甲玩法尚未实现。

## 后续实施验收方向

- [ ] 地面玩家直接控制一台机甲，机动操作能够避开可见弹幕。
- [ ] 经验升级与肉鸽选择实际改变机甲的局内成长或战斗方式。
- [ ] 地面玩家能够建造塔防设施，并与机甲战斗形成可操作的配合。
- [ ] 应用慢弹速的武器以弹丸实际命中作为伤害时机，视觉位置与伤害判定一致。

这些条目描述未来可玩行为，不表示已执行验收。用户明确只运行现有指挥官开火、公共弹丸/伤害、僚机回归和既有数据回读，不新增或修改测试/验证脚本；完成源码UE5.7 Editor/Game Development与BuildId核对，专项未覆盖内容如实记录。
