# 指挥官武器特效与独立法术场

## 背景

FourFRobot、WM01 已使用 Mass 单位模拟和按兵种、武器槽划分的技能配置，但缺少实际开火表现。新增技能不得被 Mass 表示方式限制；AOE 需要统一的、服务器权威的结算入口。

## 需求描述

1. 两兵种的机枪使用真实枪口位置和瞬时完整弹道，约 0.06 秒淡出；保留原有机枪数值。
2. WM01 增加独立自动单发导弹槽：3 秒一发、30 伤害、150 米射程、8 米爆炸半径。初值仅用于调试。
3. 导弹从发射仓抬升后弧线追踪，带服务器种子控制的随机偏移。目标丢失后飞向最后有效位置；命中产生一次范围爆炸，超时/取消/换局不爆炸。
4. 复制现有 NS_Explosion_Medium_7/8/9 为三个项目变体，服务器等概率选定，各客户端播放同一变体。没有额外直接命中伤害。
5. 独立 C++ 内核、蓝图可配置/调用的通用法术场，支持即时、延时单次、持续周期三种时序；本次实际接入导弹爆炸。
6. 通过统一目标句柄及 Damage Ledger 支持 Mass 和 Actor。来源死亡不取消已创建效果，换局清理。客户端只重建表现，Dedicated Server 不创建特效组件。

## 边界

- 不新增 Mass 导弹/法术场实体，不给每名士兵建立 ASC，不迁移现有僚机、飞船武器或旧模板 AOE。
- 不增加炮塔/骨骼动画、具体燃烧技能、Fluids、Chaos 或动态特效灯。
- 商城资产只作为只读模板；只保存本次明确修改的项目资产，保留已有未提交修改。
- 用户已明确授权三处聚焦测试：新 CombatEffectRuntimeTests、现有 SoldierCombatTests、Scripts/validate_commander_combat_effects.py；仅 Listen+1 Client、Dedicated Server+2 Clients，最多现有 500 单位。

## 验收标准

- [ ] 机枪有校准枪口闪光和瞬时指向目标的弹道，现有射击数值不变。
- [ ] 导弹与机枪独立冷却；随机弧线、丢失目标和各终止原因符合约定。
- [ ] 三种法术场时序、敌我过滤、范围边界、重复事件和生命周期验证通过。
- [ ] 多客户端一致；后加入只重建未结束效果；专服无纯表现组件。
- [ ] Niagara 零编译错误、材质及引用回读通过，无 UE 占位纹理；开始/峰值/消散视觉证据齐全。
- [ ] 在获准 500 单位场景记录特效开关前后性能，检查 Bounds、池化和裁剪。
- [ ] 源码 UE5.7 Editor/Game Development 构建成功，项目及涉及插件 BuildId 与源码引擎一致。
