# 双矿单位矿模型 UE 导入

## 目标与范围

导入蓝矿、红矿各4家族，每家族Full、Partial、Remnant三态，共24个独立静态网格。目标目录为 `/Game/GuLiStrike/Resources/Ores`，分别组织蓝矿、红矿和材质。

源模型保留原始切面网格，晶体与岩基两材质槽，米制换算为UE厘米，地面枢轴一致。将 `OreColor` 与 `OreGlow` 转为UE可用的顶点色和材质输入，并保存可重复导出、导入的脚本与清单。导入时附带基础简单碰撞；不在本轮决定游戏交互规则。

## 验收

- UE中存在24个命名正确、按矿种分类、已保存的静态网格。
- 完整态保持8米高度和12米水平长边，三状态尺寸与面数对应源模型。
- 晶体/岩基两槽正确绑定材质，顶点色存在，保留局部发光。
- 引擎内确认蓝红模型显示，提供资源位置与导入记录。

## 边界

不接入矿量、分布、采矿状态选择、归零销毁或主地图布置。Full、Partial、Remnant是资源外观状态，不作为距离LOD。最终风格与游戏内性能仍以后续正式场景验收为准。
