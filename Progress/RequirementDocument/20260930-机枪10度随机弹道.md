# 机枪10度随机弹道

## 背景与目标

当前两种指挥官地面兵种机枪子弹方向没有随机性。每发在原始瞄准方向周围独立采样，三维圆锥总夹角10°，最大偏离5°，随后固定方向直线飞行。

## 需求描述与边界

- 仅扫荡者（UnitTypeId=1）及重防号（WM01 / UnitTypeId=2）的机枪应用10°散布。
- 碰撞、伤害、命中特效和随弹照明使用真实散布弹道；枪管机械姿态与枪口表现保持原瞄准方向。
- 新字段 `ProjectileSpreadAngleDegrees` 表示总夹角，默认0，允许有限的0～180°。技能配置变化比较包含此字段。
- 圆锥内按立体角均匀采样，以单发ShotId、对局MatchEpoch与枪口索引构造种子；相同输入可复现。
- 沿用现有方向同步，不修改网络消息格式。僚机、玩家地面机甲及导弹不进入本次散布入口；既有每客户端6灯预算保持。
- 源表采用工作区已经迁移后的 `GuLiStrikeSecondaryWeapons.xlsx/UnitSkills`，UE表和结构继续使用原Commander稳定标识。

## 验收标准

- [x] 静态核对服务器采样位置、方向归一化、±5°范围、0°恢复原方向及非目标武器排除。
- [x] 源码版 `GuLiStrikeEditor Win64 Development` 编译成功，新模块已加载，BuildId一致。
