# DIY 飞船（模块化装配 + 飞行中热切换）

- 类型：gameplay
- 日期：2026-08-20
- 状态：已确认

## 背景

玩家要驾驶一艘可自由 DIY 的飞船：随时更换飞船上的组件（引擎、武器等），换装不只是外观变化，还影响飞行性能与火力。舰体使用 CombatAvatarFly 包的 `bsg_virgon_express_carina` 整块网格（147m 级大型舰），可更换部件网格取自 `fly-01` 散件包（engines / lasers / rocket）。

装配模型由用户定稿：

1. **主体是一个 Character**（不是纯 Pawn）
2. **每个部件是一个组件（Component）**，部件即网格，具体部件用蓝图子类配置
3. 每个部件携带**槽位接入名集合**（一个部件可接入集合内任一槽位）
4. **槽位通过在主体（舰体网格）上加 socket 实现**，socket 由用户手动在编辑器添加

## 需求描述

1. 主体为 `AGuLiStrikeShip : ACharacter`（全新类，不继承俯视角 `AGuLiStrikeCharacter`），舰体 = virgon 静态网格
2. 部件基类 `UGuLiStrikeShipPartComponent : UStaticMeshComponent`，C++ 子类分引擎（推力/质量）与武器（伤害/射速/投射物）；具体部件 = 蓝图组件资产，加新部件零代码
3. 槽位 = 舰体静态网格上的 socket，命名规范 `HP_<类型>_<位置>`（如 `HP_Engine_L`）
4. 部件上 `CompatibleSockets`（槽位名集合）决定可安装范围；安装时校验，不兼容则拒绝
5. 飞行中按键热切换：销毁旧部件组件 → 动态创建新组件 → 挂到目标 socket → 数值即时重算
6. 数值聚合：推力/质量 → 推重比 → 极速与加速度；武器部件决定伤害与射速
7. 第三人称 6DOF 太空飞行（WASD + 鼠标俯仰偏航 + 滚转），追尾相机
8. 开火从已装武器部件位置发射现有 `AGuLiStrikeProjectile`

## 边界

- 不做存档持久化（换装结果重启丢失）
- 不做机库换装 UI（本轮用按键循环换装）
- 不做部件破坏/脱落、燃料能耗、网络复制
- 不新增部件美术（用 fly-01 现有散件；Tripo 生成部件留作扩展）

## 验收标准

- [ ] PIE 中飞船可 6DOF 飞行（平移 + 俯仰 + 偏航 + 滚转）
- [ ] 飞行中按热切换键，引擎/武器网格即时替换且无报错
- [ ] 换引擎后极速/加速度可感变化（推重比生效）
- [ ] 换武器后伤害/射速变化（投射物从部件位置发射）
- [ ] 不兼容部件无法安装（返回 false + 日志拒绝）
