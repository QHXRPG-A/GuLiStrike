# 指挥官精确选兵与快捷提示栏

## 背景
原型只提供圆形选兵，并自动补入圈外士兵，无法精确选择单兵或屏幕范围。需要降低操作成本、呈现快捷键，并调查客户端先行移动时的拖拽感。

## 需求描述
1. 默认左键点选/拖拽框选；7及现有选取槽反复切换框选/范围。范围保留80/200/450m和键盘+，全部只选实际命中者，不补25人。
2. Shift+点/框/范围纯追加，重复命中不取消。Alt+点兵扩选同兵种，附近优先、全图补足、每次最多1000；Alt+Shift把结果追加。1000不限制普通选择或累计选择。
3. 指针为青白像素箭头、深色描边、约32逻辑px、尖端热点，使用引擎软件光标，不增加跟随缓动。
4. 底坞上方增加约56px无标题图标栏，Alt/Shift图标始终亮、只有悬停说明、点击不切换模式且不穿透世界。正式透明PNG入库、条目结构可扩展。
5. 新选兵请求完成前移动排队，只有成功回执和对应选择副本都就绪才能预测/移动；失败不能改为操作旧部队。
6. 移动拖拽只调查：真实鼠标链、预测开关A/B、时间线和轨迹证据，区分静态推断和运行实测。

## 边界
保留临时ControlCohort最多25人的内部组织及服务器权威，不新增实际兵种，不重构预测/寻路/避让算法。保留无关未提交修改。协议升级为v4，双端一起更新。

## 验收标准
- [ ] 单选1、框选26、范围选取不额外补员；Shift三种追加去重，Alt同兵种/1000边界正确。
- [ ] 空地、UI、失焦、取消、角色切换和7往返行为正确。
- [ ] 双端快速选择后移动不丢失、不预测旧兵，ACK/属性乱序、拒绝和重试覆盖。
- [ ] 三画幅/DPI视觉、透明素材、热点、Tooltip、防穿透通过。
- [ ] 编译和自动化通过，诊断证据与尚未验证部分如实归档。
