# 首版 Demo 3v3、Ship 战略机动与高频选牌

## 背景与目标

在《无畏战舰》的玩法与失败因素讨论后，用户明确两项调整：第一版 Demo 设置为 3v3；通过红矿战略支援改善 Ship 跨战场移动的无效时间，并为 Ship 牌种分配更多设计制作投入，使 Ship 选牌频率显著高于另外两类玩法。

本稿只确认本次指定的方向；[Ship 组件肉鸽讨论](../Backlog/2026-09.md#idea-202609-004-ship-组件驱动的幸存者式肉鸽玩法)中的其他机制仍按各自确认状态处理。

## 已确认需求

### 1. 第一版 Demo 采用 3v3

- 首版 Demo 为每队 3 名玩家、共 6 名玩家的对抗。
- [大战场草案](./20260826-5v5大战场玩法草案.md)已有每队 1 指挥官、1 地面操作者、1 Ship 的 Demo 建议，本轮沿用为阵容假设。用户本次直接确认的是 3v3，未单独重定角色配比。
- 原 5v5 保留为后续规模方向；首版 Demo 的人数要求以本稿为准。
- 3v3 降低完整开局所需人数；缺角色、掉线接管和人数不足时的处理仍需细化，不据此宣称匹配问题已经解决。

### 2. 红矿战略支援承担 Ship 跨战区机动

- 通过消耗红矿的战略支援，将 Ship 从战场一处瞬时或近即时转移到另一处，显著压缩跨区赶路时间。
- 用户明确举例为传送门、加速带等。两种表现均属于本次方向；Demo 实际首发几种、先制作哪种尚未指定。
- 传送门可承担两点间直接转移，加速带可承担沿路线极高速移动；这是两种表现的建议分工，最终规则仍需细化。目标不能退化为只提供小幅航速加成而仍需长时间跨区航行。
- 这类能力属于红矿战略支援；沿用[资源规则](./20260908-蓝矿红矿与据点维护及三线Roguelike成长.md)，红矿仍同时承担既有据点维护和部分强力牌费用。
- 支援由谁调用、消耗谁的库存、按布设还是通行收费、能否由队友共享均未定稿。既有指挥官支援方向不能替代对这些具体权限的确认。

### 3. 优先投入 Ship 卡牌内容

- 为 Ship 牌种的设计、制作和迭代分配更多开发劳动力，使其成为首版 Demo 的内容投入重点。
- 此处“劳动力”表示研发与内容制作投入，不新增游戏内劳动人口或生产资源。
- 沿用已有方向：组件提供基础能力，肉鸽牌强化已装组件；安装僚机仓后才获得机群和召唤玩法。
- 牌库规模、组件覆盖、牌种比例和人员工时尚未指定，不将“更多投入”换算成已经确定的卡牌数量或任务排期。

### 4. Ship 选牌频率显著高于 WM 和指挥官

- Ship、WM、指挥官三类玩法采用不同成长节奏；Ship 的选牌频率显著高于另外两类。
- 沿用三线独立经验与选牌规则，经验仍是选牌机会的触发条件。更高频可通过 Ship 自己的经验曲线、门槛及相关奖励参数实现，具体方式待定。
- 部分强力牌仍可另付红矿；支援花费和强力牌费用分别定义。消费红矿不会自动产生一次选牌机会。
- 具体每分钟次数、相对倍率、每局选牌次数、局内阶段变化及单张强化幅度均待细化；本稿不填入未经确认的数值。

## 设计解读与候选细化

建议的 Ship 体验循环为：`判断战区机会 → 使用红矿战略支援快速转场 → 用当前组件参战 → 通过经验高频选牌 → 改变或增强构筑 → 响应下一处战场机会`。局部操舰仍可保持巨舰的射界和位置决策，跨区效率通过战略支援改善。

以下为后续建议，不是本次已确认规则：

- **机动应产生战线取舍。** 红矿投入使一次重要转场值得考虑，避免无代价反复跳转令侧翼、推进和撤退失去意义。通过传送过程的瞬时性与开门准备、落点提示分别设计，可以同时保留快速响应和可读性；暂不锁定预警秒数。
- **明确机动的战斗状态。** 需要处理载具和僚机如何随行、落点安全空间、敌方是否能使用或干扰、转移中的伤害与锁定、重复进出以及冷却是否保留。瞬移不自动意味着回血、无敌或重置武器冷却。
- **控制高频选牌的操作负担。** 提供简短可读的选择，必要时积攒待选机会；真人对局不因某人选牌暂停。频繁出现微小数值卡或无关候选，不能有效支撑这一方向。
- **让频率与战力分别调节。** 可以用较轻的常规强化与较少但明确改变行为的关键牌形成节奏；同等时间的整体战斗价值应与 WM、指挥官的职责一起检查。Ship 拿牌更多不能直接作为全方位倍增战力的理由。
- **按组件组织制作投入。** 优先补足火炮、机库等已选组件的连续成长与变化，再考虑跨组件联动。组件获取和掉落规则仍待定，不能要求先获得无用牌才能开启基础组件。
- **检查红矿的多重支出。** 战略机动、强力牌与据点维护会竞争有限红矿；需检查落后方是否同时失去转场与成长选择。费用、普通候选牌可用性和断供恢复一起推演，既有双资源维护规则不因此改写。

## 边界与下一步

首版范围新增上述方向，不自动批准完整牌库、全部机动技能或对其他玩法同步扩充内容。传送门、加速带的通行规则与数值也不直接沿用既有工程车快速通道。

下一步优先形成一张包含传送、沿路线高速机动和正常飞行的战区示意，并列出一次 Ship 转场与几次经验选牌的过程，用以细化“到达目标够快、局部交战仍有意义、选牌频繁但不妨碍操控”。确认具体规则后再建立开发方案。

本轮只更新需求与关联讨论，没有更改当前席位、地图、能力、数值或代码；没有新增测试或执行实机试玩。

## 本次文档验收

本次设定记录需明确首版 3v3、红矿支付的快速战略机动、Ship 卡牌内容投入优先和选牌频率显著高于另外两类玩法，并保留经验触发与红矿费用的区别。角色配比假设、费用、频率和制作范围应与已确认方向分开呈现。
