# 一键截帧与CPU分析插件

## 需求与边界

- GuLiFrameProfiler 随编辑器自动加载；Alt+/ 和 Tools 菜单触发同一流程，快捷键可编辑。
- 当前视口正常运行 5 秒 CPU Trace，结束后 RenderDoc 单次截帧，后台分析并打开报告。
- 报告包含完整帧、GameThread、RenderThread/RHIThread、工作线程、Hybrid 细分、Slate 归属、模拟负载及队列。嵌套去重、显式等待单列、缺失埋点不可用。
- 原始证据和 JSON/Markdown 报告按独立编号保存。CPU 来自截帧前窗口，不能把截帧停顿当作正常帧成本。
- 插件核心只依赖引擎，项目适配器复用原生采样。玩法、画质、归属和网络配置不变。
- 已有采样不接管；RenderDoc 不可用仍交付 CPU 报告；提前结束保留不完整证据。
- 验证使用现有 `/Game/Maps/LVL_CommanderMassPrototype`，保持两个客户端与 Coordinator；不新增长时验收矩阵。

## 验收标准

- [ ] 重启自动加载，PIE 焦点下快捷键和菜单可用，文本输入和弹窗不误触。
- [x] CPU 窗口和截帧顺序正确，自动生成报告与原始文件。
- [x] 两次采样独立，重复触发、已有 Trace、缺少 RenderDoc和中途退出均正确收尾。
- [x] 同一 Trace 对照 Unreal Insights 的帧数、线程热点与计时去重。
- [ ] 玩家可在对应地图直接操作 Alt+/，确认报告可读、操作不被改变。
