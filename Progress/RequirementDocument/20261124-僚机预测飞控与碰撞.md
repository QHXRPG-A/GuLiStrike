# 僚机预测飞控与碰撞

目标是在有群山的开放地图上，僚机跟随巡天时能提前转向或爬升。出生、补员、攻击中断和归队均需使用真实世界几何。

| 项目 | 要求 |
| --- | --- |
| 飞行性能 | 默认最大速度 48 m/s，最大转向率 120°/s，机体表面预留 10 m。三个参数由 Excel 数据管线提供。 |
| 地形 | 飞控提前判断转弯轨迹能否通过。实际位移必须扫过完整机体，贴面时允许滑移。 |
| 飞船 | 对当前世界内的巡天及其他飞船按真实舰体处理。飞船平移和转动均可推开僚机，玩家继续掌控飞船。 |
| 其他僚机 | 可交叉、重叠。编队密度不引起彼此避让或相互阻挡。 |
| 弹丸、导弹和飞行道具 | 支持命中或重叠查询，沿用阵营、授权、伤害与终止规则。 |
| 模拟权 | 所属飞船的模拟者运行逐架飞控。查询副本接收姿态，交接后用当前几何重新检查航向。 |

正式工程退役飞行专用的八叉树、Portal、异步 A* 及其烘焙约束。地面单位使用自己的 Recast。演示中的跟随和避障模式可继续用于对比。

玩家可在同一张地图选择试飞、对空、对地或综合试玩，直接驾驶装配 08 僚机仓的巡天。对空需要可攻击的敌舰，对地需要可命中的敌军，试飞需要能低空跟随、越岭和折返的航段。验收路线和运行入口见[开发记录](../DevelopmentDocumentation/20261124-僚机预测飞控与碰撞.md)。
