# 指挥官部队操作与特殊任务系统

## 操作合同

左键点选、矩形框选替换；Shift点选切换成员、框选追加；Ctrl点选或双击同兵种选择当前屏幕与鼠标地面点500米二维半径的交集，加Shift追加。数字0–9为编队：Ctrl覆盖、Shift追加、Alt覆盖并移出其他组、Shift+Alt追加并移出其他组；单按召回、双按定位。双击窗口默认0.3秒。

单位信息定位按钮居中有效选择；Ctrl+F5–F8保存、F5–F8召回场景位置，保留缩放朝向。指挥官镜头使用方向键、边缘、中键和滚轮。移除圆形范围选择及旧数字命令槽，保留Q技能、B建造、T战术；地面角色输入保持独立。

右键或M下达移动，Shift追加，S持续停止。Esc仅退出未提交模式。编队允许重叠，不自动接纳增援；死亡或失去控制权清理，运输临时隐藏保留。空选择覆盖清空组，空组召回不改变选择。

## 特殊任务及数据

源表为`data/Excel/GuLiStrikeSpecialTasks.xlsx / Tasks`。字段为id、name、Note、DisplayName、TaskTag、ApplicableUnitIds、AutoActivate、LifetimePolicy、ExecutorClass；类引用使用`/Script/GuLiStrike.类名`的softclass。

|ID|任务|适用Soldiers.id|生命周期|原生类|
|---|---|---|---|---|
|1|Mining / 采矿|3|Persistent|GuLiMiningSpecialTaskExecutor|
|2|Construction / 建造|4|Persistent|GuLiConstructionSpecialTaskExecutor|
|3|StrongholdAdvance / 据点推进|1,2|InitialOnce|GuLiStrongholdAdvanceSpecialTaskExecutor|

三行AutoActivate=TRUE，Tag分别为Task.Special.Mining、Task.Special.Construction、Task.Special.StrongholdAdvance。配置是映射唯一来源；非法Tag、兵种、类或能力必须报错，不能静默回退硬编码。

InitialOnce按单位实例授予一次，完成或被接管后消耗，不因重连、显隐、重复注册或旧回调恢复。据点推进未被接管时保留原连续推进。Persistent保留自动工作资格，手动队列完成后恢复。S清空未来任务并持续禁止自动激活；新的有效任务解除停止，只能恢复未消耗资格。选择、镜头、编队及Q本身不打断任务。

自动建造全图选我方未完工且地面可达的最近工地，按路径长、实例ID排序，允许协作，不自行据点运输。无目标默认每秒重试；工作开始后保持目标至完成、失效或中断。

## 队列与网络

支持移动、采矿、返厂、施工、据点运输；每单位32项手动任务（含当前），自动任务不占容量。普通替换、Shift追加，冻结输入时成员；无效命令保留原状态，混编逐单位反馈。Shift自动工作交接点为采矿一轮、建筑完成、据点阶段结束。末尾指定采矿循环；耗尽有货先卸载。S保留货物和建筑进度，停止移动和工作；安全出厂/落地不可跳过。

可靠有序命令入口负责去重和权限；服务端按本地目录解析ID及类，客户端不得提交任意类。规划绑定成员和任务版本，过期结果不能复活任务。协议递增，不跨局保存、不在运行中热换表。
