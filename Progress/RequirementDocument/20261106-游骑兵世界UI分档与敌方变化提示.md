# 游骑兵世界UI分档与敌方变化提示

## 显示合同

- 仅游骑兵Ground席位视角生效，指挥官、巡天及自身固定HUD保留既有规则。
- 常态UI在距离≤350米完整，350至500米线性渐隐，≥500米隐藏；移除该视角旧屏幕尺寸提前裁剪。
- 敌方生命、最大生命、护盾、最大护盾变化（包括治疗和恢复）触发该对象描边和状态条，允许超过500米；保持3秒、渐隐0.5秒，连续变化重新计时。
- 描边透明度取距离与事件透明度最大值。时间渐隐结束回归常态；状态条临时结束后隐藏。
- 所有单位底圈隐藏，包括选中单位。前哨光环不属于单位底圈，沿用普通距离规则。
- 生命条保留原尺寸和功能色；护盾容量大于0时在下方追加同宽3像素细条，间隔2像素，颜色采用美术规范中的#6AA4BE。
- 初始化、晚加入、新生命不触发；重复通知不重置计时。死亡、移除、变友方或失去显示资格时清除。视野外不提示箭头，回屏不重播。
- 不修改玩法判定、网络消息、模型本体LOD或受击闪光Overlay；保持场景UI的环境隔离和现有遮挡规则。

## 验收

- [ ] 350/425/500米常态透明度分别为1/0.5/0，选中及未选中底圈均不提交。
- [ ] 敌方掉血、纯护盾受损、治疗回满、恢复均触发；友方不触发。
- [ ] 同一ISM批次单个远端目标变化，不点亮其他实例；双客户端敌我判断隔离。
- [x] 源码版Editor编译通过，材质与配置结构核对完成。
- [ ] 规则、事件、双客户端及性能验证由用户接手；此前只完成两轮基线，新版未自动复测。
- [x] 对应Map验收入口与5个观察/交战参照点已保存，6个实体回读完成；视觉待玩家确认。
