# 飞船骨骼部件与 Socket 保留

原部件继承 `UStaticMeshComponent`，只能配置静态网格。用户已制作炮台骨骼资产，要求继续使用 `BP_CombatAvatarFly01` 舰体上手工布置的安装 Socket。

## 已确认范围

- 部件蓝图支持静态／骨骼网格两种视觉类型，安装接口继续使用部件类和舰体 Socket 名。
- 保留舰体安装 Socket、骨骼炮台炮口 Socket、无炮管导弹舱／燃烧弹舱原 Socket。
- 保留旧部件的网格、材质覆盖、安装偏移、兼容槽位和数值，以及飞船默认装配和目录。
- 提供可选炮口 Socket 查询，保持服务器发射权威和旧 MuzzleOffset 用法。
- 本次不制作俯仰控制、动画蓝图、碰撞，也不应用组件文档中的升级、依赖和互斥规则。

## 验收标准

- [x] 静态与骨骼部件共用现有安装接口，换装后安装父项和 Socket 变换正确。
- [x] 保存、重新加载后，49 个舰体安装 Socket、16 个骨骼炮口和10 个原静态炮口与快照一致。
- [x] 4 个旧部件蓝图配置完整保留，6 个相关蓝图编译无错误或警告。
- [x] 未配置网格的换装不清除旧部件；有效骨骼部件安装与卸载正常。

实施与证据见[开发文档](../DevelopmentDocumentation/20260911-飞船骨骼部件与Socket保留.md)。
