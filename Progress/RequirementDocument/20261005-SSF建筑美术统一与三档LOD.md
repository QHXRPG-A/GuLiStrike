# SSF 建筑美术统一与三档 LOD

## 目标与范围

用户明确“PLEASE IMPLEMENT THIS PLAN”，批准六座建筑＋配套、保留全部22个动画、整套先出参考和三视图、审核A通过后严格在Blender制作、审核B通过后正式导入的方案。

源目录 `/Game/Assets/SSF_Buildings/Buildings`：AirBase、CloningCenter、CommandCenter、MilitaryFactory、Reactor、StrategyCenter；配套Floor、Lamp、Light、Drone以及无人机蓝图。实际为7个骨骼模型、3个静态模型；名称中的SK前缀不作为类型依据。

按项目[美术规范](GuLiStrike美术规范.md)和[模型制作技能](../../.agents/skills/guli-model-production/SKILL.md)执行双审核。水下机器人和机甲属于其他工作项，不因本建筑任务重做或切换。
