# 飞船（DIY 模块化装配）

- 最近更新：2026-08-24（勘误归位：CombatAvatarFly-01=无畏舰裸舰体、02=重巡舰体（新自 Blender 导入），主控舰体换为 SM_Dreadnought_Hull）

## 模块概述

玩家驾驶可自由改装的太空飞船（virgon 运输舰舰体，缩放 0.3）。装配模型：**主体是 Character，部件是组件，槽位是舰体网格上的 socket，部件携带可接入槽位名集合**。换装在飞行中按键热切换，引擎/武器的数值差异实时影响飞行性能与火力。

## 机制细节

### 装配与热切换
- 触发：R = 循环换引擎，T = 循环换武器（飞行中随时）
- 流程：`InstallPart(部件类, socket名)` → 校验（socket 存在 + 部件 CompatibleSockets 包含该 socket）→ 销毁旧部件组件 → NewObject 新组件挂到 socket → RecomputeStats 即时刷新移动参数
- 反馈：网格即时替换；不兼容/缺 socket 返回 False 并打 Warning（不崩溃）

### 6DOF 飞行
- 触发：W/S 前进/反推减速、A/D 左右平移（**平移不转向**，含 W+侧移组合；侧移时机身向侧移方向轻倾 5°、松手归位）、Space/C 升降、Q/E **偏航转向（角速度惯性模型）**、鼠标控制**摄像机环绕**、**滚轮缩放相机（4000/格，期望臂长钳 8000~50000，默认 15000；上滚拉近）**、Shift 加力（×2）
- 流程：CharacterMovement MOVE_Flying（加速 800、刹车 60、极速 2400@默认配装）；**偏航带惯性**——按住 Q/E 角速度平滑爬升到 ±40°/s（YawResponseSpeed=3），松开后按阻尼衰减继续转约 2-3 秒才停（YawStopDamping=1，越小滑得越远）；转向时同样轻倾 5°，压弯跟随**实际角速度**（惯性旋转期间保持倾斜，转停回正）
- 反馈：相机完全独立于飞船姿态（AbsoluteRotation），只跟鼠标走；松手后按 60 减速漂移（巨型舰惯性）
- **相机避障（单系统，只认舰船与地形）**：SpringArm 自带探测**关闭**（幽灵回缩，另案）；全部由飞船 Tick 校验，**命中过滤谓词只认 `AGuLiStrikeShip`（含他舰/舰上部件）与 `ALandscapeProxy`**——道具/方块等一切其他实体不参与镜头避障（2026-08-25 对照实验：相机可停进 10km 方块内）。判据两级：端点重叠门控（探针球=间隙 20m 在期望机位压不到相关几何体→直接用期望臂长）→ 压到则**两段式**由外向内扫掠推出（第一段=舰体包围球短走廊覆盖自身舰，无相关命中退全长 ZoomMax 走廊覆盖地形/他舰；凸包内起步向外扫掠引擎不报命中）。滚轮期望臂长 8000~50000 默认 15000；位置滞后关、旋转滞后开。舰体资产约定：SIMPLE_AND_COMPLEX + 凸包分解

### 数值（推重比）
- 每帧换装后重算：推重比 = Σ引擎推力 ÷ (舰体质量 + Σ部件质量)
- 极速 = 1200 × clamp(推重比 ÷ 6, 0.5, 2)；加速度同比例
- 0 引擎 → 极速 600（下限）；默认配装（2 标准+1 重型引擎）→ 推重比 13.75 → 极速 2400（上限）

### 开火
- 触发：鼠标左键按住
- 流程：遍历已装武器部件，各自按射速冷却，从部件世界变换 + MuzzleOffset 生成 BP_ShipProjectile
- 反馈：投射物复用现有一击必毁 NPC 逻辑（伤害管线待接）
