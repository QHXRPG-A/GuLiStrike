# 飞船（DIY 模块化装配）

- 最近更新：2026-08-20（MVP 框架落地：装配 API + 6DOF + 热切换，待 socket 加入后完整生效）

## 模块概述

玩家驾驶可自由改装的太空飞船（virgon 运输舰舰体，缩放 0.3）。装配模型：**主体是 Character，部件是组件，槽位是舰体网格上的 socket，部件携带可接入槽位名集合**。换装在飞行中按键热切换，引擎/武器的数值差异实时影响飞行性能与火力。

## 机制细节

### 装配与热切换
- 触发：R = 循环换引擎，T = 循环换武器（飞行中随时）
- 流程：`InstallPart(部件类, socket名)` → 校验（socket 存在 + 部件 CompatibleSockets 包含该 socket）→ 销毁旧部件组件 → NewObject 新组件挂到 socket → RecomputeStats 即时刷新移动参数
- 反馈：网格即时替换；不兼容/缺 socket 返回 False 并打 Warning（不崩溃）

### 6DOF 飞行
- 触发：W/S 前后、A/D 左右平移、Space/C 升降、鼠标俯仰偏航、Q/E 滚转、Shift 加力（×2）
- 流程：CharacterMovement MOVE_Flying，无重力无平面约束，姿态由 AddActorLocalRotation 直接驱动
- 反馈：追尾相机（臂长 3000，带 CameraLag）随机体姿态转动

### 数值（推重比）
- 每帧换装后重算：推重比 = Σ引擎推力 ÷ (舰体质量 + Σ部件质量)
- 极速 = 2000 × clamp(推重比 ÷ 6, 0.5, 2)；加速度同比例
- 0 引擎 → 极速 1000（下限）；3 标准引擎 → 推重比≈13.8 → 极速 4000（上限）

### 开火
- 触发：鼠标左键按住
- 流程：遍历已装武器部件，各自按射速冷却，从部件世界变换 + MuzzleOffset 生成 BP_ShipProjectile
- 反馈：投射物复用现有一击必毁 NPC 逻辑（伤害管线待接）

## 数值速查

| 数值 | 值 | 备注 |
|---|---|---|
| 舰体质量 HullMass | 100 | BP_GuLiStrikeShip 可调 |
| 基础极速/加速度 | 2000 / 800 | 同上 |
| 标称推重比 | 6.0 | 比值→速度倍率 clamp [0.5, 2.0] |
| 标准引擎（BP_Engine_Standard） | 推力 600 · 质量 10 | 网格 SternPod1d |
| 重型引擎（BP_Engine_Heavy） | 推力 1000 · 质量 30 | 网格 SternPod1c ×0.8 |
| 激光炮（BP_Weapon_Laser） | 伤害 10 · 3 发/s | SM_Turret；兼容艏/左舷/右舷 |
| 火箭巢（BP_Weapon_RocketPod） | 伤害 40 · 0.8 发/s | Dawn_Gate_Orb；兼容左舷/右舷/**左引擎槽**（多槽位示例） |
| 出生配装 | L/R 标准引擎 + 顶部重型引擎 + 艏部激光 | BP DefaultParts |
