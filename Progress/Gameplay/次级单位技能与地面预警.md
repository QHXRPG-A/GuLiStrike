# 次级单位技能与地面预警

选中战争机器按Q，以鼠标指向的合法地面为圆心发射一枚导弹。每枚由服务器在直径16米圆内按面积均匀采样落点，最多8次贴地尝试，失败回退圆心；结果随发射冻结，预警跟随实际落点。多选时每台独立检查圆心射程，无技能、冷却、圆心超范围或无效地面的单位跳过；随机落点允许超出射程边界，不会为了施放自动移动。成功发射后开始该台6秒冷却，左右发射口轮换。

| 项目 | 当前配置 |
|---|---|
| 战争机器Q距离 | 最终BasicAttack射程×1.6，基础48米 |
| 随机落点区 | 半径8米、直径16米，基础配置落点最远允许56米 |
| 冷却 | 每台6秒，仅成功发射计时 |
| 伤害 | MissileLauncher最终伤害，基础30，沿用升级 |
| 爆炸半径 | 发射时冻结的法术场半径，基础2米、直径4米 |
| 自动攻击 | 机枪；导弹为主动触发 |
| 预警设计 | 固定红圈、浅底色、两道外扩波纹，单道周期0.8秒；投射深度80cm，圈边界对应200cm伤害半径；原B1审核不替代本轮尺度验收 |
| 导弹表现 | 导弹、尾焰共用VisualScale=0.4；爆炸使用指定2A的项目副本，有效VisualScale=1.6，按后续反馈在0.4基础上放大四倍 |

数值入口：[GuLiStrikeSecondaryUnitSkills.xlsx](../../data/Excel/GuLiStrikeSecondaryUnitSkills.xlsx)。`Skills`维护主动技能定义及配置引用，`UnitSkills`维护全部次级单位映射；空SkillId表示无主动技能。原武器表提供最终武器伤害和挂点，法术场表提供爆炸配置，技能表引用它们。

通用地面预警由稳定ID驱动，不与某个单位绑定。C++/蓝图调用`UpsertWarning`传入位置、半径、颜色、样式与服务器时间，结束时调用`RemoveWarning`。相同形状样式共享贴花，各来源独立计数；命中、取消、过期与换局时清理。导弹预警由服务器确认的效果状态重建，双方可见，专服不显示。

本次由原自动导弹改为主动Q，CD从自动武器攻速中解耦；[开发记录及验证边界](../DevelopmentDocumentation/20260917-战争机器Q导弹与通用地面预警.md)。

2026-09-18新增`Skills.TargetAreaDiameterCentimeters=4000`，其他点技能默认0；射程固定字段同步为24000cm，继续由最终普通攻击射程成长。实施与本轮验证状态见[圆面打击开发记录](../DevelopmentDocumentation/20260918-Q导弹圆面打击与赠品建筑防卡死.md)。

同日后续[0.2倍尺度迁移](游戏对象尺度.md)：以上演进记录中的4000/24000cm已迁移至800/4800cm，法术场半径800→160cm；伤害、6秒冷却和0.8秒波纹周期不变。新尺度的运行与视觉验收以本轮实施记录为准。

2026-09-19按用户指定调整为当前表中数值：Q直径800→1600cm、单弹与预警半径160→200cm，导弹/尾焰/爆炸有效比例0.2→0.4，爆炸切换为2A。两端真实施放、运行参数及圈尺寸检查通过；[实施和证据](../DevelopmentDocumentation/20260919-战争机器导弹范围与特效调整.md)。
