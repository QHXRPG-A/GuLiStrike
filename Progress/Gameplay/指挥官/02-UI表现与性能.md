# 指挥官 · UI 表现与性能

<!-- guli-progress:split-content -->
### 指挥官 UI 与战场反馈

- 相机：WASD/屏幕边缘平移、Q/E旋转、滚轮缩放；共享Landscape子系统提供严格高度与真实边界，相机、HUD和小地图不再各用`±380000cm`常量。SpringArm碰撞收缩和内置Lag关闭，显式求解器以最多1/60秒子步约束完整视锥并沿摇臂保持枢轴/摇臂/镜头150/200/500cm硬净空。有效地形上的平移不再被上升预算打折；相机按实际速度前视0.25/0.50/0.75秒，目标加1000cm余量，以0.20秒半衰期平滑抬升并过滤300cm内小起伏，极端地形只立即补Z。普通平移、停止和Q/E不降低已保持海拔；实际滚轮缩放以0.35秒半衰期、最大15000cm/s重新锚定，`JumpToWorldLocation`立即设置当前完整净空加1000cm。边缘滚屏仍为16个DPI逻辑像素的SmoothStep，仅在视口聚焦且鼠标位于视口内生效。
- HUD：运行时使用顶中战况条、左下战术地图和底部指挥坞三岛布局；WBP 只负责布局，全部数据和输入逻辑位于原生 C++。
- 指针：本地 Commander 使用约 32 逻辑像素的青白像素箭头、深色描边与尖端热点；由 UE 软件光标直接定位，不额外添加位置缓动。切出 Commander 恢复之前的光标。
- 顶栏：显示真实比赛时长与蓝/红队；当前没有权威来源的目标和比分显示“目标未启用”与 `-- : --`。
- 底坞：保留本地队伍、角色、“在线／同步中”和己方存活数/初始总数；“编队”“指令矩阵”使用中文斜切底板标题，不再使用双斜杠分隔的英文标题。战术点和轨道能量显示 `--`，未实现命令保持禁用。
- 快捷提示栏：底坞上方增加约 56 逻辑像素高的无标题图标栏，当前放置 Alt 同兵种扩选、Shift 追加两个说明条目。图标始终亮；悬停显示用途和组合键，点击只消费 UI 输入，不启动模式、不触发选择，也不穿透世界。条目结构可继续扩展；提示由 viewport 内的原生布局显示。
- 士兵卡：选中部队汇总为一张横向卡；按SoldierId去重后，只统计可靠状态中仍存活的士兵，多Cohort不拆卡。人数显示存活人数，血条按“存活者当前生命总和÷存活者最大生命总和”填充，合计值保留小数；阵亡者退出血量分子与分母。例如25名满血士兵阵亡5名后显示20人，余下士兵仍满血时血条保持100%。
- 卡片状态：没有选择或已确认没有存活成员时折叠；已收到选择但可靠状态尚未就绪、缺少成员状态或未完成本局同步时显示“同步中”，人数与生命显示 `--`，不展示假满血。卡片继续只读，并由选择、可靠状态和命令回执事件刷新；换局清除旧选择，避免复用跨局 SoldierId。
- 小地图：左下角以 10Hz heading-up 批量绘制 Landscape、双方存活兵、选中强调和相机视野框；左键点击地图消费输入并聚焦对应世界位置。
- 选区：Box 拖拽时绘制屏幕矩形；仅 Radius 选取工具显示当前 80m、200m 或 450m 的世界选区圆。移动工具通过既有命令反馈线显示 Pending、Accepted 或 Rejected。
- Pending继续使用橙色反馈，全失败继续短暂显示红色；Accepted以逐兵“权威提交起点→实际最终槽”的1px静态绿色直线显示。绿线没有流动、箭头、脉冲、标签或淡入淡出，只对仍选中、存活且执行对应指令的单位显示；到达、Blocked、死亡、改令、取消选择或网络重置立即隐藏。显示策略与屏幕裁剪自动化已通过，500线运行性能尚未采样。
- 单位脚环：未选为队伍色，选中为金色；保留常显和穿透场景遮挡的行为。Soldier 摧毁后模型隐藏，暗红脚环保留 5 秒后隐藏。
- 世界血条：双方存活 Soldier 在“本地选中或受伤”且距相机焦点不超过 300m 时显示；一个本地 ISM 批量绘制约 84×12px 的黑底、左到右红色连续血条、四分位线和选中青框，接受地形深度遮挡。
- 输入保护：顶栏、小地图、底坞及新增快捷提示栏使用实际 Slate 像素几何阻止世界 LMB/RMB；三画幅、DPI 和完整真实输入回归仍按本轮验收记录判定。
- 角色边界：只有本地 Commander 启用指挥 HUD、相机和键鼠工具入口；`7`、`+`、`1`、Esc、左右键、滚轮以及 HUD/小地图点击都先检查当前角色。切成 Ground/Air 后迟到的旧 UI 点击不能再控制指挥相机。Controller 绑定不吞掉其他 Pawn 的输入；公共工具辅助函数仍可用于内部重置。

### 表现层性能与本地调参

- Unit 与 Ring 继续使用两个稳定 `UInstancedStaticMeshComponent`；始终保持 `SoldierId → InstanceIndex`，不按距离增删实例，也不使用 HISM。
- Unit 以每个实例到当前客户端摄像机的距离计算裁切，默认在 `100000cm` 硬切；Ring 不做距离裁切，因此远距、选中和残骸状态仍可通过脚环读取。
- Unit 默认关闭阴影、距离场照明、动态间接光和光追可见性；Ring 固定关闭同一组重型渲染功能，但继续正常 Raster 显示。
- Ring 网格改为 64 段、128 三角形的单面中空圆环，模型外/内半径为 48/34cm；保留实例缩放 12，世界外/内半径为 576/408cm。材质精简为 6 节点，保留 RGBA 色值、原有发光 `RGB × 3` 和透明度 `A × 0.58`；不改变队伍色、选中色、穿透、无限距和死亡保留时长。
- 正常 Soldier 模型为 `SM_CommanderFourFRobot_Crowd`：单材质、单 Section，LOD tris 为 `18999 / 964 / 238`；旧 FourFRobot 只保留为烘焙源和回退。
- 非 Shipping 构建可用 `gs.Commander.Presentation.List/Get/Set/Reset` 修改当前客户端 World 的六个表现白名单 key；Override 不复制、不写 Config 或磁盘，World 销毁后清空。
- 表现调参优先级为 C++ 默认值 `<` Config `<` 当前 World 本地 Override；非法值拒绝，不静默 Clamp。
