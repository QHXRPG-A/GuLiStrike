### 当前：按连接预算分批同步（2026-09-23，已加载，待玩家验收）

协议19将公共名册与所属指挥官终点改为每连接独立的可靠小批次，最多1000字节/4批未确认；按原生连接信用逐Tick发送，位置有需求时默认预留50%。等待期间按士兵合并最新状态；死亡/移除最高优先，命令终点按ActiveOrderId配套，初始同步经连接实际发布集合的数量/ID哈希/序号验证后开放操作。客户端未出现在本批的单位保持原状态。

10Hz捕获与发送排空分离，位置只保留最新未发送样本及原采样时间，获准发送后才提交序号和编码历史。现有三倍纠偏保持。`guli.Commander.StateStreamDiagnostics 1`可手动输出逐连接队列/字节/样本间隔；实际改善须在同负载下看位置缺口和追赶，不以低Ping验收。

源码及静态审查、源码Editor构建和重启加载已完成，8份BuildId一致，CDO协议号读回19。`StateTreeReview_Entry`补充说明已保存并重载读回，当前无脏包；未启动新PIE或压测，平滑体验及同步边界待玩家验证。120Hz补额限制、其他复制源及服务端导航异常保留后续。既有诊断与旧构建结论保留为历史。[本轮编译交付](../../Archive/20260923-Mass按连接预算分批同步编译交付.md)。


### 最新：名册/终点突发与每帧预算（2026-09-23）

用户重启的大部队PIE中，600单位移动时30秒记录47个姿态块被跳过；7个异常帧的CSV/日志完全一致。名册与MoveEndpoints可在同帧累积至6.37KB总发送量，挤掉下一帧姿态。运行120Hz预算计时上限使每帧仅补2083.25字节，约21FPS窗口实际持续补充约43.73KB/s，双连接字节及起止余额重建与计数完全吻合。当前仅诊断、未修复或改变参数，历史470ms具体帧与导航异常仍独立保留。[新增证据](../../Archive/20260923-Mass复制流量与同帧突发定位.md)。

### 最新：姿态发送预算饱和证据（2026-09-23）

35秒原PIE采样记录4217次位置RPC被UE发送预算检查跳过；连接实际限额250000字节/秒，同期原生Trace约37FPS。低Ping不能排除这种应用内发送跳过。持续流量与同帧突发仍待分解，历史470ms对应块未记录发送层，因此不倒推单帧原因；本轮只诊断且日志级别已恢复，平滑体验仍待源头修复。[证据及边界](../../Archive/20260923-Mass姿态RPC发送预算饱和诊断.md)。

### 最新玩家反馈：三倍限速未解决停走（2026-09-23）

用户确认限速有效，但大量单位追赶影响体验，当前不能视为平滑验收通过。常规帧率的双客户端同兵对照抓到470ms样本缺口：服务器正常行走，缺帧端外推耗尽后停约0.24秒，再三帧三倍追赶；3FPS段的1.333秒供给单独归类。另有服务器6～16米异常位移，需独立修复。当前仍是原3倍实现，本轮没有改代码或运行参数。[诊断与证据边界](../../Archive/20260923-Mass姿态缺帧与三倍追赶现场诊断.md)。

### 当前：连续纠偏与FPS/RTT（2026-09-23）

普通Mass位置更新保留8条有界历史，不再按距离阈值清空缓冲；沿用原时间插值和100ms外推，再从上一帧显示位置向求值目标连续追赶。最大总显示速度为已发布标准速度3倍，当前720→2160cm/s；追上后直接恢复原轨迹，普通行走不额外增加固定延迟。明确传送、首次显示和网络世代重置单独处理；服务器导航、伤害和碰撞规则保持。[实现与边界](../../DevelopmentDocumentation/20260923-Mass历史插值与三倍速度纠偏.md)。

左上角现有顶部状态条下方增加只读FPS/延迟RTT，每0.5秒刷新。FPS基于真实时间和引擎帧数；RTT来自连接统计，不包含客户端插值缓冲。非客户端标“本地”，尚无测量标“--”。Canvas随DPI和视口适配，不拦截输入；文本维护于GuLiStrikeGameTexts.xlsx的UI.Performance系列键。新代码和文本资产已编译加载，实际显示与行走由用户核对。[HUD交付](../../DevelopmentDocumentation/20260923-游戏左上角帧率与延迟显示.md)。

### 指挥官 UI 与战场反馈

- 本地指挥官使用 UMG 主界面和 Slate 小地图：顶栏显示真实阵营、角色、连接状态、比赛时间、存活数量和资源；左下地图、底部选择区／肖像、右下 5×3 命令卡组成局内布局。其他角色保持原界面。
- 原生 HUD 负责布局和操作意图，项目 WBP 选择视觉主题；资源来自 Dark GUI 面板、进度条、滚动条、图标与数字字体，中文沿用中文字形回退。源表 `GuLiStrikeGameTexts.xlsx / Texts` 维护界面文字、悬停说明和相关任务反馈。
- 多选区每页 24 个头像组（8×3），按兵种、Mass／Actor身份和稳定实例 ID 排序，同兵种每25名生成一组。界面仅保留24个控件池，无头像 Tick；格内显示组人数，不显示 `#实例ID`。死亡后重建分组并修正页码。类型页签和 Tab 只改变查看范围；Q 始终尝试作用于全部确认选择。
- 头像组单击选择该组，Shift 单击移除该组，Ctrl 单击保留当前选择内同类，Ctrl+Shift 单击移除当前选择内同类。头像与鼠标编队读取本次鼠标按下事件的修饰键，避免UI拦截键盘后丢失组合键。请求仅携带组内锚点和选择版本并走可靠有序入口；服务器按相同排序重建最多25名成员，只在当前合法选择内解析，不接收任意成员列表。
- 详情保留兵种名称，生命／护盾合计、基础速度、防御及单矿车蓝／红载货以图标＋数值显示。头像组血条使用组内生命合计比例；头像格不再提供实例名称、生命和选兵说明提示。肖像静态贴图按原比例适配，并有轻微状态亮度变化。
- 命令卡只显示图标，悬停展示名称、快捷键、目标要求、适用人数与禁用原因。移动、停止、Q、定位、任务、采矿、返厂、施工、据点运输接入现有入口；B/T 是全局入口。部分接受以服务端回执为准。
- 编队条显示 0–9 键位和独立成员数，空组隐藏数量；与当前选择有关联的编队高亮。鼠标单击召回、双击定位、Ctrl 覆盖、Shift 追加、Alt 组合移出其他编队，与键盘共用逻辑。
- 点击任务图标展开查看单选完整队列／多选共同前缀和差异、自动／手动来源、32 项手动容量、持续停止、安全退出、失败原因及可恢复资格；底部不再常驻文字摘要。只有具备有效目标位置的行可定位；查看不修改队列。
- 小地图保持既有地形缓存、单位标记和镜头范围框；左键／拖动定位镜头，右键移动，Shift 追加，M 模式左键提交地面移动。位置沿用地图转换和边界约束。
- B 目录使用纯图标，悬停提示首行加粗建筑名，其后展示简介与真实费用；面板显示放置限制。T 显示实际运输阶段和参与数，Commander 不再同时生成旧独立运输面板。
- 小地图下方操作说明、选择区底部说明、底部任务摘要条和命令卡标题均不常驻显示；底部设计表面由 1888×312 收紧至 1888×276，选择头像和命令图标填充腾出的空间。
- F10／菜单按钮打开本地菜单，继续、说明、退出确认不暂停多人世界。Esc 优先关闭顶层菜单／队列，其后取消未提交目标或拖选。关闭菜单恢复游戏焦点，切角色／销毁清理委托和计时器。
- 只有可交互面板阻止世界点击，透明战场区域允许输入；禁用命令仍可解释原因，提示框约束在视口内。
- 世界单位血条、脚环、武器行为与移动算法保持既有实现；本轮未新增 A 移动、点杀、巡逻或窄口算法。
- 分析、实现和实测范围见[本轮开发记录](../../DevelopmentDocumentation/20260920-星际UI拆解与指挥官界面重构.md)，截图可观察结果不代表玩家美术审核已通过。

### 表现层性能与本地调参

- Unit 与 Ring 继续使用两个稳定 `UInstancedStaticMeshComponent`；始终保持 `SoldierId → InstanceIndex`，不按距离增删实例，也不使用 HISM。
- Unit 以每个实例到当前客户端摄像机的距离计算裁切，默认在 `100000cm` 硬切；Ring 不做距离裁切，因此远距、选中和残骸状态仍可通过脚环读取。
- Unit 默认关闭阴影、距离场照明、动态间接光和光追可见性；Ring 固定关闭同一组重型渲染功能，但继续正常 Raster 显示。
- Ring 网格改为 64 段、128 三角形的单面中空圆环，模型外/内半径为 48/34cm；保留实例缩放 12，世界外/内半径为 576/408cm。材质精简为 6 节点，保留 RGBA 色值、原有发光 `RGB × 3` 和透明度 `A × 0.58`；不改变队伍色、选中色、穿透、无限距和死亡保留时长。
- 正常 Soldier 模型为 `SM_CommanderFourFRobot_Crowd`：单材质、单 Section，LOD tris 为 `18999 / 964 / 238`；旧 FourFRobot 只保留为烘焙源和回退。
- 非 Shipping 构建可用 `gs.Commander.Presentation.List/Get/Set/Reset` 修改当前客户端 World 的六个表现白名单 key；Override 不复制、不写 Config 或磁盘，World 销毁后清空。
- 表现调参优先级为 C++ 默认值 `<` Config `<` 当前 World 本地 Override；非法值拒绝，不静默 Clamp。
