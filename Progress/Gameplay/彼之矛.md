# 彼之矛

彼之矛是指挥官普通军队的巨型重炮，兵种ID6、内部名BiZhiMao。使用已审ControlRig四足机甲，放大2倍；不属于重防号WM01/ID2或Ground玩家席位。

## 数值与操作

| 项目 | 已确认值 |
|---|---|
| 基础移速 | 144 cm/s，重防号基础720 cm/s的0.2 |
| 生命 / 防御 | 1000 / 0 |
| 蓝 / 红 / 工作量 | 60 / 30 / 60 |
| 人口 | 每台1个普通军队人口，订单时预留 |
| 施工定义 / 放置类型 | Buildings ID8 / 类型7；Commander B→7 |
| 生成方式 | 只由己方工程车施工完成，不从兵营、召唤或开局编制生成 |
| 完工 | 原工地位置、朝向、阵营、剩余生命转Mass，直接展开待机 |
| 底座 | 永远保持生成时朝向；四足平移，允许四向与斜向 |
| 炮台 / 俯仰 | 360°、30°/s；−10°至+45°、15°/s |
| 战场尺寸 | 宽约18.44m、长约26.46m |

资源或人口不足拒绝订单；工地创建失败回滚费用和人口。完工先撤除自身导航阻挡并等待更新，再忽略自身代理核验出生空间；受阻保留原位工地和人口预留，空间恢复后仅转换一次。工地销毁和世界结束释放预留，客户端通过转换单位ID交接显示。

移动接入现有编队、避让、运输、右键移动和S停止，所有位移保持底座朝向。正式单位首轮保持默认炮台姿态，没有索敌、射击、弹丸、伤害或主动技能；可移动目标跟随仅出现在审核Actor。
