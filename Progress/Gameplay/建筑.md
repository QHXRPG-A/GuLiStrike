# 建筑

2026-09-18应用[0.2倍尺度合同](游戏对象尺度.md)。原网格/BuildScale不重烘焙，游戏入口MeshScale、碰撞和独立偏移各迁移一次。以下资产制作规格保留源尺寸；运行时有效尺寸为其20%，历史验收不代替本轮验证。

## 模块概述

建筑模块把“选择地点”变成服务器权威、全客户端一致的世界实体。当前实现从只放置三种建筑扩展为表驱动工地、建造车施工、占领赠品与维护生产。建筑血量和供盾接入战斗账本；具体炮塔攻击、防空和手动PlacedBuilding的Mass绕行仍待后续。

## 机制细节

### 权限与输入

- 触发：Commander 或 Ground 按 `B` 进入建造模式；首次默认建筑 1，以后记住上次选择。
- 流程：模式内 `1～6` 分别选择防空炮、哨戒炮、手动前哨、兵营、护盾发生器和矿厂，LMB 放置后保持连续建造，RMB、Esc 或 B 退出。模式外 Commander 的 `1=移动工具` 与 RMB 移动保留，`2/3` 不建造。
- 权限：Commander、Ground 可建造；Air、Observer 和未分配角色不可建造。
- 反馈：原生 Canvas HUD 显示约 2 秒的选择、成功或拒绝短提示，不接管焦点，也不修改 Commander WBP。

### 瞄准、朝向与预览

- Commander 使用鼠标指向的地面点；指针落在 HUD 命中区域时禁止放置。
- Ground 使用屏幕中心射线，目标与 Pawn 的平面距离不得超过20米，并要求 Pawn 到目标无遮挡。
- 建筑保持直立，只采用当前视角的水平 Yaw；当前版本没有手动旋转。
- 本地非复制预览复用同一参数化半透明材质，合法为绿色、非法为红色。退出模式、角色变化、失去就绪、Pawn 替换或 EndPlay 都会销毁预览。

### 服务器权威放置

- 客户端只提交递增请求号、建筑类型、目标地面位置和压缩 Yaw；Reliable RPC 的重复同请求只重放旧结果，不重复生成。
- 服务器重新校验战局/连接就绪、角色、目录资源、请求有限值、地面、15° 坡度、Ground 距离与视线、物理重叠、存活 Mass 士兵占位、请求频率、个人上限和全局上限。
- 放置碰撞以最终烘焙模型包围盒为准，检测时在水平面额外增加 100cm 间距。Mass 士兵没有物理形体，因此另用权威位置快照做圆盘与旋转建筑盒相交判定；远端预览使用复制姿态。拒绝后保留建造模式并返回明确原因；接受后只生成一个权威建筑。

### 蓝红资源事务

- 每队开局蓝矿 40、红矿 0；旧三种费用仍为20／10／40蓝矿；兵营30蓝10红、护盾20蓝10红、矿厂40蓝10红。
- 服务器先以稳定 PlayerGuid 与 ClientRequestId 建立预留，再尝试生成 Actor；成功后提交，生成失败或后续校验失败时完整退款。
- 相同请求重放旧结果，旧请求被拒绝；已经提交或退款的 RequestId 保留本局终态，不能二次扣费。余额不足返回明确拒绝原因。
- 库存只复制给本队 PlayerState；完整资源循环见[资源经济](./资源经济.md)。

### 建筑实体与生命周期

- `AGuLiPlacedBuilding` 复制建筑类型、阵营和建造者稳定 `PlayerGuid`，不复制移动、全局相关，初始化后休眠。
- Actor保持Scale 1，视觉Mesh按建筑表MeshScale缩放。根 Box 使用 `BlockAll` 提供确定性实体碰撞；视觉 Mesh 不承担碰撞。防空炮资产保留 Nanite，但其玻璃材质为半透明，预览和已放置组件均使用 fallback 表示以避免警告风暴。
- 根 Box 和 `UNavModifierComponent` 现已参与 Dynamic 导航，建筑增删更新实际占地区域；摧毁后撤销阻挡，底层地面恢复。9月3日暂时关闭导航相关性的实现已由9月15日工程车避障及导航预烘焙工作替代，见[导航技术记录](../DevelopmentDocumentation/20260915-导航预烘焙与哈希判新.md)。
- 建筑具有血量和UnderConstruction／Completed／Destroyed状态，不因建造者离线消失；死亡关闭碰撞与表现并回收。地图据点不可摧毁。

### 建造车、据点与功能组件

自动施工由Soldiers绑定的ST_CommanderBuilder驱动（兵种4，Persistent；网络兼容编号2）。每辆空闲建造车独立查己方未完工建筑：先车辆当前所在据点，再其他据点；同级按建筑创建顺序，不比较目标距离或路径长度。跳过施工位未准备好、全部占用或已确认不可达的候选；作业内寻路与据点运输沿用共享接口和预算。

接单与移动只记录目标、候选施工位及版本，按车辆稳定ID循环选择空位，不预占。每0.2秒检查失效、占用、销毁、完成和易主；外据点单途中若当前位置的据点出现可接工单，自动退单并重新优先接本地单。手动指定工地不受这类自动换单影响。

车辆进入现有100cm到位阈值后，服务器游戏线程原子检查并独占施工位；失败立即退单，该候选位排除1秒，可改接同工地其他空位。已占位并施工的车暂停接单和自动换单，持续作业；每栋最多四个有效施工位，每0.1秒结算与施工数值不变。停止、死亡、销毁、任务替换、完工时释放；没有可用单时回到限频空闲检查。等待/退单原因可由GetConstructionDebug读取。

2026-09-23本轮代码和树资产的验证边界见[地图与自主接单交付](../DevelopmentDocumentation/20260922-导航内存优化与对局容量预算.md)；运行中的抢位、换单和协作效果仍待授权PIE验收。

施工、移动、运输由每车统一队列协调；普通有效命令替换、Shift追加，S停止后保持暂停，工地已有进度不丢失。Shift等待当前工地完成才交接，人工队列结束后重新检查合法工地。兵营部队自动推进迁入 InitialOnce：未接管时继续下一据点，被有效命令或S接管后不恢复。本轮树迁移已完成原生与树资产编译、兵种绑定和原型地图交付，实际施工与中断行为待玩家验证；见[开发记录](../DevelopmentDocumentation/20260921-指挥官部队StateTree接入与特殊任务退役.md)。

- 开局每队一辆独立建造车，选择后右键己方工地施工；每车每秒1工作量，默认10，多车线性加速。采矿车不施工。地图与首占赠品不占手动6／24座额度。
- 建筑目录来自GuLiStrikeBuildings.xlsx，ID与战局实例ID分开。注册表只登记／查询和广播生成、完成、摧毁，不复制据点归属或功能状态。
- 地面票数每0.25秒统一采样，中立20秒到端点、红蓝互夺40秒，平局保持。首占优先在原插槽赠送已完成兵营、护盾和矿厂；地形不合格时自动搜索同据点附近候选及朝向。找不到合格位置保留待发放奖励；只重试失败槽，已毁不补。
- 奖励及手动建筑生成前检查占地支撑，矿厂额外检查实际坡道入口；坡道遇到无地面或不允许的高差时停用并记录原因，不终止对局。
- 赠品生成增加服务器清场事务：主体及附属阻挡在准备阶段关闭碰撞和导航影响，按单位尺寸加100cm安全余量，先为所有重叠Mass部队、工程车、矿车和玩家Pawn规划建筑外互不占位的合法落点。所有位置通过地形、对应导航和障碍校验后统一移出，随即恢复建筑碰撞与导航；不改变身份、阵营和选择。外部控制锁定或无法完整清场时撤销候选、不消耗赠品槽，继续原有搜索重试。移出的单位取消旧路径并恢复接令。
- 存活赠品随Territory换主，自建建筑和已生成部队不变。兵营10秒24名，所有来源共享每队300人口与预留；八邻接全己方时继续向外寻敌，手动命令优先。
- 每30秒逐点原子扣蓝1红1；失败只停赠品兵营和供盾，下一周期重试，不积欠款。被围只断工程车通道。矿厂旧队列保留接收阵营。
- 工程车仅在指挥官点击其他己方据点模型时运输，相邻也可用；普通地面及自动任务走地面。红蓝分别对本方未被围据点建MST，N点N−1边。无地面法阵，车辆原地化蓝球垂直上浮，汇入本方网络；动态出口按点击侧落位，建造车待命、矿车宽限后自动。拒绝保留原任务，混选士兵保持指令。
- 具体合同、实际证据与未验证项见[建筑闭环与空中通道开发文档](../DevelopmentDocumentation/20260914-指挥官白模据点占领与建筑体系.md)。
