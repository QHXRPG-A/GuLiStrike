# 2026-09-10：地图资源密度涂绘与确定性导出

## 交付结果

- 插件版本提升为 `0.2.0`，面板新增“资源涂绘”页。地图持久保存 Editor-only、非空间加载、无 Data Layer 的 `AGuLiMapDensityMap` 单例。
- Core 新增通用密度记录：稳定图层 GUID、唯一 ASCII LayerKey、默认 2500 cm 世界对齐格、每层稀疏 `32×32` uint8 瓦片；默认补齐 `BlueOre/蓝矿` 与 `RedOre/红矿`，两层可独立和重叠。
- 笔刷支持加深、擦除、半径、强度、Falloff、固定世界距离补点和同笔每格最大覆盖；一次拖拽一个事务，Esc 可回滚当前笔画。
- 代码 SceneProxy 批量绘制热力格，不创建逐格 Actor/Component；游戏线程查询并缓存 Landscape 高度，失败时回退 Visibility 或工作平面。
- 新建 Outpost 预设增加独立 `Territory` PolygonPrism，已有类型资产和 Marker 不自动迁移。格中心用于归属，严格多重内部命中为 overlap，共享边界按 MarkerKey/RegionId 稳定裁决。
- 新增 `EnsureDensityMap`、`GetDensitySnapshot`、`UpdateDensityCells`。Patch 对未知键、重复格、非整数、未知图层或越界密度整体失败，不产生部分修改。
- 密度 Actor 存在时，原六文件批次增加 `density_layers.json`、`density_cells.csv`、`density_territories.csv`；无密度旧地图仍严格输出六文件，`layout.json` 保持 schema v1。
- 密度归属中的 unassigned/overlap 是 Warning，不阻止导出；非法 Territory 形状或倾斜是 Error。据点汇总只表示 `Σ(density/255)` 和加权面积，不代表矿量或储量。
