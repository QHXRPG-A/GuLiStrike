# 2026-09-16：Ship 内部线稿烘焙遮罩

用户明确要求“把装甲内部线条烘焙成贴图遮罩，外轮廓保留独立描边”。本次将当前样板的装甲折线及边界曲线转为材质遮罩，保留原外轮廓壳、0.42m偏移、舰体形状和色块材质。

## 实现与结果

从实体线稿恢复全部1,048段结构边，使用原0.135m/0.19m半径，在独立第四UV通道 `SS_LineartUV` 上生成灰度覆盖率。仅626个有线条的表面占用图集，其余面采样黑色区域，原三个UV通道保留。采用逐面几何距离栅格化、每像素16次覆盖采样和8像素边缘扩展，修复初次曲线投射时折角断线的问题。

遮罩为4096×4096、8位、Non-Color，白色混合深蓝线色 `#213D50`，黑色保留材质原色。贴图没有场景光照和阴影，并同时保存独立PNG和打包副本。五个舰体材质共享图像，喷口保持原材质。

| 单艘评审模型 | 三角面 |
|---|---:|
| 舰体主体 | 13,314 |
| 独立外轮廓壳 | 3,088 |
| 当前合计 | 16,402 |
| 实体线稿版合计 | 37,362 |
| 减少 | 20,960（56.1%） |

当前Blender多边形数为6,143，以上均不包含地面与对照船。当前样板和并排对照中的内部曲线已移除；外壳仍为独立对象，内部线稿强度可通过材质节点 `SS_Lineart_Strength` 调整。

## 验证与交付

舰体顶点及拓扑哈希与实体线稿版一致，外壳几何哈希一致；已检查斜视、俯视、侧视、尾部和原版并排预览。已将结果接入当前打开的Blender并保存，保留用户视角；重新核对面数、UV通道、材质采样、贴图打包及对照场景共享关系。
