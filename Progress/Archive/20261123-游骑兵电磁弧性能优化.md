# 游骑兵电磁弧高频开火性能优化

在 `LVL_CommanderMassPrototype` 的 5.00 秒前台 PIE 客户端采样中，199 个完整帧的平均间隔为 25.009 ms，P95 为 36.219 ms。电磁弧在游戏线程平均独占 2.466 ms/帧。报告按名称汇总的 `spark` 在所有线程上的独占时间合计为 23.554 ms/帧，其中包含并行工作，也可能包括其他资产的同名发射器。该次采样覆盖 CPU。[原始性能报告](../../../PerformanceCaptures/GuLiStrike/20261123-003413-0A94E8CE/report.md)

每个首段和折射段都会在命中端生成一组火花。原环境特效中的 CPU 碰撞与卷曲噪声会随粒子数和存活时长重复执行。正式武器资源采用以下参数。

| 每段电弧 | 修改前 | 修改后 |
| --- | --- | --- |
| 火花数量 | 50～100 | 4～8 |
| 火花寿命 | 0.10～2.00 秒 | 0.10～0.24 秒 |
| 火花更新 | 场景碰撞、卷曲噪声、重力、阻力 | 重力、阻力 |
| 烟雾数量及寿命 | 3～5 个，资产寿命 5 秒，组件回收上限 2 秒 | 1～2 个，0.35 秒 |
| 单次发射窗口 | 闪电和烟雾 1 秒，火花和辉光 2 秒 | 四个发射器均为 0.15 秒，已发射的粒子自然消散 |

VFX 表的 `GroundElectromagneticArc`（ID 72）继续引用项目内的 `NS_GroundElectromagneticArc`。该资产重新加载后，Niagara 编译为 0 错误、0 警告。四个发射器、闪电原材质、生成及更新阶段的起止点绑定均已回读。卡牌安装器重建该资产时会应用同一组参数。[制作脚本](../../Scripts/GroundMech/Rogue/author_electromagnetic_arc.py)

地图已有 `GroundRogue_SplitObserve` 观察点和多目标蓝靶。可在同一席位、相同锁定数、分裂和折射等级下持续开火，再对照平均帧时间与 P95。[场景入口与操作](../DevelopmentDocumentation/20261122-游骑兵分裂枪管与电磁技术.md)
