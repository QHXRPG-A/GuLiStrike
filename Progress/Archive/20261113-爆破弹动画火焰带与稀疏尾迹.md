# 爆破弹动画火焰带与稀疏尾迹

用户采用单条动画 Ribbon 方案。沿用机枪尾迹的世界空间滞留和分段渐隐行为。爆破弹以当前飞行位置插值生成 Ribbon 控制点和烟团、火星，命中或超时后从最后的路径位置继续消散。弹速 168 米/秒，尾迹停留 0.12 秒并渐隐 0.38 秒。

## 资源清单

| 项目目录 | 来源与用途 |
| --- | --- |
| `/Game/GuLiStrike/FX/GroundMech/ExplosivePackage` | 正式 `NS_GroundExplosiveFlight_Loop` 延用 `VFX_Missile_Loop` 弹头与烟团、火星材质。Ribbon 每 100 厘米取一个控制点，烟团每 200 厘米，火星每 400 厘米。移除原 50 厘米间隔的叠加雾层。 |
| 同目录 `M_GroundExplosiveFlameRibbon` | 引用原包的 `T_Stamp_firestand_88`，用 8×8 火焰图集沿固定距离 UV 播放火焰，连续亮芯跨过图集拼接处。色库取 `#8E3A2A`、`#EE9D58`、`#FEE4D9`，使用一层透明、无光照、平面 Ribbon。 |

按单枚可见弹持续飞行至少 0.5 秒估算，尾迹约有 84 个 Ribbon 控制点、42 个烟团与 21 个火星，合计约 147 个，上一版约 835 个。计数只含尾迹。实战帧耗时未测。

材质诊断与 Niagara 编译通过，回读三个尾迹发射器的世界空间、发射间距和插值模式、Ribbon 绑定及正式 VFX ID 63。原图 `/Game/Maps/LVL_CommanderMassPrototype` 的 `GroundAmmo_ObserveDamage`、`GroundAmmo_ObserveExplosion`、靶、墙和验收说明保存后回读。本次修改为材质、Niagara 与制作脚本。[开发记录](../DevelopmentDocumentation/20261113-机枪与爆破弹尾迹修复.md)
