# 僚机动漫爆炸样板制作与接入

新增 `/Game/GuLiStrike/FX/WingmanWeapons/StylizedExplosion/NS_WingmanGroundExplosion_Toon`，奶黄火球、橙红边缘、浅粉灰烟团、扩散环和少量火星。4 个 CPU 发射器，默认配置 22 粒子；320 三角面团块共享，四个材质无贴图采样、无折射和动态灯。修复 Fountain 模板残留的无限循环，改为 Once。

仅将 `DA_WingmanGroundExplosion` 的视觉变体改为新系统，Scale=5、RandomYaw=true、MaximumLifetime=2、AdditionalLayers=[]；保留所有玩法字段、旧两层回退资产和池容量 32。更新部署脚本保留新版，提供 `Scripts/set_wingman_explosion_variant.py` 的 `old` / `toon` 切换入口。未修改 C++ 或自动化测试文件。

源码引擎 `D:/UnrealEngine-5.7` 的编辑器完成 Niagara 零错误、零警告及 4 材质编译检查，安装后读回与部署保护函数通过。纯资产/脚本改动，未运行原生构建。证据位于 `ArtSource/FX/WingmanGroundExplosion_Toon/` 的 `install-toon.json`、`final-readback.json` 和 `frames/`。

原版三类负载各三轮 CSV 已记录，但 GPU 基线漂移明显；新版配对对照未完成，因此不提供提速百分比。主火球外径 ±10% 精测、透明覆盖对照、真实攻击的客户端连续回池与专用服务器动态验证仍未完成。用户要求先总结进入 UE 查看，任务保留部分验收状态。

实施过程曾发生编辑器 GPU 超时；确认没有待保存关卡后重启源码编辑器，用命令行制作草稿并在实时编辑器完成最终编译。没有保存临时截图演员或修改场景光照。
