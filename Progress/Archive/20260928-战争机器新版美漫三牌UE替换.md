# 三张经典美漫牌面接入

用户授权“开始替换UE5当中的资源”，并回答导弹伤害“同时换成此前v7美漫原图”。因此本轮使用ModelComic_v9的FireRate与HighSpeed、ModelComic_v7的MissileDamage。这是制作接入授权，不扩大为最终分层效果通过。

三次内置imagegen按六层模板生成原始RGBA图集，实际输出均1254×1254、3列×2行，每格418×627。生成文件原样复制；完整输入路径、文字prompt、原始输出来源和哈希保存在[生产清单](../../ArtSource/UI/WarMachineTarotCards/ModelComic_v9/Production/manifest.json)与[layer-generation-requests.json](../../ArtSource/UI/WarMachineTarotCards/ModelComic_v9/Production/layer-generation-requests.json)。prompt要求3072尺寸和40%外扩，但未将要求当作实际达成。历史插画prompt与源图不改。

## 变更与配置

新增父材质`M_CelCardParallax_ModelComic_v9`、三份`MI_*_ModelComic_v9`和三张`T_*_Layers_ModelComic_v9`，仅替换专用评审地图的牌面数组。完整机械及附着效果安排同层，主机械置参考深度0；六层深度为0.10、0.04、0、-0.40、-0.75、-1.10，全局4。保留原动态纹样网络；主机械Alpha用平滑阈值，背景RGB作不透明合成，固定窗口裁切与环境扩展保留。

Director保持偏转16°、面积2、厚度2，入场0.5/翻面0.45/闪光0.25/退场0.5秒。卡框、卡背、DT_CardText三行FText身份与原演示默认Moon/Star/Tower均保留。没有修改正式战斗网格或C++。旧材质不删除，替换前绑定JSON可用于回退。

## 技术检查和事故恢复

[集成保存记录](../../ArtSource/UI/WarMachineTarotCards/ModelComic_v9/Production/Inspection/integration.json)为success=true，地图saved=true。随后可选静态预览在2100×900渲染目标上编辑target_gamma，触发引擎>2048尺寸提示；在Slate tick里打开模态窗口导致回调重入，最终WindowsWindow.cpp报Window Creation Failed、Error Code 87。源码阈值与堆栈在[事故记录](../../ArtSource/UI/WarMachineTarotCards/ModelComic_v9/Production/Inspection/preview-incident.json)中记录。事故发生在资产保存之后，非材质编译失败。

预览脚本已在入口停用，未重跑。恢复同一源码版编辑器后，用户关闭恢复包弹窗并允许继续核对。[恢复后磁盘读回](../../ArtSource/UI/WarMachineTarotCards/ModelComic_v9/Production/Inspection/final-readback.json)为success=true：地图重新加载，原4个Actor，临时预览Actor为0；三张新材质与1254贴图、六层参数、FOV50相机和专用GameMode、3行文本、原塔罗默认引用均符合预期。14项相关包及其直接游戏包依赖无缺失，父材质编译无错误；沿用原网络的59采样不代表性能达标。4份本轮脚本语法检查通过，三份图集复制哈希与prompt文件逐字匹配。

静态捕获只有16:9与16:10两份部分输出，没有运行时UMG；21:9、边角姿态、流程与性能未完成/未运行。按用户“不读过程图片，制作完由我核验”，助手没有打开图像、评价画风或代替用户验收。分别记录：技术配置通过；预览批次失败且已恢复；助手视觉检查未做；用户最终美术/操作验收待反馈。
