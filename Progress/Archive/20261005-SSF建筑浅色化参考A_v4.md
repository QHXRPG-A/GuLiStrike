# 2026-10-05：SSF 浅色化参考 A_v4

## 用户指令与本轮结果

用户最新原话：“深色的颜色再浅一些，不要有太深的颜色”。本轮保留此前各建筑不同色系的选择，提亮主体、设备及框架的深色，同步抬高三渲二暗部与线稿颜色。原结构、活动件、7套骨架、22个动画及三档LOD制作预算继续有效；本轮只更新参考设计，不开始成品建模。

| 建筑 | 浅色方向 | 主体/设备/点缀/框架 |
|---|---|---|
| AirBase | 暖橙航空 | `#EE9D58 / #69A6C3 / #FEE4D9 / #9590C6` |
| CloningCenter | 浅粉医疗 | `#EABCBA / #BD93A1 / #FEE4D9 / #B983C3` |
| CommandCenter | 柔莓红指挥 | `#D18B98 / #E3B6B1 / #EE9D58 / #C383A8` |
| MilitaryFactory | 浅钢蓝工业 | `#6DA6BF / #AF91D5 / #EE9D58 / #9590C6` |
| Reactor | 浅青绿动力 | `#2EAEB6 / #6DA6BF / #EE9D58 / #50A3A6` |
| StrategyCenter | 浅紫情报 | `#BC8EC9 / #E3B6B1 / #2EAEB6 / #A58BC7` |

深色在HSL中保持色相并提高亮度，过深辅色适度降低饱和度；[40项原色/派生色记录](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v4/palette_revision.json)明确原卡来源、实际HEX和L*值。主体、设备、点缀基础色目标L*至少65，框架至少62；已亮的色值保留。描线改为`#5F8A9E`，三档系数为`0.78 / 0.90 / 1.00`，内线强度0.35。数值指基础色与着色系数，不将它们误写为每个渲染像素亮度下限。

无人机沿用军工厂浅钢蓝/浅紫/橙色；平台主色`#69A6C3`，灯具辅色和框架一并提亮。共用固定艺术光向及结构线，六套色系维持统一表现。
