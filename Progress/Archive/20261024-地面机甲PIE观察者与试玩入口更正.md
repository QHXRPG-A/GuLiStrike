# 2026-10-24：地面机甲PIE观察者与试玩入口更正

用户在已开启的PIE反馈“我并没有在控制机甲”。预期是控制新版Ground；实际FireReview中的玩家为Observer、Team Unassigned、Pawn为空，视角为SpectatorPawn。会话未启动，错误为`Hybrid requires an explicit valid room identity`。

第一处分歧发生于会话启动，早于角色出生和动画运行：`Source/GuLiStrikeEditor/Private/GuLiLocalPIESubsystem.cpp`的本地地图条件仅接受`/Game/Maps/LVL_CommanderMassPrototype`，旧FireReview的GameMode类映射不能启动协调器/逻辑对端或分配身份。此前“直接在FireReview点运行”的说明不成立；新模型及动画资源检查结论仍有效。

## 修复

- `Config/DefaultEditor.ini`的本地PIE `MainRole`从Commander改为Ground，同步当前编辑器默认对象。
- 保存FireReview，结束失败PIE，切至既有CommanderMassPrototype后重新打开此次游玩。原本地启动器启动自己的协调器与逻辑对端，完成真实席位和角色分配；没有手工Spawn/Possess，也没有绕过Hybrid权威流程。
- FireReview保留编辑器红蓝展示用途；交付说明、README及需求/开发文档更正实际试玩入口。
- 本次未修改模型、动画、蓝图或原生源码，不需要编译。
