# 2026-10-05：SSF 仅深色提亮参考 A_v5

## 用户指令与结果

用户最新原话：“深色调浅，浅色别动”。[上轮A_v4](20261005-SSF建筑浅色化参考A_v4.md)按各角色提高最低明度并抬亮全局三档暗部；本轮以A_v3原色为基准，仅对原深色做提亮，恢复并锁定原浅色、中间色和原三档因子，不再全局抬亮。

| 原浅色/中间色 | 本轮结果 |
|---|---|
| 橙色 `#EE9D58` | 原HEX及三档因子保持 |
| 浅粉 `#EABCBA / #E3B6B1` | 原HEX及三档因子保持 |
| 奶油白 `#FEE4D9` | 原HEX及三档因子保持 |
| 浅蓝 `#6AA4BE` | 原HEX及三档因子保持 |
| 蓝绿中间色 `#0D9099` | 原HEX及三档因子保持 |

本参考用原色L*<50区分要提亮的深色：深紫、深蓝、深青、深莓色和深色框架沿用A_v4的提亮派生值，其余原色保留。此阈值是本参考的实现选择，不是全项目新配色标准。共40项角色中18项改变、22项保持；[原色/输出逐项记录](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v5/palette_revision.json)保存实际HEX。平台原深蓝灰仍提亮为`#69A6C3`，深色描线仍改为`#5F8A9E`；三档因子恢复`0.40/0.72/1.0`，线条强度恢复原`0.45`、平台线`0.48`。

## 实际文件与核对

[完整参考A_v5](../../ArtSource/Buildings/SSFStyle_20261005/Review_A_v5.md)已同步更新42张2048×2048单图、十套4200×4640图板、两张4096×4096原尺寸组合及打包10张纹理的参考Blender场景。六座建筑和配套各用同一原网格、姿态、比例和配色区域；无新生产几何或LOD。

[实际Blender材质节点回读](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v5/palette_preservation_validation.json)检查90个材质，46个受保护浅色材质的基础色以及90个三档色阶与原方案保持；全局曝光0、gamma1。修改深色描线会影响边缘像素，不宣称整张图与A_v3逐像素相同。[助手实际读图](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v5/visual_qa.json)覆盖40核心视图、2补充顶视及2组合，未发现新增视图结构冲突；原阴影层次保留。

[冻结清单](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v5/reference_manifest.json)SHA256为`f3a3d853bef64c1b4fba8132dd3e403a75b201d86401b513deb19769c11f48b9`，80个跟踪文件核对一致；[历史及结构核对](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v5/revision_validation.json)确认A_v1/v2/v3各64文件、A_v4的79文件保持，以及10个网格几何/权重、分件、尺寸、镜像对应和同机位未改。
