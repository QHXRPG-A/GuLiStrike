# 2026-10-24：双枪臂水平总摆幅150°

用户反馈“双手左右可摆动角度限制在150°，现在看着是180°”，本轮解释为每只枪臂相对机体正前方左右各75°。

## 决策与实现

Excel与UE表原已为`GunYawLimit=75`，并直接连接动画图限角输入。参考骨架数据表明枪管各自外偏约23.73°，因此原先约束枪口方向不足以约束枪臂朝向。`AnimNode_GuLiGroundMechAim.cpp/.h`增加最终枪臂水平角限制，限位同时作用于瞄准和非瞄准动画姿态；枪骨保持相对关系随臂转动。该水平修正保留俯仰、枪管旋转与后坐，达到机械边界时以手臂限位优先，射击及提示继续读取最终枪口轴线。

数据仍由`Data/Excel/GuLiStrikeMech.xlsx / Mobility / Default / GunYawLimit`维护，75表示半角。本次不改表值、不重复导出数据、不增加网络字段；配置指纹维持`fec3967f727c6450742b593c38d155df`。W跟随、移速216/432及两倍转身保持。
