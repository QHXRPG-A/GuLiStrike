## 二、演进时间线（每步 = 一条教训）

1. **错误起点**：把 fly-01/02 当目标舰归位并设主控——用户澄清目标是无畏舰裸舰体 + Blender 未导出的重巡舰体。错案记录并入本篇，真实归位见保留的[归位勘误](./20260824-CombatAvatarFly归位勘误-重巡舰体入库与两舰归位.md)。
2. **PIE 舰体偏移根因**：Tuning Default 行 HullMeshOffset(0,0,700) 在 BeginPlay 覆盖蓝图居中补偿 → 相机轨道支点落在舰体内。修法：加 Dreadnought 专行 + BP TuningPreset 接线。
3. **地形穿模**：开 SpringArm 自带探测 + 臂长出舰体半径（当时 15000<半长 45000 嵌船，调 55000）——**此探测后来成为第 12 步的幽灵回撤真凶**。
4. **滚轮缩放**：IA+IMC+C++ ZoomCamera。期间 **Live Coding 加 UPROPERTY 触发 ContainerPtr 断言崩溃**（坐实 LC 不支持新增反射成员），此后一律全量构建。
5. **参数定稿**：8000~50000 默认 15000（用户两次手动调 15000 的偏好被尊重）。
6. **v1 舰心外扫**：轨道球心在舰体空腔内 → 命中空腔内壁，相机停舰内（"卡飞船内部"）。
7. **v2 舰外回扫**：终点=球心在侧影内 → 每向必中舰皮 → 滚轮失效+默认被吸贴面。
8. **（废弃方案）奇偶分段分析**：拆件 FBX 非水密，穿越面可奇数，PIE 掉到 500 兜底。
9. **v3 端点重叠判据**：期望点不压几何体直接用期望值——默认恢复 15000。但它保留的"从期望点向外扫找穿出面"对凸包无效。
10. **凸包资产化（用户方案）**：舰体 flag→SIMPLE_AND_COMPLEX + 凸包分解（自带 1 个凸包是废的）；相机校验命中封闭凸体。
11. **v4 由外向内**：凸包内起步的向外扫掠引擎不报命中（扫掠只报接触/侵入事件）→ 推出改由外向内取最近命中面，推出路径首次 PIE 验证（8000→13748.6）。
12. **间隙与门控**：探针 250→2000（20m，用户定稿"相机距凸包加 20m"）；大半径下整路径扫掠把远处擦碰误当推挤（28000 事故）→ 恢复端点重叠门控（臂路径不需干净，只有端点需要）。凸包精化 15 块（旧 9 块漏后部高塔）。
13. **幽灵回撤真凶**：SpringArm 自带探测独立把相机缩到未验证位置（用户实测点：实际 7518 vs 臂长 15000）→ 关闭自带探测，**单写者纪律**。
14. **v6 命中过滤+两段式**：谓词只认舰/地形（道具彻底不影响镜头，10km 方块内臂长不变对照实验）；两段式短走廊（自身舰必覆盖、密集场景降候选），深插地形退全长保语义。

## 四、踩坑实录（引擎与工具链，跨任务复用）

**引擎语义**
- 凸包内起步的向外扫掠**不报穿出面**；逐三角网格两者皆可——扫掠方向必须由外向内。
- 对象类型查询绕过响应矩阵（QueryOnly+全 Ignore 仍可被扫到）；trace channel 查询则看响应。
- SpringArm 探测 QueryParams 以 GetOwner() 为忽略者（引擎设计），且与自研避障并存时会幽灵回缩——相机变换**必须单写者**。
- UCameraComponent 无逐相机近裁剪面覆盖（那是 SceneCapture 的），走全局 CVar。
- Tuning 行 HullMeshOffset 会覆盖蓝图模板偏移（ApplyTuningRow 语义）。
- unreal.Rotator(a,b,c) 构造参数序**不是** (pitch,yaw,roll)，用 .pitch/.yaw/.roll 字段赋值。
- FOverlapResult 定义在 Engine/OverlapResult.h（World.h 只有前置声明）。
- IMC 运行时只读 DefaultKeyMappings；旧 Mappings 属性已弃用（5.7）。

**工具链**
- Live Coding 加 UPROPERTY/UFUNCTION 必崩（ContainerPtr 断言 + Python 插件线程竞态）→ 流程固定为 taskkill → Build.bat（增量 ~5-9s）→ 重启编辑器。
- 强杀编辑器后重启弹"恢复包"模态框挡死主循环（日志停第 0 帧）→ 对窗口 PostMessage WM_CLOSE（等效跳过恢复）。
- mcpython `add_input_mapping` 写的是弃用属性，需 python 重建 DefaultKeyMappings 数组。
- 修改 `static_materials` 数组元素后回写不生效——必须新建 StaticMaterial 数组整体赋值 + modify()。
- 新建 BP 后 `load_asset` 该资产会挂 Python 插件——绕法：find_object(None, path) 或经关卡实例反查 get_class()。
- execute_python 必须 `print(json.dumps(...))`（不认 result 变量）；UE Array/Vector 不能直接 json 序列化；PIE 期间偶发卡死，停 PIE 即恢复。
- PIE 期间 vision 工具不可用（"No editor world"）；验证走输出日志 + game_world 直读。
