# 2026-09-07 解决了：Ship 僚机以三维往返缠斗替换目标点盘旋

- 对应需求：[Ship僚机三维往返缠斗与随机转向](../RequirementDocument/20260907-Ship僚机三维往返缠斗与随机转向.md)
- 对应开发文档：[技术方案与验证](../DevelopmentDocumentation/20260907-Ship僚机三维往返缠斗与随机转向.md)
- 变更类型：C++、Excel/JSON/DataTable、能力资产、测试与玩法文档。

## 完成内容

- 删除对空 `AirOrbit` 切向盘旋，新增每架独立 `AirApproachFire → AirBreakawayTurn → AirRetreat → AirReturnTurn` 循环；只在接近阶段排队机枪。
- 两类转向每次入口都用稳定种子重新随机左右 40°–90°、俯仰 ±30°，控制点距入口为 2×物理转弯半径；到达/越面或10秒超时后推进。
- 脱离点位于目标到Ship的三维作战走廊：35%–60%纵向、至少450m与避让边界+75m、150m×100m椭圆截面；最多8个FlightNav/WorldStatic安全候选，选中后冻结。
- 无安全候选时单机取消引导并等待1秒；Emergency、Recover、死亡、租约和配置屏障继续优先。Mass Integration仍是唯一运动写入者。
- 目标表改成1500m获取/1800m释放。超距后锁住自动索敌，直到服务器最新Accepted Pose满足向上取整80%存活机进入600m且无人超过900m；姿态缺失/过期不放行。
- 对地俯冲开始后完成冻结一轮，再处理超距归队；10枚/1.5秒、45°路径、固定条带和纯AOE行为保持。
- `WingmanWeapons` 删除Orbit字段并加入明确的脱离/走廊/到达/角度字段；协议升v11，自动机枪预算按25架×2发/秒调整到50发/秒。
- 保留僚机编队、机枪、对地导弹三个独立Ship技能。未来激光采用AirWeapon同槽换技能/Definition/执行器；同种武器数值升级换冻结Profile。
