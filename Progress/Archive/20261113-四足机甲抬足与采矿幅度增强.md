# 2026-11-13：四足机甲抬足与采矿幅度增强

## 动作修改

- 行进抬足设计高度 `0.24m → 0.72m`，逐帧实际采样峰值 `0.23893m → 0.71679m`，对应严格3倍；步距仍为0.72m。机身左右摆幅 `0.026m → 0.078m`、上下摆幅 `0.042m → 0.126m`、俯仰 `1.1° → 3.3°`、侧倾 `0.75° → 2.25°`。
- 按既有腿长重新解算髋、膝和踝，刚性部件整体变换，不把顶点位移直接外推3倍。为保持支撑目标可达，行进躯干支撑基准下移0.24m，足部纵向中心向对应髋部收回原纵向间距的20%；静态场景不变。
- 采矿后移、下压、俯仰和振动均为原参数2倍，设计峰值分别0.68m、0.64m、7°。前足固定支撑位置沿Y收回0.18m，以容纳更大后坐；四足在完整采矿周期保持固定。
- 行进1–29帧、采矿1–73帧、24fps、循环时长与原动作一致。阵营灯随上腿刚性运动，采矿激光起点跟随新炮口，目标点、激活时序和管径保持。
- 根据放大后的全部姿态重新计算描边安全厚度。场景面数不变：行进含地面9866三角面；采矿模型含激光9974，含演示地面9986。
- 打开时为行进第23帧，采矿场景停在第18帧；空格播放。米砂、乳白、深灰配色和阵营灯控制保持v3。
