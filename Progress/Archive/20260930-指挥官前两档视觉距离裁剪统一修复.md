# 2026-09-30：指挥官前两档世界表现不再被旧距离裁剪

用户先要求重防号“LOD第二档也需要显示”，继而明确“200米距离裁剪限制，需要找到所有这种限制，改为仅第三档LOD才限制”。这里的第二档为战术镜头／Reduced，第三档为总览／Minimal，与网格内部LOD索引不同。

## 决策与实现

公共客户端World服务将`ShouldRenderCombatBurst`扩为`ShouldRenderWorldEffect`，复用每帧本地视图缓存；近景和战术档忽略调用者的旧相机距离，总览不准入。任意本地视图允许即可提交，既有逐视图总览遮罩负责分别隐藏。连续特效使用同一策略提供透明度；非指挥官视图保留原调用方距离后备。

| 已发现的限制 | 本轮处理 |
|---|---|
| 重防号CPU 180–200m淡出、GPU尾迹另算200m | CPU接公共档位，GPU读取上传透明度并保留短暂旧尾迹透明度，取消第二次距离计算 |
| 战斗Catalog 200m及枪火两处直接判断 | 弹道、激光、持续枪口、法术场、激活爆炸和导弹后备接公共准入 |
| 单位反馈360m | 受击覆盖、Mass受击闪烁、死亡爆炸及残骸接公共准入 |
| 世界血条距焦点60m、僚机组件360m | 前两档放行，第三档隐藏；僚机转由公共准入与总览遮罩管理 |
| 选择圈可配置正值、已注册特效组件DrawDistance/裁剪体积 | 距离设0并禁止裁剪体积接管，选择圈旧正值配置迁移为0 |
| 两个Niagara EffectType距离开关、RocketJet的5个EmitterState开关 | 关闭正式资产开关，构建脚本同步；RocketJet复制为项目资源后更新VFX10 |
| WM01集群导弹200m/最小屏占比 | 现有代码已对指挥官视图旁路并按总览抑制，保留逻辑，澄清非指挥官后备注释 |

单位本体原已禁用距离裁剪。视锥、遮挡、粒子预算、残骸寿命保持原机制；导航/落地射线、攻击射程、投射物空间网格、网络相关距离和编辑器植被工具默认值属于其他含义。

盘底倒三角绑定、5–15m速度目标、约1秒起步渐长与0.30秒停后淡出保持。正式`NS_WarMachineHoverPool`及两材质原位重建保存，不含预览位移输入。旧构建记录只覆盖之前15m包围盒，不能证明本轮新C++已加载。
