# 地面机枪5Hz弹丸与僚机弹效复用

## 最终决策与交付

- 扫荡者和WM01正式 `Strafe` 使用 `GroundMachineGun` 执行器；开火射程100/150m、射速2/4发每秒、伤害10/7.5不变。没有增加前排开火限制。
- Excel UnitSkills追加弹速12000cm/s、寿命5s、半径15cm，进入生成行类型、最终技能配置、Revision变更判断及发射事件。`StrafeTest`保持即时测试变体。
- 复用公共弹丸池和Damage Ledger，固定方向直线飞行，友军穿透；首个敌方可受伤目标或场景障碍命中后回收。伤害与来源发射时冻结，来源死亡不撤销已发射子弹，目标死亡/出射程不取消，换局清理。
- **用户实施中将地面模拟由30Hz降为5Hz**。池内分域调度并保存各自目标位置历史，地面每200ms扫完整路径，僚机继续30Hz；正常步内走24m，命中结算可能延后约0.2秒，网络与卡顿另计。
- 地面存活状态按5Hz发送自包含批次，每包最多16条；从原公共1Hz快照排除，发射和终止沿用可靠及时批发。客户端连续解析飞行，战局、序号和墓碑防止过期记录复活。公共协议10→11。
- 共用僚机Niagara、材质、光晕、宽度和亮度；地面长度倍率0.6，即18m，内芯宽0.5m，我黄 `(1,1,0)`、敌红 `(1,0.025,0.015)`。僚机30m及我绿敌红保留。地面出生长度不超过已飞行距离，头部跟随弹丸，终止沿用0.04秒消退。
- 保留地面原枪口，新增仅枪口Cue，移除正式机枪的旧瞬时全长弹迹；枪口偏移使用厘米精度压缩。未改地图、僚机参数或WM01主动Q导弹配置。
