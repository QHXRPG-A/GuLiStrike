# 2026-10-24：瞄准限位与身体转向修订

用户反馈：75°后枪口仍尝试随鼠标移动、浮空右键无法转向、W转向近乎瞬时而与右键不同速。

## 实现

- `AnimNode_GuLiGroundMechAim.cpp`：旧版先求无约束旋转再修水平角，会保留随越界目标改变的扭转。本轮解析偏移枪口的水平/俯仰瞄准角，先与枪臂和枪口机械范围相交裁剪，再构造最终旋转，保留相对枪管旋转及后坐。极端姿态仍以最终枪臂限位保护为准；发射沿最终枪轴。
- `GuLiGroundMechCharacter.cpp`：右键瞄准转向不再受落地/未喷气条件阻断；W单独的镜头跟随仍只在地面生效。W和右键全部经同一TurnState及GroundTurnProgress曲线增量推进，不再直接按1080°/秒移动追向；每步以当前目标方向推进并取消末尾直接设置旧目标角度。
- `GuLiGroundMechAnimInstance.cpp`：转身状态时钟也可供移动和空中机体转向使用，但只有地面静止状态播放转身蒙太奇，方向移动与空中姿势继续保留。

数值仍读Excel配置快照，未新建硬编码转速。Gait两侧BasePlayRate保持2，资源长度2.06667秒，完整单步约1.03333秒；MovingTurnRate=1080仅为曲线转速上限。未改表值或网络字段，配置指纹维持`fec3967f727c6450742b593c38d155df`，移动216/432保持。
