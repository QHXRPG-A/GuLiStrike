# 2026-09-16：GPU渲染降耗实施与三组对照

## 变更清单

| 文件/资产 | 变更 |
|---|---|
| Config/DefaultEngine.ini | FXAA、关闭体积雾、VSM精度0/0/1/2、Lumen探针32/16及场景更新64/128；GI异步和VRS保持开启 |
| Config/DefaultGame.ini | 12条材质映射及新资产目录Cook范围 |
| Source/GuLiStrike/Gameplay/Presentation/GuLiUnitRenderPolicy.h/.cpp | 共享材质缓存和5项网格反射排除 |
| Commander/Presentation/GuLiCommanderPresentationActor.cpp | 士兵ISM初始化及表现切换接入 |
| Gameplay/Wingman/GuLiWingmanPawn.cpp | 本地/远端身体配置、传送恢复及池复用接入 |
| Gameplay/Resources/GuLiMiningVehiclePawn.cpp、Gameplay/Building/GuLiConstructionVehiclePawn.cpp | 车辆ChildActor创建/重建及表现更新接入 |
| Gameplay/CombatEffects/GuLiUnitWreck.cpp | 单位残骸继承反射排除，保留效果材质 |

| Scripts/rendering/ | 材质制作、图审计和临时画面预览脚本；没有新增自动化用例 |

上述相对C++路径均位于`Source/GuLiStrike/`。完整精确差异、资产清单和回滚依据位于[交付报告](../../TestResults/CommanderGpuOptimization-20260916/REPORT.md)。

## 决策与结果

A修改前、B全部修改且VRS开启、C全部修改且VRS关闭；各1200单位单客/双客三轮。客户端40秒、共同30秒，1080p/100%、固定镜头，采集关闭后台编辑器，临时MaxAgents=2048；B/C交替执行。

| 场景 | A GPU ms | 最终B GPU ms | 下降 | 最终整帧P95 ms |
|---|---:|---:|---:|---:|
| 单客 | 9.204 | 6.334 | 31.2% | 13.212 |
| 双客C1 | 23.318 | 17.344 | 25.6% | 25.010 |
| 双客C2 | 22.223 | 18.405 | 17.2% | 26.199 |

各列为共同30秒内统计值的三轮中位数。新A基线与前次机器耗时状态不同，收益只与本轮A比较。C双客GPU改善6.28%/9.91%，但单客恶化16.25%，未满足所有组合均改善至少3%的规则，最终保留VRS。

Lumen GI保持异步。TSR、体积雾事件在B/C消失，C的对比度自适应着色事件消失；异步事件跨度不可相加计算收益。Visibility等待下降，既有GPU遮挡查询依赖仍在。

## 验证

- 性能：27份客户端负载全部达标，18轮服务端零丢步；B/C全部18份客户端P95通过原预算，A有1份双客样本超预算。45份运行日志中目标配置正确，无指定运行错误标记。
- 构建：源码UE5.7最终Editor/Game Development均重编成功，引擎/项目/5插件共7份BuildId一致。
- 原有回归：32成功、2成功带提示、3失败。修改前源码实际重编后，同套37项复现相同失败和错误信息；恢复实现后再次构建。早期时间戳造成的未重编对照已作废。
- 材质：4个父材质编译和粗糙度图审计通过，9个MIC参数保持；两类士兵运行时材料/排除标志正确。两类车辆初建/重建各8个网格身体槽正确，采集器发光槽保留。玩家主飞船仍为原材质。
- 画面：同镜头环境和单位陈列对照、4张远距移动抽样已保存。金属高光减弱，FXAA细边缘与降档阴影更粗；未观察到整体单位/照明消失。高分辨率截图打断渲染，不能证明无时域闪烁，动态画质为partial。
- 编辑器：清理临时预览，未保存地图；恢复原关卡/镜头和B配置，无PIE及脏资产/地图。

## 遗留边界

- ShadowDepths未改善：1.136/2.853/2.684ms变为1.167/3.092/3.203ms。VSM精度降低不保证几何和缓存成本下降；地形/环境是后续候选，尚无逐对象成本证明。
- 屏幕空间倒影与Lumen粗糙反射近似仍可能存在；本轮未修改引擎渲染器。
- 建筑定义ID、网络包大小、僚机攻击通道3项既有失败未在GPU任务中修复。
- Development Editor -game与固定镜头短采样不代表Cook/Shipping、长时游玩或全部镜头。
