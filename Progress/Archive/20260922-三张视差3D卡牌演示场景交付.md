# 2026-09-22：三张视差3D卡牌演示场景交付

在 `/Game/GuLiStrike/Cards/RevealDemo` 创建三维卡牌、流程管理器、专用 PlayerController / GameMode、HUD、Enhanced Input、三个自有材质、六个视差材质实例和专用地图。复用现有 ParallaxCardMaterial 的 Moon、Star、Tower 网格与材质，RewardCards 的 `T_CardBG_00` 用作统一卡背；商城源文件保持原样。

地图 `/Game/GuLiStrike/Cards/RevealDemo/Maps/LVL_CardRevealDemo` 已保存。运行时管理器创建三张牌；左/中/右各 0.5 秒入场，第一次点击锁定并用 0.45 秒翻面，第二次新按下触发 0.25 秒局部闪光，再用 0.5 秒共同离场。完成清理后显示重播。根据追加要求，悬停最大角度由 ±8° 提高到 ±12°。

五个蓝图编译为零错误、零警告。已核对材质、资产依赖、相机固定曝光和地图实体配置。真实 PIE 的状态与输入检查见 [运行记录](../../ArtSource/UI/CardRevealDemo/runtime-live.json)；实际视口覆盖 960×540、960×600、1120×480。已保留闪光起始、峰值、消退图片并由助手查看，用户视觉验收单独待确认。

编辑器旧内存包造成预览编译错误，组件重建又触发过生成模板重名断言；修正脚本后通过重启、磁盘重载和重新验证恢复。运行资产没有 Python 依赖，本次未修改或编译 C++。

Windows 部分失焦路径仍有已知限制：鼠标离开牌面能回正，蓝图生命周期回调不能覆盖所有 Windows Alt+Tab 情况。未获得原生接口扩展许可时保持纯蓝图，未将此项记为通过。完成事件已做阶段防重入和广播位置静态核对，未接外部监听器统计次数；未执行打包或 GPU 性能验收。

操作入口、参数、参考图、验证边界与全部截图见[同名开发文档](../DevelopmentDocumentation/20260922-三张视差3D卡牌交互演示.md)。
