# 2026-10-09：15.5FPS压力场景的真实截帧分析

用户明确“直接替换成新特效新逻辑”，并要求对额外600移动单位、500弹丸仍约15.5FPS的场景截帧分析。沿用前次完整计划的指定压力测试授权，本轮从PIE停止状态复现，没有恢复旧代码、缩减负载或更改质量。

## 捕获与关键结果

源码UE5.7编辑器进程72432，`GuLiStrikeEditor Win64 Development`，同进程专服+两1280×720客户端，地图`LVL_CommanderMassPrototype`，固定镜头与质量3，600移动单位、历史混合来源各125弹丸，每客户端32持续工具光束+32枪口/命中预览。接受器时长延至90秒，仅为计时窗后仍可截帧；其他规则保持。热身10秒、有效计时30秒。

| 指标 | 本次证据 |
|---|---|
| 整帧 / FPS | 平均64.328ms / 15.545FPS；P95 88.020ms |
| GT / GPU | 平均64.345 / 16.217ms；GT为当前主瓶颈 |
| 原生样本 | CSV467帧，QPC窗口464个完整引擎帧，人口600/相机一致性通过 |
| 普通真实帧 | 63.574ms；命中特效独占8.887ms，其中事件应用3.043、帧末更新3.910、任务中1.928ms |
| P95真实帧 | 88.021ms；命中特效独占17.389ms，其中事件应用9.883、帧末更新5.303ms；移动7.255ms |
| 全窗热点 | 命中特效GT独占8.174ms、全CPU线程独占15.412ms；这些量不能相加为帧时长 |
| GPU实帧 | Graphics21.930ms，3056Draw/3768Dispatch；Compute2.128ms，不与Graphics求和 |
| Ribbon组 | 两视图分支4.752/4.501ms，共9.253ms、2560Dispatch；Pass无资产身份，不全归给一种激光 |
| 已达预算 | 避障查询平均1.223ms、活动P95 1.926ms；UI稳态发现0，更新/绘制每客户端约0.17–0.24/0.16–0.19ms |

计时后的命中特效分别249/209活跃组件，资产空闲池`MaxPoolSize=32`、无预分配，超空闲池容量时原生池DestroyComponent。边界快照间新增25,512次创建、25,431次结束，可靠队列1462→1912，说明“500活弹目标”同时伴随高频命中/补充与网络事件。池扩容收益尚未测量。无资产非活跃Niagara对象盘点包含已销毁待GC对象，不能据此认定泄漏或在模拟。

## 下一轮优先项与边界

优先给命中特效补齐真正新建/复用/完成计数并比较池与批次；保留Ship物理Actor/ProjectileMovement/NotifyHit，验证生命周期完全复位和Actor复用；复用飞行批次解码/应用容量；按用途隔离GPU Ribbon并减少生成/排序调度。保持可靠创建/结束16条/1000字节、伤害结算顺序、视觉轮廓/事件/随机序列和原寿命。**本轮没有实施这些追加修复，也没有把诊断写成新的性能提升。**

检查两个命中入口后，现有生产端Linear/Projectile与Catalog标志组合走不同播放分支；没有证据支持本场景重复播放，未据两个函数名字直接认定重复。CPU等待Scope与执行嵌套任务分开，不将inclusive反复累加。
