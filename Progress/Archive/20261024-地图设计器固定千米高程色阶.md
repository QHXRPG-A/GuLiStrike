# 2026-10-24：地图设计器固定千米高程色阶

用户进一步指定“最低是−500米，最高是500，然后色值和高度线性变化”。`Tools/MapDesigner/src/height-colors.ts` 改用固定厘米常量−50000至50000，`t=(高度cm+50000)/100000`；保留已指定的蓝→青绿→黄→橙→红色阶，各段按高度连续线性插值。范围外显示端点色，同高度始终同色，平坦地形也不再自动使用最低色。
