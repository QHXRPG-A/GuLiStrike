# 2026-10-05：SSF 两座局部提亮参考 A_v6

## 用户指令与具体基准

用户附图并明确：“以你刚刚调的这一版为准，军工厂和战略中心的深色需要调浅，其他别动”。实际附件3000×2850与已冻结A_v3总览像素一致，复制为[选定附图](../../ArtSource/Buildings/SSFStyle_20261005/Inputs/SelectedBaseline_A_v3_20261005.png)，附件SHA256为`c12f4ddf20e1a275b947d617420120e93e800f913f3820cd943ed1f9aa8513f2`。[基准确认](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v6/baseline_selection.json)记录原话和像素核对结果。

本轮读取冻结A_v3的实际Blender场景，保留六套原配色，只提亮以下四项深色角色：

| 资产/角色 | 附图A_v3 | A_v6 |
|---|---|---|
| MilitaryFactory 设备 | `#2A104B` | `#9972CA` |
| MilitaryFactory 框架 | `#1A182F` | `#756FB5` |
| StrategyCenter 主体 | `#522C5C` | `#AA6EB9` |
| StrategyCenter 框架 | `#2A104B` | `#8A67B6` |

两座浅蓝、橙、浅粉、蓝绿色保持原样；空军基地、克隆中心、指挥中心、反应堆、平台、灯柱、灯片和无人机保持A_v3。无人机本轮不随军工厂提亮，“其他别动”覆盖此前跟随军工厂改色的默认方案。原描线`#1A182F`、三档因子`0.40/0.72/1.0`、光向、线条强度与曝光不改；平台仍为原蓝灰`#274E61`。A_v4/v5原样归档，不继续其全面提亮范围。

## 实际交付与核对

[完整参考A_v6](../../ArtSource/Buildings/SSFStyle_20261005/Review_A_v6.md)包括42张2048×2048单图、十套4200×4640图板、两张4096×4096原尺寸组合、建筑/配套总览及打包10张纹理的原生参考Blender场景。仅重渲染两座的8张视图和2组合；其余八资产的34张原始视图复制自A_v3且SHA256一致。完整图板重新标注版本，不声称图板文件与A_v3字节相同。

[实际限定修改核对](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v6/scope_preservation_validation.json)检查90个材质图，5个改变、85个相同；5个是上述四项角色和军工厂设备的Pink别名。其他八资产72个材质图完全相同。[保存后Blender回读](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v6/palette_preservation_validation.json)检查实际材质RGB、三档色阶及全部90个图签名。

[历史与结构核对](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v6/revision_validation.json)确认A_v1/v2/v3各64个、A_v4的79个、A_v5的80个冻结文件不变；10资产源几何/拓扑/权重、尺寸、角色分区、镜像关系、机位及组合布局与所选A_v3保持。[助手实际读图](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v6/visual_qa.json)覆盖40核心视图、2补充俯视和2组合；军工厂与战略中心图板另行放大检查。
