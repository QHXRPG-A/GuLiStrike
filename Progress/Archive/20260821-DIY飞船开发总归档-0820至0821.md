**③ 相机模型三步演进（0820 深夜）**：鼠标只控制相机不转飞船 → 相机 AbsoluteRotation 完全独立于飞船姿态（坑：程序化设 Inherit 开关不会自动转绝对旋转，须显式开启）→ 修复镜头歪斜（unreal.Rotator() 参数顺序与直觉相反，误把滚转设成 -18°；教训：Python 改 Rotator 一律逐字段设值）。

**④ 巨型舰机动调校（0821）**：全面调重参数（极速 2000→1200 基准、加速 800→400、刹车 200→60、滚转 90→30°/s）；修复按 S 原地打转（根因：自动转向追速度方向的正反馈循环；修复：追推进意图 + 前向余弦阈值）；Q/E 从滚转改为偏航转向；修复偏航漂俯仰（根因：绕被压弯倾斜的局部上轴旋转=圆锥运动；修复：改欧拉 yaw 分量）；最终控制定稿：W+侧移纯平移+侧移压弯、Q/E 偏航、自动转向默认关闭；**UBT 编译静默崩溃破案：中文文件名 + git quotepath 默认转义，UBT 拿带引号路径硬崩，`git config core.quotepath false` 根治**。

## 关键经验教训（跨条目沉淀）

1. **Live Coding 新类/结构体 = BP 数据地雷**（反射不完整 + CDO 序列化数据被清）；全量编译+重启是唯一安全路径
2. **UE 项目含非 ASCII 文件名必须 `core.quotepath false`**，否则 UBT 全量编译崩（GitSourceFileWorkingSet 拿带引号转义路径硬崩，日志缓冲丢失造成"死在 git-status"假象）
3. 5.7 Python 建输入映射必须 `map_key()`；弃用的 mappings 属性运行时不认
4. Python 改 Rotator 一律逐字段 set_editor_property；位置参数构造器参数顺序与直觉相反（两次踩坑）
5. 程序化设 SpringArm 继承开关不会自动转绝对旋转，须显式 SetUsingAbsoluteRotation/bAbsoluteRotation
6. "只改一个轴"的旋转需求优先改欧拉分量而非局部四元数旋转（局部轴被其它姿态分量带歪时尤甚）
7. BlueprintNativeEvent 不支持 const 签名（_Implementation 与调用处指针都要去 const）
8. DestroyComponent 触发的销毁回调用"先注销再销毁"防重入
