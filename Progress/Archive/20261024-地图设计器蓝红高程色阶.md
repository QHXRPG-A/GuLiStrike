# 2026-10-24：地图设计器蓝红高程色阶

用户要求“从蓝到红，从低到高”，并询问海平面是否为0。沿用项目校验：世界Z＝0厘米即0米为海平面基准，据点地面必须高于0米。该基准与按全图高度范围动态变化的色阶分开说明。

`Tools/MapDesigner/src/height-colors.ts` 统一二维Canvas、三维顶点和图例的颜色，使用[项目统一色库](../RequirementDocument/GuLiStrike美术规范.md#11-全项目统一色库v192026-10-08)的蓝→青绿→黄→橙→红色阶。两视图采用相同归一化范围，平坦地形使用低端蓝色；三维按sRGB输入转换到其线性色彩空间。Canvas图例标注低/高高度与海平面0米。[使用说明](../../Tools/MapDesigner/README.md)和需求、开发文档已同步。
