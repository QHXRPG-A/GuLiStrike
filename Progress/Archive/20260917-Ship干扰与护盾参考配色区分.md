# Ship干扰与护盾参考配色区分

用户要求“点子干扰器和混沌发生器和CIWS 色系做一下区分，这三个色系太一致了，CIWS 不改”。按本批既有资产理解为电子干扰装置与护盾发生器，局部调整原参考的功能色。助手提出紫晶紫与叶绿作为待审候选，不能将这些具体颜色写成已通过的规范。

| 资产 | 旧参考 → 新参考 | 本轮调整 |
|---|---|---|
| Electronic_JammingDevice | v1 → v2 | 青蓝阵面及前盖板改紫晶紫，目标基色 `#8B609E`；浅框、深色背面和钢色背筋保持。 |
| Shield_Generator | v2 → v3 | 青蓝核心及两个小模块改叶绿，目标基色 `#65955D`；中央大斜面保持浅甲，背面中脊保持深色。 |
| CIWS | 已审成品v4保持 | 青蓝 `#348B9F` 不改，源文件、材质及交付物无写入。 |
| Drone_LaunchBay | 参考v2保持 | 赭黄及用户指定方向的僚机飞出标识保持。 |

使用内置image_gen分别编辑两张现有图板，效果图与正/侧/背对应色区一致，几何轮廓、浅甲、深结构、细框线和三渲二光影沿用。生成结果原样复制到项目，新旧版本并存，未用程序重绘图板。

- 护盾v3：`a20b6a31eb7915dda05ad9d0300a0bd6fd1b4325ae7c834ec08dce7f429a8312`。
- CIWS效果图前后一致：`0a784b590ef27ef0d0dbb696d7bfaef6ea27c596747b02bfa1f365dfefd67387`。
