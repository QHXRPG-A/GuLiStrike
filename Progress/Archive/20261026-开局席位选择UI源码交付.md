# 2026-10-26：开局席位选择UI源码交付

用户要求开局显示简易UI选位置，并明确回复“选择操控席位”。当前原型图本地PIE固定读取MainRole=Ground，本轮改为交互式开局先显示三个现有席位，确认后继续原对局启动；不涉及地图出生点选择。

## 实施

- 新增编辑器私有`GuLiLocalPIERolePicker.h/.cpp`：三个选项、当前选择、进入战场及取消。Slate模态窗口接管输入，关闭后恢复焦点；角色区可滚动，Esc和窗口关闭均取消。
- `GuLiLocalPIESubsystem`在会话目录、Coordinator和逻辑端创建前取得选择，只修改本次启动Config.Role；同编辑器会话记住上次确认项。
- `bPromptForRole`与DefaultEditor.ini默认开启选择。关闭时使用MainRole，无人值守调用及模拟模式维持已有入口，不强制打开窗口。
- 不新增运行时角色、RPC、出生点或兵种字段，不改飞船、僚机及地面/低空移动规则。界面中的游骑兵为Ground玩家席位，不是重防号WM01。
- 按项目色库使用深绿背景、青蓝选中状态和浅色文字；窗口不受场景渲染环境影响，未新建贴图或图标资产。

完成入口执行顺序、取消分支、角色路由、控件与焦点生命周期、既有模块依赖及本机UE5.7 API声明核对；差异格式和场景脚本语法检查通过。未编译、未运行游戏或自动化测试、未截图或读图。
