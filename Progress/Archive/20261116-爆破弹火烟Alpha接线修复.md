# 爆破弹火烟 Alpha 接线修复

玩家反馈第二版样片显示黑块，怀疑贴图没有加载。实际 SM6 编译日志报 `vector swizzle 'a' is out of bounds`。火烟材质使用程序遮罩，先前的 Custom 节点将 Particle Color 默认的 RGB 输出当作 RGBA 使用，UE 因编译失败回退到默认材质。前一份候选记录的 Niagara 粒子数据仍有效，材质图检查未覆盖实际渲染着色器的编译完成状态。[第二版记录](20261116-爆破弹白灰弹体与火烟候选.md)

制作脚本将 Particle Color 的 RGB 与 Alpha 分别接入 Custom 节点，并等待平台着色器编译后核对像素着色器指令数。重新加载火烟材质后，读取到 193 条代表性像素着色器指令、0 次像素纹理采样。弹体、喷口、火烟三套材质均有编译结果，日志无修复后新增的候选材质回退错误。回读 FireSmoke 渲染器使用本次保存的材质。Niagara 编译通过。[制作脚本](../../Scripts/GroundMech/Rogue/author_explosive_toon_flight.py)

修正后重新由 UE 导出侧视和斜后视共 166 帧，拼入原参考图并编码为 1920×768 的 H.264 样片。等待玩家审核第三版，正式 VFX ID 63 接入与实弹测试继续按原方案安排。[第三版对照样片](../../Artifacts/GroundExplosiveToon_20261116/GroundExplosiveToon_Review_v3.mp4)
