# 爆破弹火烟尾迹按距离发射

用户反馈首轮爆破弹观感仍有差距，并询问弹速的影响。原版 `VFX_Missile_Loop` 预览的默认初速度约 5 米/秒，实战爆破弹为 168 米/秒。60 FPS 下，实战弹头每帧前进约 2.8 米，按帧生成的火烟粒子容易断开。

VFX ID 63 的 `NS_GroundExplosiveFlight_Loop` 现以 `SpawnPerUnit` 为四层尾迹生成粒子。火焰和 Ribbon 间距为 35 厘米，火星 45 厘米，烟雾 50 厘米。原渲染器及材质继续使用。粒子在前后帧位置之间插值出生，以世界坐标停留并按 0.12 秒停留、0.38 秒渐隐的配置消散。实战弹速仍为 168 米/秒。

已编译并保存 Niagara。回读四个发射器的间距、100% 出生概率、插值模式、世界空间和渐隐绑定，并确认 VFX ID 63 指向同一正式资源。复用 `/Game/Maps/LVL_CommanderMassPrototype` 的 `GroundAmmo_ObserveDamage`。本轮为 Niagara 与制作脚本修改，实战画面和性能待后续验证。[开发记录](../DevelopmentDocumentation/20261113-机枪与爆破弹尾迹修复.md)
