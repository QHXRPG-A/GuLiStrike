# 2026-09-11：飞船骨骼部件沿用原安装 Socket

用户要求修改 `BP_CombatAvatarFly01` 对应装配系统，使骨骼炮台能挂接到已手工设置的舰体 Socket，并保证原 Socket 完整保留。

## 变更

| 文件／资产 | 结果 |
|---|---|
| `GuLiStrikeShipPartComponent.h/.cpp` | SceneComponent管理安装与行为，创建静态或骨骼视觉子组件，公开网格和Socket查询接口 |
| `GuLiStrikeWeaponPart.h/.cpp` | 新增可选MuzzleSocketName；相对炮口变换与服务器安装变换组合，空名沿用MuzzleOffset |
| `GuLiStrikeShip.cpp` | 卸旧件前检查新视觉网格注册就绪 |
| 4个BP_Engine／BP_Weapon部件 | 从快照恢复原网格、材质、渲染配置、兼容槽位、安装偏移和数值后保存 |
| BP_GuLiStrikeShip、BP_CombatAvatarFly01 | 编译和保存，原装配目录与默认装配保留 |
| `Scripts/migrate_ship_part_visuals.py` | 不覆盖基线的快照、一次性迁移和可重复的只读数据校验 |

当前无畏舰49个安装Socket、7个骨骼炮台16个炮口Socket、Thor导弹舱及燃烧弹舱10个原静态Socket，共75个Socket逐项一致。25个受保护网格文件的大小和修改时间也与基线一致，本次没有保存网格或Skeleton资产。

## 配置入口与边界

在武器部件蓝图默认值中选择 `VisualType=SkeletalMesh` 和 `SKM_SC_*` 网格，`CompatibleSockets`继续填写现有舰体槽位。默认装配使用原 `SocketName + PartClass` 接口。静态网格编辑器的 `PreviewStaticMesh` 字段仍仅做静态预览，骨骼部件通过组件挂接。

`BP_CombatAvatarFly01.DefaultParts`仍为空，原4项`PartCatalogue`保留。本次未把用户组件系统文档中的升级组装方案自动应用到飞船，未改外部学习文档。配置步骤和路径说明见[使用说明](../../outputs/ship-part-visual-migration/README.md)，设计记录见[开发文档](../DevelopmentDocumentation/20260911-飞船骨骼部件与Socket保留.md)。
