# 机枪与爆破弹尾迹实装

游骑兵初始弹按每个世界位置计算停留与渐隐。30 米长度控制亮段，残迹按各点的年龄继续消散。指挥官机枪的 GPU 批量尾迹同时按实际存活的路径计算可见范围。

## 资源清单

| 项目目录 | 来源与用途 |
| --- | --- |
| `/Game/GuLiStrike/FX/BulletTrails/Review_A1` | 更新正式材质 `M_GroundBulletTrail_Orange` 和 GPU 系统 `NS_MassBulletTrail_GPU`，共用现有批量槽位与颜色。 |
| `/Game/GuLiStrike/FX/GroundMech/ExplosivePackage` | 从 `/Game/Assets/VFX/WeaponBulletVFX/NS/VFX_Missile_Loop` 派生 `NS_GroundExplosiveFlight_Loop`。保留弹头、火焰、烟雾、火星和 Ribbon 的原材质，实战弹头位置驱动尾迹出生。CPU 渐隐使用三次多项式。命中爆炸继续由 VFX ID 64 负责。 |
| `/Game/GuLiStrike/Data` | `DT_GuLiStrikeVfx_Effects` 回读 65 行。Excel、JSON 和 UE 表同步，62 更新说明，63 切换资源及说明。 |
