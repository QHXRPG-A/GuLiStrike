# 资源加工厂 UE 正式资源接入与验收

资源根为 `/Game/GuLiStrike/Buildings/ResourceProcessingFactory/`，可放置蓝图为 `Blueprints/BP_ResourceProcessingFactory`，演示地图为 `Demo/LVL_RPF_Showcase`。

主体 99,600 三角面，Nanite 开启，9 个分段凸碰撞。门 10,612 三角面、3 级 LOD，刚性铰链骨骼对应 Kinematic 薄盒 PhysicsAsset。主体和门各 3 个材质槽；材质 Nanite / SkeletalMesh 使用标记显式保存并从磁盘重新加载确认。

正式接口包含 OpenDoor、CloseDoor、DoorDuration、GetDoorAlpha 纯查询、OnDoorOpened / OnDoorClosed、EntryPoint / UnloadPoint。DoorAlpha 私有存储；Timeline 正反采样开门动画，在当前位置反向。同方向重复调用不重置。独立演示控制器负责循环和完成事件计数。

现场观察确认：半开 Alpha 约 0.5，反向调用前后采样时间没有变化；实际抵达开启终点 2 次、关闭终点 3 次，事件计数对应一致。全开时角色胶囊和 10×7×5m 车辆尺寸代理可穿过门洞，关闭时命中门碰撞；地板、侧墙和后墙正常阻挡。1.5 秒自定义时长也已检查，随后恢复默认 3 秒。

使用 `D:/UnrealEngine-5.7/Engine/Binaries/Win64/UnrealEditor.exe`（5.7.4）完成导入、PIE、截图和重新打开。重开后所有演示实例 Scale 1、默认关闭；两个蓝图编译 0 错误 / 0 警告，最终地图检查 0 错误 / 0 警告。无 C++、Build.cs 或原生插件修改，因此本次不触发原生编译门禁。

本机空关卡也出现 DX12 GPU 等待；使用进程参数 `-ini:Engine:[SystemSettings]:r.D3D12.AllowAsyncCompute=0` 后普通窗口与离屏渲染均可用。未修改项目的渲染配置。图形资产保存与地图生成分阶段执行，避免同步 MCP 导入和启动阶段缩略图等待。

交付源在 `ArtSource/Buildings/ResourceProcessingFactory/`。证据在 `outputs/resource-processing-factory-20260909/`：七张 UE 截图、六张 Blender 图、两个开关门 MP4，以及 `ue_runtime_observation.json`、`ue_reload_report.json`、`ue_asset_readback.json`、`ue_capture_report.json`。UE 视频为 90 张真实引擎画面组成的 1280×720、10 fps、9 秒短片。

可重复执行 `Scripts/build_resource_processing_factory_ue.ps1`；Blender 建模、导出、预览和 UE 截图脚本均已交付。没有新增自动化测试文件。建造菜单、加工经济、联网和车辆玩法均未扩展。
