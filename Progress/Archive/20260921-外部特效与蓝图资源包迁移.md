# 2026-09-21：外部特效与蓝图资源包迁移

## 变更清单

- 新增 [外部资源目录](../../Content/Assets/ExternalPacks)，按原资源包隔离为 7 个一级文件夹，避免不同包的 `StarterContent`、材质和纹理同名冲突。
- `Skill002_JG_D` 的 World Partition 示例地图同时迁入 `Content/__ExternalActors__/Assets/ExternalPacks/Skill002_JG_D` 与 `Content/__ExternalObjects__/Assets/ExternalPacks/Skill002_JG_D`。
- 更新 [进度归档 skill](../../.agents/skills/gulistrike-progress/SKILL.md)、[归档模板](../../.agents/skills/gulistrike-progress/references/templates.md) 和 [归档策略](../../.agents/skills/gulistrike-progress/references/archive-policy.md)：以后从项目外部迁移资源时，归档必须附按最终文件夹整理的资源清单。
- 外部下载目录及 7 个源压缩包保持原样；未移动、删除或覆盖原文件。

## 决策与实现

这些资源原本使用 `/Game/VFX`、`/Game/StarterContent`、`/Game/ParticleShockwave` 等根路径。若直接把二进制包复制到 `Content/Assets`，内部软硬引用仍会指向旧包名。迁移因此在隔离的 Blueprint-only UE5.7 临时项目中完成：先用 AssetTools 批量重命名所有相关根目录，再用原生 `ResavePackages -fixupredirects -IgnoreChangelist` 修复引用，最终只复制重定位后的成品。

多个根目录有交叉依赖的资源包在同一次批量重命名中处理；各包自带的 `StarterContent` 保留在自己的一级目录下，不与项目或其他资源包共享。迁移过程只检查压缩包路径、文件元数据和 Unreal Asset Registry，不直接读取 `.uasset`、`.umap`、`.uexp`、`.ubulk` 或 `.pak` 内容。
