# 2026-10-05：SSF 六套独立配色参考 A_v3

## 用户决定与本轮结果

用户最新原话：“这些建筑色系是不是太单一了，希望每个建筑都是不同的色系，在参考色系中去选然后组合”。本批原统一奶油白＋蓝绿主体被新的六套配色替代，三渲二、结构线、完整结构、22动画及三档LOD制作范围继续有效。[上轮基线归档](20261005-SSF建筑参考A与结构基线交付.md)记录当时共同配色方案，原文与冻结参考保留。

| 建筑 | 新色系 | 主体/设备/点缀/框架 |
|---|---|---|
| AirBase | 暖橙航空 | `#EE9D58 / #274E61 / #FEE4D9 / #1A182F` |
| CloningCenter | 浅粉医疗 | `#EABCBA / #835061 / #FEE4D9 / #45184D` |
| CommandCenter | 莓红指挥 | `#A34053 / #E3B6B1 / #EE9D58 / #662249` |
| MilitaryFactory | 钢蓝工业 | `#6AA4BE / #2A104B / #EE9D58 / #1A182F` |
| Reactor | 青绿动力 | `#0D9099 / #6AA4BE / #EE9D58 / #032E30` |
| StrategyCenter | 紫色情报 | `#522C5C / #E3B6B1 / #0D9099 / #2A104B` |

所有色值均来自用户三张原色卡；无人机跟随军工厂，平台用蓝灰衬托整组建筑。固定光向、三档明暗、结构内线和外轮廓共用，颜色不同仍保持统一表现。

[技术检查](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v3/validation.json)记录原尺寸、源面数、几何和权重摘要及同资产统一正交尺度；[修改核对](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v3/revision_validation.json)比较旧版本文件哈希、同机位和结构分色区域，确认只更新色值及配色标注。[助手视觉检查](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v3/visual_qa.json)记录实际读图覆盖和边界，不构成用户A决定。
