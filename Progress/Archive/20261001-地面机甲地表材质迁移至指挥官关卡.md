# 2026-10-01：地面机甲地表材质迁移至指挥官关卡

## 决策与变更

用户指定将 `/Game/Maps/LVL_GroundMech_Demo` 的地面材质移入
`/Game/Maps/LVL_CommanderMassPrototype`，随后选择“按目标地形自动适配”和“仅迁移地表材质”，
并明确要求实施完整方案。此次复用既有松树林地表资源，不制作新模型或改变项目美术规范 v1.2。

| 对象或资产 | 最终变化 |
|---|---|
| `Landscape_2300`（对象名 `Landscape_1`） | 绑定目标专用材质实例，全范围填充自动层 |
| `/Game/GuLiStrike/Environment/Materials/MI_CommanderGround_Pine` | 新实例，以源 `MI_Landscape` 为父，仅覆盖 `Spawn_Grass? = false` |
| 绘制层 | 注册源六层，保留旧三层注册与资源；`AutoLayer=1`，其余八层为零 |

源实例完整路径为 `/Game/StylizedPineEnvironment/Assets/Materials/Landscape/MI_Landscape`，
LayerInfo 复用 `/Game/StylizedPineEnvironment/Assets/Misc/LandscapeLayerInfo` 中的对应资源。
使用项目现有 `GuLiLandscapeAuthoringLibrary` 注册持久化层并一次导入全部九层，
避免只修改 LandscapeInfo 缓存或逐层归一化导致保存后数据失效。

任务开始时目标关卡已有未保存改动；已先单独保存该目标关卡并备份当前状态，
同时保留原磁盘版备份、旧三层权重 PNG 与高度 PNG。源资源未被覆盖。
保存范围仅为目标地图与新实例，没有使用 SaveAll。

- 目标仍为 `4081 × 4081` 顶点、256 个地形组件。全部 16,654,561 个高度样本逐像素一致。
- 全部九层逐像素核对：自动层全部为 255，其余层全部为零；材质引用、父级及草簇开关读回正确。
- 257 个 Actor 的类型、变换，既有植被实例，地形边界及碰撞配置与原基线一致。
- 新材质包及目标地图已实际重载；材质引用、关闭的草簇开关、九层注册和权重均保留。
- 俯视、地面和既有指挥官 300 米观察镜头截图经助手检查，无默认网格、黑块或异常组件接缝。
- 原视口位置、旋转、FOV、曝光、显示模式和 Game View 已恢复；目标重新保存后无脏包。
- 源地图、源实例、母材质及源 LayerInfo 的文件大小和修改时间一致；未读取 UE 二进制内容。
- 未修改原生代码，未执行原生构建、PIE、Standalone 或性能测试。当前编辑器检查不代表玩家实战终验。
