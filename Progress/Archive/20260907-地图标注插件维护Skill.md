## 做了什么

创建项目内自动发现的 `$guli-map-authoring`，用于后续回答和执行以下任务：地图标注面板使用、配置类型和 Property Bag 字段、多个命名区域及四种几何、JSON/CSV 输出和 Python API、插件故障诊断、源码维护、原生扩展、构建测试与交付归档。

Skill 采用渐进加载：主入口只保留路由与不可破坏的合同，具体内容拆成四份参考。普通使用不会默认加载 C++/发布细节；改格式、排崩溃或扩展形状时才加载对应知识。

事实源顺序明确为当前源码/API → 用户 README → 开发方案 → 历史归档 → Skill 摘要。这样未来插件代码变化时，不会用过期 Skill 反向覆盖真实实现；每次维护须同步受影响参考。

维护规则中特别保留了项目的安全边界：不在正式地图做破坏性复现、不遍历禁止目录、不读取 UE 二进制资产内容、程序化更新和导出不允许部分成功、原生变更使用源码版 UE5.7 构建并核对三方 BuildId、新增/扩充自动化测试前需取得用户明确许可。
