# 游骑兵快速回镜

卡号 13.01 的 `CastCameraReturnSeconds` 从 0.70 秒调回 0.20 秒。镜头从第 78 帧沿左肩绕回，第 81 帧左肩首发，第 90 帧交还玩家视角。特效时间刻度由 `CastCameraReturnCueSeconds` 单独保存，画面白闪在第 80 帧达到 0.91，第 84 帧归零。
