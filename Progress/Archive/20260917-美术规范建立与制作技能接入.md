# 2026-09-17：建立项目独立美术规范

## 用户决定与规则

用户要求建立《GuLiStrike 美术规范》，模型默认线稿与三渲二；制作流程为需求出参考图、用户过审、Blender一比一还原且不能过度简化、用户审核成品、最后导入UE。用户同时要求清理本会话临时文件，保留两台兵种的非三视图效果图作为UI资源，并补充强调保留战争机器参考。

当前规则集中于[美术规范v1.0](../RequirementDocument/GuLiStrike美术规范.md)，维护和审核入口为[开发台账](../DevelopmentDocumentation/GuLiStrike美术规范.md)。新默认不撤销资产例外：扫荡者当前仍无线稿，战争机器保留内线与外轮廓，Ship保留内部遮罩和独立描边。颜色按资产设计，不要求模仿Ship配色。

收录八张已审兵种设计、战争机器五张后续细化参考、Ship风格锚点和爆炸参考；明确设计通过、成品视觉通过与技术导入通过是不同事实。战争机器背舱以平行、前上45°为装配目标，外撇后视保留为历史冲突参考。

爆炸规范定义奶黄亮核、橙红热边、可读的浅灰粉块状烟团、少量火星和清晰扩散环；强调真实烟火形态变化与完整消散节奏。保留NS03/05/01的现有专属约束及地面摧毁0.6调整；粒子数减少不能充当性能通过证据。灯光以实际游戏镜头中单位、暗部结构及烟火可读为准。

## 技能接入

| 技能 | 本次变化 |
|---|---|
| `guli-model-production` | 制作前必读规范，按审核参考还原；默认线稿/三渲二，保留凸曲面和机械细节，实际Blender成品过审后导入。 |
| `ue5-vfx-production` | 制作前必读规范与爆炸标准；专用网格遵循Blender流程，纯Niagara/材质先做隔离可播放候选，经对应审核后替换正式引用。 |
| `ue5-scene-building` | 制作前必读规范，以实际Ship/指挥官机位验收；已有过审资产不重复建模，保存仅限本任务目标。 |
| `gulistrike-progress` | 维护规范版本、变更、资产例外与A/B审核依据；技术成功不能自动升级为美术通过；清理时保护UI原图与参考。 |

模型旧PBR实例和地编通用人眼机位说明已补充项目规范优先关系。`Progress/README.md`增加唯一规范入口，未复制多套风格正文。
