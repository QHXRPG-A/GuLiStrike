# 直线弹丸交火复测

用户授权采旧版、编译、必要时重启编辑器并同场复测。旧编辑器在结束全部测试房间且确认地图、内容均已保存后正常关闭。源码版 `D:/UnrealEngine-5.7` 构建 `GuLiStrikeEditor Win64 Development` 返回 0，UBT 用时 125.76 秒。引擎、项目与 GuLiFrameProfiler 的 BuildId 均为 `ec746d14-0746-471d-9ee9-2dfd468f881d`。游戏模块旧版 SHA-256 为 `46f13722648438d75aecd5918b6e3e0ce88074898cd288251efaeee5978ac2e2`，新版为 `fa2992ca4ff3f5e10772d4a755b8ee111fa207c27c8f17037a3a52bc3f609a92`。已回读重启进程加载的模块路径。

## 采样条件

- 正式地图 `/Game/Maps/LVL_CommanderMassPrototype`，相同 600 单位清单，各轮独立房间。前台 PIE 视口 1292 × 997，编辑器主窗口最小化，摄像机高度 133.4 m，采样前后位置与角度一致。
- 逻辑 Tick 480–481 附近开始采样。每个版本 3 个 5 秒窗口，每轮都检查原生采集完整性和前台计数。旧版三轮共 905 个弹丸共享步，新版 901 个。
- 碰撞、发布及线程范围使用原生 CPU Trace。出生、命中、回收计数取包住采样窗口的池快照，以快照自己的墙钟时间折算每秒。不同房间保留真实伤害和各自战斗进程。

## 复测结果

| 直线弹丸游戏线程 | 旧版 | 新版 | 降幅 |
|---|---:|---:|---:|
| 每帧平均 | 0.646 ms | 0.407 ms | 37.1% |
| 每帧 P95 | 4.531 ms | 3.433 ms | 24.2% |
| 窗口最大值 | 12.767 ms | 6.439 ms | 49.6% |
| 每逻辑步平均 | 0.769 ms | 0.518 ms | 32.7% |
| 单次发布尝试 | 13.18 µs | 3.60 µs | 72.7% |
| 单次实际私有编码 | 8.61 µs | 3.51 µs | 59.3% |

每轮旧版 → 新版的弹丸 P95 分别为 4.315 → 3.302、4.596 → 3.624、4.628 → 3.536 ms。合并 P95 取全部完整帧的最近秩。同期整帧平均从 13.914 降到 13.062 ms。整帧包含本次优化范围以外的工作。

旧版 46,654 次尝试全部编码；新版 48,633 次尝试中 37,379 次因发布资格未就绪而提前返回，实际编码 11,254 次。新版编码拒绝、队列拒绝均为 0。碰撞扫掠总数分别为 53,036 和 52,804，单次扫掠平均 1.47 和 1.51 µs。收益主要发生在发布路径。
