# 2026-10-05：SSF 线稿与三档明暗可见性修正

## 反馈与实际诊断

用户原话：“线稿和三档明暗好像没加？”。重新打开冻结A_v6原生Blender场景，检查90个材质的Normal→Dot→三档Constant Ramp连接；结构线1.45px、外轮廓2.6px处于开启状态。实际渲染关闭/单独显示后确认两者存在，但军工厂Hero机位亮/中/暗区域为75.07%/24.23%/0.70%，阴影面积不足，线条缩小到总览也偏弱。诊断依据为[实际拆分图](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v7/Style_Breakdown_A_v6.png)和[原生节点回读](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v7/A_v6_native_node_audit.json)。

本轮依据原方案线稿与三渲二要求修正参考表现，配色完全沿用A_v6，不将用户反馈记为具体阈值、线宽或新版本的通过决定。

## A_v7 修正与保持

| 项目 | A_v6 | A_v7 |
|---|---|---|
| 三档分区阈值 | 0.12 / 0.55 | 0.38 / 0.68 |
| 三档亮度因子 | 0.40 / 0.72 / 1.0 | 保持 |
| 2048px结构线 / 外轮廓 | 1.45 / 2.6px | 2.2 / 4.4px |
| 内部遮罩强度 | 0.45，平台0.48 | 0.65 |
| 4096px组合图线宽 | 原参考配置 | 1.6 / 3.0px，按小建筑可见尺寸控制 |
| 配色HEX、基础及三档RGB | A_v6原值 | 40项HEX、90材质RGB均保持 |
| 光向、曝光、法线、几何、姿态、机位 | A_v6原值 | 保持 |

军工厂和战略中心继续沿用A_v6提亮后的紫色，其他四座建筑及平台、灯具、无人机色值不变。只调整色阶分区及线条可见性，渲染像素随风格修正变化，不声称新旧整张图逐像素相同。

[A_v7同机位对照](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v7/Style_Comparison_A_v6_to_A_v7.png)给出军工厂、空军基地前后结果。[实际诊断分区](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v7/style_visibility_validation.json)记录该军工厂机位亮/中/暗为48.11%/38.46%/13.43%；统计使用饱和诊断核心像素，排除抗锯齿和显示标识，仅解释本机位的三个色阶，不作为所有视图或实战帧率结论。

## 完整交付与核对

[完整审核A_v7](../../ArtSource/Buildings/SSFStyle_20261005/Review_A_v7.md)含42张2048×2048单图、十套4200×4640图板、两张4096×4096原尺寸组合、总览、同机位对照、A_v6拆分图及10纹理已打包的参考Blender场景。单资产内仍为同姿态、同尺度、同配色；原角色分区及主要结构不改。

最终场景保存后重新打开，[90材质RGB回读](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v7/palette_preservation_validation.json)核对基础RGB、三档RGB、离散阈值和固定光向；[本轮保持记录](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v7/style_preservation_validation.json)检查10资产原几何/权重。[六个历史版本与结构核对](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v7/revision_validation.json)确认A_v1/v2/v3各64个、A_v4的79个、A_v5的80个、A_v6的84个冻结文件，以及源结构、机位和组合布局保持。

[助手实际视觉检查](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v7/visual_qa.json)覆盖40核心视图、2补充俯视、2组合及对照/拆分，战略中心图板另行放大检查。组合图经单独控制线宽后，小建筑色块与结构可读。源UV参考遮罩仍含部分原边缘不规则，成品阶段按已审主要分界制作规则图集；Freestyle不是已完成的生产描边壳。单面发光Light保持原平面用途，不伪造厚度和表面三档阴影。

[冻结清单](../../ArtSource/Buildings/SSFStyle_20261005/References_A_v7/reference_manifest.json)SHA256为`d1d3dcabdac432395edd1554da297de47e555a94c9e6ff77893043a7487c0173`，[交付核对](../../ArtSource/Buildings/SSFStyle_20261005/DeliveryValidation_A_v7.json)确认137文件哈希一致。技术检查、助手读图和用户A/B决定分别登记。
