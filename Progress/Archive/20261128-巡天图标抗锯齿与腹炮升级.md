# 巡天敌机图标抗锯齿与腹炮升级

敌机旁的小炮原有 7 段笔画，每段分别绘制底色和内线。小叉的两条对角线同样重复绘制。新版把一个图标合成一个四边形，在材质内计算像素对笔画与描边的覆盖率。高度虚线从目标端起算，长度变化时连续调整节距。场景组件按视图批量提交可见目标，保留场景深度遮挡。[材质源文件](../../ArtSource/UI/Ship/XuntianHUD_20261125/Native/AirMarker.hlsl) · [场景组件](../../Source/GuLiStrike/Gameplay/Ship/UI/GuLiXuntianSceneGuide.cpp)

在主原型地图的僚机综合试飞中，红蓝双方共 50 架僚机。源码版编辑器模块 2823 的 180 个采样帧中，有 172 帧同时记录了炮形和小叉的渲染提交。材质编译通过，读取到 7 个表达式和 0 个纹理采样。[结构化对局记录](../../TestResults/XuntianHUD/air-markers-and-belly-upgrade.json)

旧版同帧提交机库节点 08 与 F4 二级腹炮时，先提交的机库改变了装配版本，腹炮仍为一级，面板保持打开。逐项提交在旧版也可以成功。新版面板等待驾驶员上一笔装配回执后，按当前版本提交所选等级。僚机试飞按实际启用的机库判定准备完成。联机升级使用驾驶员的操控权，装配结果由协调端确认。

独立 PIE 通过实际 F4 输入和面板确认回调复测了相同的同帧操作。驾驶员一次确认升为二级，第二次确认升为三级，机库一直启用。面板再打开时显示满级。可用 `Scripts/validate_xuntian_belly.py` 的 `start(concurrent_hangar=True)` 重跑。[F4 回归记录](../../TestResults/XuntianBelly/f4-hangar-regression.json)
