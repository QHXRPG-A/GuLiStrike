# 2026-09-22：卡牌窗口焦点原生接口补齐

接续[演示场景交付记录](20260922-三张视差3D卡牌演示场景交付.md)。用户明确回复“补一个最小 C++ 焦点接口，并允许编译 GuLiStrikeEditor”，因此将原先全部纯蓝图的边界调整为：动画/流程仍由蓝图和材质实现，原生仅提供窗口焦点查询。

新增 `Source/GuLiStrike/UI/Cards/GuLiCardRevealViewportLibrary.h/.cpp`，提供 `BlueprintPure IsCardRevealViewportFocused(PlayerController)`。对本地玩家查询对应游戏视口的 Slate 窗口与应用激活状态，缺少玩家/窗口/Slate 时返回 false。同窗口内的 UI 键盘焦点不阻断卡牌界面。没有对象持有、事件订阅、Tick、联网行为或新模块依赖。

`BP_CardRevealDirector.UpdatePointer` 接入该查询，悬停和点击共用结果；失焦后目标角度归零，通过已有插值回正。`BP_CardRevealPlayerController` 初始化时设置游戏视口焦点。最大倾斜仍为用户要求的 ±12°。

按授权编译 `D:/UnrealEngine-5.7` 的 `GuLiStrikeEditor Win64 Development`，使用 `-WaitMutex -NoHotReloadFromIDE`，最终退出码 0。引擎和项目的 BuildId 均为 `dd3ee083-a0fd-45c8-814e-67fe5ef95e31`，未改原生插件、未编译 Game 目标或执行打包。

重新加载后蓝图编译通过。7 项实际 PIE 检查通过：活动游戏窗口可悬停，切到本功能材质编辑器后命中无效、卡牌回正，后台输入不能选牌，空 Controller 安全返回 false。验证使用真实 UE 窗口激活切换，未模拟系统 Alt+Tab 按键，用户最终视觉与切换手感仍待确认。临时 PIE 鼠标控制设置已恢复。
