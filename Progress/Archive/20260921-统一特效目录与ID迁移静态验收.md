# 2026-09-21：统一特效目录与ID引用

## 交付

- [特效 Excel](../../Data/Excel/GuLiStrikeVfx.xlsx) 的 Effects 表登记 39 个唯一“资源路径＋基础缩放”组合；用途说明使用中文，其他表和配置使用整数 VfxId。
- [运行时目录](../../Source/GuLiStrike/Gameplay/Vfx/GuLiVfxRegistrySubsystem.h) 支持 C++/蓝图查询、类型校验、按 World 缓存、按路径复用、编辑器无 World 查询及蓝图生成类加载。Dedicated Server 只用元数据，保留销毁效果原有异步加载流程。
- 迁移法术场、机甲技能、共享战斗配置、INI、玩家子弹网络、采矿/建造激光蓝图、NPC 销毁蓝图和建筑放置预览材质。保持原伤害、碰撞、颜色、时长和生命周期。
- 三类机枪受击共用 ID 5 的 NS_Flash_1；僚机弹道 ID 4，指挥官地面机枪 ID 38，后者基础长度系数 0.3 移入表；玩家子弹/枪口 ID 8/9。网络协议为 18，客户端和服务器一起更新。
- 原资产读回确认两类导弹飞行均为 0.4，合用 ID 2。体型、法术范围与其他动态系数保留，基础缩放只应用一次。
- [迁移记录](../../Scripts/Vfx/migration-manifest.json) 保存 41 个使用位置及旧资源/缩放；它是审计和 ID 接线清单，运行时资源来源仅为 Excel 生成的 DataTable。
