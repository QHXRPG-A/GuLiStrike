# 无双双载具模拟与局内切换静态交付

用户将此前单载具二选一更新为：“无双同时模拟游骑兵、巡天及其召唤物，局内可以切换空地操控，兵种继续沿用现有平摊框架”。本轮保留原枚举、房间四席、消息格式与模拟调度器，仅合并控制者匹配并增加本地操控选择。

## 实现

| 路径 | 修改 |
|---|---|
| [GuLiNetRoomTypes.h](../../Source/GuLiNetCore/Public/GuLiNetRoomTypes.h)、Room、OwnerState、OwnerTransactions、Replacement | Ground/Air成员都匹配本队唯一无双；注册、刷新、生成和替换使用同一规则，Commander仍精确匹配 |
| [GuLiBattlePlayerState.h](../../Source/GuLiStrike/Battle/Framework/GuLiBattlePlayerState.h) / 实现 | 本地ActiveControlRole独立于已提交房间身份，重复名册不覆盖操控选择 |
| [GuLiCommanderPlayerController.cpp](../../Source/GuLiStrike/Commander/Framework/GuLiCommanderPlayerController.cpp) / 声明 | 无双Tab输入、目标授权与就绪校验、操控切换、放置/传送输入清理、HUD更新 |
| [Ground适配器](../../Source/GuLiStrike/Gameplay/GroundMech/Network/GuLiHybridGroundAdapter.cpp)、[Ship适配器](../../Source/GuLiStrike/Gameplay/Ship/GuLiHybridShipAdapter.cpp)及载具类 | 只占有当前目标，两台载具均保留PlayerState，未操控载具继续模拟且不重放持续输入 |
| GroundRogue核心/运行桥接、卡牌、建造、HUD与场景UI | 网络权限按无双身份，当前操作入口按ActiveControlRole；切换后原有异步请求继续使用原玩家归属 |
| [选席入口](../../Source/GuLiStrikeEditor/Private/GuLiLocalPIERolePicker.cpp) | Ground/Air按钮解释为起始操控选择，提供Tab提示 |

游骑兵、巡天与僚机继续使用原ControllerPinned策略；来源固定的弹丸、效果与工作对象继续沿原来源链。Mass兵种仍按同队平摊、选择/操作时收回。建筑、经济、矿与控制点仍使用原全局match/resources组。离队原身份不可返场规则保留。

切换不修改房间角色、SeatVersion、控制Epoch、OwnerEpoch或Ready状态。未操控单位保持本地模拟，只停止持续手动输入；不因切换退役召唤物。目标死亡、休眠、未就绪或授权不足时保留原操控；模态界面期间不切换。
