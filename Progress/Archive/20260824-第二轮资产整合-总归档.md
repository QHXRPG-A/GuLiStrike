## 方法论沉淀（本档精华）

1. **迁移一个包的正确姿势**：迁移动作 + 重存**外部引用方** + **包内互引资产也要固化**（材质函数→贴图默认值、MIC→父、FunctionCall→函数）；删旧重定向器前逐个验证"新副本存在 + 无引用方"。
2. **注册表依赖扫描查不出三类悬空**：空引用（无父/无函数）、函数内部贴图默认值、未保存包的内部引用。必须**节点级扫描**（ObjectIterator 按包前缀过滤逐节点查关键属性）。
3. **诊断口诀**：材质实例贴图参数数为 0 = 父引用断；网格体编辑器"多一个平台" = 轴心在世界原点处的地面网格（FBX 世界坐标陷阱）；浏览器"空文件夹" = stub 文件。
4. **Windows delete-pending**：进程持句柄的文件删不掉但 `del` 报成功，编辑器重启自清；重定向器删除优先走编辑器 `delete_asset`。
5. LFS stub 是本项目持续地雷：22 个 twin-stick 资产、Mannequins 等仍为指针文件，恢复需 `git lfs pull`。
