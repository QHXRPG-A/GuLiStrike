## 做了什么

1. 在现有 `GuLiStrike` 模块内建立 `Gameplay/Building` 边界。Controller 只路由输入，Placement Component 负责本地模式、预览和网络意图，服务器是唯一放置写者，`AGuLiPlacedBuilding` 只保存初始化后不再变化的复制事实。
2. 完成角色化操作：Commander 用鼠标地面点并避开 HUD；Ground 用屏幕中心射线并受 100m 与 LOS 限制；Air/Observer 无权建造。模式内数字键选建筑、LMB 连续放置、RMB/Esc/B 退出，模式外保留 Commander 的移动工具与 RMB 行为。
3. 服务端按固定顺序验证连接/战局、角色、资源、请求有限值、地面、坡度、Ground 距离/LOS、重叠、10 次/秒、个人 6 个与全局 24 个上限。请求号递增；完全相同的 Reliable 重试只重放结果，复用请求号但修改载荷则拒绝。
4. 建筑以最终烘焙 Mesh 包围盒建立根 Box，并在放置检测增加 100cm 水平间距。Mesh 始终 Scale 1 且无碰撞；Box 使用 `BlockAll`/WorldStatic/QueryAndPhysics。Mass 士兵无物理形体，另以存活位置快照拒绝直接压住单位。导航组件保留 `NavArea_Null` 配置但当前不相关，类型、阵营和建造者 `PlayerGuid` 复制后进入网络休眠。
5. 通过 UE Editor API 保留 `/Game/Fab` 原件并创建规范副本。Missile Turret 最终约 `2519.46 × 2728.75 × 3520.77cm`；Sentry A_a 约 `1935.79 × 3866.78 × 1675.19cm`；据点为 `2000 × 2000 × 2000cm`。Sentry 复制材质的 `DiffuseColorMap` 显式指向复制后的 `Stylized_Turrets_A`。
6. 测试迭代中修复三处真实问题：地面射线先命中既有建筑会误报“无地面”，现改为忽略已放置建筑后再由占位检测返回“空间被占用”；命名 `BlockAll` 后重复改 ObjectType 会把 Profile 变成 Custom，现移除冗余覆盖；已注册 Static Mesh 组件拒绝 `SetStaticMesh`，现先以 Movable 完成一次初始化再锁为 Static，并用 World 测试锁定实际 Mesh。
7. 为最小联网验证增加仅 Editor 可用的 `gs.Building.QA.Place [1|2|3]`。它先找清晰地面，再延迟到下一核心 Tick 发请求，避开 Editor Python 执行保护导致 RPC 本地执行的问题；Shipping 不包含该入口。
8. 现场按 B 后内存快速增长的根因不是 Mesh 常驻体量，而是半透明预览 MID 覆盖 Nanite 防空炮 32 个 Section 后，每帧重复输出非法材质警告。预览组件现明确禁用 Nanite 路径并只在合法性变化时更新颜色。实体防空炮的玻璃槽同样是半透明，故已放置组件也使用 fallback；规范资产仍保持 Nanite 开启。
9. 用户把建筑放在行军路线后观察到“所有单位停一下，然后沿原路线继续”。源码确认 `HandleNavigationGenerationFinished` 对任何 Commander NavMesh 重建都会清空所有活动编队路径，并将全部活动士兵加入暂停集合；同时 Mass 士兵没有物理碰撞兜底。按用户决定，本阶段暂不处理碰撞/绕行，因此建筑根 Box 和 NavModifier 均关闭导航相关性，建造不再触发这条全局暂停链路。
