# 2026-10-24：地面机甲动画修复与越肩视角

用户明确要求实施本次方案，基于其已记录的蓝图预览视口：根相对位置`(-988.06165,406.38665,409.13712)`cm，Pitch=-14.85°、Yaw=-3.90°、FOV90。原模型、17骨骼、原包资源、队色、武器伤害和Ground权责保留。

## 变更与原因

- 固定前进输入时，Walk/Run混合空间的运行采样权重为空、时间为0、脚骨静止，尽管源动画轨道有效。补原包网格插值配置并显式重采样后恢复。更新安装脚本，避免重导入再次遗漏。
- 原ABP右枪开火层Pose输入断开；新图由两个独立Shoot求值器和Gun_R/L遮罩组成。MuzzleIndex决定各自时钟；新增枪轴5cm后坐使用既有0.15秒曲线，晚到的旧事件不覆盖同枪新事件。腿部姿势不受开火层覆盖。
- 地面使用指定Idle/Walk/Run/Strafe；Start一次→Loop，走出平台直接Loop，空中再次喷气不重播Start，落地回地面。远端姿态更新不再传0推进动画，表现帧负责非模拟副本的动画时间。
- 当前帧组件空间解算两枪臂，将实际枪口偏移和后坐位置纳入，保留原包枪管旋转。发射、枪口特效仍使用同一Socket和目标点。
- SpringArm1084.4236cm、SocketOffset`(0,338.24235,135.74471)`、Camera局部零位、FOV90、避障；滚轮缩放保留，范围704.88–2168.85cm。Mouse2D转镜、中心准星使用统一色库奶油白`#FEE4D9`；WASD镜头方向转世界后进入旧网络输入，A/D横移、身体朝目标。建造/传送/菜单期间恢复鼠标并停止转镜和开火。
- 新骨骼节点运行实现在`GuLiStrike`，图节点外壳在`GuLiStrikeAnimGraph`（UncookedOnly），限定编辑器工具在`GuLiStrikeEditor`；无反向运行时依赖。新节点临时Editor类路径用精确ClassRedirect兼容，最终ABP编译0错误/0警告。
