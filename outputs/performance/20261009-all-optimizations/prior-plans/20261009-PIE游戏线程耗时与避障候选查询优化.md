# PIE游戏线程耗时与避障候选查询优化 — 技术方案

## 当前结论

A0–A4已实施并加载。600个存活移动单位的三组对照中，候选查询均值为1.258/1.516/1.501 ms/引擎帧，活动批次P95为1.829/2.152/2.194 ms，分别达到≤1.6/≤3 ms预算。仍保留预测避障、软避障、查询覆盖范围、威胁排序和三相调度。

最初自由运行PIE平均43–46ms、GPU约12.5ms，查询约2.62ms；本次固定600单位并加入四来源弹丸的对照有不同负载，不能将两者直接作优化前后差值。同进程三个世界仍主要受GT限制，不承诺单项优化达到60FPS。

## 实施与行为合同

| 阶段 | 实施 | 保持的合同 |
|---|---|---|
| A0 | World级CPU Scope/聚合计数；Grid、Query、Solve、格子访问、稀疏比较、环境重复、实际前缀、改令强制及半径/速度分布 | 默认不采集额外聚合数据、不刷逐兵日志；零计数不冒充没有工作 |
| A1 | 普通单位只插入中心格，不再进入重复去重集合；环境跨格重复用可复用代次标记，处理代次溢出 | 去重只去重复条目；单位与环境稳定键、参与/高度过滤不变 |
| A2 | 普通单位直接XY平方距离、平方重叠；环境仍保持表面净距语义 | 不用平方距离替换环境的净距排序 |
| A3 | 单位保留前12、环境前2，环境优先插入，最终消费者最多12 | 重叠→预测碰撞时间→距离→稳定键顺序不变，不以距离提前截断威胁 |
| A4 | 同次执行连续快照、网格工作缓冲复用；额外建立按原XY格序排列的非空格索引，跳过空格 | 覆盖同一矩形范围且按原桶访问顺序，未缩小高速/大体型查询 |

源文件：[Policy](../../Source/GuLiStrike/Commander/Mass/Navigation/GuLiCommanderAvoidancePolicy.cpp)、[Processor](../../Source/GuLiStrike/Commander/Mass/GuLiCommanderPredictiveAvoidanceProcessor.cpp)。稀疏索引在建格子结束后生成桶指针，查询期间不增删网格；快照只复用本次只读阶段，不跨执行冻结权威状态。

处理器仍仅Standalone/Server执行；30Hz推进三相，`SoldierId % 3`决定常规求解相位，低帧率至多追赶三步，每次执行每兵最多一次。改令版本绕过单位相位限制并在求解后记账；静止单位仍参与其他单位的障碍查询。保持2.5秒预测、迎面靠右、停止友军被动让行，以及0.5秒尺度的软避障职责。没有关闭预测层、缩短时域或降低已有单兵频率。

## 三对测量

| 对 | 回退查询平均 / 批次P95（ms） | 优化查询平均 / 批次P95（ms） | 预算 |
|---|---:|---:|---|
| 1 | 8.407 / 11.498 | 1.258 / 1.829 | 两项达到 |
| 2 | 8.230 / 10.919 | 1.516 / 2.152 | 两项达到 |
| 3 | 7.893 / 10.455 | 1.501 / 2.194 | 两项达到 |

这里的P95是一次到期批次的查询耗时，不是单兵P95。稀疏索引增加部分建网格工作，但查询净下降明确。实际600单位样本有大于300cm半径、800–1600cm/s速度档，覆盖范围按实值计算；没有采用固定3×3或1200cm截断。

整帧运行时局部回退对照GT均值中位变化−6.51%，GPU+0.85%，物理/虚拟内存+0.20/+0.16%。双方都已包含UI注册表、模板和服务器索引，Bounds开关又改变实际Ship客户端工作量；这只能作为局部开关的整体参考，不能算作四项全改造或避障单项整帧收益。整帧、GPU和内存绝对值/P95见统一报告。

## 功能、回退与玩家入口

600单位实机执行11,684个原/新消费前缀比较，0处差异；真实停止/替换移动命令均有读取。已有交叉、停止友军、改令及环境边缘导航用例通过。保留原查询回退开关 `gs.Avoidance.QueryOptimizations 0`、`gs.Avoidance.SparseCells 0`；可单独回退稀疏索引。`gs.Avoidance.VerifyPrefix 1`仅用于短时间核对，默认0，不计入性能窗口。

在指定Map的四来源区域 `(0,65000,902)`，用现有指挥官部署/移动/停止入口，让队列交叉、停止后重发命令并沿环境边缘通行，观察迎面靠右、停止让行、无改令滞后。固定600移动入口、镜头锁定与聚合诊断由现有QA库及 `Scripts/Performance/run_four_stage_review.py --cases runtime --pairs 3`接通。原生入口仍以服务器为权威，预览Actor默认关闭。
