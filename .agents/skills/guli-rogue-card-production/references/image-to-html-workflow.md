## 三个阶段与职责

| 阶段 | 操作者 | 产物与下一步 |
|---|---|---|
| 1. 内置生图生成初稿 | 助手 | 用真实单位模型/用户参考约束身份、装配、镜头与能力表现，交付初稿、输入图和完整提示词 |
| 2. ComfyUI中用Qwen生成参考图 | 用户 | 用户导入初稿、调节参数与提示词并选图，将最终图片交给助手；助手不自动提交用户的Qwen任务 |
| 3. 指定六层的完整生成与HTML展示 | 助手 | 冻结参考、对象归属与运动范围，逐层生图生成完整对象，对位装配并交付可交互HTML |

第2阶段尚无选定图片时，请用户提供Qwen处理结果的本地路径或附件，独立的分组、提示词与交付准备可继续；不能把初稿冒充用户最终选择。用户已经指定某张现有图片作为最终参考时沿用该选择，不要求重跑前两阶段。协助本地Qwen环境或工作流时再读取 [local-image-gen](C:/Users/a/.codex/skills/local-image-gen/SKILL.md)。

## 第3阶段的制作步骤

1. **冻结参考、分组与运动范围。** 保存最终参考的尺寸、哈希和允许修改范围；记录六组对象、附着效果和用户编号，绘制顺序单独定义。生图前确定原窗口、共同画布、最大平移/倾斜、层深度及滤波留量。将“用户定稿的可见原图窗口”和“含补绘的完整画布”分别记录；Ground新初稿/参考图的窗口须遵守[原卡框与开口比例硬指标](artwork-data-pipeline.md#卡框比例硬指标)，不能先做2:3插画再改框迁就。已有不匹配定稿记录差异，不擅自改图。只做HTML时不因此新增UE工作。
2. **记录位置与大小。** 以同一参考列出对象数量、包围框、方向、连接点、坐标单位及各层排除项。可以直接以参考图和坐标约束生图；切片仅在用户允许时作参考输入，禁止脚本抠图时不执行。
3. **逐层生成完整图。** 内置生图为每层生成完整 RGBA 主图，包含隐藏表面和所需外沿，物体外保留真实透明度。每个对象只归一层，前后层允许重叠；不把原图像素回贴或旧蒙版裁切后的残片当作成品。细节与提示词见[全画布分层与补绘](parallax-production.md)。
4. **对位并装配共同画布。** 读取真实输出尺寸与 alpha，记录必要的静态对位；运行时共用基础映射。构图、相对比例、连接或完整性有误时修正输入并重新生成，不靠逐层基础 UV 隐藏。后续仅补外沿时可保留用户已确认的完整生成图核心，记录其哈希与范围，不能混同原图切片回贴。
5. **整体移动与遮挡。** 同一物件及连接效果共用运动参数，按牌面窗口整体裁切；外沿通过真实补绘覆盖。前后遮挡用同一完整主图与互补技术蒙版，不重复叠加 alpha。新卡不使用固定物件边缘、内部渐变位移的做法。
6. **按最终清单交付并迭代。** 提供原图、原位叠合、交互视差、逐层开关/独看/透明度、回正、PNG下载和素材包。所有模式与导出使用同一批文件及哈希，更新同一页面与地址。按[原位保真](parallax-production.md#原位保真)实测成品相对冻结参考的 RGB SSIM，至少 80%；完整性、归属、极限运动接合与文件一致性分别记录，美术验收由用户完成。

承担最远底图的层应全不透明，其他层对象以外应真正透明。用户编号不必等于深度顺序；技术蒙版、前后显示通道不改变六个内容分组。

接入UE时继续使用此清单中的原图窗口、绘制顺序、运动归属和最大位移。外扩区是视差采样余量，不能为了适配卡框重新定义已定稿构图，也不把整个外扩画布缩进窗口导致二次缩小。实际卡框适配见[完整构图与卡框映射](artwork-data-pipeline.md#完整构图与卡框映射)。

以下是 2026-10-26 折射子弹的历史实现与用户分组示例，不作为新卡固定语义。其原像素提取、核心回贴和边缘固定采样方案不作为新卡默认流程；新任务遵循上文完整生成规则。

| 用户编号 | 内容 | 对象完整性 |
|---|---|---|
| 1 | 近景 | 墙岩、植被、急刹扬土与烟尘；补齐隐藏表面和外沿 |
| 2 | 速度线 | 白色漫画速度线；修复截断与串层残留 |
| 3 | 机甲 | 玩家游骑兵、直接附着的双股尾焰与枪口火光 |
| 4 | 场景 | 草原、石阶与中近景建筑残骸；补齐移除主体留下的缺口 |
| 5 | 折射弹道和三个敌方机甲 | 关联弹道、三个敌人、受击爆炸与相关碎片作为一组 |
| 6 | 远景 | 完整、不透明的天空、远处地形、建筑、烟柱和导弹尾迹 |

本次显示顺序为：远景 → 场景 → 敌人与弹道 → 近景后方部分 → 玩家机甲 → 近景前方部分 → 速度线。前景两个部分引用同一主图，通过一张二值技术蒙版分配；六组开关和透明度保持同步。

历史交付画布1536×1536，原1024×1024位于`[256,256,1280,1280]`；HTML基础映射为宽高150%、左上偏移-25%。旧实现曾固定近景外侧2%采样、2%至12%恢复内部视差，默认4px、最大8px；该边缘变形方案仅留作历史维护记录，新卡采用整体位移、窗口裁切和真实外扩。画布与运动参数按新任务重新计算。历史原始生成尺寸1254×1254不代表工具总会输出该尺寸。

本轮HTML资源载入、着色器初始化和控件状态已有技术检查，画面仍待用户验收。随后六层已导入UE，并以ArtworkId=6接入[美术资源目录](artwork-data-pipeline.md)；技术导入不代表美术审核通过。制作方法可以复用，不把未经用户确认的补绘效果标为已审美术基线。
