## 图集契约

沿用现有六层模板：3列×2行，每格是同样的竖版2:3虚拟画布；编号从左到右、从上到下。六格叠加应重建同一插画，不是六张重新构图的完整卡。

| 层 | 内容 | WM01例子 |
|---|---|---|
| 1 | 最近前景 | 近处残骸、最近自由导弹、前景速度线 |
| 2 | 脱离主体的能力动势 | 飞离枪口弹迹、中距自由导弹、分离尾流 |
| 3 | 完整机械与附着效果 | 机身/武器/所有可见腿盘/连接；接在炮口的火光、刚出膛导弹、盘底附着光边 |
| 4 | 环境中景 | 被击溃部队与爆炸、远处导弹、地面结构 |
| 5 | 环境远景 | 烟柱、工业剪影、远处部队 |
| 6 | 补全的最远底图 | 天空、地平线、安静地面；整格不透明 |

前三种能力可分配不同内容，但不要重复放同一对象，或把一条机械支架的两端放在不同深度。实际连接关系优先于“每层都要有很多东西”。第1–5层对象外真正alpha=0；第6层全不透明并补全主体遮挡区，不留剪影孔洞。透明棋盘不能画进图中。

## 当前强视差配置

- 内部 `Layers global depth=4`；层深度 `0.10 / 0.04 / 0 / -0.40 / -0.75 / -1.10`。完整机械位于参考层0，前后环境移动。
- 整牌 `MaximumTilt=16`，即每轴±16°，不是内部视差倍数。二者独立调节。
- 卡面积 `CardAreaMultiplier=2`，宽高各乘√2；厚度 `CardThicknessMultiplier=2`。不能把宽高各乘2当面积2倍。
- 这些是本批当前参数。扩展新牌优先复用，再按画面验证调整，不因“立体感更强”无限叠倍率。

## 分层生图提示词的固定部分

为已确认的无字原图另建生产prompt，不能改写原插画生成prompt。可复用以下规则，再填写六层各自内容：

> 制作UE视差卡牌生产用分层图集。以输入完整插画为唯一画面依据，准确保留机械身份、形状、部件数量、连接、透视、轮廓、配色和构图，不重新设计。
>
> 输出真正RGBA透明PNG，严格3列×2行六个等大竖版2:3单元格，无格线、间隙、标签。六格共享同一虚拟画布和同一坐标，各层对象不得独立居中、缩放或重构。
>
> 原图四边各外扩原尺寸40%，得到1.8倍画布，原图居中在每格UV 0.222222至0.777778。所有原内容按相同比例映射；向外自然续接背景和被裁切内容，不捏造额外机械。扩展区域服务于视差位移与倾斜，不形成硬矩形边界。
>
> 第1–5格对象外alpha=0，无白黑底、假棋盘、白边与随机颗粒；第6格完全不透明。机械连接与附着效果留在第3格，自由物体和环境按层分开，被遮挡背景补齐。输出无文字、数字、标记、UI、卡框、水印。
>
> 保持经典美漫清晰墨线与干净色块，不做旧、不加网点和密集排线。no grain, no dirty texture, no random speckles, no messy background, no harsh glow.

四边40%只是当前生产请求，不是生成模型的保证或所有材质的万能余量。当前v9曾请求3072×3072而实际为1254×1254，每格418×627；必须按真实文件检查，不能硬写“已获得3072”。六层原始prompt位于项目 `ArtSource/UI/WarMachineTarotCards/ModelComic_v9/Production/Prompts/*_Layers.txt`。

## 材质与边缘

复用项目父材质 `M_CelCardParallax_ModelComic_v9`，保留原视差和适用的动态纹样。独立的框/文字固定在牌面，不跟插画深度漂移。

- 每格采样做单元格内UV约束与边缘留量，防止相邻格串色；同时做固定牌面窗口裁切，不能让图层移出卡框。
- 当前插画窗口为卡UV x=0.045–0.955、y=0.043–0.772；文字区在下方。读取实际父材质再复用，避免修改错误版本。
- 当前主机械alpha使用 `smoothstep(0.12,0.72,A)`，底图作为不透明RGB合成；这是现有素材适配设置，不保证能修复白边、孔洞或错误背景。
- `BaseColor Map` 与 `Ability Layer Map` 应绑定该卡的正确图集；核对sRGB、alpha保留、压缩与Clamp寻址。旧脚本使用BC7和NeverStream，新增大量卡牌时评估纹理内存，不全库无条件常驻。
- 深度增加时要核对四边/四角及±16°复合倾斜；考虑各层最大UV位移、宽高比例和相机角度，不只看中心姿态。

“图层太小露馅”的处理顺序：确认固定窗口 → 检查图集真实外扩和背景补齐 → 修正共同UV映射/层偏移 → 必要时重新外绘。Clamp会拉伸边缘，单纯放大图层会裁掉主盘或改变构图，不能当作内容补全。

## 分层交付检查

- 技术：图集尺寸与格数、RGBA、各层alpha分布、背景覆盖、文件哈希；图像内容未经查看时只报告这些元数据。
- 机械：火光对炮口、导弹起点对孔、盘缘完整、支架不断开、视差时无重影或脱节。
- 层次：中心/四边/四角/双轴极限；背景无破洞，窗口无露边，前景不遮正文，文字与框不飘。
- 比例：16:9、16:10、21:9的实际卡面占比与可读性。实际生成/运行预览与用户验收分开记。

生成后需重绘或拆层时继续用imagegen；除非用户明确要求其他方式，不用图像脚本偷偷补画。尺寸/alpha/哈希检查不等于图像编辑。
