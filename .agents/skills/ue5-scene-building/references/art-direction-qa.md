# 美术方向与截图自查清单

适用：美术化阶段（替换白盒、加细节）和每个里程碑的截图检查。把自己当艺术导演，对着截图逐项评判，不合格就回炉。

## 截图检查通用项（每个里程碑）

- **比例**：物体相对人体参考（约 180cm）尺寸可信吗？门能过人吗？桌椅高度对吗？
- **悬浮/穿模**：物体贴地吗？相互穿插吗？（空间上可用 `actor.get_actor_bounds` + `actor.line_trace` 复核）
- **地平线**：天空与地面衔接自然吗？远景有东西看吗（不是空雾）？

## 构图（平视/展示机位）

- **焦点明确**：画面有一个视觉中心吗？还是一堆等权重的物体互相打架
- **剪影可读**：主体逆光/暗背景下剪影能认出来吗？剪影是判断形状设计是否成立的最快标准
- **引导线**：道路、围墙、光带的走向把视线引向焦点，而不是引出画面
- **前中后景**：三层都有内容，拉开纵深；不是所有东西贴在一个平面上
- **避免均匀**：等间距排布（一排等距的树/柱子）显机械，打破节奏（群组、缺失、大小变化）

## 光影

- **主光方向统一**：所有阴影朝向一致吗？出现互相矛盾的影子立刻查光源
- **明暗对比服务焦点**：想让玩家看的地方亮，次要区域压暗
- **色温讲故事**：清晨/黄昏暖光 + 冷影；阴郁场景低色温主光 + 冷雾
- **强度校准**：加灯前先读场景现有光源的 intensity（UE 模板常围绕很小的值校准，物理直觉的大数值会过曝）
- **大场景注意**：Stationary 光源数量上限；静态物体保持 Static mobility

## 三角度 QA 记录

每个大里程碑建议留存三张截图（俯视/平视/玩家视角），对比时用 `util.set_viewport_camera` 固定同一机位，方便修改前后 diff：

| 角度 | 检查什么 |
|------|----------|
| 俯视 | 布局、间距、路径走向、分区是否成立 |
| 平视 | 美观、比例、遮挡关系、构图 |
| 玩家视角（180cm） | 实际游戏观感、引导是否有效、威胁是否可见 |

## 意图对照（Refdiff）

最终交付前，回到用户最初的需求描述，逐项核对：主体、氛围、时间、内外景、交付物。截图结果与文字意图之间的差距，就是还要修的地方——不要只汇报"已完成"。
