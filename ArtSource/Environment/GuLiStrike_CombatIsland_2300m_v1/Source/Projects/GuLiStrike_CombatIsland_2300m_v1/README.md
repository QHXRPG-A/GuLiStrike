# GuLiStrike · 2.3 公里战斗海岛 v1

在 Gaea 2.3.0.1 中打开同目录的 `GuLiStrike_CombatIsland_2300m_v1.terrain`。保留整个目录，工程通过 `inputs/` 下的相对路径读取地形布局与遮罩。

## 地图与坐标

- 总范围：2300 × 2300 米，中心为原点；主要陆地位于 X/Y ±900 米以内。
- 北方为 +Y，东方为 +X；图像第一行为北侧，第一列为西侧。
- Gaea `Width=2300`、`Height=140`、`Ratio=140/2300`。`Height` 是垂直高度跨度。
- 世界海平面为 0 米；数据高度范围为 −20 至 120 米。16 位高度解码为 `height_m = pixel / 65535 * 140 - 20`。
- Gaea 原生预览的地形最低点为 0，因此世界海平面对应原生 20 米或归一化值 `1/7`。高度偏移记录在 `layout.json` 和导出验证报告中。
- 种子：`20261001`；相关生成器使用固定派生种子。

Gaea 2.3.0.1 的 4096² 原生构建结果为 `Success`，39 个节点、33 条连接。导出的 16 位高度实际覆盖 −20～120 米，4081² PNG 与 R16 逐像素一致。

西北海岸采用岩壁轮廓，东南海岸形成浅湾，低洼河谷穿过岸线进入湾内；南岸保留宽缓沙滩。三条路线的宽度与坡度按完整走廊验收，路线图的彩色线仅用于示意中心线。

完整数据与文件核对记录在输出目录的 `validation.json` 和 `delivery-checks.json`。

## 可编辑工程

节点从左向右排列：海岸与宏观布局、山地/丘陵/高台/峡谷生成、局部侵蚀、通路保护合成、高度与色彩输出。生成器种子和强度可在 Gaea 中修改；具体分区形状与通道指标来自源遮罩。

西南与东北各有 160 × 160 米集结区；中央主路设计宽 60 米，两条侧路设计宽 48 米。数值验收分别检查至少 50 米及 40 米的连续通道。东侧高台通过东路缓坡进出，西北山脊与部分陡岸作为地形边界。

生成脚本在转弯节点附近使用平缓高度过渡，并保护海岸、集结区及通路免受侵蚀。两个输入的 Combine 按本机原生示例保留 `In/Out/Input2/Mask` 四个端口，避免空的额外输入使乘法输出归零。

## 重建

在 PowerShell 中运行：

```powershell
& './scripts/Rebuild-Gaea.ps1' -Stage final
```

脚本保留现有 Gaea 节点编辑，配置 4K 构建，验收实际高度，再同步分区遮罩并完成最终导出与文件核对。使用 `-Stage draft` 可构建 1024² 草稿。

调整岛形、路径点或平台布局时，编辑 `scripts/prepare_sources.py` 的参数并增加 `-RefreshLayout`。此开关会重建本工程的源布局 PNG。直接修改 Gaea 节点后重建无需该开关。

依赖：已配置的本机 Gaea MCP、Node.js、Python 的 NumPy 与 Pillow。脚本只读写本工程和其配套输出；本交付不包含 UE 地图、导航烘焙或玩法运行结果。
