# 六座 SSF 建筑 · Blender 材质 B4

在 Blender 中切换 01–06 场景逐栋检查。上方是 A5 原图，下方是可编辑的红蓝模型。Scene Properties → Custom Properties 中的 SSF Stylization 设为 0 查看纯材质，设为 1 查看线稿、外轮廓和三档明暗。 [Blender 工程](SSF_A5_Materials_B4.blend) · [总览图](Previews/SSF_Overview_B4.png)

空军基地的前后导轨各有五段浅色横档和石墨色槽。指挥中心的下层观察带采用更低粗糙度、保护层和少量透射。战略中心的转台前缘有两段固定青绿刻线，中间留出零位间隔。保存后回读了两条导轨的十个横档、转台刻线和玻璃节点。 [回读清单](B4_Material_Manifest.json)
