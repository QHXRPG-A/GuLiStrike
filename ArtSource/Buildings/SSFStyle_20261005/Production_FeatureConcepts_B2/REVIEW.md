# 六座 SSF 建筑 · Blender 材质 B2

从总览切到 01–06 的单栋场景。上方是完整 A5 原图，下方是可编辑的红蓝模型。Scene Properties → Custom Properties 中的 SSF Stylization 设为 0 查看纯材质，设为 1 查看线稿、轮廓与三档明暗。 [打开 Blender 工程](SSF_A5_Materials_B2.blend) · [总览图](Previews/SSF_Overview_B2.png)

B2 在反应堆三组散热栅的九片栅片上分别定位青绿前缘。回读采样确认每片都有约 7.1%–7.2% 的表面落入该遮罩。六张原图板的四角均在相机范围内，下沿位于地面以上。
