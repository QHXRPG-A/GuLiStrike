# v6偏转边缘覆盖修复

用户在实际游玩中指出机动卡两侧出现矩形图层裁切边。[标注原图](user-markup.png)保留问题位置。本次只调整材质与图层覆盖，不重新生成插画，不改主悬浮盘大小、×4内部深度、±16°偏转或双倍卡牌尺寸。

## 复现与诊断

- 地图：`/Game/GuLiStrike/Cards/WarMachineTarot/Maps/LVL_WarMachineTarotReview`，右侧机动卡。
- 全部入场后向右侧及四角压动。预期：只有完整插画与卡框。实际：近景速度带左侧、后方尾流右侧的直切边进入窗口；外边缘另有细窄插画漏色。
- 源图集含透明边距，旧环境层横向Scale=.92仅勉强铺满正视窗口。右侧牌所在位置本身就带约15.6°相机斜视，再叠加16°偏转，移动后的取样边界越过卡框。
- 首个偏差在图集的尺寸/偏移到窗口覆盖这一环节，UI输入和主盘完整性不是本次原因。旧父材质整个卡面为Opaque，还会让卡框以外的插画留在外边沿。
- 诊断顺序：先检查覆盖余量（主因、低成本材质调整），再检查卡框外的整面漏色（附加问题），排除主盘素材缺失。前后采用相同相机世界原点拍摄右牌，而非把相机移到牌正前方；截图扩大显示，不作图像裁切。

## 修复

| 层 | 原Scale | 新Scale | 新Offset | 目的 |
|---|---|---|---|---|
| 1 近景速度带 | .92 / .745 | 1.16 / .745 | 0 / -.0875 | 左右裁切边移到卡框之外 |
| 2 能力尾流 | .92 / .745 | 1.20 / .745 | 0 / .025 | 补足尾流横向余量 |
| 4 后方盘及尾流 | .92 / .745 | 1.18 / .9555 | -.066 / -.039 | 等比扩大后景层并补偿中心，隐藏右侧尾流直切边 |
| 5 远景建筑 | .92 / .745 | 1.32 / .96 | 0 / -.0875 | 扩大环境覆盖 |

主盘所在第3层保持Offset=(-.02,-.12)、Scale=(.92,.745)。第4层的后方盘随该层一起等比放大，主盘不变；远处盘在极限视角可被卡框自然遮挡。

共享美漫父材质新增固定UV裁切：U=.045..955、V=.043..772，切为Masked。它比UI可见窗口留出少量重叠，既不跟随视差滑动，也不在外框和文本栏留下插画色条。原塔罗父材质不改。

实现与复现：`Scripts/Cards/comic_card_edge_coverage.py`、`fix_comic_edge_coverage.py`，已同步原v6导入脚本，重新导入不会恢复旧参数。
