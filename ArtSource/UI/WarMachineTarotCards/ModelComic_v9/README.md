## 实际文字 prompt

### 增加射速

[纯文本](Prompts/FireRate_Edit.txt)

```text
编辑输入图1这张“增加射速”插画，只修复用户指出的一处缺失机械结构。输入图1是无标注原图，是唯一编辑底图；输入图2是用户红框反馈，只用于定位；输入图3是真实新版战争机器模型的UE整机截图，只用于核对四腿布局和机械连接，不能把其渲染风格套入插画。
在输入图2红框标出的机身右侧远侧位置，补齐缺失的一条支架腿与该腿对应的悬浮盘。参照输入图3对应结构，让支架连续连接到真实的机身侧关节，向外下倾，经销轴叉耳连接到水平的橙红方形末端节点；白色套环与指示灯随节点，末端底座贴合悬浮盘中央圆环上表面，悬浮盘保持水平。按原相机透视处理这条远侧腿的大小与前后遮挡，允许机身遮挡一部分，但可见的连接和悬浮盘必须完整合理，不能穿模、悬空或成为孤立飞盘。只补这条缺失腿，不额外增加其他腿，不为了显示四腿而移动现有机体。
严格保留输入图1的画幅、主体位置、姿态、镜头、配色、经典美漫画风、现有双联炮与枪口火光、其他已有腿和悬浮盘、残骸、爆炸和背景。仅在补腿必要的局部修改遮挡，其他内容尽量保持原样。保持干净墨线、清晰色块与明暗层次。输出与原图同样的2:3竖版完整插画，不含红框、箭头、标注、文字、数字、卡框、水印或UI。no grain, no dirty texture, no random speckles, no messy background, no harsh glow.
```

### 极速机动

[纯文本](Prompts/HighSpeed_Edit.txt)

```text
编辑输入图1这张“极速机动”插画，只增加几条速度光效线。输入图1是无标注原图，是唯一编辑底图；输入图2是用户的红色箭头标注，仅用于说明光线的方向和大致分布，不把标注画入结果。
沿输入图2三个箭头指示的方向，在炮组附近、机身侧面附近和前景悬浮盘附近添加约3到5条疏落、细长、清晰的青蓝或青白色速度光效线，允许极少量紫色边光。光线方向从画面右下向左上、顺着机器向后掠过，形成连贯前冲速度感；采用经典美漫的利落线条，前端短亮，向后细长收尖，少量分段，方向一致。光效要可见但克制，不加箭头，不形成粗大激光束，不遮住炮口、关节连接和完整悬浮盘轮廓，不在机体上制造贯穿孔洞。保留现有盘底尾流和地面速度线。
除此之外，严格保留输入图1的主体身份、所有机械结构、腿与悬浮盘数量、构图、姿态、相机、配色、经典美漫画风、背景和原有明暗。保持干净墨线、清晰色块、简洁低干扰背景。输出与原图同样的2:3竖版完整插画，不包含输入图2的红箭头、下载按钮、圆角遮罩或任何文字、数字、卡框、水印、UI。no grain, no dirty texture, no random speckles, no messy background, no harsh glow.
```
