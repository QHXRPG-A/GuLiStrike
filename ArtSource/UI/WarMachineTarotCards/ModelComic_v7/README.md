### 增加射速

```text
用途：战争机器肉鸽能力卡插画，竖版2:3，经典美漫画风。
输入图1是真实UE战争机器模型的整体截图，只用来约束机械身份、部件数量、配色和装配；输入图2是该能力重点部位的真实模型截图，用来约束局部结构、透视和镜头。依据这两张截图重新绘制插画。
精确保留模型的橙红/暖白装甲、蓝灰机械、双联侧炮、平行双导弹舱、悬浮盘及支架结构。只画与能力有关的局部，不要求整机出镜。不要把机械改造成类人机器人，不要捏造连接、随意增减武器或改变炮口口径。
绘画语言：经典美式超级英雄漫画的手绘墨线、粗细分明的轮廓、大块黑影与干净的平涂色块，具有力量和明确的明暗层次。干净视觉图，让它更干净、更清晰。清理背景噪点、随机颗粒、脏纹理、浑浊阴影和过度光效。背景简洁、低噪点、低干扰，只提供空间感，不抢主体。不要纸张做旧、密集网点、满屏排线或塑料3D渲染质感。
构图适合后续分层视差：机械连接保持完整，主体与背景分离清楚；背景、地面和尾流延伸到画布边缘，保留裁切余量。画面不含文字、数字、卡框、UI、水印。
禁止项：no grain, no dirty texture, no random speckles, no messy background, no harsh glow.

能力：增加射速。沿用输入图2的侧前方局部镜头，重点表现真实模型的一侧双联炮、炮管、炮口与安装装甲。两根炮管口径一致且平行，两处短促金白色枪口火光准确接在炮口，少量连续弹迹表现密集射击。旁边安排少量近处和远处被击溃的无人部队残骸，其中部分刚爆炸、部分冒烟；残骸和烟柱用简洁可读的形状，不堆成杂乱碎片。射击方向留出空间，炮口不被大光团遮挡。主体结构和相机角度以真实模型截图为准。
```
