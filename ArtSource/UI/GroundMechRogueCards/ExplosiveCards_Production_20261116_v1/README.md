## 画布、来源与处理范围

- 12 张最终 PNG 均为 RGBA，尺寸 1088 × 1632。
- 原图窗口为 [32,48,1056,1584]，大小 1024 × 1536。左右各 32、上下各 48 像素留量。
- 所有层使用同一基础坐标 (-32,-48)，每层按原有深度做刚性平移。最大水平位移 24、垂直位移 30 源像素；最少仍有 8、18 像素纹理边界余量。没有降低视差强度来遮掩露边。
- 12 层的原窗口 RGBA 与 v6 对应的完整生成层逐像素相同。Master.png 不参与补绘装配，没有原图兜底层。
- 对跨框对象及两张天空调用 imagegen 补绘，共 7 次全画布候选和 7 次局部延伸候选。未跨框的 5 层保留完整生成对象并置于共同扩展画布；不额外生成无关物体。
- 生成模型输出尺寸与请求不同，使用特征对位及静态坐标配准，将生成外沿装配至同一画布。烟迹及顶部断梁接合处额外记录了横截面坐标配准；RGB 与 Alpha 一起变换。没有颜色键、对象分割、Alpha 补洞、边缘复制、镜像或 Clamp 拉伸。
- 外沿和原窗口最终保存为同一张 PNG，运行时每个可见层只绘制一次。装配和来源详见 assembled_outpaint_v7.json、manifest_v7.json；实际完整提示词、输入与模型输出在每张牌 Generation_v7 的 Prompts、Inputs、Raw 中。
