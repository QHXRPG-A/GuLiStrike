# 强化子弹 · 六层牌面

**本轮交付已完成（2026-11-17）。** 在[四张牌的统一预览](../ExplosiveCards_Production_20261116_v1/index.html?card=EnhancedBullet)中可查看六层成品。

以最后提交的黑描边版作为底图。原件保存为 `Master.png`，原图模式和相似度计算均把原件叠在同一墨绿底色上。

[打开本机预览](http://127.0.0.1:8194/)。解压素材包后也可直接打开 `index.html`。

| 图层 | 内容 |
| --- | --- |
| 01 近景碎玻璃 | 左下和右上的两片大玻璃，含各自的数字反射 |
| 02 弹体 | 弹体、黑描边和两条青色发光槽 |
| 03 远景碎玻璃 | 其余七片玻璃及各自的反射 |
| 04 裂纹与破口光 | 原位裂纹和破口，补齐遮挡区和四周外沿 |
| 05 二进制数字雨 | 独立背景数字列，新补字符使用排版的 0 和 1 |
| 06 墨绿背景 | 同一个不透明色值 `#001413` |

六张成品共用 1152 × 1728 画布，原图窗口为 `[64,96,1088,1632]`。弹体和破口同步位移。两组玻璃分别移动，反射随碎片移动。

原位叠合从保存后的六张 PNG 回读，RGB SSIM 为 **99.94%**。预览支持切换原图、原位和视差，开关或独看图层，调不透明度和下载 PNG。已核对独看仅绘制一个图层，最大位移后弹体和九片玻璃仍在窗口内。画面和倾斜效果待用户验收。

`manifest.json` 保存原图及六张成品的哈希和制作记录。破裂面的生图锚点、补绘源图与提示词在 `Inputs/`。
