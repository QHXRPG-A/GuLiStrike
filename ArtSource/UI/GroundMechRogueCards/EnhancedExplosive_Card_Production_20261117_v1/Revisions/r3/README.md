- 最深运动层位移最大为 27.6 源像素。四角姿态的共同画布边界留量已检查；这不代表物件外沿与接合已通过用户视觉验收。

## 使用与复用

页面可切换原图、原位叠合、交互视差、左右对照；每层有开关、独看、不透明度及 PNG 下载。下载与预览引用同一最终文件清单。素材包包含最终 PNG、冻结原图、页面、生成源、提示词、坐标与测量记录。

若本机服务已停止，可执行本目录 `serve_preview.py`，监听 `127.0.0.1:8197`；不需要启动 UE。浏览器预览与最终 UE 材质渲染是不同阶段。

本次未执行 UE 导入、Excel 登记或玩法绑定；当前交付阶段为六层 HTML 牌面。脚本的辅助数值环境与版本见 requirements-artwork.txt，源图均已留在本项目，不依赖生图缓存。
