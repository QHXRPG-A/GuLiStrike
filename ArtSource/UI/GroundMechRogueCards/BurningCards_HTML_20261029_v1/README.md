## 本次修复

1. 两张卡统一采用整物件刚性平移。移除原先边缘少动、内部多动的UV渐变，物件内所有像素接收同一位移；依靠共同画布的外扩留量提供边缘覆盖，没有降低原有14px最大视差。
2. 冲击圈重新生成完整椭圆及左右转折，源图四边有透明留白；装配后左右转折位于可见窗口外，消除旧版把源图切口缩到画面内部的问题。仍是一张完整纹理。WebGL在一次局部合成中按真实机甲alpha处理前后遮挡，不使用两份独立环图、前后独立深度或预裁切矩形蒙版。
3. 重绘爆裂卡近景灰石和背景，前景石块专属第二层，背景补成连续草地；重绘子弹卡碎片，排除属于中央机甲的连接腿、机身、枪座和天线。物件归属写入当前构建的object_ids，禁止同一声明ID同时属于不同内容层。物件是否仍被模型误画到别层，交用户逐层审核。
4. 燃烧弹体和附着火焰保留第一层。独立命中火焰仍为第三个语义分组，但跟随受击机甲使用同一刚性运动，接触点不因不同深度位移而拉开。机甲本体、腿、炮与天线整体留在机甲层。

本轮通过内置imagegen定向重绘4张，真实原始输出均为1254×1254，另外8张保留上一版已装配文件及其哈希，没有重新生成。最终仍为两卡各6张1536×1536 PNG，共用源窗口[256,256,1280,1280]和同一基础映射；前五层有真实透明，第六层不透明。
