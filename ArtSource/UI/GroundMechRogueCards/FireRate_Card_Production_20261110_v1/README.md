## 制作记录

以原图为可见面的依据，分别提取两道尘浪、电弧、机身和枪口火焰。每层使用对应的生图补绘填充遮挡面与外沿，沿轮廓配准后合入一张成品图。第六层用固定 RGBA 值铺满画布。

原位叠合由六张成品在零位实际绘制。以原图窗口、所有图层 100% 不透明度计算全幅 RGB SSIM，最低要求 95%。本版数值和设置记录在 `manifest.json`。

单层显示时，页面清空画布后直接绘制该层 PNG。多层叠合时，同一张闪电图使用互补蒙版分配前后遮挡。机身左侧和下方的完整源图覆盖设定的最大倾斜取样范围。

`Layers/` 为六张成品。素材包收录本版使用的生成源图、编辑输入和提示词。`manifest.json` 记录成品来源、文件哈希、原始尺寸、对位参数和技术检查。画面贴合和倾斜效果待用户验收。
