# Ground HUD 实机截图核验 · 2026-11-02

本轮依据用户明确指令“你来进行截图校验”，对当前 Ground PIE 的战斗 HUD、平面大地图和正面选牌进行助手读图核验。这是本 HUD 任务的明确授权，不修改项目其他任务默认的视觉核验边界。

结论：截图发现的文字遮挡、卡牌空白文案及背板露角已修正并重载；三张界面仍未达到参考图的一比一还原。以下是助手核验结论，尚无用户最终视觉通过记录。

## 画面问题与处理

| 实机问题 | 正式修正 | 复查结果 |
|---|---|---|
| 当前生命值与最大生命值相互重叠 | 按文字实际宽度横向排布，外层仅向下缩放 | 1000 / 1000 可分辨，未再相叠 |
| 喷气百分比、标题与分段条挤在一起 | 调整数值容器与竖条起点，压缩段间距 | 100% 与分段容量分别可读 |
| 底部驾驶舱边框盖住标签与地图按钮 | 边框在内容下层绘制，收窄底部实色区域 | A4B2、技能键位和地图底部提示可见 |
| 600 单位地图标记堆叠，地形过亮 | 在 5Hz 快照/缩放变化时按空间单元聚合普通友敌标记，降低地形填充亮度、增强等高线 | 密集符号有所减少；仍需继续优化符号层级和地形立体感 |
| 卡牌标题、效果说明完全没有显示 | 保留重建前的文案与 WidgetTree；将世界文字面移至插画前方 | 两张候选标题和单行效果说明已显示 |
| 卡牌图面偏小、文字太小、发光被截断 | 原六层插画统一放大 1.35 倍，以新卡框开孔裁切；富文本统一 2 倍密度后向下适配；世界控件使用透明混合 | 插画填满窗口，说明保持单行，关键词颜色保留 |
| 悬停倾斜时方形背板从切角外露出 | 仅 Ground 将厚度背板内缩为 37.4×46 局部尺寸，保留厚度与六层视差 | 新构建悬停截图未再出现灰色角块 |
| 主准星与枪口落点太细 | 增大十字/菱形尺寸与线宽 | 当前静止画面可区分两种标记；完整遮挡与移动战斗未验收 |

普通 HUD 数据仍为 0.2 秒刷新、事件合并同步；没有新增持续地图 SceneCapture 或整套媒体动画。地图聚合缓存不在每次绘制时遍历全部 Actor。截图帧率不构成性能测量。

## 与参考仍存在的差异

- 共用驾驶舱边框与卡框的多层结构、内切线、发光厚度仍较简化；顶部标题排版、卡牌垂直位置、底部按钮比例还需继续接近参考。
- 技能及生命图标沿用当前图集，仍偏插画造型，与参考的简洁符号不一致。
- 小地图已有倾斜网格和等高线，但立体层次明显弱于参考；大地图缺少参考中的道路、建筑轮廓与区域名称层。真实关卡高度场不能用概念图地貌替换。
- 参考中的 Buff、已获强化、冷却数字在当前空构筑/技能就绪状态下不出现。这轮没有为截图虚构这些玩法状态，也未覆盖其全部显示分支。
- 护甲行和确认选择按钮按已确认玩法取消；它们不是待补缺陷。关卡场景与机甲模型使用当前正式版本，不照搬概念图中的示意世界。

## 输入、构建与交付边界

实际 UI 操作确认了地图标记点击、地图内 F4 打开选牌、Esc 关闭，以及卡牌悬停/倾斜。没有点击提交候选，未发放强化。战斗中通过电脑控制工具发送 M/F4 未可靠打开界面；读取到两键确实映射到已应用的 Battle context，随后通过 Enhanced Input 对相应动作注入，均能走原绑定打开界面。这只证明动作委托路由，不证明真实键盘投递通过，相关玩家按键验收仍未完成。

沿用同一 HUD 任务已获“结束 PIE，编译重启”的授权；每次退出前确认无未保存地图/内容。源码引擎 `D:/UnrealEngine-5.7` 的 `GuLiStrikeEditor Win64 Development` 三次增量构建均成功，分别为 10 步/11.86 秒、7 步/11.55 秒、4 步/9.82 秒，退出码均 0。引擎、项目及 7 个插件的 BuildId 一致。

最终重启 PID 35416，地图 `/Game/Maps/LVL_CommanderMassPrototype`，Ground 新开局自动创建 1 个 HUD、175 个内部控件，正式 4001/A4B2 Pawn 已接管，两端 online/ready，网络错误为空。退出选牌后卡 Actor、捕获和 RT 已清理，当前保留战斗 PIE 供用户查看。原席位选择提示、Canvas 调试显示及下一次 PIE 的 3826×1984 窗口设置已恢复回读。

这轮未修改资产、卡池或玩法数值；没有新增测试场景。使用已有 Ground 验证入口，最终脏地图/内容均为空。原测试地图仍有与 HUD 无关的 `M_MassBulletTrail` 着色器问题及大量调试描边，此次未扩展修改。

完整伤害/护盾/击杀、冷却、Buff、重复回执、实际单击提交/失败、16:10/21:9 与性能测量均未由本次截图核验替代。
