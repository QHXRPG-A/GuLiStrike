以 1920×1080 为基准按视口扩展设计面，边缘模块锚定四周、中部操作居中；准星使用完整玩家视口坐标。三张界面共用切角仪表、连续驾驶舱边线、侧面电路刻度和顶部标题。HUDuiPRO 为只读静态输入：

|---|---|---|

| InstrumentGrid | Elements_Main/Grid/T_HUD_Grid_01 | 仪表网格 |

| JetRail | Basic_Elements/Progress_Bars/Progress_bar_Vertical/T_HUD_Progress_Bar_Vertical_01 | 喷气刻度装饰 |

以上路径均相对于 `/Game/Assets/UI/HUDuiPRO/Textures/Others`。技能、状态、强化与生命符号改为原生 Slate 线条绘制并缓存，常驻 HUD 不再加载原图集；血量、遮罩、文字和地图由真实控件绘制。

中文采用[原始Noto Sans CJK SC Medium/Bold](Fonts/README.md)，正式字体位于`/Game/GuLiStrike/GroundMech/UI/Fonts`，HUD表`UIFont`引用。Ground卡牌派生富文本表保留共享Excel样式的关键词颜色和字号关系，Commander仍使用原共享样式。

- 战斗：左侧强化摘要、左下生命条与紧凑属性摘要、底部四个大技能槽及键位条、上方状态图标、右上倾斜地形和右下16段喷气容量。左下同一面板内提供I详情入口。
- 地图：切角大地图框、网格坐标、真实距离比例尺、地点信息及局部地形预览、统一符号图例和底部操作。地形来自当前567×567高度场，不使用示意地形替代。
- 选牌：Ground 使用新的立体青蓝/暖橙仪表卡框，独立标题在顶部，单行富文本说明在底部。原插画/六层UV不变，整体下移5个局部单位并统一放大1.35倍，由新卡框开孔裁切；文字面置于插画前方，避免被遮挡。两张牌中心间距为设计宽度的33.5%，高度68%；三张自动缩小居中。

参考中的护甲示例、虚构数值和确认按钮不作为玩法接入。当前仍只显示武器等级、射速、移速；候选正面单击提交，服务器确认后退出；共享 Commander 行为保留。
