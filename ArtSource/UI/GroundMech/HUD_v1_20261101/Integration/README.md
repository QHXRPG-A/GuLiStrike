## 正式路径

- `AGuLiCommanderHUD::RefreshCommanderRole` 创建/移除 Ground 专用 `UGuLiGroundHUDWidget`；BeginPlay订阅Pawn接管事件、EndPlay解绑，延迟接管时立即创建，换Pawn时切换数据宿主；角色仍是4001/A4B2。
- `UGuLiGroundHUDData` 为本地玩家只读快照；普通计时器0.2秒且不补跑，多组紧急事件在帧末合并提交。生命、技能、Buff、构筑、地图分别失效；卡顿不补跑多轮。
- 地图标记通过对象事件维护成员与 Buff 宿主索引，位置只采样缓存成员。高度场567×567格，地形网格/等高线缓存；小图按附近区域，大图全图，无SceneCapture。
- M地图、I详情、F4选牌共用模态输入锁；释放持续射击/瞄准/喷气，关闭恢复当前席位焦点。隐藏选牌期间暂停HUD计时器，地图/详情仅更新可见数据组。
- 伤害回调携带局次、事件、Ground来源、实际伤害/吸收和击杀。本地事件去重，同帧击杀优先，已有恢复结果不产生新反馈；不从碰撞特效判断命中。
- Ground正面单击后先锁定再RPC，成功后局部反馈退出；失败展示服务器原因，Esc关闭重开保持原候选规则。原卡框、六层和黄色关键词保留。
- 卡牌捕获只在选牌可见时工作。现有卡牌包含时间材质动画，所以配置 `CardTimeAnimation=1`；静止且无时间动画时只在位姿/可见性变化捕获。RT仅随视口变化调整，最长边2048，关闭释放。
