# 源模型基础上的机甲制作 v1

用户 2026-09-19 指示：“blender已开，开始制作，根据源模型制作，SpiderMech 也是，在原模型和参考图基础上减面并制作”。该指令放行当前参考方案进入 Blender 制作，不等于尚未展示的成品 B 通过。

当前参考：SpiderMech 低模 v2、Mecha_01 灰蓝 v2、Mecha_02 v1、轻型机甲封舱 v4、武器红蓝降饱和 v4、独立导弹 v2；对应图片与哈希见上级交付清单。四机体、三套武器和独立导弹均从 UE 原网格提取，保留骨骼、UV、原比例和装配关系作为基础。SpiderMech 在原网格上减面及整理，不能用全新替代模型冒充源网格优化。

任务约束：保留原色系与着色逻辑；按已展示版本降低红蓝饱和度；轻型机甲封闭驾驶区，不展示驾驶员与驾驶舱；主体使用与原 Default Lit 对应的受光材质进行 Blender 预览。UE 原材质网络在本轮不修改。

本目录保存可编辑 Blender 制作副本、源/成品对照与技术检查。原 UE 资源只读取和导出，不覆盖。制作完成后交付实际 Blender 成品供审核 B；本轮不提前导入正式资源。
