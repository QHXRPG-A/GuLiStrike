# 肉鸽牌关系图

双击 [start.cmd](start.cmd)，浏览器会打开 [肉鸽牌关系图](http://127.0.0.1:4322/)。工具使用项目现有的 Python 和浏览器。

本工具由项目的 [统一保活任务](../ProgressDashboard/README.md#三个本地工具的保活) 在登录后启动。任务运行时可以直接打开本地页面。

1. 在顶部切换指挥官、地面、空中。点卡牌看说明，拖动卡片调整摆放。
2. 选「前置」，从 A 右边的圆点拖到 B，表示取得 B 前须先取得 A。多条前置都要满足。选「互斥」再连接两张卡，表示本局只能取得其中一张。也可以点一下圆点，再点目标卡。
3. 「新增卡牌」用于填写名称和描述。点卡牌或连线后，可在右侧编辑或删除。删除卡牌会一并移除相连关系。「撤销」或 Ctrl+Z 可恢复上一步。
4. 拖动空白处平移，滚轮缩放，「适应画布」把当前页全部节点放进视野。
5. 点「保存草稿」或 Ctrl+S。草稿写入项目的 `data/Design/RogueCardGraph.json`，重开工具会恢复三页内容、连线和节点位置。

初始卡图读取正式导出的卡表、公共文本和效果参数。当前指挥官有 5 张、地面有 7 张，空中从空白页开始。爆破套餐和强化爆炸弹的详情会展示逐级说明。

## 后续接入

调好后让 Codex 按保存的草稿实装即可。草稿包含正式来源及指纹、编辑后的图、按卡牌 ID 整理的 `changes.added`、`changes.removed` 和 `changes.updated`。前置线 A → B 写入 B 的 `RequiredCardIds`。互斥改动在双方的 `ExcludedCardIds` 中成对表达。纯位置改动保存在画布数据中。

正式接入以 Excel 源表和项目导入流程为准。已有卡保持稳定 ID，新增草稿使用临时 ID，接入时再分配正式 ID、效果和公共文本键。若修改强化爆炸弹与爆破套餐的前置，接入时同时核对现有机制校验。空中新增卡还需要对应的游戏卡池、确认和效果结算入口。正式卡表更新后，页面会提示先对照草稿基线。

PowerShell 可用 `Tools\RogueCardGraph\start.ps1 -Port 4322` 启动。以 `-NoBrowser` 启动时，手动打开显示的本地地址。
