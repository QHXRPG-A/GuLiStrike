## 日常编辑

1. **地形**：输入宽、长的整数格数并应用。每格始终为 3 米；原点保持不变，在 +X、+Y 扩展或裁剪。新增顶点延续原边缘高度。单轴支持 1–8160 格，总格数不超过 4,194,304，与项目占地数据容量保持一致。
2. **方形笔刷**：1、2、4、8、16 格预设或自定义边长。升降默认每笔 3 米；整平输入目标高度，Alt+左键可拾取；平滑可调强度；坡道输入起终点高程并拖动方向和长度。快速拖动补齐沿途格子，同一笔的共享顶点只计算一次。
3. **选区**：点击“框选地形”并拖出矩形，切回任意地形笔刷后只修改选区共享顶点。“清除选区”恢复全图编辑。选区属于当前编辑会话，不写入地形数据。
4. **据点**：选类型后点击放置；选择标记可移动、复制、删除、启用、搜索、编辑标签、备注、参数、位置和旋转。据点默认保持离地偏移随地形升降，可逐个关闭跟随。复制生成新 Marker/Region 身份。
5. **区域**：每个标记可有多个 Cylinder、Sphere、Box 或 PolygonPrism 区域；可以切换形状、编辑相对变换和几何参数。多边形白点可拖动，Insert 插点、Delete 删点、按钮反转；“地图重绘”点击轮廓后 Enter 提交。非法拖动会回滚，非法重绘保持草稿供修正。
6. **类型**：创建自定义类型，编辑默认区域、允许形状和字段规则。支持 bool、int32、double、Name、String、Enum、Vector、软对象、软类。字段 GUID 是身份；改键名后执行同步可保值。删除或改类型的冲突需要明确选择“升级并重置冲突字段”，整次可撤销。枚举需要填写 UE 枚举类型路径及有效项；应用端再按真实枚举校验。
7. **资源**：蓝矿、红矿独立编辑及叠加显示；提供方形和圆形笔刷、加深、擦除、强度、软边、清层。资源格遵守 `floor(WorldXY / CellSizeCm)`，负坐标同样向下取整。旧图保持 25 米，新图默认 3 米；非空密度图改格尺寸须明确清空。0–255 表示相对分布权重，红蓝可任意不对称涂绘；原始格坐标、形状和强度按原样保存、导出，不自动镜像、补点或恢复旧密度。辖区汇总及重叠/未归属统计继续保留，不按矿簇预算判断涂绘可生成性。矿簇生成适配、中央/边缘的形态与大小由后续程序处理。

滚轮缩放，中键、右键、Alt 拖动或空格拖动平移。F 聚焦选中标记，`[` / `]` 调整笔刷。右侧三维可旋转、平移、缩放和切换网格；大图采用显示 LOD，保存和导出保留完整数据。三维在笔画结束后更新。

二维与三维的高程色阶统一为 **蓝 → 青绿 → 黄 → 橙 → 红，由低到高**，范围固定为 **−500米至500米**，不随地图实际极值变化。色阶位置按 `t = (高度米数 + 500) / 1000` 线性映射，各颜色段连续线性插值；−500米为蓝端，0米在50%位置，500米为红端。范围外显示对应端点色。右上角图例显示固定范围、0米中点及当前地图实际最低/最高高度。海平面基准是世界 Z＝0（0米），据点地面须高于0米。

`Ctrl+Z` / `Ctrl+Y` 撤销重做，整笔地形及关联据点变化一起撤销。Esc 取消尚未结束的笔画或拖动。裁剪只裁掉高度数据；越界标记、区域、密度格继续保存并在校验中提示，由设计者移动或清理。

## 保存与导出

`Ctrl+S` 手动保存；修改停止约 2 秒后自动保存。打开工程时优先恢复更新的自动保存。多窗口版本不一致、已有工程保存缺少版本号，以及导入同身份的旧工程包，都会拒绝覆盖，需打开本地最新工程。打开其他工程前会保存当前未落盘修改。

工程存于 `ArtSource/MapDesigner/Projects/<GUID>.gmap`。这是版本化 ZIP，包含完整双精度厘米高度、布局、完整类型目录、字段迁移信息、离地跟随设置，以及不可变的源快照、材质权重和导入基线；复制一个 `.gmap` 就能带走完整工程。工程保存不会整体量化高度。

“导出给 UE”写入 `ArtSource/MapDesigner/Exports/<GUID>/`，先写临时批次、逐文件哈希读回核对，再切换目录。上一批保留为 `.previous`，更早批次放入 `Backups`。

| 文件 | 用途 |
|---|---|
| `layout.json`、五份布局 CSV | 保持现有六文件 schema v1 合同，只包含被标记使用的类型 |
| `density_layers.json`、两份密度 CSV | 有密度图时生成，组成原有九文件合同；含辖区汇总及异常 |
| `type_catalog.json` | 全部配置类型，包括未使用类型、默认区域和枚举选项 |
| `height.png`、`height.r16` | 16 位 UE 高度及小端原始缓冲 |
| `heights_cm.f64` / `.f32` | 完整设计高度 / 供现有地面占地数据使用的编码后逻辑高度 |
| 六份材质 `.u8` | 按源权重扩边或裁剪，保持所有顶点权重总和 255 |
| `manifest.json` | 逻辑边界、实际 Landscape 边界、组件数、高度换算、误差、源基线和逐文件 SHA256 |
| `changes.json` | 新增、删除、更新的稳定身份，字段/区域差异，资源格变化，高度变化数量及范围 |
| `walkable.u8`、`clearance.i32`、层级数据 | 按新高度、水层及源静态障碍重新生成占地数据；没有启用网格寻路 |

UE 物理地形在 +X、+Y 补到 63 格组件的整数倍，补边延续设计边缘高度。例如 570×565 设计格导出为 630×567 实际格。设计边界单独保留。高度换算为 `Zcm = (R16 - 32768) / 128 × ScaleZ + LocationZ`；超出原编码范围时选择新换算并记录最大误差。首次未编辑快照原样导出时 R16 与源逐点相同；当前已编辑工程的最大编码误差约 0.030518 厘米，完整 `heights_cm.f64` 与当前工程高度逐字节相同。

新建地图建议从已打开的当前工程进入“新建”，保留“沿用当前工程的 UE 应用基线、类型及材质配置”。可以直接补齐 7×7 据点模板。完全无基线的空白工程仍可离线保存和导出，但最终应用前需取得目标 UE 地图的基线并明确合并；软件不会猜测或覆盖目标地图。

## UE 衔接

日常流程是 **设计者编辑并导出 → 把导出目录交给助手 → 助手读取差异并调整 UE**。浏览器服务没有 UE 写入接口。

重新读取当前地图：在普通编辑器中打开目标地图、退出 PIE，然后运行 `export_current_snapshot.ps1`；软件“UE快照”列表可载入新快照。旧快照及旧工程继续保留。

以下是助手或维护人员的桥接入口；默认只预检查：

```powershell
& 'D:\UE5.7\test1\Tools\MapDesigner\apply_to_ue.ps1' -Directory '<导出目录>'
```

明确决定应用设计后才加 `-Apply`。预检查比对完整布局、资源、类型、原高度、六层权重、材质、LayerInfo、地面几何和跟随设置；基线变化返回冲突并停止。输出 `ue-preview-result.json`，应用则输出 `ue-apply-result.json`。

`GuLiMapAuthoring` 只负责类型、标记、区域、密度的完整快照及稳定身份批量导入；`GuLiStrikeEditor` 负责地形、逻辑边界、占地数据、资源烘焙和 UE NavMesh。插件没有反向依赖项目玩法模块。应用前备份包，事务内校验并读回地形、权重和生产数据，通过后保存；失败返回回滚状态，保存失败保留编辑器中的已校验改动及备份。

当前生成器仍保留 7×7、49 个启用据点、200 蓝矿簇、40 红矿簇、每簇 26 矿点等旧规则，仍使用镜像采样且只接受 25 米资源格。预算参数来源于 [当前原生规则](../../Source/GuLiStrike/Gameplay/Resources/GuLiResourceTypes.cpp) 和 [预算资料](gameplay-profile.json)，本轮保留原参数与据点安全约束。**设计器保存/导出不对称涂绘与 3 米资源格，不代表现有 UE 生成器已经适配**；不对称生成、3 米生成适配和中央/边缘形态统一在下一阶段处理，当前只设计涂绘，不执行资源烘焙。缩小地形不会自动重排玩法。拓扑替换若发现已有植被实例会拒绝，需先实施明确的植被基底迁移；当前地图植被实例数为 0。

旧道路避让改为可选能力：不要求存在固定名称、唯一数量、非空或启用的 `CommanderIsland_Roads`。启用的通用 `ResourceClearance` 可有多个；禁用标记/区域不参与避让，活动区域仍校验水平 Box/Cylinder 及几何参数。地形、据点、实体障碍等约束保持。本轮原生代码仅完成差异与接口审查，未编译或重开 UE；最终设计导入时才按稳定 GUID 删除 UE 中的旧标记。

成功应用后同步设计逻辑范围、资源可玩范围和占地数据；镜头及小地图使用逻辑范围与 Landscape 范围的交集。补边生成禁止导航条带，仍使用项目现有 UE NavMesh。桥接同时刷新指定人口配置的运行清单，默认 600；失败会明确区分地图已应用与运行清单尚未刷新。

## 维护

前端资源已经构建在 `dist`，离线使用不需要 Vite 开发服务。开发更新时在本目录执行 `npm.cmd run build`。Python 使用 `requirements.txt`，本机依赖已就绪。修改 Python 后需重开本工具的本地服务；修改前端后重新构建并刷新页面即可。

`start.ps1 -Port 4322` 可改端口，`-NoBrowser` 只启动服务。服务只监听本机回环地址。项目和导出路径固定在本项目 `ArtSource/MapDesigner` 下。
